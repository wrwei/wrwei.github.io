# FIGURES — drawing the diagrams of the AI series

Read `BRIEF.md` first. A figure is a hand-made SVG that explains a mechanism: an architecture, a
data flow, a geometric argument, a curve whose shape is the point. It is drawn once in English
(`src/figures/en/fig-NN-k.svg`) and later copied with translated labels into
`src/figures/zh/fig-NN-k.svg`. The page build inlines the SVG into the page, so it must be a
clean, self-contained SVG.

## What to draw

The plan (`plan/module_NN.json`, `sections[].figures[]`) describes each figure. If the module's
text already exists (`src/en/module_NN/*.md`), read the paragraphs around `::: figure id=...` and
its caption: the figure must show exactly what the caption and text say, with the same symbols
and numbers. A figure that contradicts its caption is worse than none.

Prefer showing the mechanism over decorating it. One idea per figure. Label what the reader needs
and nothing else.

## Format

- `<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 W H" width="W" height="H" ...>` with W
  between 560 and 760 (720 is the default) and H as small as the content allows (usually 200–460).
- `font-family="DM Sans, system-ui, -apple-system, Segoe UI, sans-serif"` on the root.
- Text sizes: 13–14 for labels, 12 for secondary labels, never below 11. Titles inside figures
  are rare (the caption does that job).
- No `<script>`, `<foreignObject>`, `<image>`, external URLs, CSS `@import`, or web fonts. No
  `$` characters anywhere (the page treats `$` as maths).
- Ids are allowed (for markers, gradients, clip paths); the build makes them unique per figure.
- Maths in labels: Unicode (θ ∇ Σ × · ≈ ≤ ≥ → ⊙ √ ∞ ∂ λ σ η μ ŷ ᵀ ² ³ ₀–₉ ᵢ ⱼ ₜ ₖ ₙ) and
  `<tspan font-style="italic">` for variables. Subscripts/superscripts that Unicode lacks:
  `<tspan dy="4" font-size="10">k</tspan><tspan dy="-4"> </tspan>` (always reset the baseline).
  Bold vectors: `<tspan font-weight="700">x</tspan>`.

## Palette (matches the page)

| Role | Colour |
|---|---|
| text, main strokes | navy `#1A2E4A` |
| secondary text | slate `#475569` |
| faint lines, grid | `#94A3B8`, `#E2E8F0` |
| primary accent | blue `#2563EB`; fills `#DBEAFE`, `#F0F9FF` |
| second accent | sky `#0EA5E9` |
| good / data / "kept" | green `#15803D`; fill `#F0FDF4` |
| warning / second series | orange `#C2410C`; fill `#FFF7ED` |
| error / "dropped" | red `#DC2626`; fill `#FEF2F2` |
| third series | purple `#7E22CE`; fill `#FAF5FF` |
| fourth series | amber `#B45309`; fill `#FFFBEB` |

Strokes 1.5–2 px; boxes `rx="8"`; arrows with a `<marker>`; generous white space. The figure sits
on a white card, so do not paint a background rectangle.

## Curves and plots

Anything that is a function or data (an activation, a loss curve, a distribution, a learning-rate
schedule, a scaling law) is **computed, not eyeballed**: write a short Python script (run it with
`tools/labpy.sh script.py`) that evaluates the function and writes the SVG. Keep such
scripts next to the figures as `src/figures/en/_gen/fig-NN-k.py`. Axes get ticks and labels;
curves get a legend or direct labels.

For plots, use matplotlib through the shared style in `src/figures/figstyle.py`, so every data
figure in the series looks the same (palette, fonts, light grid, no top or right spines) and keeps
its labels as real SVG text that a translator can edit:

```python
import sys; sys.path.insert(0, "src/figures")
import figstyle
fig, ax = figstyle.figure(width=7.2, height=3.4)
ax.plot(x, y, color=figstyle.BLUE, label="train")
ax.set_xlabel("step"); ax.set_ylabel("loss"); ax.legend()
figstyle.save(fig, "fig-01-7")          # writes src/figures/en/fig-01-7.svg
```

Write the generator so it takes the language as an argument (`fig-01-7.py en|zh`) with every
label in a small dictionary, so the Chinese version is one more run with translated labels.
Schematic diagrams (boxes, arrows, architectures) are hand-written SVG, or generated by a script
when there are many repeated elements.

## Check every figure visually

Render and look at it:

```bash
node tools/shot.mjs "src\figures\en\fig-NN-k.svg" --out "shots\fig-NN-k" --width 760 --height 520
```

Then Read the PNG. Fix and re-render until: no text overlaps anything; nothing is clipped at the
edges; arrows start and end on the boxes they connect; labels are legible; it matches the caption.
Also check it against the maths in the text (a softmax curve really saturates at 0 and 1; a
causal mask really is lower-triangular; shapes are the shapes the text gives).
