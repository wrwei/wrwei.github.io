# AI series: sources

Sources and tools of the tutorial series **From Machine Learning to Large Language Models**. This
folder sits outside `docs/`, so MkDocs does not publish it; the published pages are built from it
into `docs/tutorials/ai/`.

Start with **`HANDOVER.md`**: what the series is, where everything is, the status, how to set up,
how a module is produced and checked, how to publish, and the open issues. **`PLAN.md`** is the plan
of all ten modules.
