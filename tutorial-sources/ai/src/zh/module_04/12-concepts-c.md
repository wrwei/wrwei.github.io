## 监测传感器数据流：基于预测残差的异常检测 {#s9}

在正常运行数据上训练的预测器，是一个学到了正常动态的模型。传感器报告的值与模型预测值之差，即**残差**（residual）

$$r_t = x_t - \hat x_t,$$

在设备的行为与训练时一致时保持很小，不一致时则变大。残差大就是**异常**（anomaly）。这样，[第 8 节](#s8)的每一个预测器都变成了一个监测器，成为数字孪生的一个组成部分：孪生体做预测，设备报告实测值，二者之间的分歧受到监视。把预测器换成物理模型，逻辑也不变：控制工程师称之为**基于模型的故障检测**（model-based fault detection，Isermann，2006）。

### 阈值来自留出的正常数据

报警阈值要设在**模型没有训练过的正常数据**上，绝不能设在训练残差上：模型拟合过训练数据，所以训练残差偏小，过于乐观，把阈值放在它们的尾部，投入使用后就会过于频繁地报警。

::: worked title="1 Hz 采样下由高斯尾部带来的误报"
假设残差相互独立、服从标准差为 $\sigma$ 的高斯分布，每秒采样一次：每天 86,400 个样本。双侧阈值 $k\sigma$ 被超过的概率为 $p = 2(1-\Phi(k))$，其中 $\Phi$ 是标准正态分布函数。

- $k = 3$：$p = 2.70\times10^{-3}$，$86{,}400\times 2.70\times10^{-3} = 233$，即每天 233 次误报。
- $k = 4$：$p = 6.33\times10^{-5}$，每天 5.5 次。
- $k = 5$：$p = 5.73\times10^{-7}$，每天 0.05 次：每 20 天一次。

改为要求连续三次超过 $3\sigma$。对独立样本，某一组连续三个样本全部超过阈值的概率为 $p^3 = 1.97\times10^{-8}$，约每天 $0.0017$ 次：看上去比单次 $3\sigma$ 检验好十万倍。
:::

真实的残差同时违背这两个假设。它们是**自相关**（autocorrelated）的（预测器在某一步出错，下一步通常以同样的方式出错），所以连续超限远比 $p^3$ 所说的常见；它们还是**重尾**（heavy-tailed）的，因为正常运行中也包含启动这类罕见事件。应把阈值设在留出残差的某个经验分位数上，按可以容忍的误报率来选取，再加上一条**持续性规则**（persistence rule）：最近 $n$ 个样本中有 $k$ 次超限才报警，同样在这批数据上测定。

### 每种故障需要自己的检测器

不同故障在残差中的表现各不相同，为一种故障设计的检测器可能对另一种视而不见。

| 故障 | 残差的表现 | 检测器 |
|---|---|---|
| 尖峰、突发 | 一个很大的值 | 逐点检验 $\lvert r_t\rvert > k\sigma$ |
| 动态或噪声水平改变 | 平均变大，但很少出现极端值 | $r_t$ 的滚动均方根，或 CUSUM |
| 传感器卡死或读数不变 | 太*小*：常数是完全可预测的 | 滚动标准差低于下限 |
| 持续的水平偏移 | 只在开始和结束时很大 | 对照独立参考做水平检查 |

$n$ 个样本上的滚动均方根（RMS）会把单个值平均掉，而对残差能量的持续上升作出响应。**累积和**（CUSUM，Page，1954）则是累积证据：$S_t = \max(0,\, S_{t-1} + r_t^2/\sigma^2 - \kappa)$，其中 $\kappa$ 略大于 1（$r_t^2/\sigma^2$ 在正常情况下的均值），当 $S_t$ 超过某个界限时报警。

最后一行需要小心。采用逐窗口归一化（第 8 节的修复办法）的预测器在一步之内就会以新的水平为中心重新对齐，所以它只在偏移开始和结束的地方看到偏移。持续的偏移需要一个不随传感器移动的参考：冗余传感器、孪生体的物理预测，或者来自一个不重新对齐的模型的更长预测步长残差。图 4.14 画出了这条流程，以及每种故障在其检测器中的特征。

::: figure id=fig-04-14
上：以方框表示的监测流程：传感器数据流、预测器、残差 $r_t$、三个并行的检测器（逐点检验 $\lvert r_t\rvert > 4\sigma$；50 个样本上的滚动均方根；滚动标准差低于下限）、报警日志。下：四个小示意图，对应表中的四种故障（尖峰、持续偏移、激励增强、传感器卡死），每个都画出故障期间的残差以及能抓住它的那一个统计量，阈值为虚线，故障区间加阴影：一个高高的残差尖峰；偏移开始和结束时的两段短促的残差脉冲；一条升到界限以上的滚动均方根；一条降到下限以下的滚动标准差。

::: worked title="实验 3 的监测器"
[实验 3](#lab3) 在刚度逐渐增大的支座信号中注入四种故障：$+1.5$ 的尖峰、$+0.8$ 的偏移、加倍的随机激励，以及一个冻结的传感器。在正常的留出数据上，残差标准差为 $\sigma = 0.131$，所以逐点阈值为 $4\sigma = 4\times 0.131 = 0.52$。50 个样本的滚动均方根在超过其留出数据最大值的 1.1 倍时报警；20 个样本的滚动标准差在低于其留出数据最小值的一半时报警。实验的运行结果是：

- **尖峰**：逐点检验立即报警，并在下一个样本上再报警一次，因为该样本的输入窗口以这个尖峰结尾。
- **偏移**：逐点检验只在偏移开始前后和结束时报警（共 3 个报警样本：开始时、4 个样本之后，以及结束时）。
- **激励加倍**：极端残差很少（五次逐点报警，第一次出现在 151 个样本之后），但残差均方根从 0.134 升到约 0.21；滚动均方根在变化发生 99 个样本之后报警（换一个训练种子为 85 个）。
- **传感器卡死**：卡死期间没有残差报警（只在它恢复的那个样本上有一次逐点报警）；方差下限检验在卡死 21 个样本之后报警，这时它的窗口已经填满了几乎不变的残差。
- **正常时段**（239 个样本）：三个检测器都没有误报，但这段记录太短，无法估计误报率。
:::

### 评价一个监测器

评价监测器看四个数：从故障开始到第一次报警的**检测延迟**（detection delay）；**检出的事件数**，按故障事件而不是按样本计数；在一段很长的正常记录上的**每天误报次数**；以及**精确率**，它会被很低的基础率摧毁（[模块 01](module_01_ZH.html)）。每天 5.5 次误报、每月一次真实故障，意味着每一次真实故障对应 $30\times5.5 = 165$ 次误报，精确率接近 $1/166 = 0.6\%$。真实故障太少，无法用来测量这些指标，所以要像实验 3 那样，把每种类型的合成故障注入留出的正常数据中。

### 多通道

用全部通道预测每一个通道，构成残差向量 $\mathbf{r}_t\in\mathbb{R}^m$，再用**马氏距离**（Mahalanobis distance）$d_t^2 = \mathbf{r}_t^\top\boldsymbol{\Sigma}^{-1} \mathbf{r}_t$ 给它打分，其中 $\boldsymbol{\Sigma}$ 是正常数据上的残差协方差。即使没有哪个通道单独看起来异常，它也能抓住破坏了通道间通常相关性的模式。高斯残差给出 $d_t^2 \sim \chi^2_m$；实践中，阈值同样取经验分位数。Hundman 等人（2018）把这一模式用于航天器遥测，用 LSTM 做预测，并对平滑后的预测误差设阈值；它同样适用于泵、轴承和结构。对自编码器的重构误差打分是[模块 05](module_05_ZH.html)给出的另一种做法。

::: check
为什么报警阈值要设在留出的正常数据上，而不是训练残差上？
:::

::: answer
模型拟合过训练数据，所以它的训练残差偏小，过于乐观。把阈值放在它们的尾部，对于未见过的数据上的残差就太低了，投入使用后会过于频繁地报警。
:::

::: check
卡死的传感器不会触发任何残差阈值报警。为什么？什么能抓住它？
:::

::: answer
常数信号是完全可预测的，所以残差不增反减。在一个短的滚动窗口上检验残差（或信号）的方差是否低于某个下限，就能抓住它。
:::

## 序列到序列：编码器、解码器、教师强制与搜索 {#s10}

许多序列任务把一种长度的输入映射为另一种长度的输出：翻译一个句子，总结一份报告，把一段自由文本的维护记录变成结构化的记录，把一串数字反转（[实验 4](#lab4)）。输入第 $j$ 步与输出第 $t$ 步之间的对齐并未给出，输出长度也无法事先知道。**编码器-解码器**（encoder-decoder）模型，即**序列到序列**（sequence to sequence，seq2seq）模型，能同时处理这两点（Sutskever、Vinyals 和 Le，2014；Cho 等人，2014）。

### 编码器与解码器

**编码器**（encoder）RNN 读取源序列 $x_1, \dots, x_S$，把它的最终状态保留为摘要，$\mathbf{c} = \mathbf{h}_S$。**解码器**（decoder）RNN 从这个摘要出发，一次生成一个 token，每一步都以自己的状态和上一步产生的 token 为条件：

$$\begin{aligned}
\mathbf{h}_j &= f_\text{enc}(\mathbf{h}_{j-1}, \mathbf{x}_j), \quad j = 1, \dots, S, \\
\mathbf{s}_0 &= g(\mathbf{h}_S), \\
\mathbf{s}_t &= f_\text{dec}(\mathbf{s}_{t-1}, \mathbf{y}_{t-1}), \\
p(y_t \mid y_{<t}, x) &= \softmax(\mathbf{W}_o\mathbf{s}_t + \mathbf{b}_o)_{y_t}.
\end{aligned}$$

其中 $f_\text{enc}$ 和 $f_\text{dec}$ 是 LSTM 或 GRU 单元，$g$ 是一个学习得到的映射（通常是恒等映射，或者一个带 tanh 的线性层），$\mathbf{y}_{t-1}$ 是上一个 token 的嵌入。输出由两个特殊 token 界定：解码器的第一个输入是**序列开始**（begin-of-sequence，BOS）token，解码器通过输出**序列结束**（end-of-sequence，EOS）token 来结束输出，它正是以这种方式选择输出长度的。按概率的链式法则，模型定义了整个输出序列上的分布：

$$p(y_{1:T'} \mid x) = \prod_{t=1}^{T'} p(y_t \mid y_{<t}, x).$$

### 用教师强制训练

训练最大化给定源序列时目标序列的对数似然：

$$\mathcal{L} = -\sum_{t=1}^{T'} \ln p(y_t \mid y_{<t}, x).$$

采用**教师强制**（teacher forcing）时，解码器在第 $t$ 步的输入是*真实的*上一个 token $y_{t-1}$，而不是模型自己的猜测。这样，前向传播开始之前，解码器的每一个输入都是已知的：不需要采样循环，每一步都在干净的前缀上用普通的交叉熵训练。于是 Transformer 解码器可以并行计算所有位置（[模块 06](module_06_ZH.html)）。RNN 解码器仍然要循环，因为 $\mathbf{s}_t$ 需要 $\mathbf{s}_{t-1}$，但它的循环不生成任何东西。图 4.15 把训练和推理并排画出。

::: figure id=fig-04-15
两幅图，编码器相同（一行单元依次读入数字 3 9 1 4），解码器也相同。训练：解码器的输入是 BOS、4、1、9，即真实的上一个 token，以绿色绘制，每个输出都与其目标比较。推理：解码器的输入是模型自己先前的输出，以橙色绘制；其中一个错误的 token 被突出显示，其后的输出加了阴影，表示误差在累积。

### 暴露偏差

测试时没有真实的上一个 token；解码器以自己的输出为条件。一个错误的 token 就会把它带入任何训练步骤都没产生过的状态，下一个预测随之变得不那么可靠，误差不断累积。Ranzato 等人（2016）把这称为**暴露偏差**（exposure bias）：模型只接触过正确的前缀。[实验 4](#lab4) 测量了它。对于不带注意力的模型，在长度 12 时，每一步都给定真实前缀（教师强制）时 token 准确率为 74%，模型以自己的输出运行（自由运行）时为 53%；长度 8 时为 91% 对 80%；长度 4 时差距小到可以忽略（99.7% 对 99.4%）。

**计划采样**（scheduled sampling，Bengio 等人，2015）以一个在训练过程中逐渐升高的概率，用模型自己的预测代替真实 token 作为输入，使模型学会从自己的错误中恢复。在模型自己的展开序列上训练，能更直接地达到同样的目的。**序列级目标**（sequence-level objective）给整个生成的输出打分；[模块 09](module_09_ZH.html)的强化学习方法就是它们的现代形式。无论怎样训练，都要以自由运行的方式评估：这是部署时唯一的运行方式。

### 解码：贪心与束搜索

模型每次给出一步的 $p(y_t \mid y_{<t}, x)$。为了产生输出，我们想要概率最大的序列 $\argmax_{y} p(y \mid x)$。**贪心解码**（greedy decoding）在每一步选取概率最大的 token 并把它反馈回去。它找不到概率最大的序列，因为眼下看来最好的 token 可能只能引出糟糕的后续。精确搜索又做不到：词表大小 $V = 10{,}000$、输出 20 个 token 时，候选有 $V^{20} = 10^{80}$ 个。

**束搜索**（beam search）是一种折中。保留 $k$ 个最好的部分序列（即束），按累积对数概率 $\sum_t \ln p(y_t \mid y_{<t}, x)$ 打分。每一步用每个 token 扩展每个假设，给 $k\cdot V$ 个扩展打分，保留最好的 $k$ 个。输出 EOS 的假设已经完成：把它放到一边，继续处理其余的。当束变空或达到长度上限时停止，返回最好的已完成假设。$k = 1$ 时它就是贪心解码；翻译中通常取 $k = 4$ 到 10。

::: worked title="在一个玩具模型上比较贪心解码与束搜索"
一个在 token $\{A, B, \langle e\rangle\}$ 上的解码器，其中 $\langle e\rangle$ 是 EOS。它的概率为：

- 第 1 步：$A$ 0.5，$B$ 0.4，$\langle e\rangle$ 0.1；
- 在 $A$ 之后：$A$ 0.3，$B$ 0.3，$\langle e\rangle$ 0.4；
- 在 $B$ 之后：$A$ 0.9，$B$ 0.05，$\langle e\rangle$ 0.05；
- 任意两个 token 之后：以概率 1 输出 $\langle e\rangle$。

**贪心解码。** 第 1 步选 $A$（0.5）。在 $A$ 之后最好的 token 是 $\langle e\rangle$（0.4）。输出 $A\langle e\rangle$，概率为 $0.5\times0.4 = 0.20$。

**束搜索，$k = 2$。** 第 1 步保留 $A$（0.5）和 $B$（0.4）。第 2 步给六个扩展打分：

$BA$：$0.4\times0.9 = 0.36$；$A\langle e\rangle$：$0.5\times0.4 = 0.20$；$AA$：$0.5\times0.3 = 0.15$；$AB$：$0.15$；$BB$：$0.4\times0.05 = 0.02$；$B\langle e\rangle$：$0.02$。

最好的两个是 $BA$（0.36）和 $A\langle e\rangle$（0.20）。$A\langle e\rangle$ 已经完成，被放到一边；$BA$ 继续，并且必然以 $\langle e\rangle$ 结束，所以 $BA\langle e\rangle$ 的概率为 $0.36\times1 = 0.36$。最好的已完成假设是 $BA\langle e\rangle$，其概率是贪心解码答案的 $0.36/0.20 = 1.8$ 倍。

用对数得分表示：$\ln 0.36 = -1.022$，$\ln 0.20 = -1.609$。除以 token 长度（3 和 2）：$-0.341$ 和 $-0.805$。这里两种打分方式结论一致。图 4.16 画出了搜索树。
:::

::: figure id=fig-04-16
玩具示例的束搜索树。根节点有子节点 $A$（0.5）、$B$（0.4）和 $\langle e\rangle$（0.1）；第二层显示 $A$ 和 $B$ 各自的三个子节点及其序列概率。每一层保留的两个假设用粗线框出，被剪掉的显示为灰色。贪心路径为蓝色虚线，终止于 $A\langle e\rangle$（0.20）；束搜索的答案 $BA\langle e\rangle$（0.36）为绿色粗线。
:::

束搜索有一个已知的偏差。每个 token 都把概率乘以一个小于 1 的数，所以对数概率之和偏爱短的输出；而更大的束搜索得更努力，会找到更多短而得分高的假设：超过某一点后，加宽束反而得到更短、更差的输出。**长度归一化**（length normalisation）把得分除以长度的某个幂，$\ln p(y\mid x)/|y|^\alpha$，其中 $0 < \alpha \le 1$；Wu 等人（2016）使用平滑过的除数 $\big((5+|y|)/6\big)^\alpha$。设置最小长度是一种更粗糙的防护。束搜索适用于只想要单个最佳输出的任务；需要多样的输出时，采样更合适（[模块 07](module_07_ZH.html)）。搜索也修复不了一个不知道答案的模型：在实验 4 中，$k = 4$ 的束搜索与贪心解码一样，让瓶颈模型在长度 12 时 200 个字符串中一个都没答对，而它的 token 准确率还从 52.3% 降到 49.1%：束找到了模型认为概率更高的输出，但它们并没有更正确。

### 瓶颈

解码器对源序列所知道的一切，都要通过一个固定大小的向量。Sutskever 等人发现，把源句子的顺序反转能显著改善他们的翻译。反转使源句的头几个词紧挨着目标句的头几个词，于是解码器最先需要的依赖都很短；这样的技巧居然有用，本身就是瓶颈的一种症状。Cho、van Merriënboer、Bahdanau 和 Bengio（2014）观察到，翻译质量随句子变长而下降。实验 4 干净地测出了这一点：用摘要为 64 个数的 GRU 编码器-解码器反转数字串，序列准确率在长度 4 时约为 98%，长度 8 时为 43%，长度 12 时为 1%（一次运行；换一个种子，中间的那个值会变动几个百分点）。[第 11 节](#s11)消除了这个瓶颈。

::: keyidea
编码器-解码器逐 token 地分解 $p(y\mid x)$；它在真实前缀上训练，靠自己的输出解码，并受限于承载源序列的那一个向量。
:::

::: check
$k = 1$ 的束搜索是什么算法？
:::

::: answer
贪心解码：束中只有一个假设，每一步都用它的那个概率最大的 token 来扩展。
:::

::: check
为什么教师强制让训练更容易，却带来了暴露偏差？
:::

::: answer
解码器的输入是已知的目标，所以没有采样循环，每一步都在正确的前缀上以干净的信号训练。但模型从未见过自己的错误，所以测试时一个错误的 token 就会把它带入训练中从未遇到过的状态，误差不断累积。
:::

## 注意力：从瓶颈到软对齐 {#s11}

[第 10 节](#s10)的瓶颈是一种选择，而不是必然。编码器在每个源位置上都计算出一个状态；普通的编码器-解码器只保留最后一个，其余全部丢掉。**注意力**（attention，Bahdanau、Cho 和 Bengio，2015）把它们全部保留下来，让解码器在每一步计算自己的源序列摘要，并向那些对它即将产生的 token 重要的位置倾斜。

### 公式

把编码器状态，即**注释向量**（annotation），记作 $\mathbf{h}_1, \dots, \mathbf{h}_S$。在 Bahdanau 等人的工作中，它们来自一个双向编码器（[第 6 节](#s6)），$\mathbf{h}_j = [\overrightarrow{\mathbf{h}}_j; \overleftarrow{\mathbf{h}}_j]$，所以每一个都在整个源序列的上下文中描述位置 $j$。在解码器的第 $t$ 步，三个运算把它们变成一个**上下文向量**（context vector）$\mathbf{a}_t$：

$$\begin{aligned}
e_{t,j} &= \mathbf{v}_a^\top\tanh(\mathbf{W}_a\mathbf{s}_{t-1} + \mathbf{U}_a\mathbf{h}_j) && \text{得分}\\
\alpha_{t,j} &= \frac{\exp(e_{t,j})}{\sum_{k=1}^{S}\exp(e_{t,k})} && \text{权重}\\
\mathbf{a}_t &= \sum_{j=1}^{S}\alpha_{t,j}\,\mathbf{h}_j && \text{上下文}
\end{aligned}$$

得分是一个单隐藏层网络，评价注释向量 $j$ 与解码器当前需要的匹配程度；它的参数 $\mathbf{W}_a$、$\mathbf{U}_a$ 和 $\mathbf{v}_a$ 沿用 Bahdanau 等人的命名，与[第 2 节](#s2)的循环矩阵不是一回事。softmax 把得分变成在 $j$ 上为正且总和为 1 的权重；上下文就是注释向量的加权平均。然后解码器把上下文与自己的状态一起读入。按[实验 4](#lab4) 所用的形式，

$$\mathbf{s}_t = f(\mathbf{s}_{t-1}, [\mathbf{y}_{t-1}; \mathbf{a}_t]), \qquad
p(y_t \mid y_{<t}, x) = \softmax\big(\mathbf{W}_o[\mathbf{s}_t; \mathbf{a}_t] + \mathbf{b}_o\big).$$

一切都是可微的，所以得分网络与其余部分一样，用同一个交叉熵训练；没有人告诉模型该看哪里。由于得分是一个经过 tanh 的和，这种注意力称为**加性**（additive）注意力。图 4.17 展示了其中一步。

::: figure id=fig-04-17
解码器一步中的注意力。左边是一列编码器注释向量 $\mathbf{h}_1, \dots, \mathbf{h}_S$，每个画成上下叠放的一对（前向和后向状态）。右边是解码器状态 $\mathbf{s}_{t-1}$。连线从 $\mathbf{s}_{t-1}$ 经过一个小的“得分”节点通向每个 $\mathbf{h}_j$；编码器那一列旁边是权重 $\alpha_{t,j}$ 的条形图；一个求和节点产生 $\mathbf{a}_t$，它与 $y_{t-1}$ 一起送入解码器单元。
:::

### 形状、开销与掩码

设编码器每个方向的宽度为 $H$，则注释向量的宽度为 $2H$；解码器状态的宽度为 $H$；注意力的宽度为 $d_a$。于是 $\mathbf{W}_a \in \mathbb{R}^{d_a\times H}$，$\mathbf{U}_a\in\mathbb{R}^{d_a\times 2H}$，$\mathbf{v}_a\in\mathbb{R}^{d_a}$。乘积 $\mathbf{U}_a\mathbf{h}_j$ 与 $t$ 无关，所以每个源序列只需计算一次。之后解码器的每一步把 $\mathbf{W}_a\mathbf{s}_{t-1}$ 加到 $S$ 个预先算好的向量上，应用 tanh，与 $\mathbf{v}_a$ 做 $S$ 次点积，再对 $S$ 个注释向量求加权和：工作量为 $O(S(d_a + H))$。$T'$ 个 token 的输出需要 $O(S\,T')$ 个这样的单位，即两个长度的乘积。这是注意力的二次开销第一次出现。

在填充过的 batch 中，有些源位置是填充。它们的得分在 softmax 之前被设为 $-\infty$（实践中取 $-10^9$，指数函数会把它变成精确的零），因而得不到任何权重。实验 4 这样做了；忘了这一步，解码器就会关注填充。

::: worked title="手算一个加性得分"
取 $\mathbf{W}_a = \mathbf{I}$，$\mathbf{U}_a = \begin{bmatrix}0.5 & -0.5\\ 1 & 0\end{bmatrix}$，$\mathbf{v}_a = (1, -1)$，解码器状态 $\mathbf{s}_{t-1} = (0.5, -0.5)$，三个注释向量 $\mathbf{h}_1 = (1, 0)$，$\mathbf{h}_2 = (0, 1)$，$\mathbf{h}_3 = (1, 1)$。

1. $\mathbf{W}_a\mathbf{s}_{t-1} = (0.5, -0.5)$。
2. $\mathbf{U}_a\mathbf{h}_1 = (0.5, 1)$，$\mathbf{U}_a\mathbf{h}_2 = (-0.5, 0)$，
   $\mathbf{U}_a\mathbf{h}_3 = (0, 1)$。
3. 求和：$(1, 0.5)$，$(0, -0.5)$，$(0.5, 0.5)$。
4. tanh：$(0.7616, 0.4621)$，$(0, -0.4621)$，$(0.4621, 0.4621)$。
5. 得分 $e_j = \mathbf{v}_a^\top(\cdot)$，即第一个分量减第二个分量：
   $0.2995$，$0.4621$，$0$。
6. 权重：$\exp(e) = (1.3492, 1.5874, 1)$，总和 $3.9366$，所以 $\alpha = (0.3427, 0.4033, 0.2540)$。
7. 上下文：$0.3427(1,0) + 0.4033(0,1) + 0.2540(1,1) = (0.5967, 0.6573)$。

权重之和为 1，只是略微偏向 $\mathbf{h}_2$：得分很小时，softmax 保持柔和，上下文是一种混合。
:::

### 对齐

权重 $\alpha_{t,j}$ 构成一个矩阵，每个输出步一行，每个源位置一列：这是一种**软对齐**（soft alignment），说明解码器在产生每个输出时看的是哪些源位置。它可以画出来。Bahdanau 等人给出的英法翻译对齐图大体是对角的，因为两种语言的语序相同，在语序不同的地方，例如形容词与名词顺序互换处，则有局部的偏离。对数字反转，对齐应当是反对角线，结果也确实如此。在[实验 4](#lab4) 中，对一个 8 位数字的输入，每个数字所在行的 argmax 为 $(7, 6, 5, 4, 3, 2, 1, 0)$，峰值权重在 0.63 到 0.84 之间：模型找到了“看镜像位置”的规律。实验 4 第 6 步画出了这张热图。有注意力时，序列准确率在长度 4、8 和 12 上都是 100%，没有注意力时约为 98%、43% 和 1%。

### Luong 的变体，以及点积的尺度

Luong、Pham 和 Manning（2015）简化了这一设计，并给出了若干变体。他们比较了三种得分：**点积**（dot），$\mathbf{s}_t^\top\mathbf{h}_j$；**一般形式**（general），$\mathbf{s}_t^\top\mathbf{W}\mathbf{h}_j$；以及**拼接**（concat），即加性形式。他们用*当前的*解码器状态 $\mathbf{s}_t$ 而不是 $\mathbf{s}_{t-1}$ 计算注意力；比较了在全部源位置上的**全局**（global）注意力与在预测位置附近一个窗口内的**局部**（local）注意力；并把每一步的注意力输出作为输入送回下一步。点积得分没有参数，把注意力变成了矩阵乘积，Transformer 保留的正是这种形式。它有一个需要留意的性质：它的尺度随宽度增长。

::: worked title="点积注意力，以及尺度为何重要"
解码器状态 $\mathbf{s} = (1, 0)$；注释向量仍为 $(1,0)$、$(0,1)$、$(1,1)$。

得分 $\mathbf{s}^\top\mathbf{h}_j = (1, 0, 1)$。指数 $(2.7183, 1, 2.7183)$，总和 $6.4366$；权重 $(0.4223, 0.1554, 0.4223)$。上下文 $0.4223(1,0) + 0.1554(0,1) + 0.4223(1,1) = (0.8446, 0.5777)$。

现在取 $\mathbf{s} = (3, 0)$，方向相同，长度是三倍。得分 $(3, 0, 3)$；指数 $(20.086, 1, 20.086)$，总和 $41.171$；权重 $(0.4879, 0.0243, 0.4879)$；上下文 $(0.9757, 0.5121)$。$\mathbf{h}_2$ 上的权重从 0.155 降到 0.024。

得分越大，softmax 越尖锐。对于 $d$ 个分量相互独立、均值为零、方差为 1 的向量，$\operatorname{Var}(\mathbf{s}^\top\mathbf{h}) = \sum_{i=1}^{d} \mathbb{E}[s_i^2]\,\mathbb{E}[h_i^2] = d$，所以典型的得分按 $\sqrt d$ 增长，宽模型的 softmax 会饱和，梯度随之消失。[模块 06](module_06_ZH.html) 正是出于这个原因把得分除以 $\sqrt{d_k}$。
:::

### 它为什么有效

现在每个输出到每个输入都有一条一步长的路径，信息和梯度都走这条路。没有什么需要被挤进一个向量，从某个输出到它所需的源位置的梯度，只经过一次加权求和，而不必穿过其间的每一个编码器和解码器步骤。这与 LSTM 的加性路径（[第 5 节](#s5)）和残差连接是同一个论证：给信号一条短路。同样的手段也可以替代多对一循环分类器中的“取最后一个状态”：用一个学习得到的查询向量，对所有状态做注意力加权平均，在时间上做池化。

### 从这里到模块 06

在点积形式中，解码器状态扮演**查询**（query）的角色，编码器状态既扮演被打分的**键**（key），也扮演被平均的**值**（value）。去掉循环，让序列中的每个位置都对同一序列中的所有其他位置发出查询，结果就是**自注意力**（self-attention），即 Transformer 的核心。[模块 06](module_06_ZH.html) 从这里接着讲。

::: pitfall
对齐图不是解释。注意力权重可以大幅改变而不改变模型的预测，不同的权重模式也可以给出相同的输出（Jain 和 Wallace，2019；Wiegreffe 和 Pinter，2019 对它们何时可以提供信息给出了限定条件）。应把对齐当作诊断工具，并通过干预输入来证实所声称的依赖关系。
:::

::: check
解码器某一步的注意力权重之和是多少？是在什么上求和？
:::

::: answer
和为 1，在编码器位置 $j = 1, \dots, S$ 上求和（填充位置的权重为零）。
:::

::: check
为什么注意力能阻止准确率随源序列长度下降？
:::

::: answer
解码器在每一步都通过加权求和读取所有编码器状态，所以没有什么需要装进一个向量，而且每个输出到每个输入的路径只有一步长，信息和梯度都是如此。
:::

## Transformer 为何取代了循环 {#s12}

循环网络有两项开销是其结构所固有的。更好的单元消除不了其中任何一项，二者合起来解释了为什么序列建模先转向卷积，再转向 Transformer。

### 两项开销

**时间上无法并行。** $\mathbf{h}_t$ 需要 $\mathbf{h}_{t-1}$，所以一个 10,000 个 token 的序列在每一层都是 10,000 个相互依赖的步骤，无论有多少处理器可用。教师强制让每个输入都事先已知，但这无济于事：$\mathbf{h}_t$ *非线性地*依赖于 $\mathbf{h}_{t-1}$，后者必须先算出来。跨序列的数据并行仍然可行；受影响的是每一步计算的规模。每一步对 batch 中的每个序列只是一个小的矩阵乘积，太少，不足以让现代加速器保持繁忙，而长上下文又让这条链更长。对于[模块 08](module_08_ZH.html) 所描述的那种规模的语料，这条串行链就成了瓶颈。

**路径很长。** 位置 $j$ 的信息要经过 $t - j$ 次循环才能到达位置 $t$，每一次都有损失（[第 4 节](#s4)）。注意力一步就把它们连起来；一叠空洞卷积大约需要 $\log_2(t-j)$ 步。

### 卷积方案先出现

WaveNet（van den Oord 等人，2016）用一叠**因果空洞一维卷积**（causal dilated 1D convolution，[模块 03](module_03_ZH.html)）生成音频：每个输出只看过去，第 $l$ 层在相邻抽头之间跳过 $d_l - 1$ 个样本。Bai、Kolter 和 Koltun（2018）把这种设计提炼成通用的**时间卷积网络**（temporal convolutional network，TCN），发现它在一系列标准序列基准上达到或超过了 LSTM 和 GRU。TCN 在训练中可以在时间上并行，因为每个输出都是已知输入的卷积。卷积核大小为 $k$、空洞率为 $d_1, \dots, d_L$ 时，它的感受野为 $1 + (k-1)\sum_l d_l$ 个样本。

::: worked title="TCN 能看多远"
卷积核 $k = 2$，空洞率 $1, 2, 4, \dots, 512$：十层。感受野为 $1 + 1\cdot(1 + 2 + 4 + \dots + 512) = 1 + 1{,}023 = 1{,}024$ 步。每增加一层，所及范围翻一倍。1,000 步之前的输入经过十层到达输出；在一个循环层中，它要经过 1,000 个相互依赖的步骤。[练习 15](#e15) 为与实验 3 的 64 样本窗口相匹配的六层 TCN 确定尺寸。
:::

它的局限是固定的感受野：比感受野更早的东西不能影响输出，要覆盖更长的历史就得加层。

### Transformer 的取舍，以及循环保留下来的东西

Transformer（[模块 06](module_06_ZH.html)）用少数几个大的矩阵乘积并行计算每个位置，任意两个位置之间的路径长度为 1。代价是与序列长度成二次关系的开销，因为每个位置都要给其他每个位置打分。对于在大规模语料上训练，这个取舍是对的。

到了推理时，取舍反了过来。循环网络以恒定的计算量和固定大小的状态生成每个 token。Transformer 则要存储每个过去 token 的键和值，即[模块 10](module_10_ZH.html) 推导的 **KV cache**，它随上下文增长。

::: worked title="状态与缓存"
一个 $H = 1{,}024$、fp32 的 4 层 LSTM 每层保存 $(\mathbf{h}, \mathbf{c})$：每个序列 $2\times4\times1{,}024\times4\ \text{B} = 32{,}768$ B $= 32.8$ kB（32 KiB），与上下文长度无关。

一个宽度为 2,048、不用分组查询注意力的 24 层 Transformer，为每个过去的 token 在每层存储一个键向量和一个值向量：在 16 位精度下，每个 token $2\times24\times2{,}048\times2\ \text{B} = 196{,}608$ B $= 196.6$ kB（192 KiB）。32,768 个 token 时，这是 $196{,}608\times32{,}768 = 6.44\times10^9$ B $= 6.44$ GB（6.0 GiB）。分组查询注意力把它除以分组因子（[模块 10](module_10_ZH.html)）。
:::

下面的比较沿用 Vaswani 等人（2017）的做法，他们给出过一张类似的表；图 4.19 画出了三种依赖图。$T$ 是序列长度，$d$ 是宽度，$k$ 是卷积核大小。

| | RNN | 空洞 TCN | 自注意力 |
|---|---|---|---|
| 训练中每层的顺序操作数 | $O(T)$ | $O(1)$ | $O(1)$ |
| 最大路径长度 | $O(T)$ | $O(\log T)$ | $O(1)$ |
| 每层计算量 | $O(T d^2)$ | $O(k\,T d^2)$ | $O(T^2 d)$ |
| 推理时每个数据流的内存 | 固定状态，$O(d)$ | 每个空洞层级一个缓冲区 | KV cache，$O(T d)$ |
| 感受野 | 原则上无界 | 由空洞率固定 | 整个上下文 |

::: figure id=fig-04-19
八个位置上的三种依赖图。一条链（RNN），突出显示从位置 1 到位置 8 的路径：长度 7。一棵空洞二叉树（TCN），路径长度 3。一个画成全连接扇形的完全图（自注意力），路径长度 1。每张图都标出了它的最大路径长度，即它所图示的那张表的第二行。

### 线性注意力就是一种循环

这两类模型比表中所显示的更接近。Katharopoulos 等人（2020）用一个核特征映射 $\phi$ 取代 softmax，于是因果注意力变成 $\mathbf{y}_t = \mathbf{S}_t\phi(\mathbf{q}_t)/(\mathbf{z}_t^\top\phi(\mathbf{q}_t))$，其中 $\mathbf{S}_t = \mathbf{S}_{t-1} + \mathbf{v}_t\phi(\mathbf{k}_t)^\top$，$\mathbf{z}_t = \mathbf{z}_{t-1} + \phi(\mathbf{k}_t)$：一个状态为矩阵、靠加法更新的 RNN。[第 13 节](#s13)沿着这座桥继续往下走。

::: check
采用教师强制时，解码器的每个输入都事先已知。为什么 LSTM 仍然不能一次处理所有位置？
:::

::: answer
$\mathbf{h}_t$ 非线性地依赖于 $\mathbf{h}_{t-1}$，后者必须先算出来。知道输入并不能打断这条链。
:::

::: check
因果 TCN 和 LSTM 都可以一次处理数据流中的一个样本。谁的每流内存随它能利用的历史长度增长？
:::

::: answer
TCN 的。每一层保存它最近的 $(k-1)d_l$ 个输入，所以每个通道的缓冲区加起来大约等于感受野。LSTM 无论历史多长，都只保存一个固定大小的状态。
:::

## 回归的东西：线性循环与状态空间模型 {#s13}

[第 12 节](#s12)的两项开销来自同一个地方：循环内部的非线性。它迫使计算成为串行循环，加上饱和，又在每一步缩小梯度。把它从循环中拿出来，改放到层与层之间（逐步的 MLP 和门），循环就变得可以并行训练，在长距离上也可以控制。

### 线性循环就是卷积

让状态线性地演化，取 $\mathbf{h}_0 = \mathbf{0}$：

$$\mathbf{h}_t = \mathbf{A}\mathbf{h}_{t-1} + \mathbf{B}\mathbf{x}_t, \qquad
\mathbf{y}_t = \mathbf{C}\mathbf{h}_t + \mathbf{D}\mathbf{x}_t.$$

把它展开：$\mathbf{h}_1 = \mathbf{B}\mathbf{x}_1$，$\mathbf{h}_2 = \mathbf{A}\mathbf{B}\mathbf{x}_1 + \mathbf{B}\mathbf{x}_2$，一般地

$$\mathbf{h}_t = \sum_{k=0}^{t-1}\mathbf{A}^k\mathbf{B}\,\mathbf{x}_{t-k}, \qquad
\mathbf{y}_t = \sum_{k=0}^{t-1}\mathbf{K}_k\,\mathbf{x}_{t-k} + \mathbf{D}\mathbf{x}_t, \qquad
\mathbf{K}_k = \mathbf{C}\mathbf{A}^k\mathbf{B}.$$

输出是输入与卷积核 $\mathbf{K}_k$ 的因果卷积，而这个卷积核就是系统对单位冲激的响应。工程师熟悉这个对象：一个线性时不变系统，一个 IIR 滤波器，它的卷积核各项就是状态空间模型的马尔可夫参数。图 4.20 画出了一个标量模态的两种视角。

::: worked title="同一个映射，两种算法"
$h_t = 0.9\,h_{t-1} + x_t$，$y_t = 0.5\,h_t$，输入 $x = (1, 2, 0, -1)$。

循环：$h = (1,\ 0.9 + 2 = 2.9,\ 2.61,\ 2.349 - 1 = 1.349)$，所以 $y = (0.5, 1.45, 1.305, 0.6745)$。

卷积核：$K_k = 0.5\times0.9^k = (0.5, 0.45, 0.405, 0.3645)$。在 $t = 4$ 处做卷积：$y_4 = 0.5(-1) + 0.45(0) + 0.405(2) + 0.3645(1) = -0.5 + 0 + 0.81 + 0.3645 = 0.6745$。完全相同。
:::

### 计算同一个映射的三种方式

**循环模式**（recurrent mode）一次更新一步状态：每一步的开销和内存都是常数，非常适合生成和流式处理。**卷积模式**（convolution mode）先算出一次卷积核，再通过 FFT 以 $O(T\log T)$ 对整个序列做卷积：所有步一次完成，非常适合训练。第三种是**并行扫描**（parallel scan），即使系数随 $t$ 变化也适用。把标量循环的一步写成仿射映射 $h \mapsto a h + b$。两步复合起来仍是一个仿射映射：

$$a_2(a_1 h + b_1) + b_2 = (a_2a_1)\,h + (a_2b_1 + b_2), \qquad
(a_2, b_2)\circ(a_1, b_1) = (a_2a_1,\ a_2b_1 + b_2).$$

复合满足结合律，所以前缀 $h_1, \dots, h_T$ 可以在一棵平衡树中合并，深度为 $O(\log T)$ 层，总工作量为 $O(T)$（Blelloch，1990）。tanh 循环没有这样的运算：两步 $\tanh(w\tanh(wh + b_1) + b_2)$ 并不是同一形式的一步。

::: worked title="FFT 省下了什么"
长度 $T = 4{,}096$ 的直接因果卷积，每个通道大约需要 $T^2/2 = 8.4$ 百万次乘加。基于 FFT 的卷积填充到 $2T$，大约需要 $3\times 2T\log_2(2T) = 3\times8{,}192 \times13 \approx 0.32$ 百万次（数量级估计）。循环只需要每个通道 $T$ 次乘加，但它们是串行的。在 CPU 上，计数并不能决定胜负。[实验 5](#lab5) 的计时（batch 为 8，$N = 64$，三次取最好，所示为其中一次运行）为：$T = 256$ 时循环 4.2 ms 对 FFT 形式 3.8 ms，1,024 时 19.8 对 13.8 ms，4,096 时 79.1 对 70.0 ms。在五次运行中，FFT 形式在两个较短长度上快 1.1 到 1.7 倍，在 4,096 上为 0.7 到 1.1 倍：最多只是稍快一些，在最长的长度上则根本没有更快。卷积模式要在并行硬件能够吸收它更大的并行工作量的地方，即在 GPU 上和训练中，才划算。
:::

循环与卷积的对偶性。左：循环 $h_t = \lambda h_{t-1} + b x_t$ 画成一个带自环的单元，自环标为 $\lambda$。右：同一个系统作为卷积，$t = 0$ 处的输入冲激，以及以杆状图画出的卷积核 $K_k = c\lambda^k b$，分别对应实数 $\lambda = 0.9$（单调衰减）和复数 $\lambda = 0.95e^{i\pi/8}$（周期为 16 的阻尼振荡，包络 $\pm0.95^k$ 为虚线）。一个等号连接左右两半。

### 对角、复数与稳定

稠密 $\mathbf{A}$ 的幂计算代价高，也难以控制，所以把它对角化，$\mathbf{A} = \mathbf{V}\boldsymbol{\Lambda}\mathbf{V}^{-1}$，换元为 $\tilde{\mathbf{h}} = \mathbf{V}^{-1}\mathbf{h}$，系统就分解成 $N$ 个独立的标量循环，$\tilde h_{t,n} = \lambda_n\tilde h_{t-1,n} + (\tilde{\mathbf{B}}\mathbf{x}_t)_n$，其中 $\tilde{\mathbf{B}} = \mathbf{V}^{-1}\mathbf{B}$。特征值一般是复数，$\lambda = re^{i\theta}$：模 $r$ 决定记忆，半衰期为 $\ln 0.5/\ln r$ 步；辐角 $\theta$ 决定一个周期为 $2\pi/\theta$ 步的振荡。通过实部来看，一个复数模态就是一个阻尼振荡器。

::: worked title="一个复数模态"
$\lambda = 0.95e^{i\pi/8}$，所以 $\operatorname{Re}(\lambda^k) = 0.95^k\cos(k\pi/8)$。对 $k = 0, \dots, 8$：$1, 0.878, 0.638, 0.328, 0, -0.296, -0.520, -0.645, -0.663$。验证 $k = 2$：$0.9025\times\cos(\pi/4) = 0.9025\times0.7071 = 0.638$。周期为 $2\pi/(\pi/8) = 16$ 步，半衰期为 $\ln 0.5/\ln 0.95 = -0.6931/(-0.05129) = 13.5$ 步。
:::

稳定性由参数化本身保证。**线性循环单元**（Linear Recurrent Unit，LRU；Orvieto 等人，2023）写成 $\lambda = \exp(-\exp(\nu) + i\theta)$，其中 $\nu$ 和 $\theta$ 是可训练的实数。于是对每个 $\nu$ 都有 $|\lambda| = \exp(-e^{\nu}) < 1$：任何梯度步都不能让它爆炸。每个模态的输入乘以 $\gamma = \sqrt{1-|\lambda|^2}$，因为对于输入为单位方差白噪声的 $h_t = \lambda h_{t-1} + \gamma u_t$，平稳方差满足 $v = |\lambda|^2 v + \gamma^2$，所以即使在单位圆附近也有 $v = \gamma^2/(1-|\lambda|^2) = 1$。

::: worked title="初始化记忆"
由 $\nu$ 求半衰期：$|\lambda| = e^{-e^\nu}$，所以 $\ln|\lambda| = -e^\nu$，半衰期为 $\ln 2\cdot e^{-\nu}$。取 $\nu = \ln 0.001$：$|\lambda| = e^{-0.001} = 0.9990$，半衰期为 $0.6931/0.001 = 693$ 步。$\nu$ 每变化相同的量，半衰期就改变相同的倍数，这使 $\nu$ 成为一个便于训练的参数。

[实验 5](#lab5) 从环 $[0.9, 0.999]$ 中抽取它的 64 个模，两个端点的半衰期分别为 $\ln 0.5/\ln 0.9 = 6.6$ 步和 $\ln 0.5/\ln 0.999 = 693$ 步。抽到的模的范围为 0.902–0.998724，对应 6.7–543 步。在单位圆附近，小数点后第五位都很重要：0.9987 会给出 533 步。
:::

### 连续时间与步长

状态空间模型常写成连续时间形式，$\dot{\mathbf{h}} = \mathbf{A}\mathbf{h} + \mathbf{B}x(t)$，再以步长 $\Delta$ 离散化。在每一步内保持输入不变（**零阶保持**，zero-order hold），并精确求解这个线性常微分方程，对一个标量模态 $\lambda$ 得到

$$h(t+\Delta) = e^{\lambda\Delta}h(t) + \int_0^\Delta e^{\lambda(\Delta-\tau)}\,d\tau\;x
= a\,h(t) + b\,x, \qquad a = e^{\lambda\Delta},\quad b = \frac{e^{\lambda\Delta}-1}{\lambda},$$

写成矩阵形式为 $\bar{\mathbf{A}} = \exp(\Delta\mathbf{A})$，$\bar{\mathbf{B}} = \mathbf{A}^{-1}(\exp(\Delta\mathbf{A}) - \mathbf{I})\mathbf{B}$。$\Delta$ 是每一步经过的时间：小的 $\Delta$ 保持状态（$a\approx1$），大的 $\Delta$ 重置状态（$a\approx0$）。

::: worked title="极点在 −0.1 处的零阶保持"
$\Delta = 1$：$a = e^{-0.1} = 0.9048$，$b = (0.9048-1)/(-0.1) = 0.9516$。前向欧拉法会给出 $1 + \lambda\Delta = 0.9$ 和 $\Delta = 1.0$。

$\Delta = 0.1$：$a = e^{-0.01} = 0.990$，$b = 0.0995$：保持状态，写入很少。

$\Delta = 10$：$a = e^{-1} = 0.368$，$b = (0.368-1)/(-0.1) = 6.32$：大部分遗忘，写入很多。

作为门 $a_t = \exp(-\Delta_t)$：$\Delta_t = 0.01$ 给出 0.990（保持），$\Delta_t = 5$ 给出 0.0067（重置）。
:::

### S4 与对角模型

**S4**（Gu、Goel 和 Ré，2022）让这一切变得实用。它的 $\mathbf{A}$ 用 **HiPPO**（Gu 等人，2020）初始化，这种构造使状态保存输入历史的最优多项式逼近，并且它能高效地计算长卷积核。S4 在整个 Long Range Arena 基准（Tay 等人，2021）上胜过了先前的模型，包括其中 16,384 步的 Path-X 任务，先前的模型在这个任务上一直停留在随机水平。随后，对角变体（Gupta、Gu 和 Berant 2022 的 DSS；Gu 等人 2022 的 S4D）和 LRU 表明，一个经过仔细参数化、在单位圆附近初始化的对角复数循环就足够了。LRU 论文把它的模型表述为一个被线性化和对角化的 RNN：即[第 2 节](#s2)的朴素循环，只是把 tanh 移到了循环之外。

### Mamba：步长取决于输入

S4 的系数在每一步都相同，所以它无法根据自己读到的内容决定保留什么。**Mamba**（Gu 和 Dao，2023）加入了**选择性**（selectivity）：$\Delta$、$\mathbf{B}$ 和 $\mathbf{C}$ 变成当前输入的函数，$\Delta_t = \operatorname{softplus}(\text{linear}(\mathbf{x}_t))$。系统不再是时不变的，所以没有固定的卷积核，也没有卷积模式；Mamba 用一种硬件感知的并行扫描来计算循环。$\Delta_t$ 起着门的作用。大的 $\Delta_t$ 把 $a_t$ 推向 0、把 $b_t$ 推高：重置状态并写入当前输入。小的 $\Delta_t$ 保持状态并忽略输入（图 4.21）。[第 5 节](#s5)的遗忘门和输入门又回来了，只是位于一个线性循环之内。Mamba-2（Dao 和 Gu，2024）把选择性状态空间模型与线性注意力联系起来，与[第 12 节](#s12)首尾相接。

::: figure id=fig-04-21
选择性循环。上：一个输入序列，其中有一个突出显示的“重要”token；一个小网络把每个 $x_t$ 映射为 $\Delta_t$，以条形图画在序列下方，几乎处处很小，在重要 token 处很大。中：保持率 $a_t = \exp(-\Delta_t)$ 和状态轨迹，状态在重要 token 处重置并存下它，然后保持住。下：八个位置上的并行扫描树，分三层合并 $(a, b)$ 对。
:::

::: widget name=ssm-kernel-explorer
从 $r = 0.95$、$\theta = \pi/8$ 和一个冲激输入开始：卷积核是一个周期为 16、半衰期为 13.5 的阻尼振荡，卷积得到的圆点落在循环的曲线上。把 $r$ 推向 0.999，观察记忆变长；设 $\theta = 0$ 得到纯衰减。打开选择性步长：卷积核面板消失了，因为步长现在取决于输入。设 $w = 0$，它又会回来。
:::

### 实验 5 显示了什么

[实验 5](#lab5) 构建了一个 LRU 风格的对角循环。它的循环形式和 FFT 形式在 float32 舍入误差范围内一致，相差约百万分之几到十万分之几。在延迟回忆任务上（记住 $L+1$ 个 token 中的第一个），经过 400 次更新，它在滞后 25、100 和 200 上、在尝试过的全部五个种子上都达到 100%。朴素 RNN 只部分学会了滞后 25（五个种子上为 62% 到 87%），在滞后 100 上表现不稳定（两个种子 100%，三个种子停在随机水平）。LSTM 取决于它的遗忘门偏置：偏置为 1 时，即使在滞后 25 上也停在随机水平；偏置为 5 时，它在滞后 25 上学得最快，在五个种子中有两个学会了滞后 100，而在滞后 200 上失败。这个循环的记忆在初始化时就由它的特征值的模确定了。这是关于在给定预算内可训练性的陈述，并不证明 LSTM 无法记忆。

### 现状

截至 2026 年，保守地说：状态空间层和线性循环层在小规模和中等规模上可以与 Transformer 竞争，在长上下文中每个 token 的开销则低得多。它们的弱点是精确回忆任意一个较早的 token，因为固定大小的状态必须压缩过去，而注意力可以查找任何东西。在许多循环层或状态空间层中穿插少数几个注意力层的混合架构是一种常见设计（Jamba，Lieber 等人，2024，是一个已发表的例子），而最大的语言模型仍然以 Transformer 为主。xLSTM（Beck 等人，2024）重新审视了 LSTM 本身。循环这个想法并没有输；输掉的是 1997 年的那个实现。

| 情形 | 首选 |
|---|---|
| 短序列、数据少，或在小型设备上做流式处理 | GRU 或 LSTM，或以循环模式运行的小型对角循环 |
| 对整条序列做离线标注 | 双向 LSTM 或 Transformer 编码器 |
| 预测一条或少数几条序列 | 先用朴素、季节性朴素和线性基线；如果前向滚动验证的各折结果支持，再用 LSTM 或 TCN |
| 具有长程结构的超长序列 | 状态空间或线性循环的堆叠，或带高效注意力的 Transformer |
| 大规模语言建模 | Transformer 或混合架构（[模块 06](module_06_ZH.html)–[08](module_08_ZH.html)） |

::: keyidea
对状态线性的循环就是卷积：它可以并行训练，它的记忆由特征值的模决定，而让它的步长取决于输入，又把它变回了门。
:::

::: check
为什么 S4 式的层可以作为卷积来训练，而 Mamba 层不行？
:::

::: answer
S4 的 $\mathbf{A}$、$\mathbf{B}$、$\mathbf{C}$ 和 $\Delta$ 在每一步都相同，所以卷积核 $\mathbf{C}\bar{\mathbf{A}}^k\bar{\mathbf{B}}$ 是一个固定的序列。Mamba 的 $\Delta$、$\mathbf{B}$ 和 $\mathbf{C}$ 取决于输入，所以没有单一的卷积核；它使用并行扫描。
:::

::: check
一个对角循环的 $|\lambda| = 0.99$。经过多少步之后，一个输入的影响减半？
:::

::: answer
$\ln 0.5/\ln 0.99 = -0.6931/(-0.01005) = 69$ 步。
:::

::: check
固定大小的循环状态有什么弱点，促使人们采用带少数几个注意力层的混合架构？
:::

::: answer
状态必须压缩整个过去，所以精确检索任意一个较早的 token 很难；注意力可以直接寻址任何位置。
:::

## 常见问题与排查 {#wrong}

下面每一条都给出你看到的症状、通常的原因和修复方法。其中大多数都特意在某个实验中出现过。

### 预测器在验证中表现出色，投入使用后却失败

*症状：*验证误差远低于朴素预测；投入使用后，模型并不比持续性预测好。*原因：*重叠的窗口在随机划分之前被打乱了，归一化又用了整条序列，所以“预测”其实是在记住的邻居之间做插值（[第 8 节](#s8)）。*修复：*按时间划分，使用前向滚动验证的各折，所有统计量只在训练部分上计算，并在训练目标与验证输入之间留出至少一个预测步长的间隔。

### LSTM 输给了“明天等于今天”

*症状：*在最新的数据上，网络比持续性预测还差：[第 8 节](#s8)例题的代码得分 1.075，而朴素预测为 0.155；同一个模型在[实验 3](#lab3) 中为 0.43 对 0.36。*原因：*水平漂移到了训练中从未见过的范围，而网络不会外推水平：它的预测偏向它已知的水平。*修复：*逐窗口归一化（减去最后一个值或窗口均值；RevIN）或对序列做差分，并且始终把朴素基线打印在模型旁边。

### 损失出现尖峰或变成 NaN

*症状：*训练正常运行了几千次更新，然后损失突然跳升或变成 NaN。*原因：*损失曲面上的悬崖导致梯度爆炸（[第 4 节](#s4)）。*修复：*把全局梯度范数裁剪到 1 到 5，降低学习率，并检查输入中的离群值。在裁剪之前记录范数；持续上升的趋势就是预警。

### 网络忽略了大约 20 步之前的一切

*症状：*短程结构学到了，长程结构没有学到；在[实验 1](#lab1) 中，闭合标签大约五行中只有一行匹配，比随机猜测的八分之一高不了多少。*原因：*朴素 RNN 中的梯度消失，或者截断的随时间反向传播的窗口比依赖关系短（[第 3 节](#s3)）。*修复：*使用 LSTM 或 GRU、更长的截断，或者线性循环模型或注意力模型。画出梯度范数随滞后的变化（[实验 2](#lab2)）来证实诊断。

### LSTM 学得很慢，看起来没有记忆

*症状：*前一千次更新中损失一直平坦；几步之外的依赖都被漏掉。*原因：*遗忘门偏置留在了 0，所以每个门的初始值接近 $\sigma(0) = 0.5$，记忆每一步减半（[第 5 节](#s5)）。*修复：*把遗忘门偏置设为 1 或更大。在 PyTorch 中，各个门按 i、f、g、o 的顺序堆叠，所以遗忘门的切片是 `[H:2*H]`，而且 `bias_ih` 和 `bias_hh` 是相加的。

### 短序列失败，或结果随 batch 的组成而变化

*症状：*测试时短序列的得分比长序列差，或者同一个输入在不同的 batch 中给出不同的输出。*原因：*填充时没有使用掩码或打包：损失在填充上计算，双向编码器在读到真实 token 之前先读了填充。实验 4 可选的第 7 步中未打包的编码器，在像训练时那样填充的长度 4 字符串上得分 100%，在截到真实宽度的同样字符串上得分 0%。*修复：*对损失加掩码，打包序列，并在每条序列真实的最后一步取状态（[第 7 节](#s7)）。

### 验证得分取决于 batch 的顺序

*症状：*重新排列验证 batch 会改变得分。*原因：*状态在互不相关的序列之间传递，或者在评估之前没有重置。*修复：*在相互独立的序列之间重置状态；只在同一数据流的各个分块之间传递状态（并将其 detach），并让每个数据流始终位于 batch 的同一行。

### 双向预测器得到好得不可能的结果

*症状：*预测在评估中看上去近乎完美。*原因：*后向方向读到了未来（[第 6 节](#s6)）。*修复：*凡是在线应用都使用因果模型。直接检验因果性：扰动预测时刻之后的输入，确认预测不变。

### 生成的序列在几个 token 之后就漂移或重复

*症状：*输出在开头几个 token 还很流畅，随后跑偏或陷入循环。*原因：*暴露偏差：模型只用教师强制训练过，从未见过自己的错误（[第 10 节](#s10)）。*修复：*计划采样、部分自由运行的训练，或者序列级目标。至少要以自由运行的方式评估：在实验 4 中，长度 12 时，教师强制下的 token 准确率为 74%，自由运行下为 53%。

### 多步预测在几步之后发散

*症状：*单步误差极好，更长预测步长上的误差却很差。*原因：*递归策略把预测作为输入反馈回去，使它们的误差不断累积；在实验 3 中，单步表现最好的模型，即递归 LSTM，在 $h = 20$ 时比朴素预测还差（RMSE 0.78 对 0.72）。*修复：*训练一个直接的多输出模型，或者在递归模型自己的展开序列上训练它，并报告误差随预测步长的变化。

### 束搜索返回很短或空的输出

*症状：*输出被截断，而且束越大输出越短。*原因：*对数概率之和偏爱短的假设，而更宽的搜索会找到更多这样的假设。*修复：*用长度的某个幂对得分做归一化（[第 10 节](#s10)），或者设置最小长度。

### 监测器漏掉偏移，对卡死的传感器也从不报警

*症状：*传感器偏移开始时报警一次，然后就没有动静；冻结的传感器什么也不触发。*原因：*以最后一个值为中心重新对齐的预测器在一步之内就适应了新的水平，而平坦的信号是完全可预测的（[第 9 节](#s9)）。*修复：*加入滚动残差检验或 CUSUM 检验、方差下限检验，以及对照独立参考的水平检查。用注入的各种类型的故障测试监测器。

### 监测器的误报远多于计划

*症状：*设计时承诺每月只有几次报警，操作人员却每天收到许多次。*原因：*阈值设在训练残差上，或者在残差自相关且重尾的情况下按高斯尾部概率设定。*修复：*把阈值设在留出的正常残差的经验分位数上，要求持续（$n$ 次中有 $k$ 次），并在一段很长的正常记录上报告每天的误报次数。

### 把注意力图当作解释

*症状：*一份报告声称，模型之所以作出某个决定，是因为它的注意力突出显示的那些输入。*原因：*注意力权重未必是忠实的解释（[第 11 节](#s11)）。*修复：*把对齐当作诊断工具，并通过干预输入、观察输出的变化来证实所声称的依赖关系。
