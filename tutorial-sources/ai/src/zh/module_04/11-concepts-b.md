## LSTM：一条加性的记忆路径 {#s5}

[第 4 节](#s4)以一个诊断结束。朴素循环的逐步雅可比矩阵
$\operatorname{diag}(\phi'(\mathbf{z}_k))\,\mathbf{W}_h$ 是一个固定矩阵乘以一个至多为 1 的导数，这样的因子连乘很多次，无论怎样初始化都会消失。补救办法是结构上的：给梯度第二条路径，它的逐步因子是网络在每一步自行选择、并且可以保持在接近 1 的一个数。这条路径就是**长短期记忆网络**（long short-term memory，LSTM）的**细胞状态**（cell state）。

### 方程

细胞保存两个宽度为 $H$ 的向量：细胞状态 $\mathbf{c}_t$ 和隐状态 $\mathbf{h}_t$。在每一步，它读取拼接向量 $[\mathbf{h}_{t-1}; \mathbf{x}_t]$（长度为 $H + d_\text{in}$），计算三个**门**（gate）和一个候选值：

$$\begin{aligned}
\mathbf{f}_t &= \sigma(\mathbf{W}_f[\mathbf{h}_{t-1};\mathbf{x}_t] + \mathbf{b}_f) && \text{遗忘门}\\
\mathbf{i}_t &= \sigma(\mathbf{W}_i[\mathbf{h}_{t-1};\mathbf{x}_t] + \mathbf{b}_i) && \text{输入门}\\
\tilde{\mathbf{c}}_t &= \tanh(\mathbf{W}_c[\mathbf{h}_{t-1};\mathbf{x}_t] + \mathbf{b}_c) && \text{候选值}\\
\mathbf{c}_t &= \mathbf{f}_t\odot\mathbf{c}_{t-1} + \mathbf{i}_t\odot\tilde{\mathbf{c}}_t && \text{细胞更新}\\
\mathbf{o}_t &= \sigma(\mathbf{W}_o[\mathbf{h}_{t-1};\mathbf{x}_t] + \mathbf{b}_o) && \text{输出门}\\
\mathbf{h}_t &= \mathbf{o}_t\odot\tanh(\mathbf{c}_t) && \text{输出}
\end{aligned}$$

每个矩阵都是 $H \times (H + d_\text{in})$ 的，即 $\mathbf{W}_f \in
\mathbb{R}^{H\times(H+d_\text{in})}$。门是一个取值在 $(0, 1)$ 内的向量，逐元素地乘到另一个量上：一个由当前输入和上一步输出设定的软开关。**遗忘门**（forget gate）决定每个已存储的值*保留*多少，输入门（input gate）决定候选值*写入*多少，输出门（output gate）决定记忆*读出*多少。$\mathbf{c}_t$ 是记忆；它在步与步之间从不被压缩，所以其分量可以超过 1。$\mathbf{h}_t$ 是输出和工作状态，被 tanh 限定在有界范围内；下一层、输出头和下一步的门看到的都是它。图 4.7 画出了这个细胞。

::: figure id=fig-04-7
LSTM 细胞。顶部一条水平线把 $\mathbf{c}_{t-1}$ 送到 $\mathbf{c}_t$，途经一个乘法节点（$\times\,\mathbf{f}_t$）和一个加法节点（$+\,\mathbf{i}_t\odot\tilde{\mathbf{c}}_t$），这条线画得较粗，并以“加性路径”突出显示。它下方四个小方框 $\sigma$、$\sigma$、tanh、$\sigma$ 从 $[\mathbf{h}_{t-1};\mathbf{x}_t]$ 计算 $\mathbf{f}_t$、$\mathbf{i}_t$、$\tilde{\mathbf{c}}_t$ 和 $\mathbf{o}_t$；作用于 $\mathbf{c}_t$ 的 tanh 再乘以 $\mathbf{o}_t$ 得到 $\mathbf{h}_t$。一条红色虚线箭头沿顶线从右向左，标注为
$\partial\mathbf{c}_t/\partial\mathbf{c}_{t-1} = \operatorname{diag}(\mathbf{f}_t)$。
:::

### 细胞路径为什么能保住梯度

对细胞更新关于 $\mathbf{c}_{t-1}$ 求导。项 $\mathbf{f}_t\odot\mathbf{c}_{t-1}$ 直接依赖于它；各个门和候选值则通过 $\mathbf{h}_{t-1} = \mathbf{o}_{t-1}\odot\tanh(\mathbf{c}_{t-1})$ 依赖于它。记 $\mathbf{W}_f^{h}$ 为 $\mathbf{W}_f$ 中与 $\mathbf{h}_{t-1}$ 相乘的那个 $H\times H$ 块（其余矩阵同理），由乘积法则和链式法则得

$$\frac{\partial\mathbf{c}_t}{\partial\mathbf{c}_{t-1}}
= \operatorname{diag}(\mathbf{f}_t)
+ \Big[\operatorname{diag}(\mathbf{c}_{t-1})\frac{\partial\mathbf{f}_t}{\partial\mathbf{h}_{t-1}}
+ \operatorname{diag}(\tilde{\mathbf{c}}_t)\frac{\partial\mathbf{i}_t}{\partial\mathbf{h}_{t-1}}
+ \operatorname{diag}(\mathbf{i}_t)\frac{\partial\tilde{\mathbf{c}}_t}{\partial\mathbf{h}_{t-1}}\Big]
\frac{\partial\mathbf{h}_{t-1}}{\partial\mathbf{c}_{t-1}},$$

其中，例如 $\partial\mathbf{f}_t/\partial\mathbf{h}_{t-1} =
\operatorname{diag}(\mathbf{f}_t\odot(1-\mathbf{f}_t))\,\mathbf{W}_f^{h}$，以及
$\partial\mathbf{h}_{t-1}/\partial\mathbf{c}_{t-1} =
\operatorname{diag}(\mathbf{o}_{t-1}\odot(1-\tanh^2\mathbf{c}_{t-1}))$。方括号里的各项与朴素循环的雅可比矩阵形状相同，都是一个权重块乘以饱和函数的导数，它们的长连乘会因第 4 节所述的原因而消失。

第一项则不同。从第 $t$ 步到第 $T$ 步只跟踪这一项：

$$\frac{\partial\mathbf{c}_T}{\partial\mathbf{c}_t}\bigg|_\text{直接}
= \prod_{k=t+1}^{T}\operatorname{diag}(\mathbf{f}_k), \qquad
\frac{\partial\mathcal{L}}{\partial\mathbf{c}_t}\bigg|_\text{直接}
= \mathbf{f}_{t+1}\odot\mathbf{f}_{t+2}\odot\cdots\odot\mathbf{f}_T\odot
\frac{\partial\mathcal{L}}{\partial\mathbf{c}_T}.$$

这个乘积是对角的：单元 $j$ 的梯度在第 $k$ 步乘以 $f_{k,j}$，除此之外不乘任何东西。这里没有矩阵的幂，所以不会有小于 1 的特征值把信号缩小；没有 tanh 的导数，所以饱和不起作用；每个因子都是网络根据数据逐步设定的门值，在单元 $j$ 需要记住时保持在 1 附近，不需要时就降下来。当 $\mathbf{f}\approx\mathbf{1}$ 时，梯度可以原样穿过许多步：这就是 Hochreiter 和 Schmidhuber 所说的**恒定误差传送带**（constant error carousel）。

总梯度是所有路径之和，间接路径仍然可能消失；它们负责短程的功劳分配。细胞路径负责长程的功劳分配，告诉网络某个遥远的输入曾经起过作用。这与[模块 03](module_03_ZH.html) 中跨越深度的残差连接是同一种补救：一条在每一级都不经过权重矩阵的梯度路径。

::: worked title="标量状态下的一步 LSTM"
取 $H = 1$、$c_{t-1} = 1.0$，预激活分别为 2（遗忘门）、0（输入门）、1（候选值）和 0（输出门）。

各门：$f_t = \sigma(2) = 1/(1+e^{-2}) = 0.8808$；$i_t = \sigma(0) = 0.5$；
$\tilde c_t = \tanh(1) = 0.7616$；$o_t = \sigma(0) = 0.5$。

细胞更新：$c_t = 0.8808\cdot 1.0 + 0.5\cdot 0.7616 = 0.8808 + 0.3808 = 1.2616$。

输出：$h_t = 0.5\cdot\tanh(1.2616) = 0.5\cdot 0.8515 = 0.4258$。

沿直接路径，$\partial c_t/\partial c_{t-1} = f_t = 0.8808$。细胞现在存着一个大于 1 的值，这是受 tanh 限定的状态做不到的；输出门读出了其中约三分之一。
:::

### 简史

Hochreiter 和 Schmidhuber 1997 年的 LSTM 有输入门和输出门，以及一个权重固定为 1 的细胞自连接：也就是那条传送带，但无法清空，所以在很长的数据流上细胞会被填满。遗忘门由 Gers、Schmidhuber 和 Cummins（2000）加入；上面的形式就是如今人人所说的“LSTM”。窥视孔连接（peephole connection，即也读取 $\mathbf{c}$ 的门）不久之后出现，如今已很少使用。Greff 等人（2017）比较了八种变体，发现没有一种显著优于标准细胞；最重要的是遗忘门和输出激活函数。

### 遗忘门偏置

在初始化时权重很小，所以每个遗忘门都位于 $\sigma(b_f)$ 附近：这是每一步的默认记忆。经过 $n$ 步，细胞路径把梯度乘以约 $\sigma(b_f)^n$；对 $n$ 解 $\sigma(b_f)^n = 0.5$，就得到默认记忆的**半衰期**（half-life）：

$$n_{1/2} = \frac{\ln 0.5}{\ln\sigma(b_f)}.$$

由于 $1-\sigma(b) = 1/(1+e^{b})$，保留率为 $f = \sigma(b_f)$ 的记忆，其时间常数 $1/(1-f)$ 恰好是 $1 + e^{b_f}$ 步：偏置每增加一个单位，时间尺度约乘以 $e$。当 $b_f = 0$ 时，门从 0.5 起步，半衰期只有一步。来自 20 步之外目标的梯度到达时只剩原来的百万分之一，网络必须从这样的信号中发现记忆是值得的；它可能在最初的一千次更新里把一切都忘掉。

::: worked title="20 步和 100 步上的记忆乘积"
计算 $f = \sigma(b_f)$，再计算 $f^{20}$、$f^{100}$ 和半衰期 $\ln 0.5/\ln f$：

| $b_f$ | $f = \sigma(b_f)$ | $f^{20}$ | $f^{100}$ | 半衰期（步） |
|---|---|---|---|---|
| 0 | 0.5000 | $9.5\times10^{-7}$ | $7.9\times10^{-31}$ | 1.0 |
| 1 | 0.7311 | $1.9\times10^{-3}$ | $2.5\times10^{-14}$ | 2.2 |
| 2 | 0.8808 | 0.079 | $3.1\times10^{-6}$ | 5.5 |
| 3 | 0.9526 | 0.378 | $7.8\times10^{-3}$ | 14.3 |
| 4 | 0.9820 | 0.696 | 0.163 | 38.2 |
| 5 | 0.9933 | 0.874 | 0.511 | 103 |

手算验证一行：$\sigma(3) = 1/(1+e^{-3}) = 1/1.0498 = 0.9526$；$\ln 0.9526 = -0.04859$；
$20\times(-0.04859) = -0.9717$，$e^{-0.9717} = 0.378$；半衰期为
$-0.6931/(-0.04859) = 14.3$ 步。把 $b_f$ 从 0 调到 3，滞后 20 步处的梯度因子就从 $10^{-6}$ 变成了 0.4。
:::

训练会改变偏置，但起始值决定了早期能有哪些梯度到达。Jozefowicz、Zaremba 和 Sutskever（2015）发现，遗忘偏置取 1 就弥补了他们所测得的 LSTM 与 GRU 之间的大部分差距。Chrono 初始化（Tallec 和 Ollivier，2018）根据依赖长度的预期范围，按时间常数关系设定每个单元的 $b_f$：要记住约 $T$ 步，取 $b_f \approx \ln(T-1)$。把遗忘偏置设为 1 或 2，是最有用的一条 LSTM 技巧。

### 在 PyTorch 中

`nn.LSTM` 把四个门的权重在每一层堆成一个矩阵：`weight_ih_l0` 的形状为 `(4H, d_in)`，`weight_hh_l0` 的形状为 `(4H, H)`，顺序是 **i、f、g、o**，其中 `g` 是 PyTorch 对候选值 $\tilde{\mathbf{c}}$ 的称呼。偏置向量有两个，`bias_ih_l0` 和 `bias_hh_l0`，二者直接相加，所以实际的遗忘偏置是 `bias_ih_l0[H:2*H] + bias_hh_l0[H:2*H]`。每个权重和偏置都从 $U(-1/\sqrt{H}, 1/\sqrt{H})$ 初始化，所以默认遗忘偏置约为 0：正是表中半衰期为一步的情形。设置它只需几行：

```python
import torch
import torch.nn as nn

def set_forget_bias(lstm: nn.LSTM, value: float) -> None:
    """Make the effective forget-gate bias equal `value` in every layer and direction."""
    H = lstm.hidden_size
    with torch.no_grad():
        for name, p in lstm.named_parameters():
            if name.startswith("bias_ih"):
                p[H:2 * H].fill_(value)      # gates are stacked i, f, g, o
            elif name.startswith("bias_hh"):
                p[H:2 * H].zero_()           # the two bias vectors add

lstm = nn.LSTM(input_size=1, hidden_size=32, batch_first=True)
set_forget_bias(lstm, 1.0)
```

### 参数量与计算量

四个 $H\times(H+d_\text{in})$ 的矩阵加四个偏置，共 $4H(H + d_\text{in} + 1)$ 个参数；PyTorch 的两个偏置向量使它变成 $4H(H + d_\text{in}) + 8H$，是同宽度朴素循环层的四倍。每一步计算四次大小为 $H\times(H + d_\text{in})$ 的矩阵-向量乘积：把一次乘加算作两次运算，每条序列每一步约 $8H(H + d_\text{in})$ 次浮点运算。

::: worked title="数一个 LSTM 的参数"
`nn.LSTM(1, 32)`：$4\cdot 32\cdot(32 + 1) + 8\cdot 32 = 4{,}224 + 256 = 4{,}480$。

两层预测器 `nn.LSTM(1, 32, num_layers=2)`：第二层读取第一层 32 维的输出，所以它有 $4\cdot 32\cdot(32 + 32) + 256 = 8{,}192 + 256 = 8{,}448$ 个参数。整个堆叠合计 $4{,}480 + 8{,}448 = 12{,}928$；一个 `Linear(32, 1)` 输出头再加 $32 + 1 = 33$，得到 $12{,}961$，也就是[实验 3](#lab3) 打印的数字。
:::

### 细胞学到了什么

Karpathy、Johnson 和 Fei-Fei（2016）检查了在文本和代码上训练的字符级 LSTM，发现少数细胞跟踪着可解释的量，例如在一行中的位置，或是否处于引号之内：一个保持在 1 附近的遗忘门，加上一个遇到某个字符就打开的输入门，让这些都很容易实现。大多数细胞则找不到这样的解读。

### 实验展示了什么

在[实验 2](#lab2) 中，遗忘偏置为 0 时，LSTM 的梯度随滞后衰减的方式与朴素网络相同；偏置为 3 或 5 时，梯度比值一直到滞后 100 都保持在约 0.14 到 0.4 之间。在[实验 1](#lab1) 的维护日志上，经过 2,500 次更新后，闭合标签（位于开始标签之后 18 到 36 个字符处）的正确率，朴素 RNN 为 14% 到 25%，接近随机猜测的 12.5%；遗忘偏置为 0 和 1 的 LSTM 为 64% 到 96%（实验 2 的运行和另一个随机种子）。两个 LSTM 中哪个领先随种子而变；门控细胞与朴素细胞之间的差距则不变。

::: keyidea
沿 LSTM 的细胞路径，梯度在每一步乘以遗忘门，这是一个由网络选择、可以保持在 1 附近的数，而不是一个固定矩阵和一个 tanh 导数。
:::

::: check
沿 LSTM 的直接路径，$\partial\mathbf{c}_t/\partial\mathbf{c}_{t-1}$ 是什么？它为什么不会像 $\mathbf{W}_h^n$ 那样消失？
:::

::: answer
它是 $\operatorname{diag}(\mathbf{f}_t)$：由网络逐步、逐单元设定、并且可以保持在 1 附近的门值。其中既没有 tanh 的导数，也没有被反复求幂的固定矩阵。
:::

::: check
你把 `nn.LSTM` 的 `bias_ih_l0[H:2*H]` 设为 1，`bias_hh_l0` 保持默认。实际的初始遗忘偏置是多少？
:::

::: answer
约为 1，再加上一个从 $U(-1/\sqrt{H}, 1/\sqrt{H})$ 抽取的逐单元小量，因为两个偏置向量相加。要让它恰好为 1，还要把 `bias_hh_l0[H:2*H]` 置零。
:::

## GRU、堆叠与双向网络 {#s6}

Cho 等人（2014）的**门控循环单元**（gated recurrent unit，GRU）用一个状态和两个门构建了同样的加性路径。本节先把它与 LSTM 比较，再讨论组合循环层的两种方式：在深度上堆叠，以及在两个方向上运行。

### GRU

$$\begin{aligned}
\mathbf{z}_t &= \sigma(\mathbf{W}_z[\mathbf{h}_{t-1};\mathbf{x}_t] + \mathbf{b}_z) && \text{更新门}\\
\mathbf{r}_t &= \sigma(\mathbf{W}_r[\mathbf{h}_{t-1};\mathbf{x}_t] + \mathbf{b}_r) && \text{重置门}\\
\tilde{\mathbf{h}}_t &= \tanh(\mathbf{W}[\mathbf{r}_t\odot\mathbf{h}_{t-1};\mathbf{x}_t] + \mathbf{b}) && \text{候选值}\\
\mathbf{h}_t &= (1-\mathbf{z}_t)\odot\mathbf{h}_{t-1} + \mathbf{z}_t\odot\tilde{\mathbf{h}}_t && \text{更新}
\end{aligned}$$

更新门逐单元决定把状态向候选值移动多远。重置门决定候选值能看到多少旧状态；当 $\mathbf{r}_t\approx\mathbf{0}$ 时，单元只从输入重新开始。像[第 5 节](#s5)那样对最后一行求导，得到
$\partial\mathbf{h}_t/\partial\mathbf{h}_{t-1} = \operatorname{diag}(1-\mathbf{z}_t)$，再加上经过各门和候选值的项：沿直接路径，梯度每步乘以 $1-z_{k,j}$，只要让更新门保持在 0 附近，它就保持在 1 附近。这是 LSTM 的技巧，只是用一个状态代替了两个。图 4.9 画出了这个细胞。

::: figure id=fig-04-9
GRU 细胞，画法与图 4.7 相同。$\mathbf{h}_{t-1}$ 进入后分成两路：一路被 $(1-\mathbf{z}_t)$ 缩放；另一路经过重置门 $\mathbf{r}_t$ 进入 tanh 候选值 $\tilde{\mathbf{h}}_t$，再被 $\mathbf{z}_t$ 缩放。两路相加得到 $\mathbf{h}_t$。$(1-\mathbf{z}_t)$ 这一路作为加性路径突出显示。
:::

::: pitfall
$\mathbf{z}$ 的符号约定并不统一。Cho 等人（2014）和 PyTorch 写作
$\mathbf{h}_t = (1-\mathbf{z}_t)\odot\mathbf{n}_t + \mathbf{z}_t\odot\mathbf{h}_{t-1}$，所以他们的 $\mathbf{z}$ 表示*保留*；本模块用它表示*更新*。二者是同一个模型，只是把 $\mathbf{z}$ 换成了 $1-\mathbf{z}$，但用来偏向记忆的偏置必须取对符号：在 PyTorch 中，*正*的更新门偏置偏向记忆。PyTorch 还把重置门放在隐状态矩阵乘法之后，$\mathbf{n}_t = \tanh(\mathbf{W}_{in}\mathbf{x}_t +
\mathbf{b}_{in} + \mathbf{r}_t\odot(\mathbf{W}_{hn}\mathbf{h}_{t-1} + \mathbf{b}_{hn}))$，这是一个小变体；它的门按 r、z、n 的顺序堆叠。
:::

### 工程视角：一个学出来的低通滤波器

让更新门保持为常数 $z$。那么 $h_t = (1-z)\,h_{t-1} + z\,\tilde h_t$ 就是候选值的指数移动平均，即一阶低通滤波器的离散形式。它的冲激响应按 $(1-z)^n$ 衰减，所以其记忆半衰期为 $\ln 0.5/\ln(1-z)$ 步；若采样间隔为 $\Delta t$，则由 $1 - z = e^{-\Delta t/\tau}$ 定义其时间常数 $\tau$。GRU 就是一组这样的滤波器，其时间常数由输入逐单元、逐步设定：一个单元可以在平稳的一段里缓慢积分，然后在门打开时迅速跳到新值。

::: worked title="泄漏积分器"
更新门恒为 $z = 0.1$ 时，每一步保留状态的 $1 - z = 0.9$。半衰期为 $\ln 0.5/\ln 0.9 = -0.6931/(-0.10536) = 6.58$ 步；20 步之后剩下原值的 $0.9^{20} = 0.12$。在 100 Hz 采样率下，这是一个时间常数为
$\tau = -0.01/\ln 0.9 = 0.095$ s 的滤波器。
:::

### 参数量，以及证据

三个块而不是四个，每块一个偏置时共 $3H(H + d_\text{in} + 1)$ 个参数，在 PyTorch 中为 $3H(H + d_\text{in}) + 6H$：是同宽度 LSTM 的四分之三，每步的计算量也省下同样的比例。

::: worked title="GRU 对 LSTM"
`nn.GRU(1, 32)`：$3\cdot 32\cdot 33 + 6\cdot 32 = 3{,}168 + 192 = 3{,}360$ 个参数，而 `nn.LSTM(1, 32)` 为 $4{,}480$。
:::

在大多数任务上，两者不相上下。Chung 等人（2014）发现，在音乐和语音建模上 GRU 与 LSTM 相当，两者都远远领先朴素的 tanh 循环。Jozefowicz、Zaremba 和 Sutskever（2015）搜索了数千种循环架构，发现把 LSTM 的遗忘偏置设为 1 就弥补了 LSTM 与 GRU 之间的差距。在需要精确计数或长时间精确记忆的地方，LSTM 仍占优势：Weiss、Goldberg 和 Yahav（2018）表明，LSTM 能学会 $a^n b^n$ 这类计数语言，而 GRU 在实践中学不会，因为 LSTM 无界的细胞可以充当计数器，而 GRU 的状态只是在有界的值之间插值。实用的规则是：默认用 LSTM，参数或速度吃紧时用 GRU。朴素的 tanh 循环是教科书里的模型；实践中所说的“RNN”指的是门控细胞。

### 堆叠

循环层像 MLP 的各层一样堆叠：第 $l$ 层读取第 $l-1$ 层的整个隐状态序列 $\mathbf{h}^{(l-1)}_1, \dots, \mathbf{h}^{(l-1)}_T$。典型的是两到四层，层间加 dropout（`nn.LSTM` 的 `dropout` 参数做的正是这件事，只有一层时它什么也不做）。更深的堆叠在层间加残差连接后训练得更好，
$\mathbf{h}^{(l)}_t \leftarrow \mathbf{h}^{(l)}_t + \mathbf{h}^{(l-1)}_t$：Google 2016 年的翻译系统使用了带残差连接的八层 LSTM 堆叠（Wu 等人，2016）。

### 双向网络

**双向循环神经网络**（bidirectional RNN，Schuster 和 Paliwal，1997）在同一序列上运行两个循环层，一个向前、一个向后，并把它们的状态拼接起来，
$[\overrightarrow{\mathbf{h}}_t; \overleftarrow{\mathbf{h}}_t]$，宽度为 $2H$，这样每个位置都能看到它的过去和未来。这正是序列标注所需要的（一段录音的第 340 秒是否为故障起始，取决于它后面的内容），它也是[第 11 节](#s11)注意力模型的标准编码器。但它不能用于预测、监测或任何在线任务：反向方向读过了未来，而在部署时未来尚不存在。图 4.10 展示了一个堆叠的双向网络。

::: figure id=fig-04-10
一个跨五个时间步的堆叠双向网络：两层，每层有一行前向细胞（箭头从左到右）和一行反向细胞（箭头从右到左）。每一步把两个状态拼接起来（一个小的连接符号），再向上传给下一层。右侧，一个“预测 $x_{t+1}$”方框上打着红叉，说明文字为“反向一行已经读过 $x_{t+1}$”。
:::

::: worked title="一个双向两层 LSTM"
`nn.LSTM(16, 64, num_layers=2, bidirectional=True)`，$H = 64$。

第 1 层在每个方向上读取 16 个输入：
$4\cdot 64\cdot(16 + 64) + 8\cdot 64 = 20{,}480 + 512 = 20{,}992$ 每个方向，所以共
$2\times 20{,}992 = 41{,}984$。

第 2 层读取拼接后的输出，宽度为 $2H = 128$：
$4\cdot 64\cdot(128 + 64) + 512 = 49{,}152 + 512 = 49{,}664$ 每个方向，所以共
$2\times 49{,}664 = 99{,}328$。

合计 $41{,}984 + 99{,}328 = 141{,}312$。第二层的开销是第一层的两倍多，因为双向性使它的输入宽度翻了一倍。
:::

在建立于双向层之上的多对一模型中，概括整个序列的状态是*真实最后一步*的前向状态和*第一步*的反向状态。那个诱人的选择，即拼接输出的最后一个位置，错了两次：它的反向一半只看到了一个 token，而如果 batch 经过填充，它的前向一半还跑过了填充部分。使用打包序列时（[第 7 节](#s7)），PyTorch 返回的 `h_n` 恰好存着正确的两个状态，`h_n[-2]`（前向，最后一层）和 `h_n[-1]`（反向，最后一层）。[实验 4](#lab4) 的编码器用的就是它们。

::: check
双向 GRU 能预测明天的轴承温度吗？
:::

::: answer
不能。它的反向传递读取的是被预测时刻之后的输入；训练时这些输入是有的，模型也学会了利用它们，但在部署时它们还不存在。
:::

::: check
在双向的多对一模型中，哪些状态概括了整个序列？
:::

::: answer
前向方向在真实最后一步的状态，以及反向方向在第一步的状态。输出的最后一个位置，其反向一半只看到了一个 token。
:::

## 循环网络的训练实践 {#s7}

训练不起来的循环网络，通常是出于少数几个原因之一：填充泄漏进了损失或状态，状态被带到了不该带去的地方，使用了默认初始化，dropout 放错了位置，或者没有做裁剪。本节汇集了避免这些问题的做法。优化器和一般的调试方法属于[模块 02](module_02_ZH.html)；下面的内容是循环网络所特有的。

### 变长序列：填充、掩码、打包

把不同长度的序列组成 batch，最简单的办法是把每条序列用零**填充**（pad）到 batch 中的最大长度，并保留一个**掩码**（mask），真实步上为 1，填充处为 0。此后每个需要求和的逐步量都必须加掩码；对损失来说只需一行：

```python
loss = (per_step_loss * mask).sum() / mask.sum()    # mean over real steps only
```

掩码还必须作用到其他任何对位置求和的量上，例如[第 11 节](#s11)的注意力分数。掩码使损失正确，但每个填充步仍然要计算。**打包**（packing）则不然：PyTorch 的 `pack_padded_sequence` 重新安排 batch，使每个时间步只计算仍在运行的序列，`pad_packed_sequence` 再把输出变回填充过的张量，每条序列长度之后为零。图 4.11 画出了一个填充后的 batch、它的掩码以及它的打包形式。

对双向层来说，打包是必需的，而不仅仅是为了省计算。反向方向必须从每条序列的真实最后一步开始；在填充而未打包的 batch 上，它先读到一串零，所以它在真实 token 上的状态取决于这个 batch 碰巧需要多少填充。另外两个习惯也有帮助。**分桶**（bucketing，把长度相近的序列放进同一个 batch）可以减少花在填充上的浪费。对于多对一任务，要取每条序列真实最后一步的状态，而不是最后一列：

```python
from torch.nn.utils.rnn import pack_padded_sequence, pad_packed_sequence

lengths = torch.tensor([50, 120, 200])
packed = pack_padded_sequence(x, lengths, batch_first=True, enforce_sorted=False)
out_packed, (h_n, c_n) = lstm(packed)                 # x: (3, 200, d_in), padded
out, _ = pad_packed_sequence(out_packed, batch_first=True)
last = out[torch.arange(len(lengths)), lengths - 1]  # equals h_n[-1] for one direction
```

::: worked title="填充的代价"
长度为 50、120 和 200 的三条序列填充到 200，占据 $3\times 200 = 600$ 个位置，其中 $50 + 120 + 200 = 370$ 个是真实的。其余 230 个，即 $230/600 = 38\%$ 的计算量，花在了填充上。若用不加掩码的平均损失，这 230 个位置会被当作数据来训练（模型学会在零之后预测零），并稀释短序列的真实步。用加掩码的损失，370 个真实步承担全部权重；再加上打包，网络也只执行这 370 步。
:::

::: figure id=fig-04-11
上：一个填充后的 batch，画成 $3\times 8$ 的网格（长度为 2、5 和 8 格，按比例对应 50、120 和 200 步）；真实格子填色，填充格子画斜线，旁边是由 1 和 0 组成的掩码矩阵。中：同一个 batch 按时间步打包，画成高度递减的列（活跃序列数依次为 3、3、2、2、2、1、1、1）。下：一条长数据流被切成若干块用于有状态训练，状态箭头从一块传到下一块，每个边界处有一个“detach”标记，数据流末尾有一个“reset”标记。
:::

### 状态处理

**无状态**（stateless）训练在每条序列开始时把状态重置为零：这是默认做法，只要序列是相互独立的样本，它就是对的。**有状态**（stateful）训练把一条长数据流切成连续的块，并把每块的最终状态带入下一块，这就是截断的随时间反向传播（[第 3 节](#s3)）。要遵守三条规则。在每个块边界处分离状态（`h = h.detach()`）。在不同数据流之间以及评估之前重置状态。对每一块都把数据流 $i$ 放在 batch 的第 $i$ 行，使第 $i$ 行的状态属于在那里延续的数据，[实验 1](#lab1) 就是这样做的（图 4.11，下）。把状态带过互不相关的序列，教给模型的是 batch 的顺序，而不是数据。

### 初始化

把 $\mathbf{W}_h$ 初始化为正交矩阵（[第 4 节](#s4)）。把 LSTM 的遗忘门偏置设为 1 或 2（[第 5 节](#s5)）。让输出权重取小值，使初始损失对 $V$ 个类别约为 $\ln V$，对回归约为目标的方差；第一个损失如果远离这个值，就是 bug 最早的信号。

### 正则化

dropout 放在输入上和堆叠的层之间。在循环连接上，每一步都用新的掩码，会在 100 步中把状态打穿一百次，长程依赖就丢失了。在那里有效的形式是**变分 dropout**（variational dropout，Gal 和 Ghahramani，2016）：每条序列一个掩码，在每一步重复使用。另一种做法是丢弃循环*权重*，即对 $\mathbf{W}_h$ 做 DropConnect，如 Merity、Keskar 和 Socher（2018）的 AWD-LSTM。权重衰减照常使用。早停需要一个验证集划分，小语料最需要它：在六首莎士比亚十四行诗（3,715 个字符；实验 1“动手试试”的第 3 项）上训练时，在编写本模块时做的一次运行中，实验 1 的网络约在 250 次更新后达到最低验证损失，此后验证损失上升，而训练损失继续下降。

### 归一化

只用训练集的统计量对输入逐通道归一化（[模块 01](module_01_ZH.html)）；当水平发生漂移时，按窗口归一化（[第 8 节](#s8)）。在细胞内部，层归一化（Ba、Kiros 和 Hinton，2016）对每一步的预激活跨单元归一化，在激活值随长序列漂移的地方有帮助。批归一化在时间维上用起来很别扭：它的统计量必须按时间步分别保存，而序列的长度又各不相同。

### 裁剪、优化器与速度

始终在 1 到 5 处裁剪全局梯度范数（[第 4 节](#s4)），并记录裁剪之前的范数：上升的趋势往往预示着爆炸，而当损失变成 NaN 时，这份日志是第一个要看的东西。对小型循环模型，学习率在 $10^{-3}$ 到 $3\times10^{-3}$ 的 Adam 或 AdamW 是很好的默认选择。在 GPU 上，`nn.LSTM` 和 `nn.GRU` 调用融合的 cuDNN kernel，比在 Python 中循环调用 `nn.LSTMCell` 快得多。在 CPU 上，小型循环模型的耗时主要在逐步的开销而不是算术上，所以要把许多序列放进一个 batch：大小为 64 的 batch，开销远小于大小为 1 的 batch 的 64 倍。

### 调试清单

1. 把初始损失与 $\ln V$（或目标方差）比较。
2. 过拟合一个小 batch。如果模型做不到，bug 就在模型或损失里。
3. 用 float64 和中心差分对一个很小的模型做梯度检验（[实验 1](#lab1)）。
4. 画出梯度范数随滞后的变化（[实验 2](#lab2)）；如果在你的任务所需的滞后处它是 $10^{-10}$，再怎么训练也找不到那个依赖。

::: check
一个双向编码器在补零的 batch 上训练，没有打包，然后在未填充的输入上测试，短输入突然失败了。为什么？
:::

::: answer
训练时，反向方向先读到填充，再读到真实 token，所以它在短输入上的状态都是跟在一串零之后的状态。测试时它从一个真实 token 开始，这是它从未见过的状态。要打包序列，使反向传递从每条序列的真实最后一步开始（[实验 4](#lab4)）。
:::

::: check
dropout 放在 LSTM 的什么地方不会损害它的记忆？
:::

::: answer
放在输入上和堆叠的层之间。在循环连接上只能用变分形式，即在一条序列的每一步使用同一个掩码。

## 诚实地做时间序列预测 {#s8}

预测是循环网络在工程上最常见的用途：下一小时的轴承温度，下一分钟的振动信号。它也是最容易报告出毫无意义的数字的地方。本节讨论让这个数字值得信任的评估纪律，以及那段显而易见的代码会犯的一个错误。

### 问题设定：窗口与预测步长

对序列 $x_1, \dots, x_N$，以步长 1 沿它滑动一个长度为 $W$ 的**窗口**（window）：输入为 $x_{t-W+1}, \dots, x_t$，单步预测的目标为 $x_{t+1}$，**预测步长**（horizon）为 $h$ 时目标为 $x_{t+1}, \dots, x_{t+h}$。其他测量通道，以及事先已知的**外生**（exogenous）输入（工况、设定值、生产计划），成为额外的输入通道，所以一个 batch 的形状为 $(B, W, \text{通道数})$。

### 时间上的四种泄漏

只有当每个预测都不使用在那一时刻尚不存在的任何东西时，预测才是诚实的。有四种泄漏会破坏这一点。

1. **打乱的重叠窗口。** 相邻窗口共享 $W - 1$ 个值。随机打乱并划分，几乎每个测试窗口在训练集中都有一个近似副本：所谓“预测”其实是插值。
2. **用整条序列做归一化。** 在训练集和测试集上一起计算的统计量，会告诉模型测试数据落在哪里。
3. **用未来数据计算的特征。** 中心移动平均、前向-后向滤波器或双向层（[第 6 节](#s6)）都会读取 $t$ 之后的值。
4. **在测试期上做选择。** 根据测试误差挑选超参数或停止的轮次，会让测试误差变成训练误差。

这四种泄漏都违反了[模块 01](module_01_ZH.html) 的规则：按部署时将是新的那个单位来划分。对预测器来说，这个单位就是未来。

::: worked title="打乱划分泄漏了多少"
取 $W = 64$、步长 1，每个窗口与每个相邻窗口共享 64 个值中的 63 个。把 3,000 个这样的窗口按 80/20 随机划分。一个测试窗口在训练集中没有共享 63 个值的近似副本，当且仅当它的两个相邻窗口也都落在测试集中，概率约为 $0.2\times 0.2 = 0.04$。所以约 96% 的测试窗口都有这样的副本。最近的四个窗口（共享 62 或 63 个值）都不在训练集中的概率是 $0.2^4 = 0.0016$。
:::

### 前向滚动验证

尊重时间的替代方案是**前向滚动验证**（walk-forward validation），也叫**滚动起点评估**（rolling-origin evaluation），参见 Tashman（2000）以及 Hyndman 和 Athanasopoulos 的 *Forecasting: Principles and Practice*。在某个预测起点之前的全部数据上训练（用扩展窗口；如果旧数据已不再有代表性，则用滑动窗口），在它之后的一个数据块上验证，把起点向前移，重新拟合，如此重复。当 $h > 1$ 时，在最后一个训练目标与第一个验证输入之间至少留出 $h$ 步的间隔。报告各折上的均值和离散程度（图 4.12）。

上：一条时间轴，四个前向滚动折纵向叠放；每一折中依次是一个蓝色的扩展训练块、一小段灰色间隔，然后是一个橙色验证块，起点逐折向右移动。下，用红色划掉：一个打乱的划分，蓝色和橙色窗口沿同一条轴交错排列，其中两个重叠窗口被放大，显示它们共享的 63 个样本。

### 基线，以及一个内含基线的分数

一个误差值，如果没有同一数据上平凡预测器的误差作对照，就毫无意义。

- **朴素预测**（naive，即持续性预测）：$\hat x_{t+h} = x_t$，“明天等于今天”；在短预测步长上很强。
- **季节性朴素预测**（seasonal naive）：取早一个周期 $m$ 的同一相位，当 $h \le m$ 时 $\hat x_{t+h} = x_{t+h-m}$；对周期信号在长预测步长上很强。
- **线性自回归**（linear autoregression）：在同样的窗口上对目标做最小二乘回归（[模块 01](module_01_ZH.html)）。它是最强的廉价基线，也是带高斯噪声的线性系统的最优预测器；一个打不过它的网络，什么非线性的东西都没有找到。
- **训练均值**：一个没学到任何动态的模型会向它漂移。

**平均绝对标度误差**（mean absolute scaled error，MASE；Hyndman 和 Koehler，2006）把一个基线内置到分数中：

$$\text{MASE} = \frac{\text{测试期的 MAE}}
{\frac{1}{N-1}\sum_{t=2}^{N}|x_t - x_{t-1}|},$$

其中分母是单步朴素预测在 $N$ 个训练值上的样本内 MAE（或季节性朴素预测的样本内 MAE，滞后为 $m$）。它没有单位，MASE $< 1$ 意味着模型胜过朴素预测的样本内精度。

::: worked title="朴素预测对季节性朴素预测，周期为 4"
训练值为 $(10, 14, 12, 8, 11, 15, 13, 9)$，周期 $m = 4$；接下来四个真实值为
$(12, 16, 14, 10)$。

朴素预测：每个预测值都是 9。误差为 $3, 7, 5, 1$；MAE $= 16/4 = 4.0$。

季节性朴素预测：预测值复制最后一个周期，$(11, 15, 13, 9)$。误差为 $1, 1, 1, 1$；MAE
$= 1.0$。

标度：样本内单步朴素预测的误差为 $|14-10|, |12-14|, \dots, |9-13| =
4, 2, 4, 3, 4, 2, 4$，均值为 $23/7 = 3.286$。

按此标度计算 MASE：朴素预测 $4.0/3.286 = 1.22$，季节性朴素预测 $1.0/3.286 = 0.30$。知道周期的季节性朴素预测，以四倍的差距获胜。
:::

### 水平漂移时按窗口归一化

用训练统计量做 z 分数标准化避免了泄漏 2，但当序列发生漂移时就会失效。网络学到的是它见过的输入范围上的一个映射；在它从未见过的水平上，它的饱和单元会变平，它也不会像线性模型那样外推。那段显而易见的代码恰恰犯了这个错误。

::: worked title="输给持续性预测的 LSTM 预测器"
序列为 $\sin t + 0.05t$ 加上标准差为 0.1 的高斯噪声，每 0.1 个时间单位采样一次，共 4,000 个点：前 3,000 个用于训练，其余用于测试，用训练统计量做 z 分数标准化，窗口 $W = 64$，一个两层的 `nn.LSTM(1, 32, num_layers=2)`（连同输出头共 12,961 个参数），用带裁剪的 AdamW 训练 15 个轮次。每一步看上去都很仔细。在编写本模块时，用随机种子 0 做的一次运行给出：

LSTM 的测试 RMSE 为 1.075；朴素预测为 0.155。比“明天等于今天”差七倍。

原因在于漂移。归一化之后，训练输入的范围是 $-1.92$ 到 $1.92$，测试输入是 $1.46$ 到 $3.10$。测试期的大部分落在网络从未见过的水平上，在那里它的预测偏低：以序列本身的单位计，平均误差为 $-0.87$。

修正办法：从每个窗口的输入中减去该窗口的最后一个值，预测变化量，再把这个值加回去。同一个模型于是得到约 0.12 到 0.14 的分数（取决于随机种子），而朴素预测为 0.155。在同样的窗口上做最小二乘线性自回归，得分为 0.099，已达噪声下限（除非碰巧，没有任何单步预测能低于噪声的标准差 0.1）。对正弦加漂移加噪声的信号，线性模型才是合适的工具。[实验 3](#lab3) 在一个同样带漂移的非线性信号上运行同一个模型：它在那里也输给持续性预测（RMSE 0.43 对 0.36，平均误差 $-0.32$），修正后降到 0.13，而在那个信号上，LSTM 相对线性模型确实有所贡献。
:::

改动只是 `forward` 中的三行：

```python
    def forward(self, x):                        # x: (batch, W, 1)
        last = x[:, -1:, :]                      # each window's last value, (batch, 1, 1)
        out, _ = self.lstm(x - last)             # the network sees shape, not level
        return self.head(out[:, -1]).squeeze(-1) + last[:, 0, 0]
```

对序列做差分能起到同样的作用，可逆实例归一化（reversible instance normalisation，RevIN；Kim 等人，2022）也可以：它用每个输入窗口自身的均值和标准差对该窗口归一化，并在输出上做逆变换。有多条序列时，用每条序列自己的统计量对它归一化。

### 多步预测：递归还是直接

超过一步时有两种策略（Ben Taieb 等人 2012 对二者做了比较）。**递归**（recursive）：反复迭代一个单步模型，把每个预测值追加到窗口中。它的误差会累积，因为它把自己的错误当作输入读入：这是[第 10 节](#s10)中暴露偏差在预测问题上的形式。**直接**（direct）：每个预测步长一个模型，或一个有 $h$ 个输出的网络，从观测到的窗口一次预测全部步长；它从不读取自己的预测。对于窗口很长的最小二乘线性模型，两者几乎一致：当窗口包含系统的全部线性状态时，迭代最优的单步线性预测器就得到最优的 $h$ 步预测器，而这正是直接回归所估计的。对非线性模型，两者不同，而且常常差别很大。[实验 3](#lab3) 的第 5 步画出了两种策略的误差随预测步长的变化：递归 LSTM 在 $h = 1$ 时是最好的预测器（RMSE 0.13），而在 $h = 20$ 时比朴素预测还差（0.78 对 0.72），远远落后于直接 LSTM 和两种线性模型（约 0.55 到 0.56；两种线性策略结果一致）。

### 点预测与区间

决策通常需要知道一个预测有多可信。给网络第二个输出来表示方差，并用高斯负对数似然
$\tfrac12\ln\hat\sigma^2 + (y-\hat\mu)^2/(2\hat\sigma^2)$（`nn.GaussianNLLLoss`）训练；或者用弹球损失（pinball loss）$\max(\tau u, (\tau-1)u)$ 训练分位数输出，其中误差为
$u = y - \hat y_\tau$。两种做法都能给出[第 9 节](#s9)的阈值所需的残差尺度；但要先在留出数据上检查覆盖率。

### 神经预测器处于什么位置

截至 2026 年，保守地说：在长度适中的单条序列上，调好的经典方法（指数平滑、ARIMA）和线性模型仍然很难被超越。在 M4 竞赛（2018 年，100,000 条序列）中，纯机器学习的参赛方法表现不佳，获胜者是指数平滑与循环网络的混合模型（Makridakis、Spiliotis 和 Assimakopoulos，2020；Smyl，2020）。DeepAR（Salinas 等人，2020）这样的神经预测器，在有许多相关序列、外生输入和非线性动态的场合才显出价值，例如一组受监测的设备群。

一个预测数字的好坏，取决于它的划分和它的基线：在未来上评估，用过去做归一化，并在模型的误差旁边报告朴素预测、季节性朴素预测和线性模型的误差。
:::

::: check
你的 LSTM 预测器的验证 RMSE 是朴素预测的三分之一，用的是对重叠窗口的 80/20 随机划分。你首先检查什么？
:::

::: answer
泄漏。按时间划分（前向滚动），并且只在训练部分上计算归一化统计量。在重叠窗口下，几乎每个测试窗口在训练集中都有近似副本，所以一旦划分尊重时间，这个优势通常会缩小或消失。
:::

::: check
为什么季节性朴素预测在长预测步长上能胜过复杂的模型？
:::

::: answer
它的误差不随预测步长增长：无论 $h$ 是多少，它都复制上一个周期的同一相位。向前迭代的单步模型则把自己的误差当作输入读入，并使其累积。
:::

::: check
一个预测器的 MASE 为 0.8。这是好还是坏？
:::

::: answer
它比朴素预测的样本内误差好 20%。这是否算好，取决于该预测所服务的决策以及其他基线：如果线性自回归在同一划分上达到 0.6，这个网络就是在输。
:::
