## 本系列如何组织 {#how}

每个模块是一个约十小时的独立单元，分为五个约两小时的学习单元。每个学习单元都把阅读和动手结合在一起。

- **概念。** 写出完整数学推导的思想，使用真实数字的例题详解，图示，以及可以自己动手调整的交互演示。每一节都以一个简短问题结尾，用来检验你是否真正理解。
- **实验。** 每个模块有四到六个用 Python、NumPy 和 PyTorch 完成的动手实验。每个实验都能在笔记本电脑的 CPU 上几分钟内跑完，页面上打印的每一个输出都来自实际运行代码。
- **练习。** 十五到二十道练习，难度从 ★ 到 ★★★，每道都附完整解答，另有一套自测题。
- **论文导读。** 两到三篇关键论文，说明读什么、跳过什么，以及阅读时要回答的问题。

每个模块开头都有一份学习计划，列出各个学习单元及其用时。学完一项就勾选一项；你的进度保存在浏览器中。

### 建议的学习安排

- **十周，业余学习。** 每周一个模块：五个晚上，每晚两小时。
- **五周，集中学习。** 每周两个模块。
- **语言模型方向**（约 60 小时）：先学第 02 模块（反向传播与优化器），再学第 06、07、08、09 和 10 模块。
- **基础方向**（约 50 小时）：第 01 至 05 模块，适合需要机器学习和深度学习、但不需要语言模型的工程师。

## 本系列坚持的两条原则 {#rules}

**每个数字都有出处。** 当一个模块说某种方法达到了某个准确率、需要多少 FLOPs 或占用多少 GB 内存时，它会说明这个数字是怎么得到的，让你可以自己重算一遍。

**每种方法都会失效，正文会说明如何失效。** 只讲技术、不讲其失效方式，那就是广告。每个模块都有一节讲常见问题，因为那正是工程师在凌晨三点最需要的一节。

## 适合谁 {#audience}

熟悉微积分、线性代数和基础概率，但还没有做过机器学习的工程师和研究生。本系列的目标不是综述，而是让你读完之后能读懂一篇现代模型论文，理解一次训练究竟在对模型做什么，并凭判断而不是照搬配方来做与模型有关的工程决策。

## 环境准备 {#setup}

所有实验只需要 Python 3.11 或更高版本以及一个虚拟环境。GPU 是可选的；[Google Colab](https://colab.research.google.com/) 是本地安装之外的免费选择。

```bash
python -m venv .venv
source .venv/bin/activate          # on Windows: .venv\Scripts\activate
pip install torch numpy scipy scikit-learn matplotlib
pip install transformers datasets tokenizers tiktoken   # Modules 07 to 10
```

第 07 至 10 模块会从 Hugging Face 下载小型开源模型，最大的约 1 GB；每个实验都会注明其下载大小。

## 记号 {#notation}

向量用粗体小写字母表示，$\mathbf{x}$；矩阵用粗体大写字母表示，$\mathbf{W}$；标量用斜体，$y$。数据集记为 $\mathcal{D} = \{(\mathbf{x}_i, y_i)\}_{i=1}^{N}$。模型参数统一记为 $\theta$。损失记为 $\mathcal{L}(\theta)$，其梯度记为 $\nabla_\theta \mathcal{L}$。对数据的期望记为 $\mathbb{E}_{(\mathbf{x},y)\sim\mathcal{D}}$。除非写作 $\log_2$，对数均为自然对数。张量形状写作 $(B, T, d)$，分别表示 batch 大小、序列长度和宽度。代码使用 Python 和 PyTorch，并保持短到可以手动敲出来。

每个模块的结尾都列出其关键术语的英文和中文，方便用英文读论文、用中文讨论的读者。
