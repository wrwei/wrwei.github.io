## 从这里开始 {#start}

开始前需要掌握中学代数和勾股定理。如果你第一次学线性代数，可以按顺序学习各模块。

每个模块都有例题、附解答的练习和自测。建议先独立做题，再查看解答。六个交互演示可以让你改变输入、观察结果。读教程无需安装 Python。如果想运行[下载的 Python 示例](linear-algebra-code.zip)，请安装 SymPy 和 NumPy。
