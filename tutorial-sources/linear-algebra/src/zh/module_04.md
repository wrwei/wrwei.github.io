## 封闭性与张成 {#span}

$\mathbb R^n$ 的**子空间**含有零向量，并且对加法和数乘封闭。等价地，一个非空集合是子空间，当且仅当它对任意两个元素的线性组合封闭。因此直线 $y=2x$ 是子空间，而与它平行的直线 $y=2x+1$ 不含零向量，不是子空间。

一组向量的**张成空间**由这些向量的所有线性组合构成。它是子空间，因为对组合进行加法或数乘会得到同一组向量的另一个组合。特别是，张成是包含该组向量的最小子空间。

::: widget name=spans
改变生成向量。比较当两个方向线性无关时与其中一个方向是另一个方向的倍数时的情况。
:::

## 独立方向与坐标 {#basis}

一个列表是 **线性无关** 的，当且仅当零向量只能用该列表中所有系数均为零的组合来表示。如果存在一组不全为零的系数使线性组合为零，就可以把任一系数非零的向量用其余向量表示，因此至少有一个向量是冗余的。

一个 **基**是一个独立的生成列表。生成性为每个向量提供坐标。独立性使得这些坐标唯一，因为同一个向量的两个不同坐标列表相减会得到一个非零关系式。**维数** 是一个基中向量的个数。一种证明这个数目固定的途径是：一个包含 $k$ 个向量的基将空间与 $\mathbb R^k$ 同构，其中超过 $k$ 个向量通过消元法会线性相关，少于 $k$ 个向量无法生成，因为它们的矩阵主元个数少于 $k$。

::: example 平面上的基
在 $\mathbb R^3$ 中取平面 $x+y+z=0$。令 $x=s$，$y=t$，则 $z=-s-t$。向量 $(1,0,-1)^\mathsf T$ 和 $(0,1,-1)^\mathsf T$ 生成平面。比较它们的前两个分量可以证明线性无关。维数是 $2$。
```check
B4=Matrix([[1,0],[0,1],[-1,-1]])
same(B4*Matrix([s,t]),Matrix([s,t,-s-t]))
same(B4.rank(),2)
```
:::

## 改变基，保持向量 {#coordinates}

将各基向量依次放入矩阵 $B$ 的各列。如果 $\mathbf c$ 是相对于该有序基的坐标向量，那么 $B\mathbf c$ 是普通坐标下的向量。为了找到 $\mathbf c$，需要解 $B\mathbf c=\mathbf v$。同一个物理位移在不同的基下可以有不同的坐标。

::: compute 非标准基下的坐标
```python
from sympy import Matrix

B = Matrix([[1, 1], [0, 1]])
v = Matrix([5, 2])
print(list(B.LUsolve(v)))
```
```output
[3, 2]
```
:::

## 练习 {#exercises}

:::: exercise 偏移平面 {#ex-4-1} ★
$x+y+z=1$ 是 $\mathbb R^3$ 的子空间吗？
::: solution
不是。零向量不满足方程，因为其坐标和为 $0$。
```check
same(sum([0,0,0]),0); holds(0!=1)
```
:::
::::

:::: exercise 移除冗余生成元 {#ex-4-2} ★★
找出 $(1,0,1)^\mathsf T$、$(0,1,1)^\mathsf T$ 和 $(1,1,2)^\mathsf T$ 张成的空间的一组基。
::: solution
第三个向量是前两个的和，因此它不增加新的方向。前两个向量是线性无关的，因为它们的前两个分量分别是 $\mathbb R^2$ 的坐标向量。保留这两个。
```check
C4=Matrix([[1,0],[0,1],[1,1]])
same(C4*Matrix([1,1]),Matrix([1,1,2])); same(C4.rank(),2)
```
:::
::::

:::: exercise 两个基下的坐标 {#ex-4-3} ★★★
找出 $(5,2)^\mathsf T$ 相对于有序基 $(1,0)^\mathsf T,(1,1)^\mathsf T$ 的坐标，然后相对于倒序的基。
::: solution
在第一种顺序中，第二个分量给出 $(1,1)^\mathsf T$ 的系数 $2$。第一个分量给出 $(1,0)^\mathsf T$ 的系数 $3$。倒序后得到的坐标是 $(2,3)^\mathsf T$。
```check
D4=Matrix([[1,1],[0,1]])
same(D4*Matrix([3,2]),Matrix([5,2])); same(D4[:,::-1]*Matrix([2,3]),Matrix([5,2]))
```
:::
::::

## 自测 {#quiz}

```quiz
? 单个非零向量张成的空间的维数是多少？
- [x] 一个
- [ ] 向量分量的个数
- [ ] 零
> 该向量本身就是一个独立的生成列表。

? 哪条线是一个子空间？
- [ ] $y=x+1$
- [ ] $x=2$
- [x] $x=0$
> 直线 $x=0$ 包含零点以及其上所有点的线性组合。

? 为什么基坐标是唯一的？
- [ ] 所有基向量的长度都是单位长度
- [x] 基向量是相互独立的
- [ ] 基向量的分量都是非负的
> 两个表示相减得到的线性组合等于零。
```
