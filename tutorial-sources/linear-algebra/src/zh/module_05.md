## 输出和不可见的方向 {#four-spaces}

对于 $A$ 大小为 $m\times n$ 的矩阵，其 **列空间**（像）是可达输出的集合 $A\mathbf x$，在 $\mathbb R^m$ 中。其 **零空间**（核）是被发送到零的输入集合，在 $\mathbb R^n$ 中。

另外两个子空间来自 $A^\mathsf T$。它的列空间就是 $A$ 的**行空间**，位于 $\mathbb R^n$ 中。其零空间是 **左零空间**，在 $\mathbb R^m$ 中。名称标识了查找的位置。一个输入恰好在零空间中当且仅当它与每一行的点积为零。同样地，左零空间垂直于所有列。

## 主元和维度计数 {#rank-nullity}

行变换相当于在输出端施加可逆变换，因此保留各列之间的线性关系。所以主元的列号指出**原**矩阵中哪些列构成线性无关的一组列。简化形式中主元的个数为 $r$，也就是**秩**。简化形式的非零行构成行空间的一组基。齐次方程组有 $n-r$ 个自由坐标。依次令一个自由坐标为一、其余为零，就可以为每个自由坐标得到一个零空间的基向量。因此秩与零度之和为 $n$。

::: example 一个输出方向的映射
设 $A=\begin{pmatrix}1&2&3\\2&4&6\end{pmatrix}$。第二行是第一行的两倍，因此有一个主元。第一列 $(1,2)^\mathsf T$ 张成像空间。选择第二和第三输入作为自由变量，得到零空间基 $(-2,1,0)^\mathsf T$， $(-3,0,1)^\mathsf T$。维数相加等于 $1+2=3$。
```check
A5=Matrix([[1,2,3],[2,4,6]])
same(A5.rank(),1)
same(A5.nullspace(),[Matrix([-2,1,0]),Matrix([-3,0,1])])
same(A5.columnspace(),[Matrix([1,2])])
```
:::

## 一个特解加上一个子空间 {#families}

如果 $A\mathbf p=\mathbf b$，则 $A(\mathbf p+\mathbf z)=\mathbf b$ 对于每个 $\mathbf z$ 在核中的元素成立。反之，任何解减去 $\mathbf p$ 都在核中。如果 $\mathbf b$ 不在列空间中，则没有解。这将存在性（由像空间控制）与唯一性（由核控制）分开。

::: compute 精确计算中的基
```python
from sympy import Matrix

A = Matrix([[1, 2, 3], [2, 4, 6]])
print(A.rank())
print([list(v) for v in A.nullspace()])
print([list(v) for v in A.T.nullspace()])
```
```output
1
[[-2, 1, 0], [-3, 0, 1]]
[[-2, 1]]
```
:::

## 练习 {#exercises}

:::: exercise 左零空间 {#ex-5-1} ★
对于该示例矩阵，给出左零空间中的一个非零向量。
::: solution
由于第二行是第一行的两倍，$(-2,1)^\mathsf T$ 在该组合中会消去这两行。等价地 $A^\mathsf T(-2,1)^\mathsf T=\mathbf 0$。
```check
same(A5.T*Matrix([-2,1]),zeros(3,1))
```
:::
::::

:::: exercise 这样的输出是否可能？ {#ex-5-2} ★★
对于同样的矩阵，判断 $(3,6)^\mathsf T$ 和 $(3,7)^\mathsf T$ 是否可达。
::: solution
第一个输出是第一列的三倍。每个输出的第二个分量都是其第一个分量的两倍，因此第二个目标是不可能的。
```check
same(A5*Matrix([3,0,0]),Matrix([3,6]))
same(A5.row_join(Matrix([3,7])).rank(),2)
```
:::
::::

:::: exercise 不再约简时的维数 {#ex-5-3} ★★★
一个 $5\times8$ 矩阵的秩为 $3$。给出其四个子空间的维数。
::: solution
列空间和行空间的维数均为 $3$。秩-零度定理给出核空间的维数为 $8-3=5$。对转置矩阵应用相同的计数，得到左零空间的维数为 $5-3=2$。
```check
B5=zeros(5,8)
B5[:3,:3]=eye(3)
same([B5.rank(),B5.T.rank(),len(B5.nullspace()),len(B5.T.nullspace())],[3,3,5,2])
```
:::
