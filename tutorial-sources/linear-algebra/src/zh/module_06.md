## 符号面积和体积 {#determinant}

在二维情况下，列 $(a,c)^\mathsf T$ 和 $(b,d)^\mathsf T$ 包围一个平行四边形，其符号面积为 $ad-bc$。其绝对值给出面积。符号记录线性映射是否保持或反转方向。在更高维度中，方阵 **行列式** 衡量符号体积因子。

交换行会改变其符号，将一行乘以一个因子会将其乘以同样的因子，将一行加上另一行的倍数不会改变它。这些规则也来自于行列式在每一行上是交替的和线性的。一个三角矩阵的行列式等于其对角线元素的乘积。在化简过程中跟踪行交换和缩放。

::: example 化简时不改变行列式
对于 $A=\begin{pmatrix}2&1\\4&3\end{pmatrix}$，用第二行减去第一行的两倍。得到的三角矩阵的对角线元素为 $2,1$，因此 $\det A=2$。该映射将普通面积加倍并保持方向不变。
```check
A6=Matrix([[2,1],[4,3]])
same(A6.det(),2); same((Matrix([[1,0],[-2,1]])*A6).det(),2)
```
:::

## 哪些映射有逆映射？ {#inverse}

对于一个 $n\times n$ 矩阵，以下条件等价：秩 $n$，零空间为零，每个右侧都有唯一解，以及非零行列式。消元法解释了最后一个联系：在三角形式中出现零对角线主元当且仅当主元个数少于 $n$。逆 $A^{-1}$ 反转该映射。化简 $[A\mid I]$ 在逆存在时得到 $[I\mid A^{-1}]$。

对于单一数值系统，使用消元法等求解器而不是计算逆矩阵并乘以 $\mathbf b$。对于相同 $A$ 的重复求解，只需计算一次分解。

## 三角求解和LU分解 {#lu}

对于例子，消元法给出

$$
A=LU,\qquad L=\begin{pmatrix}1&0\\2&1\end{pmatrix},\quad U=\begin{pmatrix}2&1\\0&1\end{pmatrix}.
$$

$L$ 中的元素 $2$ 记录了消元时使用的乘数。为了解 $A\mathbf x=\mathbf b$，从上到下解 $L\mathbf z=\mathbf b$，然后从下到上解 $U\mathbf x=\mathbf z$。在进行行交换时，通用惯例是 $PA=LU$，因此在第一个解的右边使用 $P\mathbf b$。

::: compute 验证分解并求解
```python
from sympy import Matrix

A = Matrix([[2, 1], [4, 3]])
L, U, swaps = A.LUdecomposition()
print(L.tolist(), U.tolist(), swaps)
print(list(A.LUsolve(Matrix([5, 11]))))
```
```output
[[1, 0], [2, 1]] [[2, 1], [0, 1]] []
[2, 1]
```
:::

## 练习 {#exercises}

:::: exercise 方向 {#ex-6-1} ★
在 $\operatorname{diag}(-2,3)$ 下，面积和方向会发生什么变化？
::: solution
行列式是 $-6$。该映射将普通面积乘以 $6$ 并反转方向。
```check
same(diag(-2,3).det(),-6)
```
:::
::::

:::: exercise 逆矩阵检查 {#ex-6-2} ★★
求 $\begin{pmatrix}1&2\\0&1\end{pmatrix}$ 的逆矩阵。
::: solution
该映射将 $(x,y)$ 映射到 $(x+2y,y)$。从第一个输出中减去 $2y$ 会反转它，因此逆矩阵的行是 $(1,-2)$ 和 $(0,1)$。
```check
A6=Matrix([[1,2],[0,1]])
same(A6*Matrix([[1,-2],[0,1]]),eye(2))
```
:::
::::

:::: exercise 使用分解求解 {#ex-6-3} ★★★
使用上面的分解求解 $\mathbf b=(3,8)^\mathsf T$。
::: solution
下三角求解给出 $z_1=3$，$2z_1+z_2=8$，因此 $z_2=2$。上三角求解给出 $x_2=2$ 和 $2x_1+x_2=3$，因此 $x_1=1/2$。
```check
same(Matrix([[1,0],[2,1]])*Matrix([3,2]),Matrix([3,8]))
same(Matrix([[2,1],[0,1]])*Matrix([S.Half,2]),Matrix([3,2]))
```
:::

## 自测 {#quiz}

```quiz
? 交换两行后行列式会发生什么变化？
- [ ] 它加倍
- [x] 它的符号发生变化
- [ ] 其值保持不变
> 交换两行会反转方向因子。

? 行列式为零对一个方阵意味着什么？
- [ ] 每个非零输入都会被映射到非零输出
- [ ] 存在逆矩阵且行列式为零
- [x] 该映射有一个非平凡的核
> 至少缺少一个主元，导致齐次方程组中存在自由变量。

? 对于 $PA=LU$，求解 $A\mathbf x=\mathbf b$ 时第一个右侧是什么？
- [x] $P\mathbf b$
- [ ] $U\mathbf b$
- [ ] $L\mathbf b$
> 在进行三角分解前，将相同的行置换应用到等式两边。
```
