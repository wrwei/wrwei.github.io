## Vectors, systems and spaces {#spaces}

| Term | Meaning |
|---|---|
| Augmented matrix | Coefficients of a system with a right-hand side appended as a column. [Module 2](module_02_EN.html#rows) |
| Affine map | A linear map followed by a translation. [Module 3](module_03_EN.html#affine) |
| Basis | An independent list that spans the space, giving unique coordinates. [Module 4](module_04_EN.html#basis) |
| Column space or image | All possible outputs of the matrix. [Module 5](module_05_EN.html#four-spaces) |
| Dimension | The number of vectors in any basis. [Module 4](module_04_EN.html#basis) |
| Dot product | The sum of products of corresponding coordinates. [Module 1](module_01_EN.html#dot) |
| Free variable | A variable whose column lacks a pivot. For a consistent system it may be chosen freely. [Module 2](module_02_EN.html#solutions) |
| Linear combination | A sum of scaled vectors. [Module 1](module_01_EN.html#vectors) |
| Linear independence | Only the all-zero coefficients give a combination equal to the zero vector. [Module 4](module_04_EN.html#basis) |
| Linear map | A map that preserves linear combinations. [Module 3](module_03_EN.html#maps) |
| Norm | The length of a vector. The Euclidean norm uses the square root of the sum of squares. [Module 1](module_01_EN.html#dot) |
| Null space or kernel | The set of inputs a matrix maps to zero. [Module 5](module_05_EN.html#four-spaces) |
| Pivot | A leading entry used to eliminate a variable in other rows. [Module 2](module_02_EN.html#rows) |
| Rank | The dimension of the column space, equal to the number of pivots. [Module 5](module_05_EN.html#rank-nullity) |
| Row space | The span of the rows regarded as vectors in the input space. [Module 5](module_05_EN.html#four-spaces) |
| Span | The set of all linear combinations of the given vectors. [Module 4](module_04_EN.html#span) |
| Subspace | A subset containing zero and closed under addition and scalar multiplication. [Module 4](module_04_EN.html#span) |
| Transpose | An operation that swaps rows and columns. [Module 3](module_03_EN.html#composition) |

## Factorisations and approximation {#fits}

| Term | Meaning |
|---|---|
| Determinant | The signed volume scaling factor of a square matrix. Zero corresponds to collapse of dimension. [Module 6](module_06_EN.html#determinant) |
| Gram–Schmidt | A process for building an orthonormal basis by subtracting projections and normalising. [Module 7](module_07_EN.html#gram-schmidt) |
| Inverse | A square matrix that reverses a given invertible map. [Module 6](module_06_EN.html#inverse) |
| LU factorisation | A product of lower and upper triangular factors, with a permutation when needed. [Module 6](module_06_EN.html#lu) |
| Least squares | Fitting by minimising the sum of squared residual entries. [Module 8](module_08_EN.html#least-squares) |
| Orthogonal | Two vectors have zero dot product. [Module 1](module_01_EN.html#dot) |
| Orthonormal | A list of unit vectors that are pairwise orthogonal. [Module 7](module_07_EN.html#gram-schmidt) |
| Projection | The point of a subspace closest to a given vector. [Module 7](module_07_EN.html#projection) |
| QR factorisation | A product with orthonormal columns in the first factor and upper triangular structure in the second. [Module 7](module_07_EN.html#qr) |
| Residual | The observation vector minus the fitted vector. [Module 8](module_08_EN.html#least-squares) |

## Spectra and data {#data}

| Term | Meaning |
|---|---|
| Condition number | The ratio of the largest to smallest stretch for a matrix of full column rank, in Euclidean norm. [Module 11](module_11_EN.html#sizes) |
| Diagonalisation | Expressing a matrix as a diagonal action in an eigenbasis. [Module 9](module_09_EN.html#diagonalisation) |
| Eigenvector and eigenvalue | A nonzero direction preserved up to scaling and the scalar by which it is multiplied. [Module 9](module_09_EN.html#eigenpairs) |
| Eigenspace | The complete null space of $A-\lambda I$ for an eigenvalue $\lambda$. [Module 9](module_09_EN.html#eigenpairs) |
| Frobenius norm | The square root of the sum of squares of all matrix entries. [Module 12](module_12_EN.html#low-rank) |
| Principal component | A direction of greatest remaining sample variance, orthogonal to the earlier chosen directions. [Module 12](module_12_EN.html#pca) |
| Pseudoinverse | A map giving the minimum-norm least-squares solution for each right-hand side. [Module 11](module_11_EN.html#pseudoinverse) |
| Quadratic form | A scalar function of the form $\mathbf x^\mathsf TA\mathbf x$. [Module 10](module_10_EN.html#forms) |
| Singular value | A nonnegative stretch factor in a singular value decomposition. [Module 11](module_11_EN.html#svd) |
| Spectral theorem | Every real symmetric matrix admits an orthonormal eigenbasis. [Module 10](module_10_EN.html#spectral) |
