## 你已经会的证明 {#informal}

**证明**（proof）是一个不留任何怀疑余地的论证：每一步都由前面的步骤得出，所依据的理由是大家都接受的。你以前就构造过这样的论证，也许只是没有这样称呼它。当你说服一位同事，某个循环一定会终止，或者某个函数永远不会返回负数时，你会给出理由，而每条理由都建立在前面的理由之上。

本节汇集这类论证所用的模式。本模块的其余部分会把每种模式变成一条精确的规则，让计算机能够检查每一步。模块 2 和模块 3 给了你公式及其含义；本模块补上模块 1 所说的形式化方法的第三样东西：证明系统。

::: example 取款永远不会让余额变成负数
**断言**：如果余额 b 至少为 0，取款金额 a 至多为 b，那么 b − a 至少为 0。

**证明**：假设 b ≥ 0 且 a ≤ b。在 a ≤ b 的两边同时减去 a，得到 0 ≤ b − a。∎
:::

记号 ∎ 表示证明结束。这里用到了两种模式。要证明一个“如果……那么……”形式的陈述，证明先**假设**（assume）“如果”部分成立，再证明“那么”部分；这个假设只能在这段论证内部使用。而它所走的那一步，是由已知事实**直接**得出的，这里用的是一条算术定律。还要注意，假设 b ≥ 0 根本没有用到。证明可以不用某个假设；这时，断言在比所陈述的更一般的条件下也成立。

::: example 最大值不小于它的第一个参数
**断言**：对所有整数 x 和 y，都有 max(x, y) ≥ x，其中 max 的定义是

```text
max(x, y) = if x ≥ y then x else y
```

**证明**：要么 x ≥ y，要么 x < y。**情形 x ≥ y**：这时 max(x, y) = x，而 x ≥ x。**情形 x < y**：这时 max(x, y) = y，而 y > x。在两种情形下都有 max(x, y) ≥ x。∎
:::

这就是**情形分析**（case analysis）：当你知道几种情形中必有一种成立时，就在每种情形下分别证明断言。这里的情形对应定义中的 `if`，这很典型：带分支的程序，通常需要一个分情形的证明。各种情形必须涵盖所有的可能。这里确实如此，因为对任意两个整数，要么 x ≥ y，要么 x < y。

::: example 两个偶数之和是偶数
如果对某个整数 k 有 n = 2k，整数 n 就是**偶数**（even）。

**断言**：对所有整数 m 和 n，如果 m 和 n 都是偶数，那么 m + n 是偶数。

**证明**：设 m 和 n 是任意整数，并假设它们都是偶数。因为 m 是偶数，所以对某个整数 k 有 m = 2k。因为 n 是偶数，所以对某个整数 j 有 n = 2j。于是 m + n = 2k + 2j = 2(k + j)。所以对整数 i = k + j 有 m + n = 2i，即 m + n 是偶数。∎
:::

这个简短的证明用到了三种模式，都与量词有关：

- “设 m 和 n 是**任意**整数”：要证明某件事对**所有**整数都成立，就取任意的整数，除了断言所允许的之外，对它们不做任何假设，再对它们证明这件事。因为对它们没有做任何假设，这个论证对每一种选取都行得通。
- “对**某个**整数 k 有 m = 2k”：要**使用**一个形如“存在 k 使得……”的事实，就给这个未知的值起一个名字，然后用它来推理，除了这个事实所说的，对它不做任何假设。
- “对整数 i = k + j”：要**证明**一个形如“存在 i 使得……”的事实，就给出一个这样的值，即一个**见证**（witness），并检查它确实满足要求。

::: pitfall
给未知的值起的名字必须是**新的**。如果证明对第二个数也写“n = 2k”，重复使用 m 的那个 k，那就等于假设了 n 的一半与 m 的一半相同，也就是 n = m。这样的“证明”就只涵盖了 m + m 这种和。第 6.6 节会说明自然演绎怎样排除这种错误。
:::

::: note
见证是测试唯一能给出的一种证明。“某个输入会让解析器崩溃”，只需一个让它崩溃的输入就能证明。关于**所有**输入的断言则是另一回事：正如模块 1 所说，测试能表明错误的存在，却永远不能表明错误的不存在。
:::

::: example 不存在最大的自然数
**断言**：不存在最大的自然数。

**证明**：为了导出矛盾，假设存在一个最大的自然数，把它叫作 N。那么 N + 1 是自然数，并且 N + 1 > N，所以 N 不是最大的。这与 N 的选取相矛盾。所以不存在最大的自然数。∎
:::

这就是**反证法**（proof by contradiction）：假设你想要的结论的反面，推出某种不可能的事情；那么这个假设一定是假的。这个论证依赖于 N + 1 是自然数这一点。对数学中的自然数，这是对的；对 64 位机器整数，这却是错的，因为最大值加一会溢出。证明的价值取决于它所用的事实，所以关于程序的证明，需要一个精确描述程序中的数的模型。

::: example 如果 n² 是偶数，那么 n 是偶数
直接证明很别扭：从 n² = 2k 出发，怎样才能得出关于 n 的结论？不如改为证明它的**逆否命题**（contrapositive）：如果 n 不是偶数，那么 n² 不是偶数。

**证明**：设 n 是一个不是偶数的整数。那么 n 是奇数：对某个整数 k 有 n = 2k + 1。所以 n² = 4k² + 4k + 1 = 2(2k² + 2k) + 1，这是奇数，因而不是偶数。∎
:::

蕴涵“如果 A，那么 B”和它的逆否命题“如果非 B，那么非 A”排除的是同一种情况：A 为真而 B 为假。证明了其中一个，也就证明了另一个。（从逆否命题回到原来的蕴涵需要经典逻辑，第 6.5 节会解释这一点。）

下表汇集了这些模式，以及本模块后面为它们给出的自然演绎规则。

| 模式 | 什么时候用 | 怎样做 | 规则 |
|---|---|---|---|
| 假设前提 | 证明“如果 A，那么 B” | 假设 A，证明 B | (⟶I)，第 6.4 节 |
| 情形分析 | 使用“A 或 B” | 先假设 A 证明目标，再假设 B 证明目标 | (∨E)，第 6.4 节 |
| 反证 | 证明“非 A”，或证明 A | 假设 A（或“非 A”），推出不可能的事情 | (¬I)、(RAA)，第 6.4–6.5 节 |
| 逆否命题 | 证明“如果 A，那么 B” | 证明“如果非 B，那么非 A” | 可推导出，第 6.5 节 |
| 任意元素 | 证明“对所有 x” | 取任意的 x，对它证明断言 | (∀I)，第 6.6 节 |
| 见证 | 证明“存在 x” | 给出一个，并检查它 | (∃I)，第 6.6 节 |
| 给见证命名 | 使用“存在 x” | 给它起一个新名字，利用关于它的已知事实 | (∃E)，第 6.6 节 |

::: keyidea
表中的每种模式，要么是**证明**某种形状的陈述（蕴涵、“对所有”、“存在”），要么是**使用**这样的陈述（“或”、“存在”）。**自然演绎**（natural deduction）正是建立在这种划分之上的：每个联结词和量词都有**引入规则**（introduction rule），用来证明它；也有**消去规则**（elimination rule），用来使用它。
:::

::: pitfall
非形式化证明中常见三种错误：

- **用检查例子代替证明。** 在模块 1 中，double n = n * n 在 n = 0 和 n = 2 时成立，在 n = 1 时却不成立。例子可以驳倒一个“对所有”的断言，却永远不能证明它。
- **假设了要证明的东西。** 一个在推理途中用到了自身结论的论证，什么也证明不了，无论每一步看起来多么令人信服。
- **证明了逆命题。** 要你证明“如果 A，那么 B”时，很容易不知不觉地去证明它的逆命题（converse）“如果 B，那么 A”。它们是不同的断言：“如果下过雨，街道就是湿的”不同于“如果街道是湿的，就下过雨”。
:::

## 什么是证明系统 {#systems}

非形式化的证明依赖于读者。“同理”“由此可得”“不失一般性”这类说法，都是在请读者填补一个空缺，而不同的读者填补的方式不同，甚至会填错。要让机器检查证明，每一步都必须是某条事先确定的规则的一个实例，而检查一步不应需要任何洞察力。这样一组规则就是一个**证明系统**（proof system）。

先看一个与逻辑相去甚远的小例子。下面是关于形如 $\mathit{even}\ n$ 的陈述的两条规则：

$$
\dfrac{}{\mathit{even}\ 0}\;(\mathrm{ev}_0)
\qquad\qquad
\dfrac{\mathit{even}\ n}{\mathit{even}\ (n+2)}\;(\mathrm{ev}_2)
$$

每条规则这样读：由横线上方的陈述，即**前提**（premise），可以得出横线下方的陈述，即**结论**（conclusion）。规则的名字写在横线旁边。(ev₀) 没有前提：你随时都可以写下 $\mathit{even}\ 0$。(ev₂) 说的是：对任何数 n，由 $\mathit{even}\ n$ 可以得出 $\mathit{even}\ (n + 2)$。下面是用这两条规则构造的一个**推导**（derivation）：

```prooftree
even 4   (ev₂)
  even 2   (ev₂)
    even 0   (ev₀)
```

从上往下读：(ev₀) 给出 $\mathit{even}\ 0$；取 n = 0 应用 (ev₂)，得到 $\mathit{even}\ 2$；取 n = 2 应用 (ev₂)，得到 $\mathit{even}\ 4$。每条横线是一步，旁边标着所用的规则。要检查这个推导，程序只需查看每条横线，问一个问题：横线下方的公式，是不是这条规则由横线上方的公式得出的那个公式？它完全不需要知道 $\mathit{even}$ 是什么意思。

::: definition 证明系统与推导
**证明系统**规定一种公式语言和一组**推理规则**（inference rule）。一条规则有零个或多个**前提**和一个**结论**；没有前提的规则是**公理**（axiom）。**推导**是一棵由公式组成的树，画的时候根在最下面。树中的每个公式，要么是一个**假设**（assumption），即上方没有横线的叶子，要么由紧挨在它上方的公式通过某条规则得出。根上的公式是这个推导的**结论**。
:::

假设是不经证明、直接当作已知的公式：这时推导说明的是，**如果**假设成立，会得出什么。下面是同一个系统中的一个推导，最上面是一个假设：

```prooftree
even 5   (ev₂)
  even 3   (ev₂)
    even 1
```

它说明 $\mathit{even}\ 5$ 可以由假设 $\mathit{even}\ 1$ 得出。这个假设是假的，但推导是正确的：它说的是，如果 $\mathit{even}\ 1$ 成立，会得出什么。

::: definition 可推导性
**Γ ⊢ A** 读作“Γ 推导出 A”或“A 可由 Γ 推导出”，意思是：有某个推导，它的结论是 A，它的所有假设都在公式集 Γ（希腊大写字母 gamma）中。这个集合写成列表的形式：$\mathit{even}\ 1$ ⊢ $\mathit{even}\ 5$。左边什么也没有的 **⊢ A** 表示 A 有一个不带任何假设的推导；这时 A 是该证明系统的一个**定理**（theorem）。
:::

所以 ⊢ $\mathit{even}\ 4$，并且 $\mathit{even}\ 1$ ⊢ $\mathit{even}\ 5$。那么 $\mathit{even}\ 3$ 呢？没有哪个不带假设的推导能得到它；下一节会说明，怎样不必尝试每一棵可能的树，就能确信这一点。

::: analogy
编译器的类型检查器并不运行你的程序。它对照类型规则检查每个表达式：如果 `e1` 的类型是 `int`，`e2` 的类型也是 `int`，那么 `e1 + e2` 的类型是 `int`。证明检查器对推导也是这样工作的：它对照规则检查每一步的形状，而不检查公式是否为真。这就是证明助手的内核可以很小的原因（模块 1）：内核正是这样一种检查器。
:::

逻辑的证明系统有很多种：希尔伯特式系统（公理很多，规则只有一两条）、相继式演算（sequent calculus）、表列法（tableau），以及自动证明器所用的归结法（resolution）。对命题逻辑和一阶逻辑，它们能推导出的结论完全相同，区别只在于用起来是否方便。本模块使用**自然演绎**，因为它与第 6.1 节的非形式化模式贴得很紧，而且 Isabelle 就是围绕它设计的（模块 7）。

## 可推导与为真 {#soundness}

证明系统只是在摆弄符号。它不知道 $\mathit{even}$ 是什么意思，也不知道 ∧ 是什么意思。公式的真假则是另一回事，它由模块 2 和模块 3 定义：一个**赋值**（valuation）使一个命题公式为真或为假；一个**结构**（structure）连同自由变元的取值，使一个一阶公式为真或为假。所以，关于公式集 Γ 和公式 A，有两个问题：

- **Γ ⊢ A**：能否由 Γ 推导出 A？这是一个关于规则的问题（语法）。
- **Γ ⊨ A**：在使 Γ 中所有公式都为真的每个赋值或每个结构中，A 是否都为真？这就是模块 2 中的**逻辑推论**（logical consequence），是一个关于含义的问题（语义）。

这是两个不同的问题。一个好的证明系统对这两个问题给出相同的答案。

::: definition 可靠性与完备性
如果一个证明系统推导出的一切都是逻辑推论，即对所有 Γ 和 A，若 Γ ⊢ A 则 Γ ⊨ A，就说它是**可靠的**（sound）。如果它能推导出每一个逻辑推论，即对所有 Γ 和 A，若 Γ ⊨ A 则 Γ ⊢ A，就说它是**完备的**（complete）。
:::

前面关于 $\mathit{even}$ 的系统在小范围内展示了这两个性质。给 $\mathit{even}\ n$ 赋予它自然的含义：“n 能被 2 整除”。这个系统是**可靠的**：(ev₀) 得出一个真陈述，(ev₂) 把真陈述变成真陈述，因为只要 n 能被 2 整除，n + 2 就能被 2 整除。一个推导只把这些规则应用有限多次，所以它的结论为真（这是对推导大小的归纳，就像模块 5 中那样）。特别地，$\mathit{even}\ 3$ 是假的，所以它没有推导：可靠性回答了上一节的问题，一棵树也不用试。对不带假设的陈述，这个系统也是**完备的**：每个真陈述 $\mathit{even}\ 2k$ 都有一个推导，其中用一次 (ev₀)，用 k 次 (ev₂)。

::: figure id=fig-06-1
答案相同的两个问题。⊢ 问的是推导是否存在；⊨ 问的是在使假设都为真的每个赋值或结构中，公式是否都为真。可靠性和完备性把两者联系起来。
:::

如果这两个性质中有一个不成立，那意味着什么？

- **如果可靠性不成立**，系统就能推导出假的东西。假设你在本模块的规则之外再加一条看似合理的规则：由 A ∨ B 得出 A。（“请求来自管理员或访客，所以它来自管理员。”）那么 A ∨ B ⊢ A，尽管 A ∨ B ⊭ A（读作“A 不是 A ∨ B 的逻辑推论”）：当 A 为假、B 为真时，A ∨ B 为真而 A 为假。情况还会更糟。第 6.5 节会对每个公式 A 推导出 A ∨ ¬A；有了这条新规则，每个 A 都可以推出来，包括 ⊥，即永远为假的那个公式。在不可靠的系统中，推导什么也证明不了。对证明助手来说，这是最严重的一种错误，所以模块 1 中的 LCF 内核要保持很小，并经过仔细的检查。
- **如果完备性不成立**，就有某个逻辑推论没有推导。系统永远不会推导出假的东西，但它不能证明你需要的一切；而一次失败的搜索也无法告诉你，究竟是你运气不好，还是系统太弱。第 6.5 节就会遇到一个例子：没有最后那条规则，自然演绎就推导不出 A ∨ ¬A，尽管它的真值表的每一行都为真。

::: fact 自然演绎既可靠又完备
对命题逻辑和一阶逻辑，本模块的自然演绎系统（连同它的全部规则）既是可靠的，也是完备的：对每个公式集 Γ 和每个公式 A，Γ ⊢ A 当且仅当 Γ ⊨ A。
:::

可靠性是常规的那一半：只需检查每条规则都把真的前提变成真的结论。解除假设的规则和量词规则需要多加小心，它们的附加条件（第 6.6 节）正是为了让这项检查能够通过。完备性则是一个深刻的定理。库尔特·哥德尔（Kurt Gödel）在 1929 年的博士论文中对一阶逻辑证明了它，他用的是另一个证明系统，但它推导出的公式与自然演绎相同。

由此得出的三点在实践中很重要。

1. **反例说明证明不存在。** 要说明 A **不能**由 Γ 推导出来，你不必尝试每一个推导。只要找到一个使 Γ 为真而 A 为假的赋值或结构；由可靠性，推导就不存在。这正是 Isabelle 中 Quickcheck 和 Nitpick 所做的事（模块 1–3）：一个**反例**（counterexample）意味着“别再试图证明它了”。
2. **证明搜索能找到证明，却不总能断定没有证明。** 推导可以按大小一个接一个地列出来，每一个都可以机械地检查。一个按这个列表逐个检查的程序，最终会为每个**有效的**（valid）一阶公式找到推导。对于不是有效的公式，它可能永远搜索下去：一阶逻辑的有效性是不可判定的（模块 3），所以没有哪个程序能总是回答“否”。Isabelle 的 `blast` 这类证明搜索工具只能接受这一点：它们搜索到某个界限就放弃。
3. **哥德尔的不完备性定理讲的是另一回事。** 完备性关心的是在**每个**结构中为真；1931 年的不完备性定理（模块 1）关心的则是在一个特定结构（自然数）中为真：任何可以机械检查、只推导出关于算术的真陈述的证明系统，都推导不出所有这样的真陈述。Isabelle/HOL 能够表达算术，所以它的证明系统，和其他任何可由机器检查的证明系统一样，推导不出关于自然数的每一个真陈述。Isabelle 保证的是可靠性，而当你信任一个定理时，你依靠的正是可靠性。

## 自然演绎：联结词 {#connectives}

格哈德·根岑（Gerhard Gentzen）在 1934/35 年提出了自然演绎，同一篇论文还提出了相继式演算；斯坦尼斯瓦夫·雅希科夫斯基（Stanisław Jaśkowski）在 1934 年独立发表了一个类似的系统。根岑想要一个像数学家那样推理的形式系统：先做出假设，再从假设得出结论。所以自然演绎没有关于联结词的公理。相反，你可以假设任何公式，而有些规则会**解除**（discharge）假设，这就是“假设 A……因此，如果 A，那么 B”的形式化版本。每个联结词都有**引入规则**，说明怎样证明以这个联结词为主的公式；也有**消去规则**，说明怎样使用这样的公式。

哪些规则适用于一个公式，取决于它的**主联结词**（main connective）：构造这个公式时最后用到的联结词，也就是位于其语法树（parse tree）根部的联结词。在 A ∧ B ⟶ B ∧ A 中，主联结词是 ⟶，因为 ∧ 结合得更紧（模块 2）。在下面的规则中，A、B 和 C 代表任意公式：一条规则适用于每个形状合适的公式。

### 合取 {#and}

$$
\dfrac{A \qquad B}{A \land B}\;(\land\mathrm{I})
\qquad\qquad
\dfrac{A \land B}{A}\;(\land\mathrm{E}_1)
\qquad\qquad
\dfrac{A \land B}{B}\;(\land\mathrm{E}_2)
$$

(∧I) 叫作“合取引入”（and-introduction），它说：要证明 A ∧ B，就分别证明 A 和 B。(∧E₁) 和 (∧E₂) 叫作“合取消去”（and-elimination），它们说：由 A ∧ B 可以得出 A，也可以得出 B。这三条规则合起来说明了“并且”的含义：一个合取式成立，当且仅当它的两部分都成立。下面是一个用到全部三条规则的推导：

```prooftree
B ∧ A   (∧I)
  B   (∧E₂)
    A ∧ B
  A   (∧E₁)
    A ∧ B
```

它的两个叶子是同一个假设 A ∧ B，用了两次；一个假设想用多少次都可以。这个推导说明 A ∧ B ⊢ B ∧ A。

### 蕴涵与假设 {#imp}

在非形式化的证明中，要证明“如果 A，那么 B”，你会假设 A，然后证明 B。自然演绎也是这样做的：

$$
\dfrac{\begin{matrix}[A]^1\\ \vdots\\ B\end{matrix}}{A \imp B}\;({\imp}\mathrm{I}^1)
\qquad\qquad
\dfrac{A \imp B \qquad A}{B}\;({\imp}\mathrm{E})
$$

(⟶I) 有一个前提 B，竖排的点代表一个 B 的推导，这个推导可以把 A 当作假设来用。应用 (⟶I) 时，假设 A 就被**解除**了：结论 A ⟶ B 不再依赖于它，因为 A 现在成了结论的一部分。为了记下这一点，A 的每一处被解除的出现都写在方括号里，并带上一个编号，即 [A]¹；解除它的规则也带上同一个编号，即 (⟶I¹)。编号只是把假设和规则联系起来；推导中其他地方没有用过的任何编号都可以。(⟶E) 又叫**肯定前件式**（modus ponens），它使用一个蕴涵：由 A ⟶ B 和 A 得出 B。

::: definition 未解除的假设与已解除的假设
如果在推导中从某个假设往下到根的路径上，有一条规则解除了它，这个假设就是**已解除的**，写作 [A]ⁿ，其中 n 是那条规则的编号。否则，这个假设是**未解除的**（open）。推导的结论只依赖于其中未解除的假设：Γ ⊢ A 的意思是，存在一个 A 的推导，其中未解除的假设都在 Γ 中。
:::

在上面用合取规则得到的 A ∧ B ⊢ B ∧ A 的推导下面，再加一步：

```prooftree
A ∧ B ⟶ B ∧ A   (⟶I¹)
  B ∧ A   (∧I)
    B   (∧E₂)
      [A ∧ B]¹
    A   (∧E₁)
      [A ∧ B]¹
```

(⟶I¹) 解除了 A ∧ B 的两处出现。没有剩下未解除的假设，所以 ⊢ A ∧ B ⟶ B ∧ A：这个公式是一个定理。从下往上读这个推导，就能看出它是怎样找到的。这里的目标（goal）是 A ∧ B ⟶ B ∧ A，它是一个蕴涵，所以用 (⟶I)：假设 A ∧ B，证明 B ∧ A。这是一个合取，所以用 (∧I)：分别证明 B 和 A。两者都可以用一条消去规则从假设得出。第 6.7 节会把这种做法变成一种方法。

下一个公式说的是蕴涵可以串联起来：如果由 A 得到 B，由 B 得到 C，那么由 A 得到 C。

```prooftree
(A ⟶ B) ⟶ (B ⟶ C) ⟶ (A ⟶ C)   (⟶I¹)
  (B ⟶ C) ⟶ (A ⟶ C)   (⟶I²)
    A ⟶ C   (⟶I³)
      C   (⟶E)
        [B ⟶ C]²
        B   (⟶E)
          [A ⟶ B]¹
          [A]³
```

因为 ⟶ 向右结合（模块 2），这个公式有三个前提：A ⟶ B、B ⟶ C 和 A。最后一对括号不是必需的，但它能显示出结构。每个 (⟶I) 假设一个前提并解除它，两次 (⟶E) 把蕴涵串联起来：由 A 和 A ⟶ B 得到 B，由 B 和 B ⟶ C 得到 C。

一条规则也可以解除一个从未用到的假设：

```prooftree
A ⟶ B ⟶ A   (⟶I¹)
  B ⟶ A   (⟶I²)
    [A]¹
```

(⟶I²) 解除了假设 B，而 B 根本没有出现在推导中：不需要它，A 也已经有了。这是允许的，就像一个函数可以不理会它的某个参数一样。

### 假设及其辖域 {#discharge}

被解除的假设只能在解除它的规则之上使用。下面这个“推导”违反了这条规定：

```prooftree
(A ⟶ A) ∧ A   (∧I)
  A ⟶ A   (⟶I¹)
    [A]¹
  [A]¹
```

在左边的分支上，(⟶I¹) 正确地解除了 [A]¹。在右边的分支上，[A]¹ 不在任何 (⟶I¹) 之上，所以 A 在那里仍是一个未解除的假设，方括号是错的。如实的结论是 A ⊢ (A ⟶ A) ∧ A，它是对的，却没什么用。这棵树声称 ⊢ (A ⟶ A) ∧ A，而这是错的：当 A 为假时，(A ⟶ A) ∧ A 为假，所以由可靠性，这个公式没有不带假设的推导。可靠性在这里起到了调试工具的作用：结论是假的，就说明有某一步错了。

::: figure id=fig-06-2
被解除假设的辖域（scope），是推导中位于解除它的规则之上的那一部分。辖域像程序中的代码块一样嵌套。右边第二个 [A]¹ 在 (⟶I¹) 的辖域之外。
:::

::: analogy
被解除的假设就像局部变量。在下面这段程序中

```text
if (x > 0) {
    int y = x;     // y 只存在于这个块中
}
return y;          // 错误：y 不在作用域内
```

y 只存在于它所在的块中，块结束之后再使用 y，编译器会拒绝。假设 [A]¹ 只存在于推导中解除它的那个 (⟶I¹) 之上的部分，在其他任何地方使用它的推导，证明检查器都会拒绝。
:::

### 析取 {#or}

$$
\dfrac{A}{A \lor B}\;(\lor\mathrm{I}_1)
\qquad\qquad
\dfrac{B}{A \lor B}\;(\lor\mathrm{I}_2)
$$

$$
\dfrac{\begin{matrix}\\ \\ A \lor B\end{matrix} \qquad \begin{matrix}[A]^1\\ \vdots\\ C\end{matrix} \qquad \begin{matrix}[B]^1\\ \vdots\\ C\end{matrix}}{C}\;(\lor\mathrm{E}^1)
$$

(∨I₁) 和 (∨I₂)：要证明 A ∨ B，证明两边中的一边即可。(∨E) 就是情形分析：要用 A ∨ B 来证明目标 C，就在假设 A 的情况下推导出 C，再在假设 B 的情况下推导出 C。这条规则用同一个编号解除这两个假设。下面是它在第一个定理的析取版本上的应用：

```prooftree
A ∨ B ⟶ B ∨ A   (⟶I¹)
  B ∨ A   (∨E²)
    [A ∨ B]¹
    B ∨ A   (∨I₂)
      [A]²
    B ∨ A   (∨I₁)
      [B]²
```

从下往上读：要证明这个蕴涵，用 (⟶I¹) 假设 A ∨ B。要使用这个析取，用 (∨E²) 分成两种情形。在情形 A 中，目标 B ∨ A 由 (∨I₂) 得出，因为 A 是它的右边；在情形 B 中，目标由 (∨I₁) 得出。

::: pitfall
(∨I₁) 和 (∨I₂) 要求你选定一边。选得太早，你就会卡住：如果上面的推导在 (⟶I¹) 之后马上对目标 B ∨ A 应用 (∨I₁)，它就必须由 A ∨ B 证明 B，而这是不可能的，因为 A ∨ B 可以为真而 B 为假。当目标是析取式时，先看看假设；在这里，正是先用 (∨E) 拆开 A ∨ B，才使选择成为可能。第 6.7 节会把这一点变成一条经验法则。
:::

### 否定与恒假 {#not}

否定借助一个新的公式 **⊥** 来处理（读作“bottom”或“falsum”）：它在每个赋值和每个结构中都为假，是一个恒假的公式。Isabelle 把它写作 `False`。¬A 被看作 A ⟶ ⊥：说 A 是假的，就是说 A 会导致荒谬。于是 ¬ 的规则就是把 B 换成 ⊥ 之后的 ⟶ 的规则，而 ⊥ 还有一条自己的规则：

$$
\dfrac{\begin{matrix}[A]^1\\ \vdots\\ \bot\end{matrix}}{\lnot A}\;(\lnot\mathrm{I}^1)
\qquad\qquad
\dfrac{\lnot A \qquad A}{\bot}\;(\lnot\mathrm{E})
\qquad\qquad
\dfrac{\bot}{C}\;(\bot\mathrm{E})
$$

(¬I)：要证明 ¬A，就假设 A 并推导出 ⊥，就像“假设存在一个最大的自然数；那么……，矛盾”那样。(¬E)：A 和 ¬A 合起来得到 ⊥。(⊥E) 即拉丁语所说的 ex falso quodlibet（“由假可得一切”），它由 ⊥ 得出任意公式 C。它永远不会由真导向假，因为 ⊥ 永远不为真。证明用它来排除不可能的情形：一个导致 ⊥ 的情形，无论目标是什么都能证明。程序员从不可达代码中就熟悉这个想法：一个永远不会执行的分支可以承诺任何结果，因为它永远不必兑现。

下面是模块 2 中的一条德摩根律（De Morgan's law）：如果“A 或 B”不成立，那么 A 不成立，B 也不成立。

```prooftree
¬(A ∨ B) ⟶ ¬A ∧ ¬B   (⟶I¹)
  ¬A ∧ ¬B   (∧I)
    ¬A   (¬I²)
      ⊥   (¬E)
        [¬(A ∨ B)]¹
        A ∨ B   (∨I₁)
          [A]²
    ¬B   (¬I³)
      ⊥   (¬E)
        [¬(A ∨ B)]¹
        A ∨ B   (∨I₂)
          [B]³
```

要证明 ¬A，用 (¬I²) 假设 A。于是由 (∨I₁) 得到 A ∨ B，再由 (¬E)，它与假设 ¬(A ∨ B) 矛盾。¬B 同理可得，最后由 (∧I) 把两者合在一起。

把到目前为止的规则汇总成一张表：

| 公式 | 引入：怎样证明它 | 消去：怎样使用它 |
|---|---|---|
| A ∧ B | 分别证明 A 和 B (∧I) | 得出 A (∧E₁)，或得出 B (∧E₂) |
| A ∨ B | 证明 A (∨I₁)，或证明 B (∨I₂) | 由 A 证明目标，再由 B 证明目标 (∨E) |
| A ⟶ B | 假设 A，证明 B (⟶I) | 有了 A，得出 B (⟶E) |
| ¬A | 假设 A，证明 ⊥ (¬I) | 有了 A，得出 ⊥ (¬E) |
| ⊥ | 没有规则 | 得出任意公式 (⊥E) |

## 经典推理 {#classical}

用第 6.4 节的规则，你可以推导出许多重言式（tautology），但不是全部。试试 A ∨ ¬A，即**排中律**（law of excluded middle）：(∨I₁) 需要 A 的推导，(∨I₂) 需要 ¬A 的推导，而这两者你都没有。¬¬A ⟶ A 以及德摩根律中的一条 ¬(A ∧ B) ⟶ ¬A ∨ ¬B 也是如此。这三个公式都是重言式（可以检查它们的真值表），但用目前的规则，一个也推导不出来。再加一条规则就能补上这个缺口：

$$
\dfrac{\begin{matrix}[\lnot A]^1\\ \vdots\\ \bot\end{matrix}}{A}\;(\mathrm{RAA}^1)
$$

**(RAA)** 得名于拉丁语 reductio ad absurdum（归谬法），它是完整形式的反证法：要证明 A，就假设 ¬A 并推导出 ⊥。把它和 (¬I) 比较一下：(¬I) 假设 A，推导出 ⊥，然后得出 ¬A。(¬I) 通过驳倒肯定的陈述来证明否定的陈述；“不存在最大的自然数”的证明（第 6.1 节）就属于这一种。(RAA) 则由一个肯定陈述的否定不可能成立，来证明这个肯定陈述。

::: fact 经典逻辑还需要一条规则
没有 (RAA)，第 6.4 节的规则推导不出 A ∨ ¬A、¬¬A ⟶ A 或 ¬(A ∧ B) ⟶ ¬A ∨ ¬B，尽管这三个公式都是重言式。在 (RAA)、排中律（对每个 A 都有 A ∨ ¬A）和双重否定消去（由 ¬¬A 得出 A）这三条规则中，无论加入哪一条，得到的可推导公式都相同，即**经典逻辑**（classical logic）的公式。
:::

下面是双重否定消去（double-negation elimination）：

```prooftree
¬¬A ⟶ A   (⟶I¹)
  A   (RAA²)
    ⊥   (¬E)
      [¬¬A]¹
      [¬A]²
```

要证明 A，用 (RAA²) 假设 ¬A；它与 ¬¬A 一起，由 (¬E) 得出矛盾。另一个方向 A ⟶ ¬¬A 不需要 (RAA)：假设 A；要证明 ¬¬A，就用 (¬I) 假设 ¬A；A 和 ¬A 由 (¬E) 得出 ⊥。

排中律需要多一点巧思：

```prooftree
A ∨ ¬A   (RAA¹)
  ⊥   (¬E)
    [¬(A ∨ ¬A)]¹
    A ∨ ¬A   (∨I₂)
      ¬A   (¬I²)
        ⊥   (¬E)
          [¬(A ∨ ¬A)]¹
          A ∨ ¬A   (∨I₁)
            [A]²
```

假设它的反面 ¬(A ∨ ¬A)。如果 A 成立，那么 A ∨ ¬A 成立，与这个假设矛盾，所以由 (¬I²) 得到 ¬A。但由 ¬A，用 (∨I₂) 终究还是得到了 A ∨ ¬A：又一次矛盾，于是 (RAA¹) 得出 A ∨ ¬A。假设 ¬(A ∨ ¬A) 用了两次，一次在 [A]² 的辖域之内，一次在它之外。

德摩根律有四个方向，其中只有一个需要 (RAA)：

| 定律 | 需要 (RAA) 吗？ |
|---|---|
| ¬(A ∨ B) ⟶ ¬A ∧ ¬B | 不需要：第 6.4 节 |
| ¬A ∧ ¬B ⟶ ¬(A ∨ B) | 不需要：见下文 |
| ¬A ∨ ¬B ⟶ ¬(A ∧ B) | 不需要：练习 6.5 |
| ¬(A ∧ B) ⟶ ¬A ∨ ¬B | 需要：见下文 |

```prooftree
¬A ∧ ¬B ⟶ ¬(A ∨ B)   (⟶I¹)
  ¬(A ∨ B)   (¬I²)
    ⊥   (∨E³)
      [A ∨ B]²
      ⊥   (¬E)
        ¬A   (∧E₁)
          [¬A ∧ ¬B]¹
        [A]³
      ⊥   (¬E)
        ¬B   (∧E₂)
          [¬A ∧ ¬B]¹
        [B]³
```

目标 ¬(A ∨ B) 是一个否定，所以用 (¬I²) 假设 A ∨ B，再用 (∨E³) 分情形推导出 ⊥：在每种情形中，假设 ¬A ∧ ¬B 都提供了相应的否定。第四条定律需要 (RAA)，下面的推导用了它三次。用 (RAA²) 假设 ¬A ∨ ¬B 为假。那么 A 必定成立，因为 ¬A 会使 ¬A ∨ ¬B 为真，这一步用的是 (RAA³)；同理，B 也必定成立，用的是 (RAA⁴)。但由 (¬E)，A ∧ B 与假设 ¬(A ∧ B) 矛盾：

```prooftree
¬(A ∧ B) ⟶ ¬A ∨ ¬B   (⟶I¹)
  ¬A ∨ ¬B   (RAA²)
    ⊥   (¬E)
      [¬(A ∧ B)]¹
      A ∧ B   (∧I)
        A   (RAA³)
          ⊥   (¬E)
            [¬(¬A ∨ ¬B)]²
            ¬A ∨ ¬B   (∨I₁)
              [¬A]³
        B   (RAA⁴)
          ⊥   (¬E)
            [¬(¬A ∨ ¬B)]²
            ¬A ∨ ¬B   (∨I₂)
              [¬B]⁴
```

为什么这个方向需要 (RAA)？要用 (∨I₁) 或 (∨I₂) 证明 ¬A ∨ ¬B，你得知道 A 和 B 中**哪一个**不成立，而 ¬(A ∧ B) 并没有说。(RAA) 不必知道是哪一边，就能得出这个析取。第 6.1 节的逆否命题模式也是如此：(A ⟶ B) ⟶ (¬B ⟶ ¬A) 不需要 (RAA)，但这个模式所用的方向 (¬B ⟶ ¬A) ⟶ (A ⟶ B) 需要（练习 6.5）。

### 直觉主义逻辑 {#intuitionistic}

没有 (RAA) 的自然演绎就是**直觉主义逻辑**（intuitionistic logic）。它可以追溯到布劳威尔（L. E. J. Brouwer）在 20 世纪初提出的观点：证明必须把它所谈论的东西构造出来；阿伦德·海廷（Arend Heyting）在 1930 年写下了它的规则。在直觉主义逻辑中，A ∨ B 的证明会告诉你哪一边成立，∃x. P x 的证明会给出一个见证。经典的证明则不必如此，下面这个著名的例子就说明了这一点。

::: example 一个不说明是哪一个的证明
**断言**：存在无理数 a 和 b，使得 $a^b$ 是有理数。

**证明**：$\sqrt2$ 是无理数。数 $\sqrt2^{\sqrt2}$ 要么是有理数，要么不是（排中律）。如果它是有理数，取 $a = b = \sqrt2$。如果它不是，取 $a = \sqrt2^{\sqrt2}$ 和 $b = \sqrt2$；那么 $a^b = \sqrt2^{\sqrt2 \cdot \sqrt2} = \sqrt2^{\,2} = 2$，是有理数。∎

这个证明说明了合适的一对数是存在的，却没有说明它是两组候选中的哪一组。
:::

::: note
直觉主义的证明可以读作程序：A ⟶ B 的证明是一个函数，它把 A 的证据变成 B 的证据；A ∧ B 的证明是一个有序对；A ∨ B 的证明是一个标记为“左”或“右”的值。于是 A ∧ B ⟶ B ∧ A 的推导就是交换有序对两个分量的函数，而 (A ⟶ B) ⟶ (B ⟶ C) ⟶ (A ⟶ C) 的推导则把两个函数复合起来。这就是**柯里–霍华德对应**（Curry–Howard correspondence），Rocq 和 Lean 等证明助手就建立在它的基础之上。(RAA) 一般没有这样的解读：一个能为每个 A 都给出 A ∨ ¬A 的证据的程序，将能判定每一个问题，包括任意一个程序是否会停机。
:::

和大部分数学一样，Isabelle/HOL 是经典的：(RAA) 是它的规则之一（模块 7）。尽管如此，还是要留意证明在什么时候用到了 (RAA)：它说明了某件事**成立**，却没有说明是**哪种**情形，或者见证是**什么**。

## 量词规则 {#quantifiers}

在 ∀ 和 ∃ 的规则中，**P x** 代表任意一个公式，变元 x 可以在其中自由出现；**P t** 代表把其中每个自由出现的 x 都换成项（term）t 之后得到的公式。和模块 3 一样，必要时要给约束变元（bound variable）改名，使 t 中的变元不会被捕获（capture）。例如，如果 P x 是 x ≤ y，那么 P 3 是 3 ≤ y；如果 P x 是 ∃y. x < y，那么 P y 是 ∃z. y < z，而不是 ∃y. y < y。

$$
\dfrac{P\,a}{\forall x.\; P\,x}\;(\forall\mathrm{I})
\qquad\qquad
\dfrac{\forall x.\; P\,x}{P\,t}\;(\forall\mathrm{E})
$$

$$
\dfrac{P\,t}{\exists x.\; P\,x}\;(\exists\mathrm{I})
\qquad\qquad
\dfrac{\begin{matrix}\\ \\ \exists x.\; P\,x\end{matrix} \qquad \begin{matrix}[P\,a]^1\\ \vdots\\ C\end{matrix}}{C}\;(\exists\mathrm{E}^1)
$$

每条规则都对应第 6.1 节的一种非形式化模式：

- **(∀I)** 就是任意元素模式。如果你对一个没有做任何假设的名字 a 证明了 P a，那么同样的论证对每个元素都行得通，所以 ∀x. P x。**附加条件**（side condition）：a 不在 ∀x. P x 中自由出现，也不在 P a 的推导的任何未解除的假设中自由出现。
- **(∀E)** 应用一个一般性的事实：对所有元素成立的，对 t 也成立，t 可以是你选择的任何项。
- **(∃I)** 就是见证模式：对某个项 t，由 P t 得出 ∃x. P x。
- **(∃E)** 给见证命名。要用 ∃x. P x 来证明目标 C，就给见证起一个新名字 a，假设 P a，然后推导出 C；这条规则解除 [P a]。**附加条件**：a 不在 ∃x. P x 中、不在 C 中，也不在 C 的推导中除 [P a] 以外的任何未解除的假设中自由出现。C 不能提到 a，因为在这段论证之外，见证是未知的。

::: definition 本征变元条件
(∀I) 和 (∃E) 中的名字 a 叫作这条规则的**本征变元**（eigenvariable），这是根岑的术语，意思是“自己的变元”。**本征变元条件**（eigenvariable condition）就是上面每条规则的附加条件：a 必须是**新的**（fresh）。它不能在规则的结论中、在被量化的公式中，也不能在关于 a 的论证所依赖的任何未解除的假设中自由出现，但 (∃E) 所解除的假设 [P a] 除外。
:::

第一个例子：如果每个账户都已开通并且已认证，那么每个账户都已开通，并且每个账户都已认证。用 P x 表示“x 已开通”，Q x 表示“x 已认证”：

```prooftree
(∀x. P x ∧ Q x) ⟶ (∀x. P x) ∧ (∀x. Q x)   (⟶I¹)
  (∀x. P x) ∧ (∀x. Q x)   (∧I)
    ∀x. P x   (∀I)
      P a   (∧E₁)
        P a ∧ Q a   (∀E)
          [∀x. P x ∧ Q x]¹
    ∀x. Q x   (∀I)
      Q a   (∧E₂)
        P a ∧ Q a   (∀E)
          [∀x. P x ∧ Q x]¹
```

按照模块 3 中 Isabelle 的约定来读这个公式：量词的辖域尽可能向右延伸，所以 ∀x. P x ∧ Q x 外面的括号是必需的。现在检查附加条件。在每个 (∀I) 处，本征变元 a 都不出现在结论 ∀x. P x 或 ∀x. Q x 中，而它上方唯一未解除的假设 ∀x. P x ∧ Q x 也没有提到 a。(∀E) 用 a 实例化这个假设。两个分支可以使用同一个名字，因为每个 (∀I) 都只在自己的分支上检查。

第二个例子交换两个量词。把 R x y 读作“钥匙 x 能打开门 y”。于是 ∃x. ∀y. R x y 说的是存在一把万能钥匙，即一把能打开每扇门的钥匙；而 ∀y. ∃x. R x y 说的是每扇门都有一把能打开它的钥匙。万能钥匙就是每扇门的钥匙：

```prooftree
(∃x. ∀y. R x y) ⟶ (∀y. ∃x. R x y)   (⟶I¹)
  ∀y. ∃x. R x y   (∀I)
    ∃x. R x b   (∃E²)
      [∃x. ∀y. R x y]¹
      ∃x. R x b   (∃I)
        R a b   (∀E)
          [∀y. R a y]²
```

从下往上看：用 (⟶I¹) 假设存在一把万能钥匙。要说明每扇门都有钥匙，用 (∀I) 取任意一扇门 b。用 (∃E²) 把万能钥匙叫作 a，于是 ∀y. R a y。特别地，由 (∀E)，a 能打开 b；所以由 (∃I)，门 b 有一把钥匙，就是 a。检查附加条件：

- (∃E²) 的本征变元是 a，它既不出现在 ∃x. ∀y. R x y 中，也不出现在结论 ∃x. R x b 中，也不出现在除 [∀y. R a y]² 以外的任何未解除的假设中。
- (∀I) 的本征变元是 b。它上方的推导只有一个未解除的假设 ∃x. ∀y. R x y，因为 [∀y. R a y]² 在这个推导内部已经被 (∃E²) 解除了。这个假设和结论 ∀y. ∃x. R x y 都没有提到 b。

它的逆命题 (∀y. ∃x. R x y) ⟶ (∃x. ∀y. R x y) 说的是：如果每扇门都有钥匙，那么存在一把万能钥匙。它不是有效的。取论域（domain）为 {0, 1} 的结构，其中 R x y 在 x = y 时成立：每个元素只能打开它自己。每个元素都能被某个元素打开，所以 ∀y. ∃x. R x y 为真；没有哪个元素能同时打开两者，所以 ∃x. ∀y. R x y 为假，于是逆命题在这个结构中为假。由可靠性，它没有推导。

### 两个错误的证明 {#wrong}

如果硬要去证明，会在哪里出错？下面是对这个逆命题的一次尝试：

```prooftree
(∀y. ∃x. R x y) ⟶ (∃x. ∀y. R x y)   (⟶I¹)
  ∃x. ∀y. R x y   (∃E²)
    ∃x. R x b   (∀E)
      [∀y. ∃x. R x y]¹
    ∃x. ∀y. R x y   (∃I)
      ∀y. R a y   (∀I)
        [R a b]²
```

除了一步之外，每一步都符合规则。用话来说就是：“门 b 有一把钥匙，把它叫作 a (∃E²)；所以 a 能打开 b；b 是任意的，所以 a 能打开每扇门 (∀I)；所以存在一把万能钥匙 (∃I)”。错的是 (∀I) 这一步。它的本征变元 b 出现在未解除的假设 [R a b]² 中，而这个假设要到更下面才被 (∃E²) 解除。门 b 并不是任意的：它的钥匙已经被叫作 a 了。

第二次尝试“证明”了：如果某个元素具有某个性质，那么所有元素都具有这个性质：

```prooftree
(∃x. P x) ⟶ (∀x. P x)   (⟶I¹)
  ∀x. P x   (∀I)
    P a   (∃E²)
      [∃x. P x]¹
      [P a]²
```

用话来说就是：“某个用户是管理员；把这个用户叫作 a；所以 a 是管理员；a 是任意的，所以每个用户都是管理员”。这一次，(∀I) 遵守了它的规则：它唯一未解除的假设 ∃x. P x 没有提到 a。错误在于 (∃E²)，它的结论 P a 提到了本征变元 a。这个名字逃出了引入它的那段论证，于是 (∀I) 把一个特定的、未知的见证当成了任意元素。

第 6.1 节中的那个错误，即用同一个名字 k 表示 m 和 n 两者的一半，违反的也是这个条件。第一个 (∃E) 用假设 m = 2k 引入了 k 之后，第二个以 k 为本征变元的 (∃E) 就会有一个提到 k 的未解除的假设 m = 2k。

::: keyidea
正是附加条件使 (∀I) 和 (∃E) 成为可靠的规则。上面两个错误的结论在一个有两个元素的结构中都为假，所以它们没有正确的推导，而错误的推导恰恰是在附加条件上出的错。手工检查推导时，先检查每个本征变元。
:::

::: pitfall
使用 (∀E) 时要小心约束变元。由 ∀x. ∃y. x < y（“没有最大的数”），用 y 实例化 x，可以得出 ∃z. y < z。如果不改名就把 x 换成 y，会得到 ∃y. y < y，它说的完全是另一回事，而且对数来说是假的。代入的 y 必须保持自由（模块 3）。
:::

## 寻找证明：反向与正向 {#search}

检查推导是机械的；寻找推导则需要搜索。搜索有两个方向。

**正向**：从假设出发，不断应用规则，直到目标出现。关于 $\mathit{even}$ 的系统就是这样得到 $\mathit{even}\ 4$ 的。它的弱点是，规则能推导出无穷无尽的公式（单是 (∧I) 就能造出 A ∧ A、A ∧ (A ∧ A)……），却没有什么能告诉你其中哪些通向目标。

**反向**：从目标出发。选一条结论与目标相匹配的规则；规则的前提成为新的目标，叫作**子目标**（subgoal），而规则所解除的假设可以在这些子目标中使用。重复这样做，直到剩下的每个目标都是它自己的假设之一。目标引导着搜索：它的主联结词决定用哪条引入规则，它的假设则提示可以用哪些消去规则。Isabelle 就是这样工作的。它的证明状态（proof state）是一个目标列表，每个目标都带着自己的假设；每一步证明都把一个目标换成某条规则的子目标（模块 7）。

把一个目标写成 Γ ⊢ C：Γ 列出它的假设，C 是还有待证明的东西。下面一步一步地为 A ∨ B ⟶ B ∨ A 搜索推导（图 6.3）：

1. ⊢ A ∨ B ⟶ B ∨ A。主联结词是 ⟶，所以应用 (⟶I¹)。新的目标是 A ∨ B ⊢ B ∨ A。
2. A ∨ B ⊢ B ∨ A。有两类规则适用。对目标应用 (∨I₁) 会留下 A ∨ B ⊢ B，而当 A 为真、B 为假时它不成立：这是一条死路（dead end）。对假设 A ∨ B 应用 (∨E²) 会留下两个目标 A ⊢ B ∨ A 和 B ⊢ B ∨ A，两个都必须证明。
3. A ⊢ B ∨ A。应用 (∨I₂) 留下 A ⊢ A，这个目标就是它自己的假设之一：它被关闭了。
4. B ⊢ B ∨ A。应用 (∨I₁) 留下 B ⊢ B：关闭。

没有剩下的目标了。把这些步骤从最后一步倒着读回第一步，就得到第 6.4 节中的那个推导。

::: figure id=fig-06-3
A ∨ B ⟶ B ∨ A 的反向搜索。每个方框是一个带着假设的目标。实线箭头指向必须全部证明的子目标；虚线箭头是另一种走法，它通向一条死路。
:::

反向工作时，消去规则作用于目标的某个假设：

- 已有 A ∧ B 时，(∧E₁) 和 (∧E₂) 把 A 或 B 加入假设。
- 已有 A ∨ B 时，(∨E) 把目标一分为二，一个以 A 为新假设，一个以 B 为新假设。
- 有假设 A ⟶ B 时，(⟶E) 把目标 B 变成目标 A。
- 有假设 ¬A 时，(¬E) 把目标 ⊥ 变成目标 A。
- 已有 ∀x. P x 时，(∀E) 加入 P t，其中 t 是你选择的项。
- 已有 ∃x. P x 时，(∃E) 加入 P a，其中 a 是一个新名字。

有些步骤永远不会出错；另一些则是在打赌。

::: definition 安全的步骤
如果反向搜索中的一步永远不会把一个可证的目标变成不可证的目标，即只要目标能被证明，所有子目标也都能被证明，这一步就是**安全的**（safe）。不安全的步骤可能把你带进死路，那时你必须退回去，换一种做法。
:::

作用于目标的 (⟶I)、(¬I)、(∧I) 和 (∀I) 是安全的，作用于假设的 (∧E₁)、(∧E₂)、(∨E) 和 (∃E) 也是安全的。(∨I₁) 和 (∨I₂) 不安全，第 2 步已经说明了这一点；(∃I) 也不安全，因为它的见证可能选错；(⊥E) 也不安全，因为它把目标换成了 ⊥。Isabelle 的参考手册对它的自动证明器做了同样的区分：安全规则“绝不能把一个可证的目标归约为一组不可证的子目标”。由此得出下面的经验法则：

1. 如果一个目标是它自己的假设之一，就**关闭**它。
2. 对目标**应用安全的引入规则**：(⟶I)、(¬I)、(∧I)，以及带新名字的 (∀I)。
3. 对假设**应用安全的消去规则**：拆开 A ∧ B，按 A ∨ B 分情形，用一个新名字打开 ∃x. P x。
4. **然后再做选择**，并随时准备退回。如果某个假设 A ⟶ B 的结论恰好是目标，就用 (⟶E) 使用它。用 (∀E) 以一个已经出现过的项实例化 ∀x. P x。对于目标 ∃x. P x，用 (∃I) 选一个你已经有的见证。对于目标 A ∨ B，用 (∨I₁) 或 (∨I₂) 选择能从假设得出的那一边。
5. **如果目标是 ⊥**，就找一个假设 ¬A，试着用 (¬E) 去证明 A。如果目标是别的公式，而假设之间相互矛盾，就用 (⊥E) 把目标变成 ⊥。
6. **如果卡住了**，就用 (RAA)：假设目标的否定，然后以 ⊥ 为目标。像 A ∨ ¬A 这样两边都无法单独证明的目标 A ∨ B，就需要这样做。

对量词来说，第 3 步和第 4 步的顺序很重要：先打开存在量词的假设，让它们的见证有名字，再用这些名字实例化全称量词的假设。在万能钥匙的推导中，(∃E²) 把万能钥匙命名为 a，然后 (∃I) 用 a 作为它的见证。

在逆命题 (∀y. ∃x. R x y) ⟶ (∃x. ∀y. R x y) 上试试这个策略。用了 (⟶I) 之后，目标 ∃x. ∀y. R x y 没有可用的安全规则，假设也没有，所以你必须做出选择。用某个名字 c 实例化假设，再打开得到的结果：对一把新钥匙 a 有 R a c。取 a 作为见证：目标变成 ∀y. R a y，而 (∀I) 需要一扇新的门，它不能是 c，因为 c 出现在假设中。所以它是一扇新门 d，而目标 R a d 遥不可及：你知道的只是 R a c。用 d 实例化假设会得到 d 的一把钥匙，但 (∃E) 必须给它起一个新名字，不能叫 a。每一扇新门都带来一把新钥匙，搜索永远无法结束。这并非偶然：这个公式不是有效的，所以由可靠性，每一次搜索都必定失败。

::: widget name=nd-builder
像上面那样反向构造证明。从列表中选一个目标，或者输入你自己的公式。先选中一个目标，再选一条规则；如果是消去规则，先点击它要使用的假设。项和名字的输入框供 (∀I)、(∃I)、(∀E) 和 (∃E) 使用；如果留空，(∀I) 和 (∃E) 会得到一个新名字。先从 A ∧ B ⟶ B ∧ A 开始，把完成的树与第 6.4 节比较。然后在 A ∨ B ⟶ B ∨ A 中过早地应用 (∨I₁)，看看死路警告，再点击**撤销**。最后选倒数第二个目标，也就是上面的逆命题，看本征变元检查怎样堵住每一条出路。

## 相等 {#equality}

相等有两条规则：一条用来证明等式，一条用来使用等式。

$$
\dfrac{}{t = t}\;(\mathord{=}\mathrm{I})
\qquad\qquad
\dfrac{s = t \qquad P\,s}{P\,t}\;(\mathord{=}\mathrm{E})
$$

(=I) 即**自反性**（reflexivity），它没有前提：每个项都等于它自己。(=E) 即**代入**（substitution），它说：如果 s = t，那么对 s 成立的任何事情对 t 也成立，也就是说，可以用相等的东西替换相等的东西。和量词规则中一样，P x 是一个 x 在其中自由出现的公式，P s 和 P t 是把其中的 x 分别换成 s 和 t 得到的公式。通过选择 x 在 P x 中的位置，你可以选择替换哪些出现。

由此可以推出相等的对称性：

```prooftree
s = t ⟶ t = s   (⟶I¹)
  t = s   (=E)
    [s = t]¹
    s = s   (=I)
```

这里 P x 是 x = s。于是 P s 是 s = s，由 (=I) 提供；P t 是 t = s，即结论。传递性也可以推出：

```prooftree
r = s ⟶ s = t ⟶ r = t   (⟶I¹)
  s = t ⟶ r = t   (⟶I²)
    r = t   (=E)
      [s = t]²
      [r = s]¹
```

这一次 P x 是 r = x：由 s = t 和 P s（即 r = s），得出 P t（即 r = t）。

第三个推论对程序员很重要。对一个函数符号 f：

```prooftree
s = t ⟶ f s = f t   (⟶I¹)
  f s = f t   (=E)
    [s = t]¹
    f s = f s   (=I)
```

这里 P x 是 f s = f x：函数对相等的参数给出相等的结果。在程序中，这只对**纯**函数（pure function）成立，即结果只取决于参数的函数；对读取时钟的方法就不成立。一个复用 `f(s)` 的值、而不再次调用 `f` 的编译器，依赖的就是这条定律，所以它必须先确认 `f` 是纯函数。Isabelle/HOL 中的函数是数学意义上的函数，所以在那里这条定律总是成立。

::: pitfall
代入时不能捕获变元。由 x = y 和 ∀y. R x y，不能得出 ∀y. R y y。取 P z = ∀y. R z y，那么给约束变元改名之后（模块 3），公式 P y 是 ∀w. R y w；被代入的 y 必须保持自由。
:::

## 从纸面到 Isabelle {#isabelle}

Isabelle 自带的 Isabelle/HOL 教程说，Isabelle“是围绕自然演绎设计的”。模块 7 会在 Isabelle 中一条规则一条规则地重现本模块的推导；在这里，先让证明搜索来完成工作。`blast`（模块 2 和模块 3）是 Isabelle 中针对这类目标的证明搜索工具。它的参考手册把它描述为一个表列证明器（tableau prover），它使用 Isabelle 的经典规则，这些规则像第 6.7 节那样分为安全的和不安全的两类；它找到的证明会用 Isabelle 的规则重新构造出来，并由内核检查。把下面这些引理加到一个理论中，例如模块 1 中的那个理论：

```isabelle
lemma "A ∧ B ⟶ B ∧ A"
  by blast

lemma "(A ⟶ B) ⟶ (B ⟶ C) ⟶ (A ⟶ C)"
  by blast

lemma "A ∨ B ⟶ B ∨ A"
  by blast

lemma "¬(A ∨ B) ⟶ ¬A ∧ ¬B"
  by blast
```

Isabelle 接受了全部四条引理：没有出现任何错误。Isabelle/HOL 是经典的，所以第 6.5 节的公式也都是定理：

```isabelle
lemma "¬¬A ⟶ A"
  by blast

lemma "A ∨ ¬A"
  by blast

lemma "¬(A ∧ B) ⟶ ¬A ∨ ¬B"
  by blast
```

量词的例子也是一样。给关系起一个比 R 更能说明含义的名字，再用 k 和 d 表示钥匙和门，万能钥匙引理就写成：

```isabelle
lemma "(∀x. P x ∧ Q x) ⟶ (∀x. P x) ∧ (∀x. Q x)"
  by blast

lemma "(∃k. ∀d. opens k d) ⟶ (∀d. ∃k. opens k d)"
  by blast
```

和模块 3 中一样，自由变元 `P`、`Q` 和 `opens` 不需要声明：Isabelle 会推断它们的类型，并把它们看作代表任意的谓词。逆命题则失败了：

```isabelle fails
lemma "(∀d. ∃k. opens k d) ⟶ (∃k. ∀d. opens k d)"
  by blast
```

```output
*** Failed to apply initial proof method⌂:
*** goal (1 subgoal):
***  1. (∀d. ∃k. opens k d) ⟶ (∃k. ∀d. opens k d)
```

`blast` 放弃了，Isabelle 报告“Failed to apply initial proof method”（未能应用初始的证明方法）。单凭这一点什么也证明不了：`blast` 只搜索到某个界限为止（它的参考手册说，它先不允许任何不安全的步骤，然后允许一步，依此类推，直到 20 步，然后停止），更聪明的搜索也许能成功。反例才能解决这个问题。在 Isabelle/jEdit 中，Auto Quickcheck（模块 1）可能已经给这条引理标出了一个反例；Nitpick 则能给出更清楚的图景：

```isabelle
lemma "(∀d. ∃k. opens k d) ⟶ (∃k. ∀d. opens k d)"
  nitpick [card = 2]
  oops
```

```output result
Nitpicking formula...

Nitpick found a counterexample for card 'a = 2 and card 'b = 2:
  Free variable:
    opens =
      (λx. _)
      (b⇩1 := (λx. _)(a⇩1 := False, a⇩2 := True),
         b⇩2 := (λx. _)(a⇩1 := True, a⇩2 := False))
  Skolem constants:
    λk. d = (λx. _)(b⇩1 := a⇩1, b⇩2 := a⇩2)
    λd. k = (λx. _)(a⇩1 := b⇩2, a⇩2 := b⇩1)
```

Isabelle 推断出了两个类型，一个是钥匙的类型，一个是门的类型；Nitpick 在每个类型中考察了两个元素：钥匙 b₁ 和 b₂，门 a₁ 和 a₂。它给出的 `opens` 的值是一张由表组成的表：钥匙 b₁ 能打开门 a₂，打不开 a₁；钥匙 b₂ 能打开门 a₁，打不开 a₂。所以每扇门都有钥匙，却没有哪把钥匙能同时打开两扇门。**Skolem constants**（Skolem 常量）这一部分给出了反例背后的选择：`λk. d` 对每把钥匙 k 给出一扇它打不开的门 d，`λd. k` 对每扇门 d 给出能打开它的钥匙 k。钥匙是门的函数，这正是这个例子的要点：在 ∀d. ∃k 中，钥匙可以依赖于门。由可靠性，这条引理不存在证明。

最后，相等也在 Isabelle 的规则集中：

```isabelle
lemma "s = t ⟶ t = s"
  by blast
```

::: keyidea
无论在纸上还是在 Isabelle 中，你用的都是同样的两件工具：推导确立 ⊢，反例驳倒 ⊨。可靠性把两者联系起来，而证明助手还提供了一项纸面无法提供的保证：每个推导的每一步都经过了它的内核的检查。
:::

## 小结 {#summary}

- **证明**是一串步骤，每一步都以一条规则为依据。非形式化的证明遵循几种模式：假设前提、情形分析、反证、逆否命题、任意元素、见证，以及给见证命名。
- **证明系统**由推理规则组成；**推导**是一棵由规则应用构成的树。**Γ ⊢ A** 的意思是 A 有一个推导，其中未解除的假设都在 Γ 中；检查推导是机械的。
- **Γ ⊨ A** 关乎真。**可靠性**（⊢ 蕴涵 ⊨）意味着系统推导不出任何假的东西；**完备性**（⊨ 蕴涵 ⊢）意味着它能推导出每一个逻辑推论。对命题逻辑和一阶逻辑，自然演绎两者兼备。一个反例就能说明推导不存在。
- **自然演绎**有引入规则和消去规则，前者用来证明带某个联结词的公式，后者用来使用这样的公式：(∧I)、(∧E₁)、(∧E₂)、(∨I₁)、(∨I₂)、(∨E)、(⟶I)、(⟶E)、(¬I)、(¬E) 和 (⊥E)。(⟶I) 这样的规则会**解除**假设，被解除的假设写作 [A]¹；它只能在解除它的规则之上使用。
- **(RAA)** 使这个系统成为经典的：A ∨ ¬A、¬¬A ⟶ A 和 ¬(A ∧ B) ⟶ ¬A ∨ ¬B 都需要它。没有它，逻辑就是**直觉主义的**，它的证明可以读作程序。
- 量词规则 (∀I)、(∀E)、(∃I)、(∃E) 对应于非形式化的模式。(∀I) 和 (∃E) 的**本征变元**必须是新的；大多数错误的量词证明都违反了这个条件。
- 相等有两条规则：(=I) 即自反性，(=E) 即用相等的东西替换相等的东西。
- **反向搜索**从目标出发，把它换成子目标，Isabelle 就是这样做的。先应用**安全的**规则，再做选择，卡住时用 (RAA)。`blast` 就是这样搜索的；Nitpick 则寻找反例。

:::: exercise 说出模式 {#ex-6-1} ★
下面每个论证都用到了第 6.1 节中的一种或两种模式。说出它们的名称，以及每种模式背后的自然演绎规则。

1. “如果门锁上了，警报就处于戒备状态。门锁上了。所以警报处于戒备状态。”
2. “设 u 是任意一个用户。每个用户都有密码，所以 u 有密码；每个密码都以哈希形式存储，所以 u 的密码也是。因为 u 是任意的，所以每个用户的密码都以哈希形式存储。”
3. “一个事务要么提交，要么中止。如果它提交了，日志会记录下来；如果它中止了，日志会记录这次中止。无论哪种情况，日志中都有这个事务的一条记录。”
4. “假设某个进程同时持有两把锁；把它叫作 p。那么 p 在持有第一把锁的同时获取了第二把锁，而锁管理器从不允许这样做。所以没有进程同时持有两把锁。”
5. “对输入 [3, 1, 2]，这个函数返回 [1, 3, 2]，它不是有序的。所以这个函数对某个输入是错的。”

::: solution
1. 一个直接的步骤，即**肯定前件式**：由 A ⟶ B 和 A 得出 B。规则 (⟶E)。
2. **任意元素**：先通过 (∀E) 使用关于所有用户和所有密码的两个一般性事实，再对 u 应用 (∀I)。本征变元条件成立：所用的事实都没有提到 u。
3. **情形分析**：对“提交或中止”应用 (∨E)，在每种情形中再用 (⟶E)。
4. 用**反证**来证明一个否定的陈述，即 (¬I)：假设某个进程同时持有两把锁，然后推出不可能的事情。在这个论证内部还有**给见证命名**：“把它叫作 p”就是 (∃E)。
5. **见证**：输入 [3, 1, 2] 是“存在一个使函数出错的输入”的见证，规则 (∃I)。一个测试就能证明一个存在性的断言。
:::

:::: exercise 可靠、完备，还是都不是？ {#ex-6-2} ★
1. 一个命题逻辑的证明系统包含第 6.4 节的全部规则，外加一条：由 A ⟶ B 和 B 得出 A。它是可靠的吗？用一个赋值来说明你的理由。
2. 另一个系统只有 (∧I)、(∧E₁) 和 (∧E₂) 三条规则。它是可靠的吗？对命题逻辑来说，它是完备的吗？
3. 对公式 A 的证明搜索已经运行了一个小时，还没有找到推导。关于 A，你知道些什么？
4. Nitpick 找到了 A 的一个反例。关于 ⊢ A，你知道些什么？

::: solution
1. **不可靠。** 新规则由 A ⟶ B 和 B 推导出 A。A 为假、B 为真的赋值使两个前提都为真（A ⟶ B 为真，因为 A 为假），而使结论 A 为假，所以 A ⟶ B, B ⊭ A。用话来说：“如果下过雨，街道就是湿的；街道是湿的；所以下过雨”不是一个有效的论证。
2. **可靠**，因为每条规则都把真的前提变成真的结论。**不完备**：不带假设时，它什么也推导不出来，因为每条规则都需要前提，所以它漏掉了每一个重言式，例如 A ⟶ A。即使有假设，它也只能把合取式拆开、再拼起来：A ∧ B ⊨ A ∨ B，但没有任何推导能得到含 ∨ 的公式。
3. **什么也不知道。** 这个公式可能是有效的，只是搜索很慢；也可能不是有效的。一阶逻辑的有效性是不可判定的，所以没有哪种搜索总能分辨出来。去找一个反例：如果有反例，A 就是不可推导的。
4. **A 没有推导**：由可靠性，⊢ A 会蕴涵 ⊨ A，而反例表明 A 并非在每个结构中都为真。别再试图证明 A 了，应该去修正这个陈述。
:::

:::: exercise 哪些推导是正确的？ {#ex-6-3} ★
判断下面每个推导是否符合规则。对每个不符合规则的推导，指出哪条规则用错了，并给出一个结构，说明它的结论不是有效的。

**推导 1**

```prooftree
P a ⟶ ∀x. P x   (⟶I¹)
  ∀x. P x   (∀I)
    [P a]¹
```

**推导 2**

```prooftree
(∀x. P x) ⟶ (∀y. P y)   (⟶I¹)
  ∀y. P y   (∀I)
    P a   (∀E)
      [∀x. P x]¹
```

**推导 3**

```prooftree
(∃x. P x) ⟶ P a   (⟶I¹)
  P a   (∃E²)
    [∃x. P x]¹
    [P a]²
```

::: solution
1. **错误。** 在 (∀I) 这一步，本征变元 a 在未解除的假设 [P a]¹ 中自由出现（它要到下面才被 (⟶I¹) 解除）。结构：论域 {0, 1}，P 只对 0 为真，a = 0。那么 P a 为真而 ∀x. P x 为假，所以这个蕴涵为假。
2. **正确。** 在 (∀I) 处，唯一未解除的假设是 ∀x. P x，a 不在其中自由出现，a 也不出现在结论 ∀y. P y 中。这个公式说的是：给约束变元改名不会改变任何东西。
3. **错误。** (∃E²) 的结论 P a 提到了它的本征变元 a。结构：论域 {0, 1}，P 只对 0 为真，a = 1。那么 ∃x. P x 为真而 P a 为假。
:::

:::: exercise 柯里化 {#ex-6-4} ★★
推导下面两个公式：

1. (A ⟶ B ⟶ C) ⟶ (A ∧ B ⟶ C)
2. (A ∧ B ⟶ C) ⟶ (A ⟶ B ⟶ C)

程序员把它们叫作**反柯里化**（uncurrying）和**柯里化**（currying）：一个有两个参数的函数，既可以把两个参数作为一个有序对一次接收，也可以一个接一个地接收。

::: solution
1. 用 (⟶I¹) 假设 A ⟶ B ⟶ C，用 (⟶I²) 假设 A ∧ B。从合取式中取出 A 和 B，然后两次应用这个蕴涵：

   ```prooftree
   (A ⟶ B ⟶ C) ⟶ (A ∧ B ⟶ C)   (⟶I¹)
     A ∧ B ⟶ C   (⟶I²)
       C   (⟶E)
         B ⟶ C   (⟶E)
           [A ⟶ B ⟶ C]¹
           A   (∧E₁)
             [A ∧ B]²
         B   (∧E₂)
           [A ∧ B]²
   ```

2. 假设 A ∧ B ⟶ C、A 和 B（三次使用 (⟶I)），构造出 A ∧ B，再应用这个蕴涵：

   ```prooftree
   (A ∧ B ⟶ C) ⟶ (A ⟶ B ⟶ C)   (⟶I¹)
     A ⟶ B ⟶ C   (⟶I²)
       B ⟶ C   (⟶I³)
         C   (⟶E)
           [A ∧ B ⟶ C]¹
           A ∧ B   (∧I)
             [A]²
             [B]³
   ```

两个推导都没有用到 (RAA)。把它们读作程序（第 6.5 节），第一个推导把一个逐个接收参数的函数变成一个接收有序对的函数，第二个则反过来。
:::

:::: exercise 逆否与德摩根律 {#ex-6-5} ★★
推导下面三个公式。哪一个需要 (RAA)？

1. (A ⟶ B) ⟶ (¬B ⟶ ¬A)
2. ¬A ∨ ¬B ⟶ ¬(A ∧ B)
3. (¬B ⟶ ¬A) ⟶ (A ⟶ B)

::: solution
1. 不需要 (RAA)：要证明 ¬A，用 (¬I³) 假设 A；由 A ⟶ B 得到 B，这与 ¬B 矛盾。

   ```prooftree
   (A ⟶ B) ⟶ (¬B ⟶ ¬A)   (⟶I¹)
     ¬B ⟶ ¬A   (⟶I²)
       ¬A   (¬I³)
         ⊥   (¬E)
           [¬B]²
           B   (⟶E)
             [A ⟶ B]¹
             [A]³
   ```

2. 不需要 (RAA)：要证明 ¬(A ∧ B)，用 (¬I²) 假设 A ∧ B，再用 (∨E³) 按 ¬A ∨ ¬B 分情形推导出 ⊥。

   ```prooftree
   ¬A ∨ ¬B ⟶ ¬(A ∧ B)   (⟶I¹)
     ¬(A ∧ B)   (¬I²)
       ⊥   (∨E³)
         [¬A ∨ ¬B]¹
         ⊥   (¬E)
           [¬A]³
           A   (∧E₁)
             [A ∧ B]²
         ⊥   (¬E)
           [¬B]³
           B   (∧E₂)
             [A ∧ B]²
   ```

3. 这个需要 (RAA)：目标 B 是一个原子公式，所以没有引入规则适用，假设中也没有什么能直接得出 B。用 (RAA³) 假设 ¬B；于是得到 ¬A，这与 A 矛盾。

   ```prooftree
   (¬B ⟶ ¬A) ⟶ (A ⟶ B)   (⟶I¹)
     A ⟶ B   (⟶I²)
       B   (RAA³)
         ⊥   (¬E)
           ¬A   (⟶E)
             [¬B ⟶ ¬A]¹
             [¬B]³
           [A]²
   ```

第三个公式正是第 6.1 节的逆否命题模式所依赖的那一步，所以这种模式属于经典推理。
:::

:::: exercise 存在与所有 {#ex-6-6} ★★
1. 推导 (∀x. P x ⟶ Q x) ⟶ (∃x. P x) ⟶ (∃x. Q x)。用话来说：如果每个管理员都可以删除文件，并且某个用户是管理员，那么某个用户可以删除文件。
2. 推导 (∃x. P x ∧ Q x) ⟶ (∃x. P x) ∧ (∃x. Q x)。
3. 第 2 题的逆命题是 (∃x. P x) ∧ (∃x. Q x) ⟶ (∃x. P x ∧ Q x)。给出一个使它为假的结构，并说明试图推导它时会在哪里违反规则。

::: solution
1. 先用 (∃E³) 以新名字 a 打开存在量词的假设，再用同一个 a 实例化全称量词的假设：

   ```prooftree
   (∀x. P x ⟶ Q x) ⟶ (∃x. P x) ⟶ (∃x. Q x)   (⟶I¹)
     (∃x. P x) ⟶ (∃x. Q x)   (⟶I²)
       ∃x. Q x   (∃E³)
         [∃x. P x]²
         ∃x. Q x   (∃I)
           Q a   (⟶E)
             P a ⟶ Q a   (∀E)
               [∀x. P x ⟶ Q x]¹
             [P a]³
   ```

   (∃E³) 的本征变元 a 既不出现在 ∃x. P x 中，也不出现在结论 ∃x. Q x 中，也不出现在另一个未解除的假设 ∀x. P x ⟶ Q x 中。

2. 用一次 (∃E)，两部分用同一个见证：

   ```prooftree
   (∃x. P x ∧ Q x) ⟶ (∃x. P x) ∧ (∃x. Q x)   (⟶I¹)
     (∃x. P x) ∧ (∃x. Q x)   (∃E²)
       [∃x. P x ∧ Q x]¹
       (∃x. P x) ∧ (∃x. Q x)   (∧I)
         ∃x. P x   (∃I)
           P a   (∧E₁)
             [P a ∧ Q a]²
         ∃x. Q x   (∃I)
           Q a   (∧E₂)
             [P a ∧ Q a]²
   ```

3. 论域 {1, 2}，P 只对 1 为真，Q 只对 2 为真：有元素具有 P，也有元素具有 Q，但没有元素同时具有两者。（“某个用户是管理员，某个用户是访客”并不能给出一个既是管理员又是访客的用户。）推导必须打开两个存在量词。第一个 (∃E) 引入 a 和 P a；第二个需要一个新名字，比如 b，以及 Q b，于是 P 和 Q 说的是不同的元素。如果改用 a 打开第二个存在量词，就违反了本征变元条件，因为未解除的假设 P a 提到了 a。Nitpick 找到了同一类反例，元素是 a₁ 和 a₂：P 只对 a₂ 成立，Q 只对 a₁ 成立。

   ```isabelle
   lemma "(∃x. P x) ∧ (∃x. Q x) ⟶ (∃x. P x ∧ Q x)"
     nitpick [card = 2]
     oops
   ```

   ```output result
   Nitpicking formula...

   Nitpick found a counterexample for card 'a = 2:
     Free variables:
       P = (λx. _)(a⇩1 := False, a⇩2 := True)
       Q = (λx. _)(a⇩1 := True, a⇩2 := False)
     Skolem constants:
       x = a⇩2
       x = a⇩1
   ```
:::

:::: exercise 反向搜索 {#ex-6-7} ★★
用第 6.7 节的经验法则找出 A ∧ (B ∨ C) ⟶ (A ∧ B) ∨ (A ∧ C) 的一个推导。对每一步，说明它是否安全。然后在第 6.7 节的交互工具中构造这个证明；在那里，这个公式显示为 A ∧ (B ∨ C) ⟶ A ∧ B ∨ A ∧ C，因为 ∧ 比 ∨ 结合得更紧。

::: solution
1. 目标 ⊢ A ∧ (B ∨ C) ⟶ (A ∧ B) ∨ (A ∧ C)：应用 (⟶I¹)，**安全**。
2. 目标 A ∧ (B ∨ C) ⊢ (A ∧ B) ∨ (A ∧ C)。先不要选择目标的哪一边。用 (∧E₁) 和 (∧E₂) 拆开假设，**安全**：A 和 B ∨ C 成为假设。
3. 用 (∨E²) 按 B ∨ C 分情形，**安全**：一个目标带有 B，另一个带有 C。
4. 情形 B：现在选择 (∨I₁)，它**不安全**，但在这里是对的；然后用 (∧I)，**安全**：目标 A 和 B 都是假设。
5. 情形 C：用 (∨I₂)，然后用 (∧I)：A 和 C 都是假设。

```prooftree
A ∧ (B ∨ C) ⟶ (A ∧ B) ∨ (A ∧ C)   (⟶I¹)
  (A ∧ B) ∨ (A ∧ C)   (∨E²)
    B ∨ C   (∧E₂)
      [A ∧ (B ∨ C)]¹
    (A ∧ B) ∨ (A ∧ C)   (∨I₁)
      A ∧ B   (∧I)
        A   (∧E₁)
          [A ∧ (B ∨ C)]¹
        [B]²
    (A ∧ B) ∨ (A ∧ C)   (∨I₂)
      A ∧ C   (∧I)
        A   (∧E₁)
          [A ∧ (B ∨ C)]¹
        [C]²
```

如果在第 2 步、还没有分情形时就选择 (∨I₁)，就会留下目标 A ∧ (B ∨ C) ⊢ A ∧ B：这是一条死路，交互工具会用赋值“A 为真、B 为假、C 为真”把它标出来。
:::
::::

:::: exercise 皮尔士定律 {#ex-6-8} ★★★
推导 ((A ⟶ B) ⟶ A) ⟶ A。这个公式中除了 ⟶ 没有别的联结词，它的推导却需要 (RAA)。提示：马上就用 (RAA)，并记住由 ¬A 和 A 可以得出任何公式。

::: solution
用了 (⟶I¹) 之后，用 (RAA²) 假设 ¬A。要使用假设 (A ⟶ B) ⟶ A，你需要 A ⟶ B。为了证明它，用 (⟶I³) 假设 A：它与 ¬A 一起得出 ⊥，再由 (⊥E) 得出 B。然后由 (⟶E) 得出 A，这与 ¬A 矛盾。

```prooftree
((A ⟶ B) ⟶ A) ⟶ A   (⟶I¹)
  A   (RAA²)
    ⊥   (¬E)
      [¬A]²
      A   (⟶E)
        [(A ⟶ B) ⟶ A]¹
        A ⟶ B   (⟶I³)
          B   (⊥E)
            ⊥   (¬E)
              [¬A]²
              [A]³
```

(RAA²) 的假设 ¬A 用了两次：一次用来完成推导，一次用在 [A]³ 的辖域之内。皮尔士定律（Peirce's law）是重言式（它的真值表最后一列全是 T），但没有 (RAA) 就推导不出来：它是经典逻辑的定律之一。
:::
::::

:::: exercise 从所有到存在 {#ex-6-9} ★★★
1. 推导 (∀x. P x) ⟶ (∃x. P x)。
2. 你的推导用了哪个见证？它是从哪里来的？
3. 为什么这个公式是有效的？描述一下在一个根本没有元素的“结构”中会发生什么。
4. 在 Isabelle 中用 `blast` 检验这个公式。

::: solution
1. 在 (⟶I¹) 之后再走两步：

   ```prooftree
   (∀x. P x) ⟶ (∃x. P x)   (⟶I¹)
     ∃x. P x   (∃I)
       P a   (∀E)
         [∀x. P x]¹
   ```

2. 见证是一个在别处都没有出现过的名字 a。(∀E) 允许任何项，(∃I) 也接受任何项作为见证，所以这个推导不需要任何已知存在的元素。
3. 这个公式是有效的，因为每个结构的论域都至少有一个元素，而规则内含了这一点：任何名字都可以充当见证。在空论域中，∀x. P x 会为真，因为没有什么需要检查；∃x. P x 会为假，因为什么也找不到。一阶逻辑排除了空论域，所以这个推导是可靠的。
4. Isabelle 的类型也从来不是空的。Isabelle/HOL 教程解释了原因：否则“量词规则就会是不可靠的，因为 ∃x. x = x 是一个定理”。所以 `blast` 能证明这个公式：

   ```isabelle
   lemma "(∀x. P x) ⟶ (∃x. P x)"
     by blast
   ```
:::

## 自测题 {#quiz}

```quiz
? ⊢ A ∧ B ⟶ B ∧ A 说的是什么？
- [ ] A ∧ B ⟶ B ∧ A 在每个赋值下都为真
- [x] A ∧ B ⟶ B ∧ A 有一个推导，其中没有未解除的假设
- [ ] A ∧ B ⟶ B ∧ A 已经被 Isabelle 检查过
- [ ] 在某个赋值下，B ∧ A 可以由 A ∧ B 得出
> ⊢ 讲的是推导：一棵由规则应用构成的树，它未解除的假设都在 ⊢ 的左边，这里一个也没有。在每个赋值下都为真，说的是 ⊨；可靠性和完备性表明两者是一致的。

? 一个证明系统是可靠的，如果……
- [x] 它由 Γ 推导出的每个公式，在使 Γ 为真的每个赋值或结构中都为真
- [ ] 在每个赋值下都为真的每个公式都能被推导出来
- [ ] 每个推导都能由计算机检查
- [ ] 它对每个联结词都有一条引入规则和一条消去规则
> 可靠性就是“⊢ 蕴涵 ⊨”：系统推导不出任何假的东西。第二个选项说的是完备性。

? 在一个推导中，(⟶I¹) 得出 A ⟶ B。假设 [A]¹ 会怎样？
- [ ] 它成为结论的一个未解除的假设
- [ ] 它必须在前面已经由另一条规则推导出来
- [x] 它被解除了：结论 A ⟶ B 不再依赖于它，它只能在这条规则之上使用
- [ ] 它从推导中被删去
> 解除把假设移进了结论。它的辖域是推导中位于解除它的规则之上的那一部分。

? 哪个公式没有 (RAA) 就推导不出来？
- [ ] A ⟶ ¬¬A
- [ ] ¬(A ∨ B) ⟶ ¬A ∧ ¬B
- [ ] (A ⟶ B) ⟶ (¬B ⟶ ¬A)
- [x] ¬¬A ⟶ A
> 双重否定消去属于经典逻辑。另外三个公式在第 6.4、6.5 节和练习 6.5 中都有不用 (RAA) 的推导。

? 这一步为什么是错的：由未解除的假设 P a，用 (∀I) 得出 ∀x. P x？
- [ ] (∀I) 需要两个前提
- [x] 本征变元 a 在一个未解除的假设中自由出现，所以 a 不是任意的
- [ ] 必须先把 P a 变成 ∃x. P x
- [ ] 名为 a 的变元不能全称概括，只有 x 可以
> 这是 (∀I) 的本征变元条件：a 不能在任何未解除的假设中自由出现。在这里，正是假设 P a 使 a 变得特殊。

? 反向搜索到达了目标 A ∨ B ⊢ B ∨ A。哪一步是安全的？
- [ ] (∨I₁)，把目标变成 B
- [ ] (∨I₂)，把目标变成 A
- [x] 对假设 A ∨ B 应用 (∨E)，得到两个目标
- [ ] (⊥E)，把目标变成 ⊥
> (∨E) 永远不会丢失可证性。(∨I₁)、(∨I₂) 和 (⊥E) 则可能丢失：A ∨ B ⊢ B、A ∨ B ⊢ A 和 A ∨ B ⊢ ⊥ 都不可证，尽管原来的目标是可证的。
```
