## 算术与代数 {#algebra}

### 第 1 项 分数 {#d1}

计算 $3/4-2/3$，展示公分母。

::: answer
$9/12-8/12=1/12$。若直接相加分母或不能解释等值分数，请复习 [分数](module_00_ZH.html#s1)。
:::

### 第 2 项 符号 {#d2}

计算 $-3^2$ 与 $(-3)^2$，解释差异。

::: answer
$-9$ 与 $9$。第一式负号在平方外，第二式负号属于底数。复习 [运算次序](module_00_ZH.html#s1)。
:::

### 第 3 项 方程 {#d3}

解 $3x+5=17$，代回原式验证。

::: answer
减五再除三得 $x=4$，检查 $3(4)+5=17$。若可逆步骤不清楚，复习 [方程](module_00_ZH.html#s3)。
:::

### 第 4 项 展开 {#d4}

展开 $(x+2)(x-3)$，不要漏交叉项。

::: answer
$x^2-3x+2x-6=x^2-x-6$。复习 [多项式](module_00_ZH.html#s4)。
:::

### 第 5 项 指数 {#d5}

解 $2^x=8$，说明逆运算。

::: answer
$x=3$。二为底的对数询问产生八的指数。复习 [乘方与对数](module_00_ZH.html#s5)。
:::

## 数学语言 {#language}

### 第 6 项 定义域 {#d6}

给出 $1/(x-2)$ 的实定义域。

::: answer
所有实输入除去 $x=2$，因为二使分母为零。学习 [模块 01 函数](module_01_ZH.html#s3)。
:::

### 第 7 项 下标记法 {#d7}

展开 $\sum_{i=1}^4 i$ 并计算。

::: answer
$1+2+3+4=10$。上下界包含在范围内，下标取整数。学习 [模块 01 求和](module_01_ZH.html#s5)。
:::

### 第 8 项 否定 {#d8}

否定“每个项目都有效”。“每个项目都无效”是其否定吗？

::: answer
否定为“至少一个项目无效”。“每个项目都无效”更强，因为原主张为假时仍可能有一些有效项目。模块 02 将说明这一差异，当前仍在计划中。开始模块 01 无需先掌握逻辑。
:::

### 第 9 项 主张与反例 {#d9}

$f(a+b)=f(a)+f(b)$ 是否对每个实函数成立？给出有效例子支持回答。

::: answer
不是。取 $f(x)=x^2$、$a=2$、$b=3$，得到 $25\ne13$。学习 [约定与主张](module_01_ZH.html#s6)。某些函数有加性，不等于所有函数都有。
:::

## Python 准备 {#python}

### 第 10 项 跟踪循环 {#d10}

预测打印值：

```python norun
for i in range(3):
    print(i)
    print(i * i)
```

::: answer
依次六行为 `0,0,1,1,2,4`。两个缩进打印都属于每次迭代。复习 [Python 记法](python_primer_ZH.html#notation)。
:::

### 第 11 项 定义函数 {#d11}

写返回输入平方的函数，并用负三调用。

::: answer
使用 `def square(x):`，缩进 `return x*x`；`square(-3)` 返回九。仅打印不提供返回值。复习 [函数](python_primer_ZH.html#functions)。
:::

### 第 12 项 运行与诊断 {#d12}

在终端运行 [入门脚本](python_primer_ZH.html#lab1)，指出最后的异常信息并解释为什么仍然完成。

::: answer
它报告捕获的 `ZeroDivisionError` 与 “division by zero”。明确的 `except` 处理了故意故障。若文件打不开，先检查终端当前文件夹与名称。参考 [安装运行](python_primer_ZH.html#setup) 与 [错误指南](python_primer_ZH.html#errors)。
:::
