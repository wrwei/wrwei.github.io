先做 [入门诊断](diagnostic_ZH.html)。若前五项不熟悉，学习本复习；若只有一种运算不确定，选择相应章节和练习。六小时估计包括自行书写计算、绘图、纠错，以及解释每种操作为什么允许。

## 分数 符号与运算次序 {#s1}

分数 $p/q$ 表示除以非零分母。分子与分母乘相同非零值，比例不变：$1/2=2/4$。相加前应统一分母；把分母直接相加不是正确操作。

::: worked title="通分后相减"
$3/4-2/3=9/12-8/12=1/12$。十二能同时被四和三整除，因此可作为公分母。检查符号：$0.75$ 大于约 $0.667$，结果应小而为正。
:::

乘法为 $(p/q)(r/s)=pr/(qs)$。除以非零分数等于乘倒数：$(3/4)/(2/3)=(3/4)(3/2)=9/8$。除数不能为零。只能约去乘积中的共同因子，不应约去和中的项：当 $y\ne0$ 时，$(2x)/(2y)=x/y$，但 $(x+2)/(y+2)$ 通常不能化成 $x/y$。

负数的相反数为正，减去负数等于加上相应正值：$5-(-2)=7$。括号决定负号是否属于被平方的底数：$-3^2=-9$，$(-3)^2=9$。先括号、后乘方、再乘除、最后加减；同优先级运算按适用顺序处理，有歧义时增加括号。

::: check
计算 $1/2+1/3$ 与 $2-(-4)$。为什么 $(x+2)/2=x/2+1$ 而不是 $x$？
:::
::: answer
结果为 $5/6$ 与 $6$。分子各项都除以二，得到 $x/2+2/2=x/2+1$。分子是和，直接删去二不能保留含义。
:::

## 比例 百分比与科学计数法 {#s2}

百分比是以一百为基准的比率，$25/100=1/4$。百分比变化把差值与选定起始值比较：从八十增加到一百为 $(100-80)/80=25\%$，从一百降低到八十为 $20\%$。分母不同解释了变化率不同。

比率需要单位与参照。在简单可加时间模型中，每请求三毫秒、十个请求共三十毫秒。但这不能自动证明并发系统的总耗时；模型决定何时允许相加。

科学计数法写为 $a\times10^k$，通常要求 $1\le|a|<10$。$0.00032=3.2\times10^{-4}$，$45000=4.5\times10^4$。相乘时乘前导系数、加指数：$(2\times10^3)(3\times10^{-2})=6\times10^1=60$。这种写法保持极大与极小尺度清晰。

::: check
将 $0.0045$ 写成科学计数法。数值从五十增至六十，百分比增加多少？
:::
::: answer
$4.5\times10^{-3}$；$(60-50)/50=0.2=20\%$。必须说明作为分母的原始参照值。
:::

## 方程 不等式与可逆操作 {#s3}

解方程是寻找使两边相等的值。两边执行相同可逆操作，才能保持解集。加减固定数可逆，乘除固定非零数也可逆。若除以可能为零的表达式，需要单独讨论，否则可能丢掉有效解。

::: worked title="解线性方程并代回检查"
$3x+5=17$ 两边减五得到 $3x=12$，再除三得到 $x=4$。代回原式：$3(4)+5=17$。检查原方程能发现抄写与算术错误。
:::

不等式两边加相同数不改变方向；乘除正数也不改变方向，乘除负数则反向。由 $-2x<6$ 除以 $-2$ 得 $x>-3$。可检查包含的零与排除的边界 $-3$。

平方在全部实数上不可逆，因为二与负二都平方为四。若整理过程中平方两边，必须把候选值代回原式。例如 $\sqrt{x}=x-2$ 要求 $x\ge0$ 且 $x-2\ge0$；只平方可能产生违反限制的候选值。

::: check
解 $2x-7=5$ 与 $-3x\ge9$。为什么 $x(x-1)=0$ 不能直接除以 $x$？
:::
::: answer
$x=6$；$x\le-3$。原乘积方程允许 $x=0$，除以它会丢掉有效解。完整解集为 $\{0,1\}$。
:::

## 展开 因式分解与多项式 {#s4}

分配律为 $a(b+c)=ab+ac$。逐项应用得 $(x+2)(x-3)=x^2-3x+2x-6=x^2-x-6$。只合并同类项；$x$ 与 $x^2$ 表示不同次幂，不能变成一个 $x$ 的系数。

因式分解逆转展开。$3x+6=3(x+2)$ 提取公因子；$x^2-x-6=(x-3)(x+2)$，因为负三与二的和为负一、积为负六。展开因式分解结果来检查。

实数乘积为零时，至少一因子为零，因此 $(x-3)(x+2)=0$ 得 $x=3$ 或 $x=-2$。分式仅在因子不为零时允许约去。$(x^2-1)/(x-1)$ 在 $x\ne1$ 时等于 $x+1$；一处仍未定义，除非明确另定义一个新函数。

::: check
展开 $(x+1)^2$，并用代数与 $x=1$ 解释为何不是 $x^2+1$。
:::
::: answer
展开为 $x^2+2x+1$。取一时原式为四，而 $x^2+1$ 为二；遗漏交叉项造成差异。
:::

## 乘方 对数与三角函数预览 {#s5}

非零 $a$ 满足 $a^0=1$、$a^{-k}=1/a^k$。正底数满足 $a^r a^s=a^{r+s}$ 与 $(a^r)^s=a^{rs}$。区分 $x^2$ 与 $2^x$：变量角色不同。实平方根要求非负输入，根号表示非负平方根；因此 $\sqrt9=3$，但方程 $x^2=9$ 有两个解。

当 $a>0$、$a\ne1$、$x>0$ 时，$\log_a x$ 是使底数 $a$ 产生 $x$ 的指数。因为 $2^3=8$，所以 $\log_2 8=3$；$2^x=8$ 的解为 $x=3$。对数把正数乘积转成和，不普遍分配到加法上。模块 01 将详细解释定义域和恒等式。

三角函数为后续几何与微积分作预览。弧度是弧长与半径的比；半周为 $\pi$ 弧度，即 $180$ 度。单位圆上角度 $\theta$ 的坐标为 $(\cos\theta,\sin\theta)$，满足 $\cos^2\theta+\sin^2\theta=1$。零角度对应 $(1,0)$，$\pi/2$ 对应 $(0,1)$。Python 标准三角函数使用弧度；模块 01 的实验不要求三角计算。

::: check
计算 $2^{-3}$，求解 $x^2=9$。$\ln(x-2)$ 的实定义域是什么？
:::
::: answer
$1/8$；$x=3$ 或 $x=-3$。对数要求 $x-2>0$，即 $x>2$。
:::

## 坐标 斜率与图像阅读 {#s6}

有序对 $(x,y)$ 表示一个点，先水平后垂直坐标。函数图在允许输入上放置 $(x,f(x))$。读值时，先在水平轴找输入，沿曲线读垂直值。解释形状之前检查坐标单位与显示范围。

当横坐标不同，两点 $(x_1,y_1)$、$(x_2,y_2)$ 间斜率为 $(y_2-y_1)/(x_2-x_1)$。$(1,2)$ 与 $(3,6)$ 给出 $(6-2)/(3-1)=2$，相应直线为 $y=2x$。$y=2x+1$ 斜率仍为二，但纵截距为一。

画直线可先计算两三个点。$y=2x+1$ 使用 $(0,1),(1,3),(2,5)$；平方使用 $(-2,4),(-1,1),(0,0),(1,1),(2,4)$。平方图弯曲，只用两点直线连接会误表示。垂直直线的横坐标差为零，因此本公式不给出有限斜率。

::: check
求 $(0,1)$ 与 $(2,5)$ 间的斜率。若某一轴从米改为厘米，数值斜率会改变吗？
:::
::: answer
斜率为 $(5-1)/(2-0)=2$。单轴单位改变会改变数值比率；解释物理含义前应声明单位。
:::

## 十项练习 {#practice}

前六项为手算，随后两项关于图像，最后两项修复无效操作。为做错的题更换数值重新练习，直到能解释每一步。

::: exercise #e1 level=1 kind=calculation
计算 $3/4-2/3$ 与 $(3/4)/(2/3)$。
:::
::: solution
$9/12-8/12=1/12$；乘倒数得到 $9/8$。
:::
::: exercise #e2 level=1 kind=calculation
计算 $-3^2$、$(-3)^2$ 与 $5-(-2)$。
:::
::: solution
$-9,9,7$；括号决定负号是否参加平方。
:::
::: exercise #e3 level=1 kind=calculation
解 $3x+5=17$ 并检查。
:::
::: solution
减五、除三得到 $x=4$；代回得到十七。
:::
::: exercise #e4 level=1 kind=calculation
展开 $(x+2)(x-3)$，再分解结果。
:::
::: solution
$x^2-x-6=(x+2)(x-3)$。交叉项为 $-3x+2x=-x$。
:::
::: exercise #e5 level=1 kind=calculation
解 $2^x=8$，并把 $0.00032$ 写成科学计数法。
:::
::: solution
$x=3$；$3.2\times10^{-4}$。小数点向左移四位，对应十的负次幂。
:::
::: exercise #e6 level=1 kind=calculation
解 $-2x<6$，求八十增至一百的百分比变化。
:::
::: solution
$x>-3$，除以负数需反向；增长为 $20/80=25\%$。
:::
::: exercise #e7 level=1 kind=calculation
画出 $(1,2)$、$(3,6)$，求斜率与直线方程。
:::
::: solution
斜率为二，直线为 $y=2x$；两点都满足它。
:::
::: exercise #e8 level=1 kind=conceptual
通过负二至二的五个整数输入画 $y=x^2$。读零处值并解释对称性。
:::
::: solution
点为 $(-2,4),(-1,1),(0,0),(1,1),(2,4)$，零处为零。相反输入平方相同，因此关于纵轴对称。
:::
::: exercise #e9 level=2 kind=conceptual
有人解 $x(x-1)=0$ 时除以 $x$，断定只有一可能。修复论证。
:::
::: solution
先考虑 $x=0$，它有效。$x\ne0$ 时可除，得到 $x=1$。合起来解为零与一。
:::
::: exercise #e10 level=2 kind=conceptual
学习者约去 $(x^2-1)/(x-1)$ 中的 $x-1$，声称原式在一处值为二。修复结论。
:::
::: solution
分子为 $(x-1)(x+1)$，仅 $x\ne1$ 时可约。原式在一处未定义；化简式只在原定义域上与它同值。
:::
