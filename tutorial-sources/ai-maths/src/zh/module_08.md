## 在浮点数与整数编码之间转换 {#quantise}

对于一个简单的对称量化器，选择一个比例因子 $s>0$ 和一个整数限制 $K>0$。存储 $q=\operatorname{clip}(\operatorname{round}(x/s),-K,K)$ 并重建 $\hat x=sq$。指定舍入的规则。例如，恰好位于两个整数中间时，Python 的舍入规则选择其中的偶数。使用 $K=127$，整数编码可以存储在一个带符号的 8 位字段中。

如果仅通过四舍五入就能得到允许范围内的码字，那么绝对重建误差最大为 $s/2$。如果进行裁剪改变了码字，误差可能会超过这个界限。固定较窄的可表示范围可以在给定码字数量下提高小值的分辨率，并且可以裁剪更多的异常值。允许每组有不同的尺度可以适应不同量级的组的分辨率。每个尺度也需要被存储或恢复。

::: example 裁剪和四舍五入
使用 $s=1/4$ 和 $K=3$，输入 $0.30$ 映射到码字 $1$ 并重建为 $0.25$。输入 $1.20$ 在裁剪后映射到码字 $3$ 并重建为 $0.75$，误差为 $0.45$。
```check
same(Rational(3,10)-Rational(1,4),Rational(1,20))
same(Rational(6,5)-Rational(3,4),Rational(9,20))
```
:::

## 估计预测误差的上界 {#error}

设 $w$ 为权重向量，$\hat w$ 为其重建值，$x$ 为输入向量。在没有裁剪且使用公共尺度 $s$ 的情况下，三角不等式给出
$$
\left|x^\mathsf T\hat w-x^\mathsf T w\right|
 \le\sum_i |x_i|\,|\hat w_i-w_i|
 \le \frac{s}{2}\lVert x\rVert_1.
$$
这是在精确算术中的绝对界限，适用于量化权重和原始输入。实际实现过程中乘法或累加可能会引入更多误差。即使绝对误差很小，原始点积非常小时也可能产生较大的相对误差。

::: compute 用精确的有理数作为参考值
对于权重 $(3/10,-11/20,1/5)$、输入 $(2,-1,4)$ 和尺度 $1/4$，比较量化后的点积与未量化的点积。
```python
from fractions import Fraction as F

weights = [F(3, 10), F(-11, 20), F(1, 5)]
inputs = [2, -1, 4]
scale, limit = F(1, 4), 3
codes = [max(-limit, min(limit, round(w / scale))) for w in weights]
reference = sum(x * w for x, w in zip(inputs, weights))
approximation = sum(x * q * scale for x, q in zip(inputs, codes))
print(codes)
print(reference, approximation, abs(reference - approximation))
print(scale * sum(map(abs, inputs)) / 2)
```
```output
[1, -2, 1]
39/20 2 1/20
7/8
```
:::

为了评估一组输入上的量化效果，报告尺度规则、绑定规则、参考精度、绝对误差以及下游指标。检查跨运行的保留评估是否一致。在玩具示例中，绝对误差是 $1/20$，远低于 $7/8$ 的界限。真实输入分布可以从一个选定向量中产生非常不同的误差。

## 练习 {#exercises}

:::: exercise 重构一个权重 {#ex-8-1} ★
在尺度 $1/10$ 下，重构整数码 $-7$。
::: solution
将码乘以尺度，得到 $-7/10$。
```check
same(-7*Rational(1,10),Rational(-7,10))
```
:::
::::

:::: exercise 精确的舍入平局 {#ex-8-2} ★★
在尺度 $1/4$ 下，当平局时采用偶数和 $K=3$，$5/8$ 会得到哪个码？
::: solution
量化的输入是 $5/2$。其最近的偶数整数是 $2$。重构的值是 $1/2$，绝对误差是 $1/8$。
```check
same(round(Rational(5,2)),2)
same(Rational(5,8)-Rational(1,2),Rational(1,8))
```
:::
::::

:::: exercise 限制点积 {#ex-8-3} ★★★
对于输入 $x=(-1,2,-2)$ 和尺度 $1/10$，当没有权重发生裁剪时，绝对误差的上限是什么？
::: solution
一范数是 $5$。乘以 $1/10$ 的一半得到 $1/4$。
```check
same(Rational(1,20)*(1+2+2),Rational(1,4))
```
:::
::::

- [x] $s/2$
- [ ] $2s$
> 每个输入值都在其最近重构级别的半个步长范围内。

? 裁剪会对这个界限产生什么影响？
- [x] 它可以使误差超过 $s/2$
- [ ] 它总是将误差归零
- [ ] 它证明了每个点积的误差都相同
> 一个超出可表示区间值的数值可能与其端点相差很远。

? 在推导的点积界限中，哪个量乘以 $s/2$？
- [ ] 存储的位数
- [ ] 权重向量的二范数长度
- [x] 绝对输入坐标的总和
