## 对预测损失进行求导 {#gradient}

对于一个特征向量为 $x$ 的例子，线性预测器给出 $\hat y=w^\mathsf Tx$。残差为 $r=\hat y-y$。损失 $r^2/2$ 关于 $r$ 的导数为 $r$，而 $r$ 关于 $w$ 的导数为 $x$。链式法则给出 $\nabla_w(r^2/2)=rx$。对于相同因子 $1/2$ 的均方损失，对所有例子的梯度取平均。对于一个以特征为行、目标向量为 $y$ 的矩阵 $X$，这表示为 $X^\mathsf T(Xw-y)/n$。

梯度下降应用 $w_{\rm next}=w-\eta\nabla L(w)$，学习率为 $\eta>0$。梯度表示损失在位移下的一阶变化，描述局部斜率，因此在梯度非零的区域，足够小的下降步长可降低损失。对于较大的步长，曲率起作用。

::: example 一次更新
取 $x=(2,-1)^\mathsf T$、$w=(1,1)^\mathsf T$ 和 $y=3$。预测为 $1$，梯度为 $(-4,2)^\mathsf T$。在学习率 $1/10$ 下，更新得到 $w=(7/5,4/5)^\mathsf T$，损失从 $2$ 下降到 $1/2$。
```check
x1,w1=Matrix([2,-1]),Matrix([1,1])
g1=(w1.dot(x1)-3)*x1
same(g1,Matrix([-4,2]))
u1=w1-g1/10
same(u1,Matrix([Rational(7,5),Rational(4,5)]))
same((u1.dot(x1)-3)**2/2,Rational(1,2))
```
:::

## 跟踪二次损失下的误差 {#curvature}

对于 $L(w)=a(w-w_*)^2/2$ 与 $a>0$，误差 $e=w-w_*$ 每一步发生变化为 $(1-\eta a)e$。对于非零误差，当且仅当 $\lvert 1-\eta a\rvert<1$ 时，误差的绝对值缩小，等价于 $0<\eta<2/a$。当 $1<\eta a<2$ 时，迭代值会交替落在最小点两侧，同时逐渐收敛。在 $\eta=2/a$ 且初始误差非零时，它会在不缩小的情况下震荡。

对于 Hessian 矩阵 $H$ 正定的二次函数，选取 $H$ 的一组标准正交特征向量作为基。此时每个误差坐标遵循标量规则，其中 $a$ 等于其对应的特征值。为了所有初始误差的稳定性，需要 $0<\eta<2/\lambda_{\max}(H)$。较小特征值对应的方向仍可能收敛缓慢。深度网络的损失函数通常是非线性的，因此这种二次论证描述了在曲率正的点附近的一个局部模型。

::: widget name=descent
选择对角曲率 1 和 4，依次试用学习率 0.25、0.5 和 0.6。对照稳定步长、临界步长和不稳定步长下的迭代路径及两个误差因子。
:::

::: compute 观察收缩与超调
从误差为1和曲率为4开始。比较一个稳定步长在符号交替下的表现与超过稳定性边界的情况。
```python
for rate in (0.375, 0.625):
    error = 1.0
    for _ in range(3):
        error *= 1 - 4 * rate
    print(f"{error:.3f}")
```
```output
-0.125
-3.375
```
:::

## 练习 {#exercises}

:::: exercise 一个标量导数 {#ex-5-1} ★
在 $w=1$ 处对 $L(w)=(2w-3)^2/2$ 求导。
::: solution
导数为 $2(2w-3)$，得到 $-2$。
```check
same(diff((2*x-3)**2/2,x).subs(x,1),-2)
```
:::
::::

:::: exercise 落在最小值点 {#ex-5-2} ★★
找到标量二次函数在曲率 $a=5$ 下的一步学习率。
::: solution
设 $1-5\eta=0$。答案是 $\eta=1/5$。
```check
same(solve(1-5*x,x),[Rational(1,5)])
```
:::
::::

:::: exercise 两种速度 {#ex-5-3} ★★★
一个二次函数的Hessian矩阵特征值为 $1$ 和 $9$。在学习率 $1/9$ 下，找出两个误差因子。
::: solution
将 $1-\eta a$ 应用于每个特征值。因子为 $8/9$ 和 $0$。
```check
same(1-Rational(1,9),Rational(8,9))
same(1-9*Rational(1,9),0)
```
:::
::::
