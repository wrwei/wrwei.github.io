## 拟合概率 {#likelihood}

一个伯努利变量是在概率 $p$ 下取值为1，概率 $1-p$ 下取值为0的变量。假设我们在 $n>0$ 次独立试验中观察到 $k$ 个1，且每次试验的成功概率是相同的未知参数 $p$。一个特定有序观察的似然函数是 $p^k(1-p)^{n-k}$。这是一个关于 $p$ 的函数，数据保持不变。如果我们只观察到计数结果，二项式系数 $\binom nk$ 会乘以似然函数，但不会改变其最大值点。

对于 $0<k<n$，对数似然函数是 $k\ln p+(n-k)\ln(1-p)$。将其导数 $k/p-(n-k)/(1-p)$ 设为零得到 $\hat p=k/n$。二阶导数在 $(0,1)$ 上为负。如果所有试验结果一致，最大值出现在 $0$ 或 $1$。

::: example 统计首个词元的出现次数
在同一个提示下独立采样十次，其中有七次生成的首个词元是 $A$，因此 $A$ 作为首个词元的概率的最大似然估计为 $0.7$。
```check
p = symbols("p", positive=True)
ell = 7*log(p)+3*log(1-p)
same(solve(diff(ell,p),p),[Rational(7,10)])
```
:::

## 在新例子上进行测量 {#held-out}

在训练模型时，使用训练数据进行拟合，使用验证数据选择模型或设置，使用保留的测试数据进行最终评估。对于存在近似重复项或来自同一来源的许多项目，应按来源进行划分，例如文档或用户。否则，报告的性能可能反映了对相关项目的记忆。如果测试结果用于选择另一个模型，则需要一个独立的留出数据集来进行相同类型的最终比较。

设 $X_1,\ldots,X_n$ 是来自同一总体的独立得分，方差为 $\sigma^2$。均值 $\bar X$ 的方差为 $\sigma^2/n$。将 $\sigma$ 替换为样本标准差 $s$，并在 $s^2$ 中使用分母 $n-1$，得到估计的标准误 $s/\sqrt n$。该公式未考虑同一文档中词元之间的相关性。对于文档级别的评估，应使用独立采样的文档作为单位，并明确说明得分是按文档等权重还是按词元等权重。

::: compute 计算留出集上的平均得分
对四个独立的文档得分，打印均值和估计的标准误。四个观测值展示了计算过程，并提供了关于总体的有限证据。
```python
from math import sqrt
from statistics import mean, stdev

scores = [0.6, 0.8, 1.0, 0.8]
print(f"{mean(scores):.3f}")
print(f"{stdev(scores) / sqrt(len(scores)):.3f}")
```
```output
0.800
0.082
```
:::

## 练习 {#exercises}

:::: exercise 从计数中进行估计 {#ex-2-1} ★
找出八个独立试验中两个成功情况下的伯努利最大似然估计。
::: solution
估计值为 $2/8=1/4$。
```check
same(Rational(2,8),Rational(1,4))
```
:::
::::

:::: exercise 精度和样本量 {#ex-2-2} ★★
如果总体标准差是 $0.3$，求 9 和 36 个独立观测值的均值标准差。
::: solution
用 $\sqrt n$ 相除。这两个值分别是 $0.1$ 和 $0.05$。
```check
same(Rational(3,10)/sqrt(9), Rational(1,10))
same(Rational(3,10)/sqrt(36), Rational(1,20))
```
:::
::::

:::: exercise 分类相关项目 {#ex-2-3} ★★★
十二份文档，每份提供四个段落。将四份完整的文档用于测试，两份完整的文档用于验证。用于训练的段落还有多少？
::: solution
六份文档用于训练，因此有 $6\cdot4=24$ 个段落。每个文档的所有段落在划分时保持一致。
```check
same((12-4-2)*4,24)
```
:::

## 自测 {#quiz}

```quiz
? 将似然函数视为函数时，什么保持固定？
- [ ] 候选参数
- [x] 观测数据
- [ ] 似然值
> 似然函数比较相同观测数据下的候选参数。

? 在独立性条件下，当样本量四倍时，标准误如何变化？
- [x] 当总体方差保持固定时，它减半
- [ ] 它减小到四分之一
- [ ] 它保持不变
> 均值的标准差随着样本量的倒平方根而变化。

? 哪种分组方式有助于防止在评估分割中的信息泄露？
- [ ] 即使每个文档包含多个段落，也按段落进行处理。
- [ ] 每个标记通过硬币抛掷的方式进行处理。
- [x] 当文档内的段落之间存在关联时，按原始文档进行处理。
> 在分配分割之前，将依赖或近似重复的项目进行分组。
```
