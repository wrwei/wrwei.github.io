## 估计完整梯度 {#mini-batch}

经验损失是 $n$ 个样本损失的平均值。在固定参数向量处，其梯度等于这 $n$ 个样本梯度的平均值。如果一个小批量的 $b$ 个样本索引是独立、均匀且有放回地抽取的，那么批量平均梯度是全梯度的无偏估计。由于各次抽样相互独立，平均梯度的协方差为 $\Sigma/b$，其中 $\Sigma$ 是单次抽样的协方差。均匀地无放回抽取固定大小的子集也能得到无偏均值，但需要对协方差作有限总体修正。

::: example 在抽样上取平均
对于标量每个示例梯度 $2$ 和 $-6$，完整梯度是 $-2$。使用一个均匀抽样时，期望更新梯度仍然是 $-2$，尽管单个抽样不会返回该值。单个抽样方差是 $16$。对于四个独立抽样，它们的平均值的方差是 $4$。
```check
same((2-6)/2,-2)
same(((2+2)**2+(-6+2)**2)/2,16)
same(16/4,4)
```
:::

对下一个词元的损失进行训练时，先确定对什么单位取平均。如果目标是让每个计分词元的权重相同，就可以均匀抽取计分词元。如果均匀抽取文档，然后对各文档的平均损失取平均，得到的是以文档为单位的估计。同一文档内的词元梯度可能相关，不能直接套用独立抽样下的方差公式。

## 跟踪梯度矩 {#adam}

Adam 保持两个指数移动平均值，初始为零。对于梯度 $g_t$，其一阶矩是 $m_t=\beta_1m_{t-1}+(1-\beta_1)g_t$，其原始二阶矩是 $v_t=\beta_2v_{t-1}+(1-\beta_2)g_t^2$。下面的平方和除法都是逐坐标进行的。对于 $0\le\beta_1,\beta_2<1$，使用 $\hat m_t=m_t/(1-\beta_1^t)$ 和 $\hat v_t=v_t/(1-\beta_2^t)$ 来校正初始为零的问题。更新时减去 $\eta\hat m_t/(\sqrt{\hat v_t}+\varepsilon)$，其中 $\varepsilon$ 是一个正数。分母适应每个坐标中的步长尺度。

将 $\lambda\lVert w\rVert^2/2$ 加到损失上，会将其梯度加上 $\lambda w$。解耦权重衰减则是在参数更新时直接减去 $\eta\lambda w$。在普通梯度下降中，这些操作是一致的。在 Adam 中，将惩罚加到梯度上会改变矩估计及其缩放，而直接衰减本身不进入矩估计，矩估计仍基于数据梯度。

::: compute 第一步
在第一步，无论采用何种允许的矩系数，经偏差校正的一阶矩和二阶矩分别为 $g_1$ 和 $g_1^2$。使用两个坐标来比较更新符号。
```python
from math import sqrt

rate, eps = 0.1, 1e-8
for gradient in (2.0, -6.0):
    first = 0.1 * gradient / (1 - 0.9)
    second = 0.001 * gradient**2 / (1 - 0.999)
    update = -rate * first / (sqrt(second) + eps)
    print(f"{update:.3f}")
```
```output
-0.100
0.100
```
:::

## 练习 {#exercises}

:::: exercise 批量的均值 {#ex-6-1} ★
一批数据具有 $1$、$3$ 和 $5$ 的等权重梯度。求更新梯度。
::: solution
它们的均值是 $3$。
```check
same((1+3+5)/3,3)
```
:::
::::

:::: exercise 原始和修正的矩 {#ex-6-2} ★★
求 $m_1$ 和 $\hat m_1$ 对于 $g_1=5$ 和 $\beta_1=0.8$。
::: solution
$m_1=(1-0.8)5=1$ 和 $\hat m_1=1/(1-0.8)=5$。
```check
same((1-Rational(4,5))*5,1)
same(1/(1-Rational(4,5)),5)
```
:::
::::

:::: exercise 一个衰减步骤 {#ex-6-3} ★★★
在没有数据梯度和无历史矩的情况下，求从 $w=2$ 开始的解耦衰减步骤后的参数，其中包含 $\eta=0.1$ 和 $\lambda=0.2$。
::: solution
乘以 $1-\eta\lambda=0.98$ 得到 $w=1.96$。
```check
same(2*(1-Rational(1,10)*Rational(1,5)),Rational(49,25))
```
:::
::::

## 自测 {#quiz}

```quiz
? 在固定参数下，均匀小批量均值的期望是多少？
- [x] 经验全梯度
- [ ] 最小的每个样本梯度
- [ ] 每个参数向量都是零
> 每个采样的样本具有相等的概率。

? Adam 的 $v_t$ 跟踪什么？
- [ ] 方差围绕当前样本均值
- [ ] 所有过去梯度的总和
- [x] 坐标-wise 平方梯度的指数平均值
> 它跟踪偏差校正前的原始二阶矩。

? 解耦衰减作用在何处？
- [ ] 仅在二阶矩内部
- [x] 直接作用在参数上
- [ ] 在损失计算之前的 targets 上
> 衰减直接减去当前参数的倍数。
```
