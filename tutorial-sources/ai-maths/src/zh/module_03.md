## 自信息量与熵 {#entropy}

一个概率为 $p_i>0$ 的结果具有 $-\log p_i$ 的自信息量。在本系列中，始终使用自然对数，因此值以纳特（nats）为单位。若要以比特（bits）为单位进行测量，则使用以二为底的对数。熵是真实分布 $p$ 下的平均自信息量：
$$
H(p)=-\sum_{i:p_i>0}p_i\ln p_i.
$$
一个确定性分布的熵为零。一个在 $K$ 个结果上的均匀分布的熵为 $\ln K$。按连续延拓，权重为零的项贡献零。

## 在不同分布下的预测 {#cross-entropy}

一个模型 $q$ 分配的自信息量为 $-\ln q_i$。在数据分布上平均得到 $H(p,q)=-\sum_{i:p_i>0}p_i\ln q_i$。如果某个 $p_i>0$ 对应 $q_i=0$，交叉熵就是 $+\infty$。减去真实熵得到
$$
D_{\rm KL}(p\|q)=\sum_{i:p_i>0}p_i\ln\frac{p_i}{q_i}=H(p,q)-H(p).
$$
为了理解为何它是非负的，将 $-\ln x\ge 1-x$ 应用于 $x=q_i/p_i$ 在 $p$ 的正支撑集上。得到的下界为 $1-\sum_{i:p_i>0}q_i\ge0$。等号成立当且仅当 $p=q$。交换 $p$ 和 $q$ 会改变每个项的分布权重，因此 KL 散度通常不对称。

::: example 比较一个公平模型和一个有偏源
如果 $p=(3/4,1/4)$ 和 $q=(1/2,1/2)$，则 $H(p,q)=\ln2$。源熵约为 $0.5623$ 个纳特，超额损失约为 $0.1308$ 个纳特。
```check
h1 = -Rational(3,4)*log(Rational(3,4))-Rational(1,4)*log(Rational(1,4))
rounds(h1,"0.5623351446")
rounds((log(2)-h1),"0.1308120359")
```
:::

::: widget name=information
将数据分布的权重设为 3、1、0，将预测分布的权重设为 1、1、0。选择纳特，复现上面的例题。然后将第二个预测权重设为零，观察哪个方向的 KL 散度变成无穷大。
:::

::: compute 平均自信息量
使用相同的单位计算所有得分。
```python
from math import log

p, q = (0.75, 0.25), (0.5, 0.5)
entropy = -sum(pi * log(pi) for pi in p if pi > 0)
cross_entropy = -sum(pi * log(qi) for pi, qi in zip(p, q) if pi > 0)
print(f"{entropy:.4f} {cross_entropy:.4f} {cross_entropy - entropy:.4f}")
```
```output
0.5623 0.6931 0.1308
```
:::

## 练习 {#exercises}

:::: exercise 均匀源 {#ex-3-1} ★
计算四个等概率标记的熵（以纳特为单位）。
::: solution
每个词元的自信息量为 $\ln4$。其平均值为 $\ln4$。
```check
same(-4*Rational(1,4)*log(Rational(1,4)),log(4))
```
:::
::::

:::: exercise 一个确定性源 {#ex-3-2} ★★
计算当 $p=(1,0)$ 和 $q=(1/4,3/4)$ 时的超额损失。
::: solution
$H(p)=0$，并且唯一发生的输出导致损失 $-\ln(1/4)=\ln4$。
```check
same(-log(Rational(1,4)),log(4))
```
:::
::::

:::: exercise 改变单位 {#ex-3-3} ★★★
将八个等概率输出的熵从纳特转换为比特。
::: solution
将 $\ln8$ 除以 $\ln2$ 得到 $3$ 比特。
```check
same(log(8)/log(2),3)
```
:::
::::

## 自测 {#quiz}

```quiz
? 哪种分布提供了 $H(p,q)$ 中的权重？
- [x] $p$
- [ ] $q$
- [ ] 均匀分布
> 在 $q$ 下的损失是在 $p$ 的输出上平均的。

? 如果 $p_i>0$ 和 $q_i=0$ 呢？
- [ ] 该项贡献为零
- [ ] 熵和交叉熵相同
- [x] 交叉熵为无穷大
> 模型对一个可能观察到的输出给出零概率。

? $D_{\rm KL}(p\|q)=0$ 在什么情况下成立？
- [ ] 当两个分布具有相同的熵时
- [x] 恰好在 $p=q$ 时
- [ ] 当两个分布具有相同的支撑集时
> 零超额期望对数损失要求两个分布一致。
```
