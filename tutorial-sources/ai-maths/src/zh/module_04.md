## 计算观测词元的损失 {#loss}

对一个具有 $N>0$ 个计分位置的序列，将观察到的词的负对数概率相加，再除以 $N$：
$$
\ell=-\frac{1}{N}\sum_{i=1}^N \ln q(t_i\mid t_{<i}),
\qquad \operatorname{PPL}=e^\ell.
$$
训练过程中可以在每个位置提供实际的前序词元。这被称为**教师强制（teacher forcing）**。提示、填充和其他被掩码的位置可以通过同时从分子和分母中排除它们来不计入损失。语料级别的平均值将总损失除以参与计分的词元总数。文档级别的平均值的无权重平均在文档长度不同时回答的是不同的问题。

::: example 两个词元
如果分配的概率是 $1/2$ 和 $1/8$，则总负对数似然为 $\ln16$，均值为 $\ln4$，困惑度为 $4$。
```check
same(-(log(Rational(1,2))+log(Rational(1,8)))/2,log(4))
same(exp(log(4)),4)
```
:::

在相同的数据、分词和计分位置上比较困惑度。使用不同的分词方式会改变平均的单位。一个模型将所有观察到的词元的概率分配为 $1/K$，其困惑度为 $K$，这解释了名称的由来。困惑度是一个概率得分，但并不能直接保证生成文本的事实准确性。

## 生成后续序列 {#sampling}

每个生成的词元将成为下一个前缀的一部分。在 logits 为 $z_i$ 和温度为 $T>0$ 的情况下，采样概率与 $e^{z_i/T}$ 成比例。标记 $i$ 相对于标记 $j$ 的概率比为 $e^{(z_i-z_j)/T}$。温度越低，较高 logit 的词元相对于较低 logit 的词元就越容易被采到。贪心解码在每一步选择最大的 logit。Top-$k$ 采样保留 $k$ 个由最大得分选出的候选标记，在需要时按预定规则处理并列项，然后重新归一化所选概率。改变采样规则会改变生成分布。使用原始概率评估原始模型的困惑度。

::: compute 比较两个温度
对于两个相差 $\ln3$ 的 logit，将温度减半并比较两者的概率比。
```python
from math import exp, log

gap = log(3)
for temperature in (1.0, 0.5):
    print(f"{exp(gap / temperature):.0f}")
```
```output
3
9
```
:::

## 练习 {#exercises}

:::: exercise 相同置信度 {#ex-4-1} ★
计算模型在每个三个观察到的词元在其各自前缀上的概率为 $1/5$ 时的困惑度。
::: solution
平均损失是 $\ln5$，因此困惑度是 $5$。
```check
same(exp((-3*log(Rational(1,5)))/3),5)
```
:::
::::

:::: exercise 为每个词元加权 {#ex-4-2} ★★
一个文档在三个词元上的平均损失是 $2$，另一个在一个词元上的平均损失是 $1$。找出整个语料库的平均损失。
::: solution
总和是 $3\cdot2+1=7$。除以四得到 $7/4$。
```check
same(Rational(3*2+1,4),Rational(7,4))
```
:::
::::

:::: exercise 改变概率 {#ex-4-3} ★★★
在温度 $1$ 下，$A$ 对 $B$ 的概率比是 $16:1$。找出在相同 logit 下温度 $2$ 时的概率比。
::: solution
温度加倍会使 log 概率比减半。新的概率比是 $\sqrt{16}:1=4:1$。
```check
same(exp(log(16)/2),4)
```
:::
::::

## 自测 {#quiz}

```quiz
? 自回归评估中一个评分位置是什么？
- [ ] 整个词汇表
- [x] 一个下一个标记的目标及其前面的上下文
- [ ] 没有目标的随机生成后缀
> 损失使用在该上下文中分配给观察到的标记的概率。

? 语料库困惑度如何从标记损失的总和计算得出？
- [ ] 将该和的指数除以标记数量
- [ ] 对每个文档均值进行指数运算，然后取它们的无权重平均值
- [x] 将和除以评分标记的数量，然后进行指数运算
> 在计算困惑度之前，先在对数尺度上取平均值

? 提高一个正温度是否会改变哪个logit最大？
- [x] 顺序保持不变
- [ ] 顺序被反转
- [ ] 顺序向量旋转一个标记
> 将每个logit除以相同的正数，不会改变它们的顺序
```
