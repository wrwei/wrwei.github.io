## 适合谁 {#who}

所有从没用过 Git 的人：学生、研究人员、写作者、设计师，以及到现在为止没用 Git 也应付过来的程序员。你不需要会编程，也不需要用过终端（terminal）。只要你会打字，能照着说明一步步做，就能学会。

## 你将学会做什么 {#what}

- 保存一个项目的完整历史，并回到其中任何一个版本。
- 在分支（branch）上尝试新想法，然后把它们合并（merge）进来，或者干脆丢掉。
- 冷静地解决合并冲突。
- 把你的工作保存在 GitHub 上，并在不止一台电脑上继续工作。
- 用拉取请求（pull request）提出、审查并合并修改，一个人做或和别人一起做都可以。
- 改正常见的错误，并知道该用哪一种“撤销”。
- 用 GitHub Pages 发布一个你自己的网页。

整个过程中，你会一直做同一个小项目：一个个人网页。学完时，它就在你自己的网址上线了。
