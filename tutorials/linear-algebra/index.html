Linear Algebra

Learn how vectors describe data and how matrices transform it, from solving equations to compressing and reconstructing observations.

Start here

You need school algebra and the Pythagorean theorem. Work through the modules in order if linear algebra is new to you.

Each module has a worked calculation, exercises with solutions, and a quiz. Try each exercise before opening its solution. Six demonstrations let you change the inputs and see what changes in the result. Python is optional. Install SymPy and NumPy if you want to run the examples using the Python download.
