方向在映射下保持不变

一个方阵 AAA 的 特征向量 是一个非零向量 v，\mathbf v\mathclose{\text{，}}v，使得 Av=λv。A\mathbf v=\lambda\mathbf v\mathclose{\text{。}}Av=λv。其对应的特征值 λ\lambdaλ 记录了该方向上映射的作用。负值表示方向反转，零特征值是允许的，并表示非零核的存在。

对于候选 λ，\lambda\mathclose{\text{，}}λ，条件是 (A−λI)v=0。(A-\lambda I)\mathbf v=\mathbf 0\mathclose{\text{。}}(A−λI)v=0。非零解存在的充要条件是 det⁡(A−λI)=0。\det(A-\lambda I)=0\mathclose{\text{。}}det(A−λI)=0。首先找到这些根，然后对每个根解一个齐次方程组。整个核是 特征空间，包含零向量，尽管零向量本身不是特征向量。

转换为特征向量坐标

如果 AAA 有一个特征基，将特征向量作为 PPP 的列，将对应的特征值按顺序放在 DDD 的对角线上。然后 AP=PD，AP=PD\mathclose{\text{，}}AP=PD，因此 A=PDP−1。A=PDP^{-1}\mathclose{\text{。}}A=PDP−1。转换为特征向量坐标，独立地缩放每个坐标，然后转换回来。在幂 AkA^kAk 中，中间的因子 P−1PP^{-1}PP−1P 抵消，留下 PDkP−1。PD^kP^{-1}\mathclose{\text{。}}PDkP−1。模长小于一的特征值对应的分量随 kkk 增加而衰减。对于这个例子，(0,1)T(0,1)^\mathsf T(0,1)T 是两个选定的特征向量之和，因此在 kkk 步之后它变为 (2k−1,1)T。(2^k-1,1)^\mathsf T\mathclose{\text{。}}(2k−1,1)T。

不同的特征值有独立的特征向量。在一个最简非平凡线性关系中，应用 A−λIA-\lambda IA−λI 对于关系中的一个特征值会去掉该向量，留下一个更简短的非平凡关系。因此 nnn 个不同的实特征值就足以构成一个实特征基。重复本身并不能得出结论。一些实矩阵也有复特征对，但没有实特征基。

动手计算一个重复的特征值缺少一个方向
Python
from sympy import Matrix

A = Matrix([[1, 1], [0, 1]])
for value, multiplicity, basis in A.eigenvects():
    print(value, multiplicity, [list(v) for v in basis])
print((A**4).tolist())

[[1, 4], [0, 1]]

练习 9.2★★一个重复的根
