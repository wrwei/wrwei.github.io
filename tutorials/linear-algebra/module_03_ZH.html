仿射映射

形如 Ax+bA\mathbf x+\mathbf bAx+b 的映射是 仿射映射。它的平移项将每个输出移动相同量。它恰好是线性映射当且仅当 b=0。\mathbf b=\mathbf 0\mathclose{\text{。}}b=0。如果坐标表示地图上的点，平移原点会改变位置但保持每个位移由 AAA 转换。

动手计算比较两个乘积
Python
from sympy import Matrix

scale = Matrix([[2, 0], [0, 1]])

print((scale * shear).tolist())
