最接近可到达的观测值

假设 b\mathbf bb 包含测量值，AxA\mathbf xAx 是预测值的向量。可能不存在精确解。最小二乘 最小化 ∥Ax−b∥2。\|A\mathbf x-\mathbf b\|^2\mathclose{\text{。}}∥Ax−b∥2。拟合向量是 b\mathbf bb 到列空间的正交投影，因为所有候选预测值都位于该空间中。剩余量 r=b−Ax^\mathbf r=\mathbf b-A\widehat{\mathbf x}r=b−Ax 与每一列正交。这给出了 正规方程

ATAx^=ATb.A^\mathsf TA\widehat{\mathbf x}=A^\mathsf T\mathbf b. ATAx=ATb.

相反，这些方程的任何解都是通过平方距离分解得到的最小二乘解。即使系数不唯一，拟合向量也是唯一的。任何产生相同拟合的两个系数向量之间的差异是一个零空间向量。

使用 QR 分解求解

对于独立列，写出 A=QR，A=QR\mathclose{\text{，}}A=QR，并将投影表示为 QQTb。QQ^\mathsf T\mathbf b\mathclose{\text{。}}QQTb。在 QQQ 的列中匹配系数得到 Rx^=QTb。R\widehat{\mathbf x}=Q^\mathsf T\mathbf b\mathclose{\text{。}}Rx=QTb。这是一个三角求解。它避免了形成 ATA，A^\mathsf TA\mathclose{\text{，}}ATA，其条件数是 AAA 条件数的平方。模块 11 推导了该比例。

观测值的小扰动在列近似相关时可能迫使系数发生较大变化。对于 A=(110ε)，A=\begin{pmatrix}1&1\\0&\varepsilon\end{pmatrix}\mathclose{\text{，}}A=(10​1ε​)，将第二个观测值增加 ε，\varepsilon\mathclose{\text{，}}ε，会使第二个系数增加 1，1\mathclose{\text{，}}1，第一个系数减少 1。1\mathclose{\text{。}}1。预测值仅发生了一点变化。将小残差视为对测量拟合的证据，并分别检查灵敏度。

动手计算使用 QR 分解求解线性拟合
Python
from sympy import Matrix

A = Matrix([[1, 0], [1, 1], [1, 2]])
b = Matrix([1, 2, 2])
Q, R = A.QRdecomposition()
x = R.upper_triangular_solve(Q.T * b)
print(list(x))
print(list(A.T * (b - A * x)))
输出
[7/6, 1/2]
[0, 0]
动手计算拟合浮点数据的直线

NumPy 的最小二乘求解器返回系数和一个数值秩。在解释结果之前，给列顺序命名。残差范数衡量观测坐标中拟合误差的大小。

Python
import numpy as np

x_data = np.array([0., 1., 2.])
y_data = np.array([1., 2., 2.])
design = np.column_stack((np.ones(x_data.size), x_data))
coefficients, _, rank, _ = np.linalg.lstsq(design, y_data, rcond=None)
residual = y_data - design @ coefficients
print(f"intercept={coefficients[0]:.3f}, slope={coefficients[1]:.3f}")
print(f"rank={rank}, residual norm={np.linalg.norm(residual):.3f}")
输出
intercept=1.167, slope=0.500
rank=2, residual norm=0.408
