模块 4下一个词元的损失、困惑度与采样

计算自回归模型的训练损失，理解文本生成中的采样规则。

在本模块中，你将

  • 计算平均下一个词负对数似然和困惑度

1

计算观测词元的损失

对一个具有 N>0N>0N>0 个计分位置的序列，将观察到的词的负对数概率相加，再除以 N：N\mathclose{\text{：}}N：

ℓ=−1N∑i=1Nln⁡q(ti∣t<i),PPL⁡=eℓ.\ell=-\frac{1}{N}\sum_{i=1}^N \ln q(t_i\mid t_{<i}), \qquad \operatorname{PPL}=e^\ell. ℓ=−N1​i=1∑N​lnq(ti​∣t<i​),PPL=eℓ.

训练过程中可以在每个位置提供实际的前序词元。这被称为教师强制（teacher forcing）。提示、填充和其他被掩码的位置可以通过同时从分子和分母中排除它们来不计入损失。语料级别的平均值将总损失除以参与计分的词元总数。文档级别的平均值的无权重平均在文档长度不同时回答的是不同的问题。

例 4.1两个词元✓ 已检验

如果分配的概率是 1/21/21/2 和 1/8，1/8\mathclose{\text{，}}1/8，则总负对数似然为 ln⁡16，\ln16\mathclose{\text{，}}ln16，均值为 ln⁡4，\ln4\mathclose{\text{，}}ln4，困惑度为 4。4\mathclose{\text{。}}4。

在相同的数据、分词和计分位置上比较困惑度。使用不同的分词方式会改变平均的单位。一个模型将所有观察到的词元的概率分配为 1/K，1/K\mathclose{\text{，}}1/K，其困惑度为 K，K\mathclose{\text{，}}K，这解释了名称的由来。困惑度是一个概率得分，但并不能直接保证生成文本的事实准确性。

生成后续序列

每个生成的词元将成为下一个前缀的一部分。在 logits 为 ziz_izi​ 和温度为 T>0T>0T>0 的情况下，采样概率与 ezi/Te^{z_i/T}ezi​/T 成比例。标记 iii 相对于标记 jjj 的概率比为 e(zi−zj)/T。e^{(z_i-z_j)/T}\mathclose{\text{。}}e(zi​−zj​)/T。温度越低，较高 logit 的词元相对于较低 logit 的词元就越容易被采到。贪心解码在每一步选择最大的 logit。Top-kkk 采样保留 kkk 个由最大得分选出的候选标记，在需要时按预定规则处理并列项，然后重新归一化所选概率。改变采样规则会改变生成分布。使用原始概率评估原始模型的困惑度。

动手计算比较两个温度

对于两个相差 ln⁡3\ln3ln3 的 logit，将温度减半并比较两者的概率比。

Python
from math import exp, log

gap = log(3)
for temperature in (1.0, 0.5):
    print(f"{exp(gap / temperature):.0f}")
