面向对象设计

通过 Python 示例和 UML 图学习面向对象设计。九个模块从对象与类讲起，逐步介绍封装、继承、多态、组合和接口，再用设计模式与 SOLID 原则改进已有设计。

课程目录

  1. 模块 01

    对象与类

    区分对象与类，用属性、方法和构造器表示领域中的实体。
  2. 模块 02

    封装

    用属性访问和公开接口保护对象的不变式。
  3. 模块 03

    继承与层次结构

    用类继承表示泛化关系，练习重写方法和调用 super()。
  4. 模块 04

    多态

    让不同类型的对象响应同一种操作，比较方法重写和鸭子类型。
  5. 模块 05

    组合与聚合

    用整体与部分的关系表示对象结构，比较所有权、委派与继承。
  6. 模块 06

    接口与契约

    用抽象基类和协议定义接口，检查不同实现能否相互替换。
  7. 模块 07

    设计模式

    用策略、观察者和工厂等模式解决常见的设计问题。
  8. 模块 08

    面向对象设计实践

    从领域建模到重构，把前面几章的原则用到一个完整案例中。
  9. 模块 09

    SOLID 原则

    学习单一职责、开闭、里氏替换、接口隔离和依赖倒置五项原则。
