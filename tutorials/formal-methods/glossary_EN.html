Glossary

Every term the series defines, in alphabetical order, with a short definition, its Chinese equivalent and the sections that explain it.

A term with two meanings lists both. Symbols and notation are in the cheat sheet, and Isabelle’s messages in Troubleshooting. The numbers in the last column are sections of the modules: 7.2.1 is Module 7, Section 7.2.1.

Terms from A to Z

A

Term Meaning Section
abstract syntax
抽象语法		 The structure of a program as a tree: each node is an operation and its children are its operands. In Isabelle it is a datatype. 14.2.1
abstraction function
抽象函数		 A function that maps each concrete value or state to the abstract one it represents, such as set_of from search trees to sets. 12.5.1, 13.7.1
accumulator
累加器		 An argument in which a function collects its result as it goes. Inductions about such functions usually need arbitrary:. 11.1.1
affirming the consequent
肯定后件		 Concluding A from A ⟶ B and B: an invalid argument form, common enough to have a name. 2.6
α-equivalent
α 等价的		 Formulas that differ only in the names of their bound variables, such as ∃y. R x y and ∃z. R x z, are α-equivalent; they mean the same. 3.5.2
antecedent
前件		 In A ⟶ B, the formula A; B is the consequent. 2.1
antisymmetric
反对称的		 A relation R is antisymmetric if (x, y) ∈ R and (y, x) ∈ R imply x = y. 4.2.3
application
函数应用		 Applying a function f to an argument a, written f a, without parentheses or commas. Application groups to the left: f x y is (f x) y. 8.2.1
apply script
apply 脚本		 A proof written as a sequence of apply steps that ends with done. 5.4.2
Archive of Formal Proofs
形式化证明档案库		 An online library of checked Isabelle developments. 1.4
argument
论证		 Premises together with a conclusion. An argument is valid if its conclusion is a logical consequence of its premises. 2.6
arity
元数		 (1) The number of arguments of a symbol. (2) In Isabelle, the record that a type belongs to a type class, as in the message No type arity light :: numeral. 3.2, 8.6.2
assignment
赋值		 A choice of a value in the domain for every variable. Whether a formula with free variables is true depends on it. 3.3
assumption
假设		 A formula you may use without proving it: a leaf of a derivation, or a formula before ⟹ in a subgoal. 6.2, 7.1.2
atom (atomic proposition)
原子命题（原子）		 A proposition that is not built from other propositions, written as a name such as A or fire. 2.1
atomic formula
原子公式		 In predicate logic, a predicate applied to terms, P t₁ … tₙ, or an equation t₁ = t₂ between terms. 3.2.2
auxiliary lemma
辅助引理		 A lemma proved first because a larger proof needs it. The goal on which the larger proof gets stuck usually shows what it must say. 11.3, 14.5.1
axiom
公理		 An inference rule without premises. 6.2

B

Term Meaning Section
backward search
反向搜索		 Finding a proof by starting from the goal: choose a rule whose conclusion matches it, and its premises become subgoals. Isabelle works this way. 6.7
bad row
坏行		 A row of a truth table in which every premise is true and the conclusion false. An argument is valid exactly when it has no bad row. 2.6
base case
基础情形		 The case of a recursive definition or an induction that does not use the function or the hypothesis, such as 0 or the empty list. 5.1.2, 5.3.1
base type
基本类型		 A type that is a name, such as bool, nat or int. 8.1.1
β-reduction
β 归约		 The step that applies λx. t to an argument a: the result is t with a in place of x. 8.2.1
biconditional
双条件		 A ⟷ B, read “A if and only if B”: true when A and B have the same truth value. Module 2 calls it equivalence; Isabelle prints it as =. 2.1
bijective
双射的		 Both injective and surjective: the function pairs the elements of two sets one to one. Isabelle writes bij f. 4.6.2
binary search tree
二叉搜索树		 A binary tree that stores keys so that the keys in the left subtree of a node are smaller than the node’s key and those in the right subtree larger; its operations must preserve this invariant. 12.5
binary tree
二叉树		 Either empty, or a node that holds an element and two smaller trees, its left and right subtrees. 5.2.2
bound variable
约束变元		 An occurrence of a variable in the scope of a quantifier for that variable. Renaming it throughout the scope changes nothing. 3.2.4
bounded quantifier
有界量词		 ∀x ∈ A. P x, “for all x in A, P x”, short for ∀x. x ∈ A ⟶ P x. 4.2.3

C

Term Meaning Section
calculation
计算推理		 In Isar, a chain of steps t₁ R t₂, t₂ R t₃, …, each with its own proof, from which Isabelle derives t₁ R tₙ by transitivity. It is written with also and finally. 10.4.1
call by value
传值调用		 An order of evaluation that evaluates the arguments of a call before the call itself. 5.1.3
Cantor’s theorem
康托尔定理		 No function maps a set onto its power set, so some sets are larger than others. The proof is the diagonal argument. 4.7.4
cardinality
基数		 The number of elements of a finite set A, written A
Cartesian product
笛卡儿积		 A × B, the set of all pairs (a, b) with a ∈ A and b ∈ B. 4.2.1
case analysis
情形分析		 A proof that splits into cases that together cover every possibility, and proves the claim in each. 6.1, 10.5
case expression
case 表达式		 A term that takes a value apart by matching it against patterns, with one branch per pattern, such as a case on an option with branches for None and Some x. 8.3.4
case split
情形拆分		 Splitting a goal that contains an if or a case into one case per possibility. The simplifier splits if by itself, case only when asked with split:. 9.3.3
CDCL (conflict-driven clause learning)
冲突驱动子句学习（CDCL）		 After a conflict, a SAT solver adds a clause that rules out the decisions that caused it, so that the search never makes the same mistake twice. 2.8
classical logic
经典逻辑		 The logic in which A ∨ ¬A holds for every A. Natural deduction needs (RAA), or an equivalent rule, to derive it. 6.5
classical reasoner
经典推理器		 Isabelle’s search methods built on natural-deduction rules, such as blast, auto, force and fastforce. They backtrack when a choice fails. 7.9, 9.4
clause
子句		 A disjunction of literals, such as ¬A ∨ B ∨ ¬C; a single literal counts as a clause too. 2.7
closure
闭包		 The smallest relation that contains R and has a given property: reflexive, symmetric or transitive. 4.5.1
code generation
代码生成		 Translating HOL definitions into Standard ML, OCaml, Haskell or Scala with export_code. value uses the same machinery. 8.8
codomain
陪域		 For a function f : A → B, the set B. 4.6.1
compiler
编译器		 A program that translates programs of one language into another, here arithmetic expressions into code for a stack machine. 14.4
compiler correctness
编译器正确性		 Running the compiled code agrees with the meaning of the source: here, exec (compile e) s stk = eval e s # stk. 14.4.2
complement
补集		 −A, the elements of the type that are not in A. Isabelle writes - A. 4.1.2
complete
完备的		 A proof system is complete if it derives every logical consequence. A proof method is complete for a logic if, given unlimited time, it proves every valid formula of it. 6.3, 9.4.1
complete induction
完全归纳法		 Another name for strong induction: the step may use the claim for every smaller value. In Isabelle, rule: less_induct. 5.6, 11.8
completeness theorem
完备性定理		 Gödel’s theorem (1929/1930) that every valid first-order formula can be proved. 3.9
composition
复合		 R O S takes an R-step followed by an S-step. For functions, (g ∘ f) x = g (f x), read “g after f”. 4.2.4, 4.6.3
compositional
组合式的		 A semantics is compositional if the meaning of each node is computed from the meanings of its children. 14.2.2
computation induction
计算归纳		 Induction that follows the recursion of a function f: one case per defining equation and one hypothesis per recursive call. In Isabelle, rule: f.induct. 11.5.3
conclusion
结论		 The formula that an argument, a rule or a derivation reaches. In a subgoal, the formula after ⟹. 2.6, 6.2
concrete syntax
具体语法		 The text of a program, with its parentheses and spaces, as opposed to its abstract syntax. 14.2.1
conditional rewrite rule
条件重写规则		 A rule H ⟹ l = r, which the simplifier uses only after it has proved the condition H by simplification. 9.3.1
conjunction
合取		 A ∧ B, read “A and B”: true when both are true. 2.1
conjunctive normal form (CNF)
合取范式		 A conjunction of clauses, such as (A ∨ ¬B) ∧ (¬A ∨ C ∨ D) ∧ ¬C. SAT solvers work on it. 2.7.2
connective
联结词		 A symbol that builds a larger formula from smaller ones: ¬, ∧, ∨, ⟶ and ⟷. 2.1
consequent
后件		 In A ⟶ B, the formula B. 2.1
consistent
一致的		 A set of requirements is consistent if their conjunction is satisfiable: some valuation makes all of them true. 2.9
constant
常量		 A symbol that names a single object, such as alice or 0. In Isabelle, a name that has been defined or declared, as opposed to a variable. 3.2
constant folding
常量折叠		 An optimisation that replaces the parts of a program whose value does not depend on the state by their value, and removes operations that have no effect. 14.6.1
constructor
构造子		 One of the functions that build the values of a datatype, such as [] and # for lists, or Red for traffic lights. 5.2.2, 8.3.1
contingent
可满足但非有效的		 A formula that is satisfiable but not a tautology: true in some rows of its truth table and false in others. 2.4
contradiction
矛盾式		 A formula that is true under no valuation; also called unsatisfiable. 2.4
contrapositive
逆否命题		 The contrapositive of A ⟶ B is ¬B ⟶ ¬A. Both say the same, so proving one proves the other. 6.1
converse (of a relation)
逆关系		 R⁻¹, which reverses every pair of R. Isabelle writes r¯. 4.2.4
converse (of an implication)
逆命题		 The converse of A ⟶ B is B ⟶ A, which says something different. Proving it instead is a common mistake. 6.1
corollary
推论		 A fact that follows directly from a theorem. In Isabelle the command corollary means the same as lemma; the name only tells the reader. 11.7.3, 14.5.4
correctness theorem
正确性定理		 A theorem stating that for every input, the result of the implementation has the property of the specification. 12.1
countable
可数的		 A set is countable if there is an injective function from it to ℕ: it is finite, or its elements can be listed as a₀, a₁, a₂, … 4.7.3
counterexample
反例		 Something that makes a claim false: a valuation, values of the free variables, or a run that reaches a bad state. 2.4, 13.3
counterexample to induction
归纳反例		 A state and an event that break the step case of an invariant proof: the state satisfies the invariant, and the event leads out of it. 13.5.1
counterexample trace
反例轨迹		 A run, written as a list of events, from an initial state to a state that violates a property. 4.5.2, 13.6
countermodel
反模型		 A structure, with an assignment for the free variables, in which a formula is false. One countermodel refutes validity. 3.4
Curry–Howard correspondence
柯里–霍华德对应		 Intuitionistic proofs can be read as programs: a proof of A ⟶ B is a function from evidence for A to evidence for B. Rocq and Lean are built on this idea. 6.5.1
currying
柯里化		 Writing a function of several arguments as a function that takes the first argument and returns a function of the rest, after the logician Haskell Curry. 8.2.2

D

Term Meaning Section
data refinement
数据精化		 Showing that a concrete data structure implements an abstract model: with an abstraction function and an invariant, every concrete operation corresponds to its abstract one. 12.6.1
datatype
数据类型		 A type whose values are built from constructors; values built differently are different. It is defined with the command datatype. 5.2.2, 8.3.1
De Morgan’s laws
德摩根律		 ¬(A ∧ B) ≡ ¬A ∨ ¬B and ¬(A ∨ B) ≡ ¬A ∧ ¬B. 2.5
decidable
可判定的		 A question is decidable if some algorithm answers it correctly for every input and always terminates. 3.9
decision problem
判定问题		 A yes-or-no question about inputs, such as “is this number prime?”; as a set, a subset of ℕ. 4.7.4
decision procedure
判定过程		 A program that decides, for every formula of some kind, whether it holds, and proves it if it does, such as linarith. 9.5
denying the antecedent
否定前件		 Concluding ¬B from A ⟶ B and ¬A: an invalid argument form. 2.6
derivable
可推导的		 Γ ⊢ A, “A is derivable from Γ”: some derivation has the conclusion A and all its open assumptions in Γ. 6.2
derivation
推导		 A tree of formulas in which every formula is an assumption or follows from the formulas directly above it by a rule. 6.2, 11.6.1
destruction rule
析构规则		 A rule with the connective in its major premise and a part of that premise as its conclusion, such as conjunct1, mp and spec. It is used with drule and frule. 7.2.3
diagonal argument
对角线论证		 Cantor’s proof that no function f maps a set onto its power set: the set of elements x that are not in f x is not a value of f. 4.7.4
difference
差集		 A − B, the elements of A that are not in B. 4.1.2
discharge
解除（假设）		 A rule such as (⟶I) discharges an assumption: the conclusion no longer depends on it. A discharged assumption is written [A]¹. 6.4.2
disjoint
不相交的		 Two sets are disjoint if they have no element in common: A ∩ B = ∅. 4.1.2
disjunction
析取		 A ∨ B, read “A or B”: true when at least one of them is true. 2.1
disjunctive normal form (DNF)
析取范式		 A disjunction of conjunctions of literals, such as (A ∧ ¬B) ∨ (¬A ∧ C) ∨ D. 2.7.2
disjunctive syllogism
析取三段论		 From A ∨ B and ¬A, conclude B: a valid argument form. 2.6
domain (of a function)
定义域		 For a function f : A → B, the set A. 4.6.1
domain (of a structure)
论域		 The non-empty set of objects that the variables range over. 3.3
DPLL procedure
DPLL 算法		 The search on which SAT solvers are based: unit propagation, decisions, and going back to the latest decision after a conflict. 2.8
dual
对偶		 The law obtained by swapping ∪ and ∩ (and ∅ and UNIV). The dual of a law of sets holds as well. 4.1.3

E

Term Meaning Section
effect
效果		 How an event changes the state of a state machine. 13.1
eigenvariable
本征变元		 The name a in the rules (∀I) and (∃E). It must be fresh: this is the eigenvariable condition. 6.6
element
元素		 A member of a set: x ∈ A means that x is an element of A. 4.1.1
elimination rule
消去规则		 A rule that says how to use a formula with a given connective. In Isabelle its major premise contains the connective, and it is used with erule. 6.4, 7.2.3
empty set
空集		 ∅, the set without elements. Isabelle writes {}. 4.1.1
enumeration
枚举类型		 A datatype whose constructors take no arguments, such as the four states of a traffic light. 8.3.1
equisatisfiable
等可满足的		 Two formulas are equisatisfiable if one is satisfiable exactly when the other is. 2.7.2
equivalence class
等价类		 The set of the elements related to x by an equivalence relation, written [x]. 4.3
equivalence relation
等价关系		 A relation that is reflexive, symmetric and transitive. Its equivalence classes form a partition. 4.3
evaluation
求值		 Computing the value of a term by rewriting it with the defining equations until none applies. 5.1.3
event
事件		 A kind of step of a state machine, such as pressing a button. It can happen when its guard holds, and changes the state by its effect. 13.1
existential quantifier
存在量词		 ∃: ∃x. φ says that φ holds for at least one x. 3.2.3
extensionality
外延性		 Two sets are equal when they have the same elements. 4.1.1

F

Term Meaning Section
fact
事实		 In Isar, a proved statement that a proof can use: an assumption, the result of have or show, or a lemma. 10.3.1
fairness
公平性		 An assumption that rules out unfair runs, such as “an event whose guard stays true is eventually taken”. Proofs of liveness need it. 13.8.1
falsum (⊥)
恒假（⊥）		 ⊥, read “bottom” or “falsum”: the formula that is false in every valuation and every structure. Isabelle writes False. 6.4.5
finite model
有限模型		 A model in which every type is finite. Nitpick searches for one that makes a claim false. 9.7.2
fixed variable
固定变元		 A variable bound by ⋀ in a subgoal, or introduced by fix in Isar. It stands for an arbitrary value, and unification never replaces it. Isabelle also calls it a parameter. 7.6.1, 10.2.4
formal language
形式语言		 A language with an exact grammar, so that every statement has one reading; the first ingredient of a formal method. 1.2
formal method
形式化方法		 A way of specifying or verifying a system in a language with a precise mathematical meaning, so that claims about the system can be checked by calculation or proof. 1.2
formal specification
形式化规约		 A specification written in a formal language. 1.2
formula
公式		 An expression built by the formation rules: from atoms (or atomic formulas), True and False, with the connectives and, in predicate logic, the quantifiers. 2.2.1, 3.2.3
forward chaining
正向链接		 In Isar, passing facts to the next claim, whose proof method then receives them; then, from and with do it. 10.3.1
free variable
自由变元		 An occurrence of a variable that no quantifier binds; in Isabelle, a name that is not a constant. The free variables of a lemma are implicitly universal. 3.2.4, 8.1.2
fresh
新的		 A name is fresh if it does not occur free where a rule forbids it: in the conclusion, in the quantified formula or in the open assumptions. 6.6
function
函数		 A relation in which every element of the domain is related to exactly one element of the codomain. In HOL a function is a value like any other. 4.6.1
function symbol
函数符号		 A symbol that names an operation whose result is an object, such as owner or +. 3.2
functional correctness
功能正确性		 Correctness about which result a program computes, not about how long it takes or how much memory it uses. 12.1

G

Term Meaning Section
generalise
推广		 To prove a claim for all values of a variable at once, so that the induction hypothesis can be used with other values. arbitrary: does this. 11.2, 14.5.1
genuine
真实的（反例）		 A Nitpick counterexample is genuine when Nitpick has checked that it falsifies the claim. A potentially spurious one might disappear in a larger model. 9.7.2
goal
目标		 The statement still to be proved. 1.7.3
guard
守卫		 (1) A predicate such as user that says which kind an object is, in a domain with several kinds (Module 3). (2) The condition under which an event of a state machine can happen (Module 13). 3.7, 13.1

H

Term Meaning Section
Hasse diagram
哈斯图		 A drawing of a partial order on a finite set: smaller elements lower, and a line only where one element covers another. 4.4.2
head
头部		 The first element x of a list x # xs. 5.2.1
higher-order logic (HOL)
高阶逻辑		 A typed logic in which functions and predicates are values, so variables and quantifiers may range over them. It is the logic of Isabelle/HOL. 1.4, 3.8
hypothetical syllogism
假言三段论		 From A ⟶ B and B ⟶ C, conclude A ⟶ C; also called chaining. A valid argument form. 2.6

I

Term Meaning Section
identity relation
恒等关系		 Equality on a set A: the relation {(x, x). x ∈ A}. 4.2.2
image
像		 The set of everything related by R to an element of S, or the values of f on S. Isabelle writes r `` S and f ` A. 4.2.4, 4.6.1
implementation
实现		 The program that does the work: it says how to compute the result. 12.1
implication
蕴涵		 A ⟶ B, read “A implies B” or “if A then B”: false only when A is true and B false. 2.1
inclusion–exclusion
容斥原理		 For finite sets, A ∪ B
incomparable
不可比较的		 Two elements of a partial order are incomparable if neither is below the other, such as {1} and {2} under ⊆. 4.4.1
incompleteness theorems
不完备性定理		 Gödel’s theorems (1931): no proof system whose axioms a program can check, and which proves only true statements, proves every truth about the natural numbers. 3.9
induction
归纳		 Proving a claim for every value by proving it for the smallest values and showing that it passes from smaller values to larger ones. Mathematical, structural, strong and rule induction are kinds of it. 5.3.1
induction hypothesis (IH)
归纳假设		 The assumption, in the induction step, that the claim holds for the smaller value. In Isabelle’s subgoals it stands before ⟹; in Isar it is c.IH. 5.3.1
induction step
归纳步骤		 The part of an induction that proves the claim for n + 1, or for a larger value, from the induction hypothesis. 5.3.1
inductive definition
归纳定义		 A definition of a predicate by introduction rules. It holds exactly for what finitely many rule applications derive: it is the smallest predicate closed under the rules. 11.6
inductive invariant
归纳不变式		 A property that holds in every initial state and is preserved by every step. It then holds in every reachable state. 13.3
inference rule
推理规则		 A rule with zero or more premises and one conclusion, which says what may be derived from what. 6.2
initial method
初始方法		 The method after proof, which turns the goal into the pending goals of the block. 10.2.1
initial state
初始状态		 A state in which a state machine may start. 13.1
injective
单射的		 Different inputs give different outputs: f x = f y implies x = y. Isabelle writes inj f. 4.6.2
inner syntax
内层语法		 The language of terms and types, written between quotation marks. 1.7.2
instance
实例		 A type that belongs to a type class: nat and int are instances of the class plus. 8.6.2
interactive theorem proving
交互式定理证明		 Writing definitions, theorems and their proofs in an expressive logic, with a program that checks every step and automation that helps. 1.3
interpretation
解释		 What a structure makes each constant, function symbol and predicate symbol mean. 3.3
intersection
交集		 A ∩ B, the elements that are in both A and B. 4.1.2
introduction rule
引入规则		 A rule that says how to prove a formula with a given connective; it is used with rule. For an inductive definition, one of its defining rules. 6.4, 7.2.3, 11.6
intuitionistic logic
直觉主义逻辑		 Natural deduction without (RAA): A ∨ ¬A and ¬¬A ⟶ A are not derivable, and proofs can be read as programs. 6.5.1
invariant
不变式		 A property that keeps holding. In Module 5, one that holds initially and is preserved by every step; in Module 13, one that holds in every reachable state; for a data structure, one that every value built by its operations has. 5.8, 12.5.3, 13.3
inventor’s paradox
发明者悖论		 Pólya’s observation that a more ambitious claim can be easier to prove. In an induction, a stronger claim gives a stronger induction hypothesis. 11.2.3
inverse
逆函数		 g is an inverse of f : A → B if g (f a) = a and f (g b) = b for all a and b. A function has one exactly when it is bijective; Isabelle writes inv f. 4.6.3
irreflexive
反自反的		 A relation is irreflexive on A if no element of A is related to itself. 4.2.3
Isabelle/HOL
Isabelle/HOL		 Isabelle with higher-order logic, the proof assistant this series uses. 1.4
Isabelle/jEdit
Isabelle/jEdit		 Isabelle’s prover IDE: an editor in which Isabelle checks the text as you type. 1.6
Isabelle/Pure
Isabelle/Pure		 Pure, Isabelle’s meta-logic: rules and goals are written in it with ⟹, ⋀ and ≡, and HOL is defined inside it. 7.1.1
Isar
Isar		 Isabelle’s language of structured proofs, short for “Intelligible semi-automated reasoning”: each step states a fact, and Isabelle checks it. 10.1

K

Term Meaning Section
kernel
内核		 The small part of an LCF-style prover that implements the inference rules. Every theorem is built by it. 1.4

L

Term Meaning Section
λ-abstraction
λ 抽象		 λx. t, the function without a name that maps each x to t. 8.2.1
law of excluded middle
排中律		 A ∨ ¬A: every proposition is true or false. Natural deduction derives it only with (RAA). 2.4, 6.5
LCF approach
LCF 方法		 An architecture in which theorems are values of an abstract type that only the kernel’s inference rules can create, so that bugs in proof tools cannot produce false theorems. 1.4
least element
最小元素		 An element below every element of a partial order; the greatest element is above every element. 4.4.2
lemma
引理		 A statement to be proved, in Isabelle stated with lemma. theorem and corollary mean the same. 1.7.3
lexicographic order
字典序		 The order of a dictionary on pairs: compare the first components, and only if they are equal, the second ones. 5.7.2
linear arithmetic
线性算术		 Formulas built from variables, numbers, +, −, =, < and ≤ and the connectives, in which a variable may be multiplied by a number but not by another variable. linarith decides it. 9.5
list
列表		 Either the empty list [] or x # xs, a head x in front of a tail xs. All elements of a list have the same type. 5.2.1
list comprehension
列表推导式		 [e. x ← xs, P x], the list of the values of e for the elements x of xs that satisfy P x. 8.5.2
listing
列举法		 Describing a set by naming its elements between braces, as in {2, 3, 5, 7}. 4.1.1
literal
文字		 An atom or a negated atom, such as A or ¬A. 2.7
