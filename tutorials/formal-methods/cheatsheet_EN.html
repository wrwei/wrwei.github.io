In Isabelle, ¬ binds most tightly, then ∧, then ∨, then ⟶ and ⟷, which group to the right; = binds more tightly than all of them, and a quantifier’s scope runs as far to the right as possible. When you mix ⟶ and ⟷, write the parentheses (2.2.2, 3.2.4, 3.6).

3

Theories

Everything you write goes into a theory. The theory First lives in the file First.thy (1.7.1):

theory First
  imports Main
begin

end

A theory that needs a library theory outside Main names it after imports (12.2.1):

theory Verify
  imports Main "HOL-Library.Multiset"
begin

end
  • Commands go between begin and end, and Isabelle checks them as you type.
  • Terms and types go between quotation marks (inner syntax); commands such as value and lemma stay outside (outer syntax) (1.7.2).
  • A string is written between two pairs of single quotes: ''alice'' (4.2.4).
  • Every theory of the series is in formal-methods-theories.zip.

Isar

Two proofs from Module 10: natural deduction written forwards, and an induction whose step is a calculation.

lemma "A ∧ B ⟶ B ∧ A"
proof (rule impI)
  assume ab: "A ∧ B"
  have b: "B" using ab by blast
  have a: "A" using ab by blast
  show "B ∧ A" using b a by blast
qed

lemma "mysum (xs @ ys) = mysum xs + mysum ys"
proof (induction xs)
  case Nil
  show ?case by simp
next
  case (Cons x xs)
  have "mysum ((x # xs) @ ys) = x + mysum (xs @ ys)" by simp
  also have "… = x + (mysum xs + mysum ys)" using Cons.IH by simp
  also have "… = mysum (x # xs) + mysum ys" by simp
  finally show ?case .
qed
