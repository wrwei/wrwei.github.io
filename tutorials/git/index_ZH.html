一步一步学 Git 与 GitHub

一套面向初学者的入门教程，共 11 节短课。学会用 Git 保存工作的历史，在 GitHub 上分享它，并发布你自己的网页。适用于 Windows、macOS 和 Linux，不需要任何经验。

11 课约 6 小时Windows · macOS · LinuxEN · 中文

适合谁

所有从没用过 Git 的人：学生、研究人员、写作者、设计师，以及到现在为止没用 Git 也应付过来的程序员。你不需要会编程，也不需要用过终端（terminal）。只要你会打字，能照着说明一步步做，就能学会。

你将学会做什么

  • 保存一个项目的完整历史，并回到其中任何一个版本。
  • 在分支（branch）上尝试新想法，然后把它们合并（merge）进来，或者干脆丢掉。
  • 冷静地解决合并冲突。
  • 把你的工作保存在 GitHub 上，并在不止一台电脑上继续工作。
  • 用拉取请求（pull request）提出、审查并合并修改，一个人做或和别人一起做都可以。
  • 改正常见的错误，并知道该用哪一种“撤销”。
  • 用 GitHub Pages 发布一个你自己的网页。

整个过程中，你会一直做同一个小项目：一个个人网页。学完时，它就在你自己的网址上线了。

课程列表

请按顺序学习：每一课都从上一课结束的地方开始。每课需要 15 到 45 分钟。

第 1 课15 分钟
Git 和 GitHub 是什么？
Git 能做什么，GitHub 又增加了什么，你会遇到的几个词，以及学完本系列时你会做出什么。这一课还不用输入命令。
✓
第 2 课45 分钟
安装与设置
注册 GitHub 账号，安装 VS Code 和 Git，打开终端，然后告诉 Git 你是谁。每台电脑只需要做一次。
✓
第 3 课40 分钟
你的第一个仓库
为你的项目建一个文件夹，把它变成 Git 仓库，写一个小网页，再为它保存第一个快照。
✓
第 4 课40 分钟
保存改动，回顾历史
修改你的网页，准确看清改了什么，保存更多快照，回看以前的快照，再丢弃一个你不想要的改动。
✓
第 5 课40 分钟
分支：放心尝试新想法
在分支上给你的页面试一个新外观，一秒钟就能在两个版本之间切换，最后把改动并入你的主线。
✓
第 6 课30 分钟
从容应对合并冲突
故意制造一个合并冲突，看懂 Git 在问你什么，在 VS Code 中解决它，然后完成合并。
✓
第 7 课40 分钟
把项目放到 GitHub 上
在 GitHub 上创建一个空仓库，把你的项目连接上去，登录，再推送你的提交，让你的工作安全地保存在网上。
✓
第 8 课15 分钟
用 GitHub Pages 发布网页
开启 GitHub Pages，你的网页就上线了，还有属于你自己的地址。之后，推送一次就能更新它。
✓
第 9 课40 分钟
在两个地方工作：拉取、推送、克隆
把 GitHub 上的修改带到你的电脑上，处理被 GitHub 拒绝的推送，再用 git clone 给你的项目做第二份副本。
✓
第 10 课40 分钟
拉取请求
在分支上提出一项改动，在 GitHub 上审查并合并它，再把本地整理干净。然后看看同样的步骤怎样让你和别人一起工作。
✓
第 11 课40 分钟
撤销与修正错误
帮你摆脱麻烦的命令，按情形整理成一份份“菜谱”。每一份都在你的项目上试一试，等真遇到的时候，你就知道该怎么做了。
✓
