估计完整梯度

经验损失是 nnn 个样本损失的平均值。在固定参数向量处，其梯度等于这 nnn 个样本梯度的平均值。如果一个小批量的 bbb 个样本索引是独立、均匀且有放回地抽取的，那么批量平均梯度是全梯度的无偏估计。由于各次抽样相互独立，平均梯度的协方差为 Σ/b，\Sigma/b\mathclose{\text{，}}Σ/b，其中 Σ\SigmaΣ 是单次抽样的协方差。均匀地无放回抽取固定大小的子集也能得到无偏均值，但需要对协方差作有限总体修正。

例 6.1在抽样上取平均✓ 已检验

对于标量每个示例梯度 222 和 −6，-6\mathclose{\text{，}}−6，完整梯度是 −2。-2\mathclose{\text{。}}−2。使用一个均匀抽样时，期望更新梯度仍然是 −2，-2\mathclose{\text{，}}−2，尽管单个抽样不会返回该值。单个抽样方差是 16。16\mathclose{\text{。}}16。对于四个独立抽样，它们的平均值的方差是 4。4\mathclose{\text{。}}4。

对下一个词元的损失进行训练时，先确定对什么单位取平均。如果目标是让每个计分词元的权重相同，就可以均匀抽取计分词元。如果均匀抽取文档，然后对各文档的平均损失取平均，得到的是以文档为单位的估计。同一文档内的词元梯度可能相关，不能直接套用独立抽样下的方差公式。

跟踪梯度矩

Adam 保持两个指数移动平均值，初始为零。对于梯度 gt，g_t\mathclose{\text{，}}gt​，其一阶矩是 mt=β1mt−1+(1−β1)gt，m_t=\beta_1m_{t-1}+(1-\beta_1)g_t\mathclose{\text{，}}mt​=β1​mt−1​+(1−β1​)gt​，其原始二阶矩是 vt=β2vt−1+(1−β2)gt2。v_t=\beta_2v_{t-1}+(1-\beta_2)g_t^2\mathclose{\text{。}}vt​=β2​vt−1​+(1−β2​)gt2​。下面的平方和除法都是逐坐标进行的。对于 0≤β1,β2<1，0\le\beta_1,\beta_2<1\mathclose{\text{，}}0≤β1​,β2​<1，使用 m^t=mt/(1−β1t)\hat m_t=m_t/(1-\beta_1^t)m^t​=mt​/(1−β1t​) 和 v^t=vt/(1−β2t)\hat v_t=v_t/(1-\beta_2^t)v^t​=vt​/(1−β2t​) 来校正初始为零的问题。更新时减去 ηm^t/(v^t+ε)，\eta\hat m_t/(\sqrt{\hat v_t}+\varepsilon)\mathclose{\text{，}}ηm^t​/(v^t​​+ε)，其中 ε\varepsilonε 是一个正数。分母适应每个坐标中的步长尺度。

将 λ∥w∥2/2\lambda\lVert w\rVert^2/2λ∥w∥2/2 加到损失上，会将其梯度加上 λw。\lambda w\mathclose{\text{。}}λw。解耦权重衰减则是在参数更新时直接减去 ηλw。\eta\lambda w\mathclose{\text{。}}ηλw。在普通梯度下降中，这些操作是一致的。在 Adam 中，将惩罚加到梯度上会改变矩估计及其缩放，而直接衰减本身不进入矩估计，矩估计仍基于数据梯度。

动手计算第一步

在第一步，无论采用何种允许的矩系数，经偏差校正的一阶矩和二阶矩分别为 g1g_1g1​ 和 g12。g_1^2\mathclose{\text{。}}g12​。使用两个坐标来比较更新符号。

Python
from math import sqrt

rate, eps = 0.1, 1e-8
for gradient in (2.0, -6.0):
    first = 0.1 * gradient / (1 - 0.9)
    second = 0.001 * gradient**2 / (1 - 0.999)
    update = -rate * first / (sqrt(second) + eps)
    print(f"{update:.3f}")
输出
-0.100
0.100
