Convert between floats and integer codes

For a simple symmetric quantiser choose a scale s>0s>0s>0 and an integer limit K>0.K>0\mathclose{\text{.}}K>0. Store q=clip⁡(round⁡(x/s),−K,K)q=\operatorname{clip}(\operatorname{round}(x/s),-K,K)q=clip(round(x/s),−K,K) and reconstruct x^=sq.\hat x=sq\mathclose{\text{.}}x^=sq. Specify a tie rule for rounding. For example, Python’s round-to-nearest sends an exact tie to the even integer. With K=127,K=127\mathclose{\text{,}}K=127, the integer codes fit in a signed 8-bit field.

If rounding alone produces a code in the allowed range, the absolute reconstruction error is at most s/2.s/2\mathclose{\text{.}}s/2. If clipping changes the code, the error can exceed that bound. Fixing a narrow representable range improves resolution for small values at a given number of codes and can clip more outliers. Allowing per-group scales can adapt the resolution to groups with different magnitudes. Every scale also needs to be stored or recovered.

Bound the effect on a prediction

Let www be a weight vector, w^\hat ww^ its reconstruction, and xxx an input vector. With no clipping and common scale s,s\mathclose{\text{,}}s, the triangle inequality gives

∣xTw^−xTw∣≤∑i∣xi∣ ∣w^i−wi∣≤s2∥x∥1.\left|x^\mathsf T\hat w-x^\mathsf T w\right| \le\sum_i |x_i|\,|\hat w_i-w_i| \le \frac{s}{2}\lVert x\rVert_1. ​xTw^−xTw​≤i∑​∣xi​∣∣w^i​−wi​∣≤2s​∥x∥1​.

This is an absolute bound in exact arithmetic, for quantised weights and original inputs. Actual implementation may introduce more error during multiplication or accumulation. A very small original dot product can result in large relative error, even with a small absolute error.

Compute itCompare exact rational reference values

For weights (3/10,−11/20,1/5),(3/10,-11/20,1/5)\mathclose{\text{,}}(3/10,−11/20,1/5), inputs (2,−1,4)(2,-1,4)(2,−1,4) and scale 1/4,1/4\mathclose{\text{,}}1/4, compare the quantised dot product with the unquantised dot product.

Python
from fractions import Fraction as F

weights = [F(3, 10), F(-11, 20), F(1, 5)]
inputs = [2, -1, 4]
scale, limit = F(1, 4), 3
codes = [max(-limit, min(limit, round(w / scale))) for w in weights]
reference = sum(x * w for x, w in zip(inputs, weights))
approximation = sum(x * q * scale for x, q in zip(inputs, codes))
print(codes)
print(reference, approximation, abs(reference - approximation))
print(scale * sum(map(abs, inputs)) / 2)
