在新例子上进行测量

在训练模型时，使用训练数据进行拟合，使用验证数据选择模型或设置，使用保留的测试数据进行最终评估。对于存在近似重复项或来自同一来源的许多项目，应按来源进行划分，例如文档或用户。否则，报告的性能可能反映了对相关项目的记忆。如果测试结果用于选择另一个模型，则需要一个独立的留出数据集来进行相同类型的最终比较。

动手计算计算留出集上的平均得分

对四个独立的文档得分，打印均值和估计的标准误。四个观测值展示了计算过程，并提供了关于总体的有限证据。

Python
from math import sqrt
from statistics import mean, stdev

scores = [0.6, 0.8, 1.0, 0.8]
print(f"{mean(scores):.3f}")
print(f"{stdev(scores) / sqrt(len(scores)):.3f}")
