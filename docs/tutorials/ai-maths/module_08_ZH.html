估计预测误差的上界

设 www 为权重向量，w^\hat ww^ 为其重建值，xxx 为输入向量。在没有裁剪且使用公共尺度 sss 的情况下，三角不等式给出

这是在精确算术中的绝对界限，适用于量化权重和原始输入。实际实现过程中乘法或累加可能会引入更多误差。即使绝对误差很小，原始点积非常小时也可能产生较大的相对误差。

动手计算用精确的有理数作为参考值

对于权重 (3/10,−11/20,1/5)、(3/10,-11/20,1/5)\mathclose{\text{、}}(3/10,−11/20,1/5)、输入 (2,−1,4)(2,-1,4)(2,−1,4) 和尺度 1/4，1/4\mathclose{\text{，}}1/4，比较量化后的点积与未量化的点积。

Python
from fractions import Fraction as F

weights = [F(3, 10), F(-11, 20), F(1, 5)]
inputs = [2, -1, 4]
scale, limit = F(1, 4), 3
codes = [max(-limit, min(limit, round(w / scale))) for w in weights]
reference = sum(x * w for x, w in zip(inputs, weights))
approximation = sum(x * q * scale for x, q in zip(inputs, codes))
print(codes)
print(reference, approximation, abs(reference - approximation))
print(scale * sum(map(abs, inputs)) / 2)

7/8

为了评估一组输入上的量化效果，报告尺度规则、绑定规则、参考精度、绝对误差以及下游指标。检查跨运行的保留评估是否一致。在玩具示例中，绝对误差是 1/20，1/20\mathclose{\text{，}}1/20，远低于 7/87/87/8 的界限。真实输入分布可以从一个选定向量中产生非常不同的误差。
