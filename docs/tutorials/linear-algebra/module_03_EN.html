A matrix as a rule for vectors

A linear map preserves addition and scalar multiplication. The two properties combine to give T(au+bv)=aT(u)+bT(v).T(a\mathbf u+b\mathbf v)=aT(\mathbf u)+bT(\mathbf v)\mathclose{\text{.}}T(au+bv)=aT(u)+bT(v). In particular, it sends zero to zero. A matrix with mmm rows and nnn columns sends vectors in Rn\mathbb R^nRn to vectors in Rm.\mathbb R^m\mathclose{\text{.}}Rm. Its columns say where the coordinate vectors go.

Example 3.1Build the matrix of a shear✓ Checked

Let T(x,y)=(x+2y,y).T(x,y)=(x+2y,y)\mathclose{\text{.}}T(x,y)=(x+2y,y). The first coordinate vector goes to (1,0)(1,0)(1,0) and the second to (2,1).(2,1)\mathclose{\text{.}}(2,1). The matrix therefore has columns (1,0)T(1,0)^\mathsf T(1,0)T and (2,1)T.(2,1)^\mathsf T\mathclose{\text{.}}(2,1)T. At (0,3)(0,3)(0,3) its output is (6,3),(6,3)\mathclose{\text{,}}(6,3), three times the second column.

Try it

Apply a matrix to the square and to (1,1)T.(1,1)^\mathsf T\mathclose{\text{.}}(1,1)T. Start with the identity, then try a shear and a matrix with dependent columns. Notice what happens to the square.

Composition and transpose

To apply BBB first and AAA second, form AB.AB\mathclose{\text{.}}AB. Its jjjth column is AAA applied to column jjj of B.B\mathclose{\text{.}}B. The inner dimensions must agree. If AAA is m×nm\times nm×n and BBB is n×p,n\times p\mathclose{\text{,}}n×p, then ABABAB is m×p.m\times p\mathclose{\text{.}}m×p.

The transpose swaps rows with columns. At the entry level, (AB)ij=∑kAikBkj.(AB)_{ij}=\sum_k A_{ik}B_{kj}\mathclose{\text{.}}(AB)ij​=∑k​Aik​Bkj​. Switching iii and jjj gives (AB)T=BTAT.(AB)^\mathsf T=B^\mathsf TA^\mathsf T\mathclose{\text{.}}(AB)T=BTAT. The order reverses.

Example 3.2A scale and a shear✓ Checked

Let S=(2001)S=\begin{pmatrix}2&0\\0&1\end{pmatrix}S=(20​01​) and H=(1101).H=\begin{pmatrix}1&1\\0&1\end{pmatrix}\mathclose{\text{.}}H=(10​11​). On (0,1),(0,1)\mathclose{\text{,}}(0,1), shearing then scaling gives (2,1),(2,1)\mathclose{\text{,}}(2,1), while scaling then shearing gives (1,1).(1,1)\mathclose{\text{.}}(1,1). Both compositions exist and give different maps.

3

Affine maps

A map of the form Ax+bA\mathbf x+\mathbf bAx+b is affine. Its translation term moves every output by the same amount. It is linear exactly when b=0.\mathbf b=\mathbf 0\mathclose{\text{.}}b=0. If coordinates represent points on a map, translating the origin changes positions but keeps every displacement transformed by A.A\mathclose{\text{.}}A.

Compute itCompare the two products
Python
from sympy import Matrix

scale = Matrix([[2, 0], [0, 1]])
shear = Matrix([[1, 1], [0, 1]])
print((scale * shear).tolist())
print((shear * scale).tolist())
Output
[[2, 2], [0, 1]]
[[2, 1], [0, 1]]

Exercise 3.1★Shapes

If AAA is 4×24\times24×2 and BBB is 2×3,2\times3\mathclose{\text{,}}2×3, give the shape of AB.AB\mathclose{\text{.}}AB. Does BABABA exist?

Show solution✓ Checked

ABABAB maps R3\mathbb R^3R3 through R2\mathbb R^2R2 to R4,\mathbb R^4\mathclose{\text{,}}R4, so the shape is 4×3.4\times3\mathclose{\text{.}}4×3. BABABA has inner dimensions 333 and 4,4\mathclose{\text{,}}4, so it is undefined.

Exercise 3.2★★Reflection

Find the matrix for reflection across the line y=x.y=x\mathclose{\text{.}}y=x.

Show solution✓ Checked

The reflection swaps the coordinates, hence swaps the two coordinate vectors. Its matrix is (0110).\begin{pmatrix}0&1\\1&0\end{pmatrix}\mathclose{\text{.}}(01​10​). Applying it twice gives the identity.
