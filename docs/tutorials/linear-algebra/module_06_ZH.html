符号面积和体积

在二维情况下，列 (a,c)T(a,c)^\mathsf T(a,c)T 和 (b,d)T(b,d)^\mathsf T(b,d)T 包围一个平行四边形，其符号面积为 ad−bc。ad-bc\mathclose{\text{。}}ad−bc。其绝对值给出面积。符号记录线性映射是否保持或反转方向。在更高维度中，方阵 行列式 衡量符号体积因子。

交换行会改变其符号，将一行乘以一个因子会将其乘以同样的因子，将一行加上另一行的倍数不会改变它。这些规则也来自于行列式在每一行上是交替的和线性的。一个三角矩阵的行列式等于其对角线元素的乘积。在化简过程中跟踪行交换和缩放。

例 6.1化简时不改变行列式✓ 已检验

对于 A=(2143)，A=\begin{pmatrix}2&1\\4&3\end{pmatrix}\mathclose{\text{，}}A=(24​13​)，用第二行减去第一行的两倍。得到的三角矩阵的对角线元素为 2,1，2,1\mathclose{\text{，}}2,1，因此 det⁡A=2。\det A=2\mathclose{\text{。}}detA=2。该映射将普通面积加倍并保持方向不变。

哪些映射有逆映射？

对于一个 n×nn\times nn×n 矩阵，以下条件等价：秩 n，n\mathclose{\text{，}}n，零空间为零，每个右侧都有唯一解，以及非零行列式。消元法解释了最后一个联系：在三角形式中出现零对角线主元当且仅当主元个数少于 n。n\mathclose{\text{。}}n。逆 A−1A^{-1}A−1 反转该映射。化简 [A∣I][A\mid I][A∣I] 在逆存在时得到 [I∣A−1]。[I\mid A^{-1}]\mathclose{\text{。}}[I∣A−1]。

对于单一数值系统，使用消元法等求解器而不是计算逆矩阵并乘以 b。\mathbf b\mathclose{\text{。}}b。对于相同 AAA 的重复求解，只需计算一次分解。

对于例子，消元法给出
