Module 5Rank, nullity and the four subspaces

Distinguish reachable outputs from invisible input directions and connect them by rank–nullity.

1

Outputs and invisible directions

For AAA of size m×n,m\times n\mathclose{\text{,}}m×n, the column space (image) is the set of reachable outputs Ax,A\mathbf x\mathclose{\text{,}}Ax, in Rm.\mathbb R^m\mathclose{\text{.}}Rm. The null space (kernel) is the set of inputs sent to zero, in Rn.\mathbb R^n\mathclose{\text{.}}Rn.

The other two spaces come from AT.A^\mathsf T\mathclose{\text{.}}AT. Its column space is the row space of A,A\mathclose{\text{,}}A, in Rn.\mathbb R^n\mathclose{\text{.}}Rn. Its null space is the left null space, in Rm.\mathbb R^m\mathclose{\text{.}}Rm. The names identify where to look. An input is in the null space exactly when its dot product with each row is zero. In the same way, the left null space is perpendicular to all columns.

2

Pivots and the dimension count

Row operations preserve linear relations between columns, since they amount to an invertible operation on the output. Thus the pivot indices identify independent columns in the original matrix. The pivots in reduced form give their count r,r\mathclose{\text{,}}r, the rank. The nonzero rows of reduced form are a basis of the row space. The homogeneous system has n−rn-rn−r free coordinates. Choosing one free coordinate to be one and the rest zero gives one null-space basis vector per free coordinate. Hence rank plus nullity is n.n\mathclose{\text{.}}n.

Example 5.1A map with one output direction✓ Checked

Let A=(123246).A=\begin{pmatrix}1&2&3\\2&4&6\end{pmatrix}\mathclose{\text{.}}A=(12​24​36​). The second row is twice the first, so there is one pivot. The first column (1,2)T(1,2)^\mathsf T(1,2)T spans the image. Choosing the second and third inputs as free variables gives null-space basis (−2,1,0)T,(-2,1,0)^\mathsf T\mathclose{\text{,}}(−2,1,0)T, (−3,0,1)T.(-3,0,1)^\mathsf T\mathclose{\text{.}}(−3,0,1)T. The dimensions add to 1+2=3.1+2=3\mathclose{\text{.}}1+2=3.

3

One solution plus a subspace

If Ap=b,A\mathbf p=\mathbf b\mathclose{\text{,}}Ap=b, then A(p+z)=bA(\mathbf p+\mathbf z)=\mathbf bA(p+z)=b for every z\mathbf zz in the kernel. Conversely, any solution minus p\mathbf pp lies in the kernel. If b\mathbf bb is outside the column space there is no solution. This separates existence, controlled by the image, from uniqueness, controlled by the kernel.

Compute itBases in exact arithmetic
Python
from sympy import Matrix

A = Matrix([[1, 2, 3], [2, 4, 6]])
print(A.rank())
print([list(v) for v in A.nullspace()])
print([list(v) for v in A.T.nullspace()])
Output
1
[[-2, 1, 0], [-3, 0, 1]]
[[-2, 1]]

Exercises

Exercise 5.1★Left null space

For the example matrix, give a nonzero vector in the left null space.

Show solution✓ Checked

Since the second row is twice the first, (−2,1)T(-2,1)^\mathsf T(−2,1)T annihilates both rows in that combination. Equivalently AT(−2,1)T=0.A^\mathsf T(-2,1)^\mathsf T=\mathbf 0\mathclose{\text{.}}AT(−2,1)T=0.

Exercise 5.2★★Is the output possible?

For the same matrix, decide whether (3,6)T(3,6)^\mathsf T(3,6)T and (3,7)T(3,7)^\mathsf T(3,7)T are reachable.

Show solution✓ Checked

The first is three times the first column. Every output has second entry twice its first, so the second target is impossible.

Exercise 5.3★★★Dimension without reducing again

A 5×85\times85×8 matrix has rank 3.3\mathclose{\text{.}}3. Give the dimensions of its four subspaces.

Show solution✓ Checked

The column and row spaces both have dimension 3.3\mathclose{\text{.}}3. Rank–nullity gives kernel dimension 8−3=5.8-3=5\mathclose{\text{.}}8−3=5. Apply the same count to the transpose to get left null dimension 5−3=2.5-3=2\mathclose{\text{.}}5−3=2.
