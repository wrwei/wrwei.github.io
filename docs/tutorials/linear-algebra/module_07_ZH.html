作垂线

要用 cuc\mathbf ucu 逼近 b\mathbf bb（其中 u\mathbf uu 非零），选择线上使得残差垂直于 u\mathbf uu 的点。解 u⋅(b−cu)=0\mathbf u\cdot(\mathbf b-c\mathbf u)=0u⋅(b−cu)=0 得到

c=u⋅bu⋅u.c=\frac{\mathbf u\cdot\mathbf b}{\mathbf u\cdot\mathbf u}. c=u⋅uu⋅b​.

对于直线上的任意其他点，到 b\mathbf bb 的平方距离等于相同垂直残差的平方长度加上沿直线的平方距离。勾股定理使得垂直足成为唯一最近点。

标准正交基与 Gram–Schmidt 正交化

如果一组向量的长度都为一，且两两正交，就称其为标准正交向量组。如果 QQQ 的各列是一组标准正交基，则 QTbQ^\mathsf T\mathbf bQTb 给出投影的系数。实际上， QTQ=IQ^\mathsf TQ=IQTQ=I 和 QT(b−QQTb)=0。Q^\mathsf T(\mathbf b-QQ^\mathsf T\mathbf b)=0\mathclose{\text{。}}QT(b−QQTb)=0。

Gram–Schmidt 正交化将线性无关的各列变为这样一组基。每一步，从下一列中减去其在已有标准正交列上的投影，再将所得残差归一化。由线性无关性，残差长度非零。每一步减掉的向量都在已有向量的张成空间内，所以新向量在每一步张成同样的空间。

简约 QR 分解

对于具有独立列的 m×nm\times nm×n 矩阵 A，A\mathclose{\text{，}}A，该过程得到 A=QR，A=QR\mathclose{\text{，}}A=QR，其中 QQQ 的形状为 m×n，m\times n\mathclose{\text{，}}m×n，而 RRR 是上三角形，形状为 n×n。n\times n\mathclose{\text{。}}n×n。AAA 的第 jjj 列只用到 QQQ 的前 jjj 列。最新方向的系数是余向量的长度。在浮点运算中使用 QR 分解库。它可以使用正交反射来避免当列向量几乎相关时的正交性损失。

动手计算检查两个性质
Python
from sympy import Matrix

A = Matrix([[1, 1], [1, 0], [0, 1]])
Q, R = A.QRdecomposition()
print((Q.T * Q).tolist())
print(Q * R == A)
