封闭性与张成

Rn\mathbb R^nRn 的子空间含有零向量，并且对加法和数乘封闭。等价地，一个非空集合是子空间，当且仅当它对任意两个元素的线性组合封闭。因此直线 y=2xy=2xy=2x 是子空间，而与它平行的直线 y=2x+1y=2x+1y=2x+1 不含零向量，不是子空间。

一组向量的张成空间由这些向量的所有线性组合构成。它是子空间，因为对组合进行加法或数乘会得到同一组向量的另一个组合。特别是，张成是包含该组向量的最小子空间。

独立方向与坐标

一个列表是 线性无关 的，当且仅当零向量只能用该列表中所有系数均为零的组合来表示。如果存在一组不全为零的系数使线性组合为零，就可以把任一系数非零的向量用其余向量表示，因此至少有一个向量是冗余的。

一个 基是一个独立的生成列表。生成性为每个向量提供坐标。独立性使得这些坐标唯一，因为同一个向量的两个不同坐标列表相减会得到一个非零关系式。维数 是一个基中向量的个数。一种证明这个数目固定的途径是：一个包含 kkk 个向量的基将空间与 Rk\mathbb R^kRk 同构，其中超过 kkk 个向量通过消元法会线性相关，少于 kkk 个向量无法生成，因为它们的矩阵主元个数少于 k。k\mathclose{\text{。}}k。
