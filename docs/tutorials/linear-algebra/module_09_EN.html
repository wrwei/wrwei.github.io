Module 9Eigenvalues and diagonalisation

Find invariant directions and use an eigenbasis to understand repeated applications of a map.

85 minYou need Modules 3–6

In this module you will

  • Find eigenvalues from the characteristic equation
  • Find an eigenspace as a null space
  • Decide whether an eigenbasis exists and use it to compute powers
1

Directions that survive the map

An eigenvector of a square matrix AAA is a nonzero vector v\mathbf vv such that Av=λv.A\mathbf v=\lambda\mathbf v\mathclose{\text{.}}Av=λv. Its eigenvalue λ\lambdaλ records what the map does along that direction. A negative value reverses it. A zero eigenvalue is allowed and signals a nonzero kernel.

For a candidate λ,\lambda\mathclose{\text{,}}λ, the condition is (A−λI)v=0.(A-\lambda I)\mathbf v=\mathbf 0\mathclose{\text{.}}(A−λI)v=0. A nonzero solution exists exactly when det⁡(A−λI)=0.\det(A-\lambda I)=0\mathclose{\text{.}}det(A−λI)=0. Find these roots first, then solve a homogeneous system for each root. The entire kernel is the eigenspace and includes zero, although zero is never an eigenvector.

Change to eigenvector coordinates

If AAA has an eigenbasis, put the eigenvectors into the columns of PPP and the eigenvalues in the matching order on the diagonal of D.D\mathclose{\text{.}}D. Then AP=PD,AP=PD\mathclose{\text{,}}AP=PD, so A=PDP−1.A=PDP^{-1}\mathclose{\text{.}}A=PDP−1. Convert to eigenvector coordinates, scale each coordinate independently, then convert back. In a power AkA^kAk the middle factors P−1PP^{-1}PP−1P cancel, leaving PDkP−1.PD^kP^{-1}\mathclose{\text{.}}PDkP−1. A factor with magnitude below one decays as kkk increases. For the example, (0,1)T(0,1)^\mathsf T(0,1)T is the sum of the two selected eigenvectors, so after kkk steps it is (2k−1,1)T.(2^k-1,1)^\mathsf T\mathclose{\text{.}}(2k−1,1)T.

Distinct eigenvalues have independent eigenvectors. In a shortest nontrivial linear relation, applying A−λIA-\lambda IA−λI for one eigenvalue in the relation would remove that vector and leave a shorter nontrivial relation. Thus nnn distinct real eigenvalues suffice for a real eigenbasis. Repetition alone gives no verdict. Some real matrices also have complex eigenpairs and no real eigenbasis.

Compute itA repeated eigenvalue with a missing direction
Python
from sympy import Matrix

A = Matrix([[1, 1], [0, 1]])
for value, multiplicity, basis in A.eigenvects():
    print(value, multiplicity, [list(v) for v in basis])
print((A**4).tolist())
Output
1 2 [[1, 0]]
[[1, 4], [0, 1]]
