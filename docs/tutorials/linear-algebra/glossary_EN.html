Glossary

Look up a term and follow it back to the first lesson that develops it.

1

Vectors, systems and spaces

Term Meaning
Augmented matrix Coefficients of a system with a right-hand side appended as a column. Module 2
Affine map A linear map followed by a translation. Module 3
Basis An independent list that spans the space, giving unique coordinates. Module 4
Column space or image All possible outputs of the matrix. Module 5
Dimension The number of vectors in any basis. Module 4
Dot product The sum of products of corresponding coordinates. Module 1
Free variable A variable whose column lacks a pivot. For a consistent system it may be chosen freely. Module 2
Linear combination A sum of scaled vectors. Module 1
Linear independence Only the all-zero coefficients give a combination equal to the zero vector. Module 4
Linear map A map that preserves linear combinations. Module 3
Norm The length of a vector. The Euclidean norm uses the square root of the sum of squares. Module 1
Null space or kernel The set of inputs a matrix maps to zero. Module 5
Pivot A leading entry used to eliminate a variable in other rows. Module 2
Rank The dimension of the column space, equal to the number of pivots. Module 5
Row space The span of the rows regarded as vectors in the input space. Module 5
Span The set of all linear combinations of the given vectors. Module 4
Subspace A subset containing zero and closed under addition and scalar multiplication. Module 4
Transpose An operation that swaps rows and columns. Module 3
2

Factorisations and approximation

Term Meaning
Determinant The signed volume scaling factor of a square matrix. Zero corresponds to collapse of dimension. Module 6
Gram–Schmidt A process for building an orthonormal basis by subtracting projections and normalising. Module 7
Inverse A square matrix that reverses a given invertible map. Module 6
LU factorisation A product of lower and upper triangular factors, with a permutation when needed. Module 6
Least squares Fitting by minimising the sum of squared residual entries. Module 8
Orthogonal Two vectors have zero dot product. Module 1
Orthonormal A list of unit vectors that are pairwise orthogonal. Module 7
Projection The point of a subspace closest to a given vector. Module 7
QR factorisation A product with orthonormal columns in the first factor and upper triangular structure in the second. Module 7
Residual The observation vector minus the fitted vector. Module 8
3

Spectra and data

Term Meaning
Condition number The ratio of the largest to smallest stretch for a matrix of full column rank, in Euclidean norm. Module 11
Diagonalisation Expressing a matrix as a diagonal action in an eigenbasis. Module 9
Eigenvector and eigenvalue A nonzero direction preserved up to scaling and the scalar by which it is multiplied. Module 9
Eigenspace The complete null space of A−λIA-\lambda IA−λI for an eigenvalue λ.\lambda\mathclose{\text{.}}λ. Module 9
Frobenius norm The square root of the sum of squares of all matrix entries. Module 12
Principal component A direction of greatest remaining sample variance, orthogonal to the earlier chosen directions. Module 12
Pseudoinverse A map giving the minimum-norm least-squares solution for each right-hand side. Module 11
Quadratic form A scalar function of the form xTAx.\mathbf x^\mathsf TA\mathbf x\mathclose{\text{.}}xTAx. Module 10
Singular value A nonnegative stretch factor in a singular value decomposition. Module 11
Spectral theorem Every real symmetric matrix admits an orthonormal eigenbasis. Module 10
