A rectangular map has two coordinate systems

A rectangular matrix sends inputs and outputs between different spaces. To find input directions that stretch independently, look at ATA.A^\mathsf TA\mathclose{\text{.}}ATA. It is symmetric and positive semidefinite because xTATAx=∥Ax∥2.\mathbf x^\mathsf TA^\mathsf TA\mathbf x=\|A\mathbf x\|^2\mathclose{\text{.}}xTATAx=∥Ax∥2. Its orthonormal eigenvectors vi\mathbf v_ivi​ have nonnegative eigenvalues σi2.\sigma_i^2\mathclose{\text{.}}σi2​. Arrange the square roots σi\sigma_iσi​ from largest to smallest. They are the singular values.

For each σi>0,\sigma_i>0\mathclose{\text{,}}σi​>0, take ui=Avi/σi.\mathbf u_i=A\mathbf v_i/\sigma_i\mathclose{\text{.}}ui​=Avi​/σi​. These output directions have unit length and are mutually orthogonal, since (Avi)⋅(Avj)=σj2vi⋅vj.(A\mathbf v_i)\cdot(A\mathbf v_j)=\sigma_j^2\mathbf v_i\cdot\mathbf v_j\mathclose{\text{.}}(Avi​)⋅(Avj​)=σj2​vi​⋅vj​. Input directions with zero eigenvalue satisfy Avi=0.A\mathbf v_i=\mathbf0\mathclose{\text{.}}Avi​=0. Complete the output basis orthonormally to obtain the singular value decomposition A=UΣVT,A=U\Sigma V^\mathsf T\mathclose{\text{,}}A=UΣVT, with a rectangular diagonal matrix Σ.\Sigma\mathclose{\text{.}}Σ. Keeping only the rrr positive directions gives the compact form A=∑i=1rσiuiviT.A=\sum_{i=1}^r \sigma_i\mathbf u_i\mathbf v_i^\mathsf T\mathclose{\text{.}}A=∑i=1r​σi​ui​viT​.

The effect of small singular values

For a full-column-rank matrix, σmax⁡\sigma_{\max}σmax​ is the greatest output norm for a unit input and σmin⁡\sigma_{\min}σmin​ the smallest. In spectral coordinates the squared output norm is a weighted sum ∑iσi2zi2\sum_i\sigma_i^2 z_i^2∑i​σi2​zi2​ with ∑izi2=1.\sum_i z_i^2=1\mathclose{\text{.}}∑i​zi2​=1. The condition number in Euclidean norm is σmax⁡/σmin⁡.\sigma_{\max}/\sigma_{\min}\mathclose{\text{.}}σmax​/σmin​. The Gram matrix has condition number equal to its square. This explains why forming the normal equations can make a numerical solve more sensitive to rounding.

3

Solve in singular coordinates

The pseudoinverse A+=∑σi>0σi−1viuiTA^+=\sum_{\sigma_i>0}\sigma_i^{-1}\mathbf v_i\mathbf u_i^\mathsf TA+=∑σi​>0​σi−1​vi​uiT​ first reads the part of b\mathbf bb along the reachable output directions, then undoes each nonzero stretch. This produces a least-squares fit. Other coefficient vectors producing that fit add a vector in the kernel. Since the pseudoinverse gives a coefficient vector orthogonal to the kernel, adding a nonzero kernel vector increases its length. Thus A+bA^+\mathbf bA+b is the unique least-squares solution of minimum norm.

In a numerical fit a very small singular value amplifies noise. Truncating that direction changes the problem by discarding an unstable component. Choose a threshold according to scale and noise, and report it when interpreting the fit.

Compute itCompare exact and minimum-norm fits
Python
from sympy import Matrix

A = Matrix([[3, 0, 0], [0, 2, 0]])
b = Matrix([6, 8])
print(list(A.pinv() * b))
print((A * A.pinv() * b).tolist())
Output
[2, 4, 0]
[[6], [8]]

Check yourself

1
Which matrix gives the right singular directions?
Right singular directions lie in the input space, and their squared stretches are eigenvalues of ATA.A^\mathsf TA\mathclose{\text{.}}ATA.
2
Which parts of the SVD are inverted by the pseudoinverse?
Null-space directions stay zero, so the computed coefficients have minimum norm.
3
What can a very small positive singular value do in a solve?
The solve multiplies that coordinate by the reciprocal of the singular value.
