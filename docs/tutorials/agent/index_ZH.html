构建 AI 智能体

十五个模块从智能体的基本概念讲起，循序练习模型 API、工具调用、记忆、RAG 和 MCP，再学习多智能体协作，以及系统的安全、测试、评估和部署。

课程目录

  1. 模块 01

    什么是 AI 智能体？

    比较智能体和聊天机器人，认识模型、工具、状态等基本组成。
  2. 模块 02

    环境搭建与 API 配置

    准备 Python 环境、安装 SDK、配置 API 密钥并测试连接。
  3. 模块 03

    提示工程

    练习编写系统指令和示例，使用提示模板并检查输出。
  4. 模块 04

    第一次 API 调用

    发送聊天消息，理解消息角色、温度和 token 用量。
  5. 模块 05

    构建智能体循环

    理解观察、决策和行动如何组成多步任务的执行过程。
  6. 模块 06

    工具调用与函数调用

    定义工具接口，理解模型请求与工具返回结果之间的交互。
  7. 模块 07

    记忆与上下文管理

    区分短期上下文和长期记忆，管理上下文窗口和持久化状态。
  8. 模块 08

    RAG（检索增强生成）

    用文档分块、向量表示和检索为模型提供相关上下文。
  9. 模块 09

    MCP 服务器

    了解 MCP 如何向智能体提供工具、资源和提示模板。
  10. 模块 10

    LangChain 与 CrewAI

    比较通用智能体框架与按角色组织的协作框架。
  11. 模块 11

    多智能体编排

    了解任务委派、监督协调和智能体之间的协作模式。
  12. 模块 12

    A2A 协议

    认识 Agent-to-Agent 协议如何描述智能体之间的通信与任务。
  13. 模块 13

    安全与护栏

    识别提示注入风险，用权限边界、输出校验和人工审批降低风险。
  14. 模块 14

    测试与评估

    编写单元测试，设计评估用例和指标，衡量智能体的表现。
  15. 模块 15

    部署与最佳实践

    了解上线后的监控、运行安全和成本管理。
