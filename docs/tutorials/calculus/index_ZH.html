微积分

从函数与极限学到向量微积分。掌握导数、积分、微分方程和级数的用法，并理解这些方法为什么成立。

20 个模块约 88 小时所有结果均经 SymPy 检验EN · 中文
从模块 1 开始 →

适合哪些读者

你还记得中学代数，包括分数、幂、方程和直线的图像。也许你从未学过微积分，也许你以前学过，现在希望重新理解它。无论是在校学习，还是在计算、工程或科学工作中遇到导数、积分和梯度，这套教程都从这些基础知识讲起。如果你想复习代数，可以先读《面向计算机科学与人工智能的数学基础》中的代数复习。

学习目标

  • 借助图像和精确定义解释极限、导数和积分，读懂说明三者联系的证明。
  • 熟练求导和积分，用导数刻画变化率、求最大值与最小值，并近似函数。
  • 为面积、体积、长度、功和概率建立并计算积分，求解描述增长、冷却与运动的微分方程。
  • 判断级数是否收敛，并用泰勒级数表示函数。
  • 处理多元函数，学习偏导数、梯度、约束优化、多重积分和向量微积分的主要定理。

怎样使用教程

从模块 1 开始，按顺序学习五个部分。每个新概念先用图像或例题引入，然后给出精确定义。正文证明许多定理，部分较难的论证放在可选的「深入一步」栏目。每个模块都包含自测和三个难度等级的练习，附有完整解答。大部分模块还提供交互演示。

准备材料。 准备纸、笔和一台设为弧度模式的科学计算器。「已检验」标记表示例题中的计算结果已用 SymPy 验证。Python 是可选的。「动手计算」栏展示怎样用代码探索数学，其中的输出来自实际运行。

第一部分 · 函数、极限与连续

模块 14 h
函数与变化
先了解微积分研究什么，再认识它的基本对象——函数，以及几类常用函数。你将计算越来越短的时间段内的平均速度，为学习导数做准备，也可以配置 Python 来检验计算。
✓
模块 24 h
极限
理解函数趋近某个值的含义，学会从表格、图像和代数式求极限。你将证明三角函数求导所需的基本极限，用严格的 ε–δ 定义写证明，并了解计算机何时会给出错误的极限。
✓
模块 34.5 h
连续性与无穷远
理解连续性的含义，学习何时能保证方程有解，以及连续函数何时达到最大值和最小值。你将用二分法把方程的解逼近到所需精度，再通过渐近线和无穷远处的极限，理解大 O 记号背后的增长阶。
✓

第二部分 · 导数

模块 44.3 h
导数
从模块 1 的平均变化率过渡到瞬时变化率。你将用极限定义导数，理解导数与切线斜率、速度的关系，再证明基本求导法则。用 SymPy 作精确计算，并比较数值求导在小步长下受到的浮点误差。
✓
模块 54.3 h
求导法则
用法则求积、商、三角函数和复合函数的导数，并理解每条法则为什么成立。手算后用图像和 SymPy 复核。你还将看到程序如何用双数对另一个程序求导。
✓
模块 64.5 h
指数、对数与隐函数求导
了解常数 e 的由来，以及为什么 e 的 x 次方的导数等于它自身。接着对对数函数、反函数、反三角函数、双曲函数和方程定义的曲线求导，并验证指数增长与衰减公式。
✓
模块 74.3 h
变化率、近似与洛必达法则
用导数关联两个量的变化率、用切线近似函数，并估计测量误差如何传到结果中。你还将用牛顿法求方程的根，并用洛必达法则处理极限法则无法直接求出的极限。
✓
模块 84.5 h
函数图像与优化
用导数找最大值和最小值，判断图像的升降与凹凸，并解决几何、物理和经济学中的优化问题。你将证明微分中值定理及据此得到的判别法，根据导数描绘图像，并像训练机器学习模型一样用梯度下降法极小化函数。
✓

第三部分 · 积分

模块 94.5 h
面积与定积分
把细长矩形的面积相加，再取极限，就能精确求面积和路程。你将手算黎曼和并用计算机检验，通过黎曼和的极限定义定积分，再利用积分的性质、几何和对称性计算或估计其值。
✓
模块 104.3 h
微积分基本定理
把微分和积分联系起来。你将从导数还原函数，观察曲线下的面积怎样随右端点移动而变化，并证明其变化率等于曲线在端点处的高度。用原函数计算定积分，用换元法逆用链式法则，再用 SymPy 验证。
✓
模块 114.5 h
积分方法
学习为不同的被积函数选择积分方法。用分部积分、三角恒等式、三角换元和部分分式处理乘积、三角函数的幂、二次式的平方根及有理函数。你还将验证计算机的结果，识别没有初等原函数的被积函数，并在满足可微条件时给出数值积分的误差上界。
✓
模块 124.5 h
积分的应用与反常积分
用同一套方法求曲线间的面积、体积、弧长、变力做的功和质心。先切成小片，再近似、求和、取极限。接着把积分推广到无穷区间和被积函数无界的情形，并用积分计算概率。
✓
模块 134.5 h
微分方程
为增长、冷却、下落与混合现象建立微分方程，先从图像了解解的趋势，再用欧拉法逐步近似。你将求出可分离变量方程、线性方程和弹簧振动等问题的精确解，并通过代入原方程检验答案。
✓

第四部分 · 数列与级数

模块 144.5 h
数列与级数
判断无穷数列是否趋于极限，并理解无穷多个数相加的含义。你将求等比级数与裂项相消级数的和，解释调和级数的项趋于零却仍然发散的原因，运用判别法判断收敛性，并在估计级数和时给出误差上界。
✓
模块 154.5 h
幂级数与泰勒级数
用无限项的多项式来表示函数。你将求幂级数的收敛范围，构造常用函数的幂级数，并用泰勒定理控制近似误差。用级数计算 e、π 和 ln 2，求极限，简化物理公式，并理解计算机如何计算正弦。最后，把指数函数、正弦和余弦的级数组合起来，得到欧拉公式。
✓

第五部分 · 多元微积分

模块 164.5 h
曲线与向量
用动点和极坐标描述曲线，求斜率、弧长和面积。接着用平面与空间中的向量描述直线、平面以及沿曲线的运动，为多元微积分打下基础。
✓
模块 174.5 h
偏导数与梯度
把导数推广到多元函数。你将读懂曲面与等值线图，计算偏导数、切平面与线性近似，并借助树状图应用链式法则。最后，用梯度找出最陡上升方向，并理解梯度下降和反向传播在机器学习中的作用。
✓
模块 184.5 h
多元函数的优化
求二元和多元函数的极值。你将用海森矩阵判别临界点，在有界闭区域上寻找全局最值，用拉格朗日乘数法处理约束，并用最小二乘法拟合直线。你还会看到各方向的曲率相差较大时，梯度下降为何呈锯齿状前进。
✓
模块 194.5 h
重积分
通过积分累加平面或空间区域内的量，求曲面下方的体积、薄板的质量、立体的质心和随机点落入区域的概率。你将用黎曼和的极限定义二重、三重积分，再逐个变量计算，选用极坐标、柱坐标、球坐标或自定义坐标简化计算，并证明模块 12 引用的高斯积分。
✓
模块 204.5 h
向量微积分
用向量场描述风、水流、重力和电场，计算沿曲线和穿过曲面的积分，再用旋度和散度衡量流动的旋转与发散。格林定理、斯托克斯定理与散度定理把微积分基本定理的思想推广到了曲线、曲面和立体。
✓
