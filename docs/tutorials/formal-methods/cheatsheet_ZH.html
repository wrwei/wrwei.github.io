速查表

把整个系列浓缩在一页上：符号怎样输入、怎样读，命令、证明方法、自然演绎规则、Isar、归纳和编辑器，每一项都链接到讲解它的章节。

遇到看不懂的消息？请看问题排查。遇到不认识的术语？请看术语表。每张表最后一列的数字是各模块的章节号：7.2.2 指模块 7 的第 7.2.2 节。本页的 Isabelle 文本都摘自各模块，在那里经过了 Isabelle 的检查。Isabelle 的界面和消息只有英文，下文在英文标签后面给出中文解释。

理论

你写的所有内容都放在一个理论（theory）中。理论 First 存放在文件 First.thy 中（1.7.1）：

theory First
  imports Main
begin

end

需要 Main 之外的库理论时，在 imports 后面写出它的名字（12.2.1）：

theory Verify
  imports Main "HOL-Library.Multiset"
begin

end
  • 命令写在 begin 和 end 之间，Isabelle 在你输入的同时就检查它们。
  • 项和类型写在引号之间（内层语法）；value、lemma 这样的命令写在引号外面（外层语法）（1.7.2）。
  • 字符串写在两对单引号之间：''alice''（4.2.4）。
  • 本系列的所有理论都在 formal-methods-theories.zip 中。

自然演绎规则

模块 6 的规则以及它们在 Isabelle 中的名字，陈述按 thm 显示的样子给出（7.2.2）。问号标出的是图式变量。

规则 用话说 Isabelle 陈述
(∧I) 要证明 A ∧ B，就证明 A 并证明 B conjI ⟦?P; ?Q⟧ ⟹ ?P ∧ ?Q
(∧E₁) 由 A ∧ B 得出 A conjunct1 ?P ∧ ?Q ⟹ ?P
(∧E₂) 由 A ∧ B 得出 B conjunct2 ?P ∧ ?Q ⟹ ?Q
(∧E₁) 和 (∧E₂) 合在一起 同时使用 A ∧ B 的两个部分 conjE ⟦?P ∧ ?Q; ⟦?P; ?Q⟧ ⟹ ?R⟧ ⟹ ?R
(∨I₁) 要证明 A ∨ B，就证明 A disjI1 ?P ⟹ ?P ∨ ?Q
(∨I₂) 要证明 A ∨ B，就证明 B disjI2 ?Q ⟹ ?P ∨ ?Q
(∨E) 分别由 A 和由 B 证明目标 disjE ⟦?P ∨ ?Q; ?P ⟹ ?R; ?Q ⟹ ?R⟧ ⟹ ?R
(⟶I) 假设 A，证明 B impI (?P ⟹ ?Q) ⟹ ?P ⟶ ?Q
(⟶E) 肯定前件式：由 A ⟶ B 和 A 得出 B mp ⟦?P ⟶ ?Q; ?P⟧ ⟹ ?Q
(⟶E) 的消去形式 同上，用于假设 A ⟶ B impE ⟦?P ⟶ ?Q; ?P; ?Q ⟹ ?R⟧ ⟹ ?R
(¬I) 假设 A，证明 ⊥ notI (?P ⟹ False) ⟹ ¬ ?P
(¬E) 由 ¬A 和 A 得出 ⊥（进而得出任何公式） notE ⟦¬ ?P; ?P⟧ ⟹ ?R
(⊥E) 由 ⊥ 得出任何公式 FalseE False ⟹ ?P
(∀I) 对一个新的 a 证明 P a allI (⋀x. ?P x) ⟹ ∀x. ?P x
(∀E) 由 ∀x. P x 得出任意 t 的 P t spec ∀x. ?P x ⟹ ?P ?x
(∀E) 的消去形式 同上，用于假设 ∀x. P x allE ⟦∀x. ?P x; ?P ?x ⟹ ?R⟧ ⟹ ?R
(∃I) 由 P t 得出 ∃x. P x exI ?P ?x ⟹ ∃x. ?P x
(∃E) 给见证取名为 a，假设 P a，证明目标 exE ⟦∃x. ?P x; ⋀x. ?P x ⟹ ?Q⟧ ⟹ ?Q
(RAA) 假设 ¬A，证明 ⊥ ccontr (¬ ?P ⟹ False) ⟹ ?P
(RAA) 的变体 假设 ¬A，证明 A classical (¬ ?P ⟹ ?P) ⟹ ?P
(=I) 自反性：t = t refl ?t = ?t
(=E) 代入：用相等的东西替换相等的东西 subst ⟦?s = ?t; ?P ?s⟧ ⟹ ?P ?t
(=E)，从右往左 同上，等式反过来用 ssubst ⟦?t = ?s; ?P ?s⟧ ⟹ ?P ?t
无 由两个方向的蕴涵证明 A ⟷ B iffI ⟦?P ⟹ ?Q; ?Q ⟹ ?P⟧ ⟹ ?P = ?Q
无 按一个方向使用 A ⟷ B iffD1、iffD2 ⟦?Q = ?P; ?Q⟧ ⟹ ?P、⟦?P = ?Q; ?Q⟧ ⟹ ?P

同样的规则作为 apply 脚本的步骤和 Isar 证明的步骤（10.7.2）。ab、imp、a、b、na、all、pa 和 ex 分别是事实 A ∧ B、A ⟶ B、A、B、¬ A、∀x. P x、P a 和 ∃x. P x 的名字。

规则 apply 步骤 Isar
(⟶I) rule impI assume "A" … show "B"
(⟶E) erule impE from imp a have "B" by (rule mp)
(∧I) rule conjI from a b have "A ∧ B" by (rule conjI)
(∧E₁)、(∧E₂) erule conjE from ab have "A" by (rule conjunct1)
(∨I₁) rule disjI1 from a have "A ∨ B" by (rule disjI1)
(∨E) erule disjE from ‹A ∨ B› show "C" proof … next … qed
(¬I) rule notI assume "A" … show False
(¬E) erule notE from na a show False by (rule notE)
(∀I) rule allI fix x … show "P x"
(∀E) erule allE from all have "P a" by (rule spec)
(∃I) rule exI from pa have "∃x. P x" by (rule exI)
(∃E) erule exE from ex obtain a where "P a" by blast
(RAA) rule ccontr proof (rule ccontr) assume "¬ A" … show False

Isar

下面是模块 10 中的两个证明：一个是正向书写的自然演绎证明，另一个是归纳证明，它的归纳步骤是一串计算推理。

lemma "A ∧ B ⟶ B ∧ A"
proof (rule impI)
  assume ab: "A ∧ B"
  have b: "B" using ab by blast
  have a: "A" using ab by blast
  show "B ∧ A" using b a by blast
qed

lemma "mysum (xs @ ys) = mysum xs + mysum ys"
proof (induction xs)
  case Nil
  show ?case by simp
next
  case (Cons x xs)
  have "mysum ((x # xs) @ ys) = x + mysum (xs @ ys)" by simp
  also have "… = x + (mysum xs + mysum ys)" using Cons.IH by simp
  also have "… = mysum (x # xs) + mysum ys" by simp
  finally show ?case .
qed

目标涉及 方法 在 Isabelle 中 章节

  • 先试 by (induction xs) auto，并对函数拆开的那个参数做归纳（5.4.3、5.5.1）。
  • 在证明状态中，把 ⋀n. 读作“对任意的 n”；归纳假设位于 ⟹ 的左边（5.4.2）。
  • 规则归纳作用于第一个前提，而这个前提的参数必须是变量（11.7.1、11.7.2）。
