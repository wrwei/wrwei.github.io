术语表

本系列定义的每一个术语，按汉语拼音排序，附简短的释义、英文原文以及讲解它的章节。

A

术语 释义 出处
α 等价的
α-equivalent		 只在约束变元的名字上不同的公式是 α 等价的，例如 ∃y. R x y 和 ∃z. R x z；它们的含义相同。 3.5.2
安全规则
safe rule		 如果一条规则（或证明搜索中的一步）永远不会把可证的目标变成不可证的子目标（例如 conjI 和 impI），它就是安全的；不安全的规则（例如 disjI1 和 allE）则可能会。 6.7, 9.4
安全性质
safety property		 说明坏事永远不会发生的性质：它必须在每个可达状态中成立。 4.5.2, 13.3
apply 脚本
apply script		 由一串 apply 步骤组成、以 done 结束的证明。 5.4.2

B

术语 释义 出处
半可判定的
semi-decidable		 存在一个算法，对答案为“是”的每个输入都回答“是”，但对其他输入可能永远运行下去。谓词逻辑中的有效性是半可判定的。 3.9
保持语义的
semantics-preserving		 如果优化后的程序在每个状态下都与原程序含义相同，这个优化就是保持语义的，也就是正确的。 14.6.1
爆炸原理
principle of explosion		 由不一致的前提或由 ⊥ 可以推出任何东西；拉丁语为 ex falso quodlibet。 2.6
本征变元
eigenvariable		 规则 (∀I) 和 (∃E) 中的名字 a。它必须是新的：这就是本征变元条件。 6.6
β 归约
β-reduction		 把 λx. t 作用于参数 a 的那一步：结果是把 t 中的 x 换成 a。 8.2.1
闭包
closure		 包含 R 并具有某种性质（自反、对称或传递）的最小关系。 4.5.1
编译器
compiler		 把一种语言的程序翻译成另一种语言的程序，这里是把算术表达式翻译成栈机代码。 14.4
编译器正确性
compiler correctness		 运行编译出的代码与源程序的含义一致：这里是 exec (compile e) s stk = eval e s # stk。 14.4.2
变式
variant		 循环的度量：每一步都会减小的量，它表明循环会停止。 5.8.1
变元捕获
variable capture		 代入的项中的变元被某个量词约束，从而改变了含义；先给约束变元改名就能避免。 3.5.2
标准规则
standard rule		 不带方法的 proof 所应用的规则，按目标的主联结词选定，或者是针对传给它的事实的消去规则。 10.2.6
并集
union		 A ∪ B，属于 A 或属于 B 的元素。 4.1.2
补集
complement		 −A，该类型中不属于 A 的元素。Isabelle 中写作 - A。 4.1.2
不变式
invariant		 始终保持成立的性质。在模块 5 中指初始时成立、并被每一步保持的性质；在模块 13 中指在每个可达状态中都成立的性质；对数据结构来说，指由其操作构造出的每个值都具有的性质。 5.8, 12.5.3, 13.3
不可比较的
incomparable		 如果偏序中两个元素谁也不在谁的下面，它们就是不可比较的，例如在 ⊆ 下的 {1} 和 {2}。 4.4.1
不可满足的
unsatisfiable		 在任何赋值下（或在任何结构中）都不为真。 2.4, 3.4
不可判定的
undecidable		 没有算法能对每个输入都正确回答这个问题。谓词逻辑中的有效性是不可判定的（丘奇和图灵，1936）。 3.9
不可数的
uncountable		 不是可数的，例如由康托尔的对角线论证可知，自然数的所有子集组成的集合不可数。 4.7.4
不完备性定理
incompleteness theorems		 哥德尔的定理（1931）：任何一个公理可由程序检查、并且只证明真陈述的证明系统，都不能证明关于自然数的全部真理。 3.9
不相交的
disjoint		 没有公共元素的两个集合是不相交的：A ∩ B = ∅。 4.1.2
部分函数
partial function		 每个输入至多有一个输出的关系，例如可能陷入死循环的程序所计算的函数。HOL 把它建模为结果为 option 的全函数。 4.6.1
部分应用
partial application		 把柯里化的函数作用于少于它可接受个数的参数。结果是一个函数，例如 (+) 3。 8.2.2
部分正确性
partial correctness		 程序返回的每个结果都与逻辑一致的保证，但不保证它一定会返回。 8.8, 12.7.1

术语 释义 出处
case 表达式
case expression		 通过与模式匹配来拆开一个值的项，每个模式一个分支，例如对一个选项值进行 case，分别处理 None 和 Some x。 8.3.4
差集
difference		 A − B，属于 A 但不属于 B 的元素。 4.1.2
常量
constant		 指称单个对象的符号，例如 alice 或 0。在 Isabelle 中，指已定义或已声明的名字，与变元相对。 3.2
常量折叠
constant folding		 一种优化：把程序中值不依赖于状态的部分替换为它们的值，并去掉不起作用的运算。 14.6.1
冲突驱动子句学习（CDCL）
CDCL (conflict-driven clause learning)		 发生冲突后，SAT 求解器添加一个子句，排除导致冲突的那组决策，使搜索不会两次犯同样的错误。 2.8
重叠的等式
overlapping equations		 模式可以匹配同一个参数的 fun 等式。fun 使用第一个匹配的等式。 8.4.3
重写
rewriting		 反复把项中与等式左边匹配的部分替换为右边。 5.1.3, 9.2.1
重写规则
rewrite rule		 只从左往右使用的等式 l = r。 5.1.3, 9.2.1
重言式
tautology		 在每个赋值下都为真的公式；也称为有效的。 2.4
重载
overloading		 一个名字根据类型有多种含义，例如 nat 和 int 上的 +。Isabelle 用类型类来组织重载。 8.6.2
抽象函数
abstraction function		 把每个具体的值或状态映射为它所表示的抽象值或状态的函数，例如把搜索树映射为集合的 set_of。 12.5.1, 13.7.1
抽象语法
abstract syntax		 把程序看作一棵树的结构：每个结点是一个运算，它的子结点是操作数。在 Isabelle 中，抽象语法是一个数据类型。 14.2.1
初始方法
initial method		 proof 后面的方法，它把目标变成证明块中的待证目标。 10.2.1
初始状态
initial state		 状态机可以从它开始运行的状态。 13.1
传递闭包
transitive closure		 R⁺，由一步或多步 R 连接起来的有序对。Isabelle 中写作 r⇧+。 4.5.1
传递的
transitive		 如果由 (x, y) ∈ R 和 (y, z) ∈ R 可以推出 (x, z) ∈ R，关系 R 就是传递的。 4.2.3
传值调用
call by value		 一种求值顺序：先对调用的参数求值，再执行调用本身。 5.1.3
纯函数
pure function		 结果只依赖于参数的函数。HOL 中的每个函数都是纯函数。 6.8
词汇表
vocabulary		 一种语言的非逻辑符号及其元数：常量、函数符号和谓词符号；也叫签名。 3.2
存在量词
existential quantifier		 ∃：∃x. φ 表示至少有一个 x 使 φ 成立。 3.2.3

D

术语 释义 出处
大小
size		 fun 首先尝试的度量：对自然数是这个数本身，对列表是它的长度，对其他数据类型的值是其中带参数的构造子的个数。 8.7.2
代码生成
code generation		 用 export_code 把 HOL 中的定义翻译成 Standard ML、OCaml、Haskell 或 Scala。value 也使用同一套机制。 8.8
代入
substitution		 φ[t/x]，把 φ 中每个自由的 x 换成项 t；也指规则 (=E)，即用相等的东西替换相等的东西。 3.5.2, 6.8
待证目标
pending goal		 Isar 证明块中在 qed 之前仍需由 show 解决的目标。 10.2.1
单调的
monotone		 归纳定义的规则必须是单调的：关于被定义谓词成立的事实越多，规则能推出的结论不能越少。否定形式的前提会破坏这一点。 11.6.4
单射的
injective		 不同的输入给出不同的输出：由 f x = f y 可以推出 x = y。Isabelle 中写作 inj f。 4.6.2
单元传播
unit propagation		 DPLL 算法中的一步：如果一个子句中除一个文字外都为假，剩下的那个文字必须为真，于是给它赋值。 2.8
德摩根律
De Morgan’s laws		 ¬(A ∧ B) ≡ ¬A ∨ ¬B 以及 ¬(A ∨ B) ≡ ¬A ∧ ¬B。 2.5
等价关系
equivalence relation		 自反、对称且传递的关系。它的等价类构成一个划分。 4.3
等价类
equivalence class		 在一个等价关系下与 x 相关的元素组成的集合，记作 [x]。 4.3
等可满足的
equisatisfiable		 如果一个公式可满足当且仅当另一个公式可满足，这两个公式就是等可满足的。 2.7.2
笛卡儿积
Cartesian product		 A × B，所有满足 a ∈ A 且 b ∈ B 的有序对 (a, b) 组成的集合。 4.2.1
递归定义
recursive definition		 用等式定义函数，函数本身也可以出现在等式右边，但只作用于更小的参数。 5.1.2
递归情形
recursive case		 递归定义中对较小参数调用函数本身的情形。 5.1.2
递归数据类型
recursive datatype		 在定义中引用自身的数据类型，例如列表、栈和树。 8.3.2
定理
theorem		 不需要任何假设就能推导出的公式。在 Isabelle 中指已证明的陈述，只有内核能创建它。 6.2
定义域
domain (of a function)		 对函数 f : A → B 来说，集合 A。 4.6.1
DPLL 算法
DPLL procedure		 SAT 求解器所依据的搜索方法：单元传播、决策，以及发生冲突后回到最近的决策。 2.8
度量
measure		 从递归函数的参数到自然数的函数，在每次递归调用时都严格变小。它证明了递归会终止。 5.7.2, 8.7.2
队列
queue		 排队的队伍：元素从队尾加入、从队首离开，先加入的先离开。 12.6.2
对称的
symmetric		 如果由 (x, y) ∈ R 可以推出 (y, x) ∈ R，关系 R 就是对称的。 4.2.3
对角线论证
diagonal argument		 康托尔证明“没有函数 f 能把一个集合映射到其幂集上”的方法：由所有不属于 f x 的元素 x 组成的集合不是 f 的值。 4.7.4
对偶
dual		 把 ∪ 和 ∩（以及 ∅ 和 UNIV）互换得到的定律。集合定律的对偶也成立。 4.1.3
对象逻辑
object logic		 书写公式所用的逻辑；在 Isabelle/HOL 中是 HOL，含 ¬ ∧ ∨ ⟶ ∀ ∃ 和 =。 7.1.1
多重集
multiset		 不计顺序、但计每个元素出现次数的汇集；也叫袋。mset xs 是列表元素组成的多重集。 12.2.2
多类别逻辑
many-sorted logic		 类型化的逻辑：符号的每个参数和结果都有一个类别，每个变元只在一个类别的论域中取值。 3.8
多态的
polymorphic		 类型中含有类型变元的函数（例如 rev :: 'a list ⇒ 'a list）对该类型的每个实例都适用。 8.1.1

术语 释义 出处
二叉树
binary tree		 要么为空，要么是一个结点，带有一个元素和两棵更小的树，即左子树和右子树。 5.2.2
二叉搜索树
binary search tree		 一种存放键的二叉树：每个结点左子树中的键都比该结点的键小，右子树中的键都比它大；它的操作必须保持这个不变式。 12.5

F

术语 释义 出处
发明者悖论
inventor’s paradox		 波利亚的观察：更有雄心的断言可能更容易证明。在归纳中，更强的结论带来更强的归纳假设。 11.2.3
反对称的
antisymmetric		 如果由 (x, y) ∈ R 和 (y, x) ∈ R 可以推出 x = y，关系 R 就是反对称的。 4.2.3
反例
counterexample		 使断言为假的东西：一个赋值、一组自由变元的值，或者一条到达坏状态的运行。 2.4, 13.3
反例轨迹
counterexample trace		 从初始状态到违反某个性质的状态的一条运行，写成事件列表。 4.5.2, 13.6
反模型
countermodel		 使一个公式为假的结构（连同对自由变元的赋值）。一个反模型就足以否定有效性。 3.4
反向搜索
backward search		 从目标出发寻找证明：选一条结论与目标相符的规则，它的前提就成为新的子目标。Isabelle 就是这样工作的。 6.7
反证法
proof by contradiction		 要证明 A，先假设 ¬A 并推出矛盾：即规则 (RAA)，在 Isabelle 中是 ccontr。 6.1, 6.5
反自反的
irreflexive		 如果 A 中没有元素与自身相关，关系在 A 上就是反自反的。 4.2.3
范式
normal form		 （1）公式的一种标准形状：否定范式、合取范式或析取范式。（2）在重写中，指不能再被任何规则重写的项。 2.7, 9.2.1
否定
negation		 ¬A，读作“非 A”：A 为假时为真。 2.1
否定范式
negation normal form (NNF)		 只用 ¬、∧ 和 ∨、并且每个 ¬ 都紧挨在原子前面的公式。 2.7.1
否定后件式
modus tollens		 由 A ⟶ B 和 ¬B 得出 ¬A：一种有效的论证形式。 2.6
否定前件
denying the antecedent		 由 A ⟶ B 和 ¬A 得出 ¬B：一种无效的论证形式。 2.6
辅助引理
auxiliary lemma		 因为一个更大的证明需要它而先行证明的引理。更大的证明卡住时剩下的目标通常会显示它应当说什么。 11.3, 14.5.1
附加条件
side condition		 规则的额外条件，例如本征变元条件，或者引入规则中不涉及被定义谓词的前提。 6.6, 11.6
复合
composition		 R O S 先走一步 R，再走一步 S。对函数来说，(g ∘ f) x = g (f x)，读作“g 在 f 之后”。 4.2.4, 4.6.3
赋值
assignment		 为每个变元在论域中选定一个值。含自由变元的公式是否为真取决于赋值。 3.3
赋值
valuation		 给每个原子指定一个真值 T 或 F。 2.3

G

术语 释义 出处
高阶逻辑
higher-order logic (HOL)		 一种带类型的逻辑，函数和谓词都是值，因此变元和量词可以取遍它们。它就是 Isabelle/HOL 的逻辑。 1.4, 3.8
鸽巢原理
pigeonhole principle		 不存在从一个有限集合到更小集合的单射。 4.7.2
公理
axiom		 没有前提的推理规则。 6.2
公平性
fairness		 排除不公平运行的假设，例如“守卫一直为真的事件终究会发生”。活性的证明需要它。 13.8.1
公式
formula		 按形成规则构造的表达式：由原子（或原子公式）、True 和 False 出发，用联结词以及（在谓词逻辑中）量词构成。 2.2.1, 3.2.3
功能正确性
functional correctness		 关于程序计算出什么结果的正确性，不涉及它花多长时间、用多少内存。 12.1
构造子
constructor		 构造数据类型的值的函数之一，例如列表的 [] 和 #，或者交通灯的 Red。 5.2.2, 8.3.1
固定变元
fixed variable		 子目标中由 ⋀ 约束的变元，或在 Isar 中由 fix 引入的变元。它代表一个任意的值，合一永远不会替换它。Isabelle 也称之为参数。 7.6.1, 10.2.4
关系
relation		 有序对的集合：从 A 到 B 的关系是 A × B 的子集。 4.2.2
归谬法（RAA）
RAA (reductio ad absurdum)		 拉丁语 reductio ad absurdum 的缩写，指这样一条规则：要证明 A，假设 ¬A 并推出 ⊥。它使自然演绎成为经典的；在 Isabelle 中是 ccontr。 6.5
归纳
induction		 先证明结论对最小的值成立，再证明它能从较小的值传到较大的值，以此证明它对每个值成立。数学归纳法、结构归纳法、强归纳法和规则归纳都是它的形式。 5.3.1
归纳不变式
inductive invariant		 在每个初始状态都成立、并被每一步保持的性质。它因此在每个可达状态中都成立。 13.3
归纳步骤
induction step		 归纳中由归纳假设证明结论对 n + 1（或更大的值）成立的那一部分。 5.3.1
归纳定义
inductive definition		 用引入规则定义谓词。谓词恰好对有限次应用规则所能推导出的对象成立：它是对这些规则封闭的最小谓词。 11.6
归纳反例
counterexample to induction		 破坏不变式证明中步骤情形的一个状态和一个事件：该状态满足不变式，而这个事件使系统离开它。 13.5.1
归纳假设
induction hypothesis (IH)		 归纳步骤中“结论对较小的值成立”的假设。在 Isabelle 的子目标中它位于 ⟹ 前面；在 Isar 中它是 c.IH。 5.3.1
规约
specification		 对系统必须做什么的精确陈述，不说明怎样做。 1.2, 12.1
规则反演
rule inversion		 从事实 I t 往回推理：只有结论能与 t 匹配的规则才可能推出它，因此这些规则的前提成立。 11.6.3
规则归纳
rule induction		 证明归纳定义推导出的一切都具有某个性质：每条规则一个情形，每个关于该谓词的前提都有一个归纳假设。在 Isabelle 中用 rule: I.induct。 11.6.2
轨迹
trace		 写成事件列表（以及它们所到达的状态）的运行。 13.1

术语 释义 出处
哈斯图
Hasse diagram		 有限集合上偏序的一种画法：较小的元素画在下面，只在一个元素覆盖另一个元素时才连线。 4.4.2
函数
function		 定义域中每个元素都恰好与陪域中一个元素相关的关系。在 HOL 中，函数和其他东西一样是值。 4.6.1
函数符号
