模块 4集合、关系与函数

用集合描述对象的汇集，用关系表示元素之间的联系，找出系统可达的状态，用函数比较集合的大小。通过 Isabelle 检查过的例子和证明，理解为什么有些无限集比另一些更大。

集合

规约时时刻刻都在谈论一组组的事物：可以读某个文件的用户，系统能够到达的状态，正在传输中的消息。数学用一个概念涵盖了所有这些，这就是集合（set）；许多规约语言都建立在它之上：Z 和 B 建立在集合论之上，Alloy 建立在关系之上，TLA+ 建立在集合和函数之上。本模块一层一层地搭建这套词汇：先是集合，然后是把元素联系起来的关系（relation），再是函数（function），最后是集合的大小。一切都建立在模块 2 和模块 3 的逻辑之上；你会看到，集合的定律其实是改头换面的逻辑定律。想在数学上多做些练习，请参阅数学基础系列中的集合、关系与离散结构。

元素与描述法

集合是由其elements组成的集合，完全由属于它的元素决定。x∈Ax \in Ax∈A读作“x是A的元素”或“x在A中”；x∉Ax \notin Ax∈/A读作“x不在A中”，是¬(x∈A)\lnot (x \in A)¬(x∈A)的缩写。

描述一个集合有两种方式。列举法（listing）在花括号中列出它的元素：{2,3,5,7}\{2, 3, 5, 7\}{2,3,5,7}⁠。描述法（set-builder notation）用一个性质来描述它的元素：{x.  P x}\{x.\; P\,x\}{x.Px} 读作“所有使 P x 成立的 x 组成的集合”。小于 10 的素数组成集合 {x.  x 是素数∧x<10}\{x.\; x \text{ 是素数} \land x < 10\}{x.x 是素数∧x<10}⁠，它也就是 {2,3,5,7}\{2, 3, 5, 7\}{2,3,5,7}⁠。许多书写作 {x∣P(x)}\{x \mid P(x)\}{x∣P(x)}⁠；本系列和 Isabelle 一样，写作 {x.  P x}\{x.\; P\,x\}{x.Px}⁠。一种常见的变体从一个给定的集合中取元素：{x∈A.  P x}\{x \in A.\; P\,x\}{x∈A.Px} 的意思是 {x.  x∈A∧P x}\{x.\; x \in A \land P\,x\}{x.x∈A∧Px}⁠。

描述法把集合和模块 3 的谓词（predicate）联系了起来。一个东西属于 {x.  P x}\{x.\; P\,x\}{x.Px}⁠，恰好是在它具有性质 PPP 的时候：

a∈{x.  P x}⟷P aa \in \{x.\; P\,x\} \iff P\,a a∈{x.Px}⟷Pa

所以，一个集合和一个谓词携带的是同样的信息。在 Isabelle/HOL 中，由某个类型的元素组成的集合，实际上就是这个类型上的一个谓词。

定义 4.1集合

集合是由元素组成的整体；x∈Ax \in Ax∈A 表示 xxx 是 AAA 的元素。集合可以用列举法给出，例如 {1,2,3}\{1, 2, 3\}{1,2,3}⁠；也可以用描述法 {x.  P x}\{x.\; P\,x\}{x.Px} 给出，它表示所有使 P xP\,xPx 成立的 xxx 组成的集合。在 Isabelle/HOL 中，每个集合都有一个元素类型：自然数集合的类型是 nat set，它的元素全都是自然数。

两个集合什么时候相等？在它们有相同的元素时。别的都不算数：既不看你按什么顺序列出元素，也不看你怎样描述它们。

定义 4.2外延性

两个集合有相同的元素时，它们就相等：

A=B⟷(∀x.  x∈A⟷x∈B)A = B \iff (\forall x.\; x \in A \iff x \in B) A=B⟷(∀x.x∈A⟷x∈B)

所以 {1,2,3}={3,1,2}={1,1,2,3}\{1, 2, 3\} = \{3, 1, 2\} = \{1, 1, 2, 3\}{1,2,3}={3,1,2}={1,1,2,3}⁠，并且 {x.  x∈Z∧x2=1}={−1,1}\{x.\; x \in \Z \land x^2 = 1\} = \{-1, 1\}{x.x∈Z∧x2=1}={−1,1}⁠。

定义 4.3子集、空集、全集

如果 AAA 的每个元素都是 BBB 的元素，即 ∀x.  x∈A⟶x∈B\forall x.\; x \in A \imp x \in B∀x.x∈A⟶x∈B⁠，就说 AAA 是 BBB 的子集（subset），记作 A⊆BA \subseteq BA⊆B⁠。如果还有 A≠BA \neq BA=B⁠，AAA 就是 BBB 的真子集（proper subset），记作 A⊂BA \subset BA⊂B⁠。空集（empty set）∅\emptyset∅ 没有元素；Isabelle 把它写作 {}。全集（universe）包含该类型的每一个元素；Isabelle 把它叫做 UNIV。

事实 4.1子集与相等

对所有集合 AAA 和 BBB⁠：

  1. ∅⊆A\emptyset \subseteq A∅⊆A⁠，并且 A⊆AA \subseteq AA⊆A⁠。
  2. A=B⟷A⊆B∧B⊆AA = B \iff A \subseteq B \land B \subseteq AA=B⟷A⊆B∧B⊆A⁠。

先看第一条。对每个 xxx⁠，x∈∅x \in \emptysetx∈∅ 都为假，所以 x∈∅⟶x∈Ax \in \emptyset \imp x \in Ax∈∅⟶x∈A 是空真的（vacuously true，见模块 2）；本模块还会再遇到空真。而无论 xxx 是什么，x∈A⟶x∈Ax \in A \imp x \in Ax∈A⟶x∈A 都成立。第二条把外延性（extensionality）和定律 (p⟷q)⟷(p⟶q)∧(q⟶p)(p \iff q) \iff (p \imp q) \land (q \imp p)(p⟷q)⟷(p⟶q)∧(q⟶p) 结合了起来。它也是证明两个集合相等的常用方法：证明每一个都是另一个的子集。

由于 HOL 是有类型的（模块 3），全集总是某一个类型的全集：UNIV :: bool set 是 {True,False}\{\mathit{True}, \mathit{False}\}{True,False}⁠，而 UNIV :: nat set 包含所有自然数。不存在包含一切东西的集合，第 4.7 节会说明这为什么是件好事。
