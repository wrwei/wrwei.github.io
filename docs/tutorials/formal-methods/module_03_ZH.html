模块 3谓词逻辑

用量词描述对所有对象成立或对某些对象成立的性质，判断公式在给定结构中是否为真，寻找反模型，并在纸上和 Isabelle 中把需求写成精确的公式。

⏱ 240 分钟开始之前：学完模块 1 和模块 2

在本模块中，你将

  • 读写含有谓词、函数、∀ 和 ∃ 的公式，分清自由变元和约束变元
  • 手工判断一个公式在一个小结构中是否为真，并构造反模型
  • 运用量词定律，并认出那些不成立的“定律”
  • 把用自然语言写成的需求翻译成谓词逻辑，避开经典的错误
  • 在 Isabelle 中用 blast 和 nitpick 检查一阶逻辑的断言，并声明带类型的词汇表
  • 解释为什么没有程序能判定谓词逻辑公式的有效性，以及这对工具意味着什么
1

命题逻辑之外

模块 2 把每个陈述都看作一个不可分割的原子。对于“如果门开着并且警报已布防，警笛就会响”这样的规则，这就够用了。但大多数需求会同时谈到许多对象：“每个请求”“某台服务器”“没有两列火车”“文件的所有者”。下面是一条访问控制策略，以及任何人都会从中得出的结论：

  1. 每个管理员都能删除每一份文档。
  2. Alice 是管理员，且季度报告是文档。
  3. 所以，Alice 能删除那份季度报告。

在命题逻辑中，每个句子都变成一个原子，比如 AAA⁠、BBB 和 CCC⁠，整个论证就变成公式 A∧B⟶CA \land B \imp CA∧B⟶C⁠。它的真值表是：

第二行使公式为假：AAA 和 BBB 为真，CCC 为假。就命题逻辑所能看到的而言，结论推不出来。可它明明推得出来，原因藏在句子内部：第 2 句中的 Alice 就是第 3 句中的 Alice，第 1 句中的“每个管理员”包括她，“每一份文档”也包括那份报告。要捕捉这样的原因，逻辑需要：

  • 对象的名字，例如 Alice 和那份报告；
  • 对象的性质和关系，例如“是管理员”和“能删除”；
  • 量词（quantifier），即“每个”“某个”这类表示数量的词，以及在这些对象上取值的变元。

此处谓词逻辑意为一阶逻辑：其变量遍历对象，而非谓词或关系本身。它在 Module 2 的连接词基础上增加了上述词汇与量词。Gottlob Frege 在 1879 年的 Begriffsschrift 中引入了量词，自此谓词逻辑成为精确陈述数学的标准语言。以此书写，整个论证为一个公式：

(∀u d. admin u∧doc d⟶can_delete u d)∧admin alice∧doc report⟶can_delete alice report(\forall u\ d.\ \mathit{admin}\ u \land \mathit{doc}\ d \imp \mathit{can\_delete}\ u\ d) \land \mathit{admin}\ \mathit{alice} \land \mathit{doc}\ \mathit{report} \imp \mathit{can\_delete}\ \mathit{alice}\ \mathit{report} (∀u d. admin u∧doc d⟶can_delete u d)∧admin alice∧doc report⟶can_delete alice report

此处 doc d\mathit{doc}\ ddoc d 表示“ddd 是一个文档”。将公式读作“如果每位管理员都能删除每个文档，Alice 是管理员，且报告是文档，则 Alice 能删除报告”。在本模块结束时，您将了解无论其词汇如何解释，该公式为真的含义，且 Isabelle 将在一行内证明它（第 3.8 节）。

谓词逻辑是规范的一种语言。模块 1 的排序条件 sorted ys∧mset ys=mset xs\mathit{sorted}\ ys \land \mathit{mset}\ ys = \mathit{mset}\ xssorted ys∧mset ys=mset xs 以这种方式使用了谓词、函数和等式。Isabelle 在其更丰富的逻辑 HOL 中提供了它们的类型化定义。

2

项、谓词与公式

谓词逻辑的公式由两类符号构成。逻辑符号在每个应用中都一样：模块 2 的联结词、量词、等号，还有变元。其他符号则为某个特定应用中的事物命名，例如用户、文档和权限。这些符号组成了这个应用的词汇表。

定义 3.1词汇表

词汇表（vocabulary），也称签名（signature），列出一种语言的非逻辑符号，并给出每个符号的参数个数，即它的元数（arity）：

  • 常量（constant）为单个对象命名：alice\mathit{alice}alice⁠、report\mathit{report}report⁠、000⁠；
  • 函数符号（function symbol）为得出一个对象的运算命名：owner\mathit{owner}owner（一个参数：一份文档的所有者）、+++（两个参数）；
  • 谓词符号（predicate symbol）为性质和关系命名，性质和关系要么成立，要么不成立：admin\mathit{admin}admin（一个参数：是管理员）、can_delete\mathit{can\_delete}can_delete（两个参数：能删除）、<<<（两个参数）。

大多数逻辑书写作 P(x)P(x)P(x)⁠、R(x,y)R(x, y)R(x,y) 和 f(x)f(x)f(x)⁠。本系列按 Isabelle 的方式书写：先写符号，再写参数，中间用空格隔开：P xP\ xP x⁠、R x yR\ x\ yR x y⁠、f xf\ xf x⁠。括号只用来分组：can_delete (owner d) d\mathit{can\_delete}\ (\mathit{owner}\ d)\ dcan_delete (owner d) d 把 can_delete\mathit{can\_delete}can_delete 应用于两个参数 owner d\mathit{owner}\ downer d 和 ddd⁠。+++ 和 <<< 这样的符号照常写在两个参数之间。

项

定义 3.2项

项（term）是下面两者之一：

  1. 一个变元（xxx⁠、yyy⁠、zzz……）或一个常量；
  2. f t1 … tnf\ t_1\ \dots\ t_nf t1​ … tn​⁠，其中 fff 是有 nnn 个参数的函数符号，t1,…,tnt_1, \dots, t_nt1​,…,tn​ 都是项。

项为一个对象命名。它永远不会为真或为假。

alice\mathit{alice}alice⁠, ddd⁠, owner d\mathit{owner}\ downer d⁠, x+1x + 1x+1 和 2∗(x+y)2 * (x + y)2∗(x+y) 是项。owner d\mathit{owner}\ downer d 命名了由 ddd 所代表的文档的所有者，x+1x + 1x+1 命名了一个数字。项类似于编程语言中的表达式，因为它们表示值。解释不必提供用于计算它们的可执行算法。

原子公式

定义 3.3原子公式

原子公式（atomic formula）要么是 P t1 … tnP\ t_1\ \dots\ t_nP t1​ … tn​⁠，其中 PPP 是有 nnn 个参数的谓词符号，t1,…,tnt_1, \dots, t_nt1​,…,tn​ 是项；要么是两个项之间的等式 t1=t2t_1 = t_2t1​=t2​⁠。

admin alice\mathit{admin}\ \mathit{alice}admin alice⁠、can_delete x report\mathit{can\_delete}\ x\ \mathit{report}can_delete x report⁠、x<y+1x < y + 1x<y+1 和 owner report=alice\mathit{owner}\ \mathit{report} = \mathit{alice}owner report=alice 都是原子公式。一旦知道其中的项代表哪些对象，每个原子公式就有了真假。没有参数的谓词符号就是模块 2 中的命题原子，所以命题逻辑的每个公式也都是谓词逻辑的公式。

注意

项和公式处在不同的层次上，一个不能出现在另一个该出现的位置。admin (can_delete alice report)\mathit{admin}\ (\mathit{can\_delete}\ \mathit{alice}\ \mathit{report})admin (can_delete alice report) 不是公式：admin\mathit{admin}admin 需要一个对象，而 can_delete alice report\mathit{can\_delete}\ \mathit{alice}\ \mathit{report}can_delete alice report 是一个陈述。owner report∧admin alice\mathit{owner}\ \mathit{report} \land \mathit{admin}\ \mathit{alice}owner report∧admin alice 也不是公式：∧\land∧ 连接的是陈述，而 owner report\mathit{owner}\ \mathit{report}owner report 是一个对象。Isabelle 会拒绝这样的表达式，第 3.8 节会演示这一点。

量词

新的成分是对对象的量化。下面的 φ\varphiφ（希腊字母 phi）和 ψ\psiψ（psi）代表任意公式。

  • ∀x. φ\forall x.\ \varphi∀x. φ 读作“对所有 xxx⁠，φ\varphiφ 成立”。它说的是：无论 xxx 代表哪个对象，φ\varphiφ 都成立。∀\forall∀ 是全称量词（universal quantifier）。
  • ∃x. φ\exists x.\ \varphi∃x. φ 读作“存在 xxx⁠，使得 φ\varphiφ 成立”，或“对某个 xxx⁠，φ\varphiφ 成立”。它说的是：φ\varphiφ 至少对一个对象成立。∃\exists∃ 是存在量词（existential quantifier）。

一个量词可以引入多个变元：∀x y. φ\forall x\ y.\ \varphi∀x y. φ 是 ∀x. ∀y. φ\forall x.\ \forall y.\ \varphi∀x. ∀y. φ 的简写。

定义 3.4公式

一个词汇表上的公式（formula）按下面的规则构造：

  1. 每个原子公式都是公式，True\mathit{True}True 和 False\mathit{False}False 也是公式。
  2. 如果 φ\varphiφ 和 ψ\psiψ 是公式，那么 ¬φ\lnot \varphi¬φ⁠、φ∧ψ\varphi \land \psiφ∧ψ⁠、φ∨ψ\varphi \lor \psiφ∨ψ⁠、φ⟶ψ\varphi \imp \psiφ⟶ψ 和 φ⟷ψ\varphi \iff \psiφ⟷ψ 也是公式；按模块 2 的优先级需要括号的地方要加上括号。
  3. 如果 φ\varphiφ 是公式，xxx 是变元，那么 ∀x. φ\forall x.\ \varphi∀x. φ 和 ∃x. φ\exists x.\ \varphi∃x. φ 是公式。

辖域、自由变元与约束变元

在 ∀x. φ\forall x.\ \varphi∀x. φ 中，公式 φ\varphiφ 是这个量词的辖域（scope）：在这个范围里，xxx 指的就是这个量词所引入的变元。公式没有括号时，辖域延伸到哪里为止？本系列遵循 Isabelle 的约定：量词的辖域尽可能向右延伸。所以 ∀x. P x⟶Q x\forall x.\ P\ x \imp Q\ x∀x. P x⟶Q x 的意思是 ∀x. (P x⟶Q x)\forall x.\ (P\ x \imp Q\ x)∀x. (P x⟶Q x)⁠。要让辖域提前结束，就加括号：(∀x. P x)⟶Q x(\forall x.\ P\ x) \imp Q\ x(∀x. P x)⟶Q x⁠。

注意

许多逻辑教科书采用相反的约定：在那里，量词和 ¬\lnot¬ 结合得一样紧，∀x P(x)⟶Q(x)\forall x\, P(x) \imp Q(x)∀xP(x)⟶Q(x) 的意思是 (∀x P(x))⟶Q(x)(\forall x\, P(x)) \imp Q(x)(∀xP(x))⟶Q(x)⁠。读其他书时，先弄清它们的约定。为 Isabelle 写公式时，要记住量词的辖域一直延伸到公式的末尾，或者延伸到量词所在的那组括号的右括号为止。

定义 3.5自由变元与约束变元

变元 xxx 在公式中的一次出现，如果位于某个量词 ∀x\forall x∀x 或 ∃x\exists x∃x 的辖域之内，就是约束的（bound），并且属于包围它的、离它最近的那个这样的量词。否则，这次出现是自由的（free）。有约束出现的变元称为约束变元（bound variable），有自由出现的变元称为自由变元（free variable）。没有任何变元自由出现的公式称为语句（sentence），也叫闭公式。

图 3.1 标出了一个公式中的各个辖域，在这个公式里，同一个变元名既有约束出现，也有自由出现。

一旦语句中的符号有了含义，语句就有了真假。含有自由变元的公式还取决于这些变元代表什么：在 xxx 取值之前，x<3x < 3x<3 既不为真也不为假；而 ∃x. x<3\exists x.\ x < 3∃x. x<3 是一个语句，在自然数上为真。自由变元就像函数的参数，约束变元就像局部变量：在约束变元的整个辖域中把它统一换成一个新名字，什么也不会改变，所以 ∀x. P x\forall x.\ P\ x∀x. P x 和 ∀y. P y\forall y.\ P\ y∀y. P y 说的是同一件事。

结构与真值

∀x. ∃y. R x y\forall x.\ \exists y.\ R\ x\ y∀x. ∃y. R x y 为真吗？这个问题现在还没有答案。如果 xxx 和 yyy 在自然数上取值，RRR 是 <<<⁠，它就为真：每个数都有比它大的数。如果 RRR 是 >>>⁠，它就为假：没有比 0 小的自然数。只有说清楚变元在什么范围内取值、符号是什么意思，公式才有真值。这些信息就是一个结构。

定义 3.6结构

一个词汇表的结构（structure）M\mathcal MM 由以下几部分组成：

  1. 一个非空集合 DDD⁠，称为论域（domain）：变元在其中取值的那些对象；
  2. 对每个常量 ccc⁠，DDD 中的一个元素 cMc^{\mathcal M}cM⁠；
  3. 对每个有 nnn 个参数的函数符号 fff⁠，一个函数 fMf^{\mathcal M}fM⁠，它把由 DDD 的元素组成的每个 nnn 元组映射到 DDD 的一个元素；
  4. 对每个有 nnn 个参数的谓词符号 PPP⁠，一个由 DDD 的元素组成的 nnn 元组的集合 PMP^{\mathcal M}PM⁠：也就是使 PPP 成立的那些元组。

nnn 元组（nnn-tuple）是按顺序排列的 nnn 个元素 (d1,…,dn)(d_1, \dots, d_n)(d1​,…,dn​)⁠；2 元组就是有序对（pair）。cMc^{\mathcal M}cM 读作“M\mathcal MM 中的 ccc⁠”，即 M\mathcal MM 让符号 ccc 表示的东西；fMf^{\mathcal M}fM 和 PMP^{\mathcal M}PM 也是这样读。第 2 到第 4 项合起来是词汇表的解释（interpretation）。结构也叫模型（model）或解释。

论域可以是有限的，也可以是无限的，但按照惯例，它永远不是空的；Isabelle 也遵循同样的惯例。函数符号被解释为一个对每个参数都给出值的函数，即使对某些参数来说这个值毫无意义，比如一个不是文档的东西的“所有者”。第 3.8 节会说明类型怎样避免这类无意义的东西。

要对含有自由变元的公式求值，还需要知道这些变元的值。

定义 3.7结构中的真值

赋值（assignment）sss 给每个变元一个 DDD 中的值。项的值由它的变元和常量的值，借助 M\mathcal MM 中的函数算出。公式是否在 M\mathcal MM 中、在 sss 下为真，按以下规则确定：

  • 当 t1,…,tnt_1, \dots, t_nt1​,…,tn​ 的值组成的元组属于 PMP^{\mathcal M}PM 时，P t1 … tnP\ t_1\ \dots\ t_nP t1​ … tn​ 为真；当两个项的值相同时，t1=t2t_1 = t_2t1​=t2​ 为真。
  • True\mathit{True}True 为真且 False\mathit{False}False 为假；¬\lnot¬⁠, ∧\land∧⁠, ∨\lor∨⁠, ⟶\imp⟶ 和 ⟷\iff⟷ 遵循来自 Module 2 的它们的真值表。
  • 当 xxx 取 DDD 中的每一个值（其他变元保持原值）时 φ\varphiφ 都为真，∀x. φ\forall x.\ \varphi∀x. φ 就为真。
  • 当 xxx 取 DDD 中至少一个值时 φ\varphiφ 为真，∃x. φ\exists x.\ \varphi∃x. φ 就为真。

打个比方

在有限域上，量词是一个循环。∀x\forall x∀x 是一个仅在每轮都成功时才成功的循环；∃x\exists x∃x 是在一轮成功时即成功的循环。在 Python 中，∀x. ∃y. R x y\forall x.\ \exists y.\ R\ x\ y∀x. ∃y. R x y 对列表 D 的操作是 all(any(R(x, y) for y in D) for x in D)。在无限域上，枚举不是一般决策过程：搜索可能找到见证者或反例，但无法完成检查每个元素。一般推理可以解决枚举无法处理的断言。

例 3.4量词的顺序

在 M1\mathcal M_1M1​ 中，语句 ∀x. ∃y. R x y\forall x.\ \exists y.\ R\ x\ y∀x. ∃y. R x y 说的是每个元素都有一个从它出发的箭头。确实如此：a→ba \to ba→b⁠、b→cb \to cb→c 和 c→cc \to cc→c⁠。每个 xxx 都有自己的见证 yyy⁠。

∃y. ∀x. R x y\exists y.\ \forall x.\ R\ x\ y∃y. ∀x. R x y 说的是有某个元素从每个元素（包括它自己）那里都收到一个箭头。逐个试每个候选的 yyy⁠：aaa 没有收到任何箭头；bbb 只从 aaa 那里收到箭头；ccc 从 bbb 和 ccc 那里收到箭头，但没有从 aaa 那里收到。没有一个候选行得通，所以这个语句为假。

这两个语句只是 ∀x\forall x∀x 和 ∃y\exists y∃y 的顺序不同。在第一个语句中，yyy 可以依赖于 xxx⁠；在第二个语句中，同一个 yyy 必须对每一个 xxx 都适用。

一个 ∀ 语句为真，还可能出于一个不那么明显的原因。在没有任何元素具有性质 PPP 的结构中，无论 QQQ 是什么，语句 ∀x. P x⟶Q x\forall x.\ P\ x \imp Q\ x∀x. P x⟶Q x 都为真：对每个 xxx⁠，条件 P xP\ xP x 都为假，所以蕴涵式为真。这样的语句是空真的（vacuously true）。在一家没有管理员的公司里，“每个管理员都在值班”成立；对一台从未收到请求的服务器来说，“每个请求都得到了响应”也成立。写规约时必须考虑到这一点。

4

有效性、可满足性与反模型

模块 2 的核心概念都可以沿用过来，只是把“真值表的每一行”换成“每一个结构”。

定义 3.8有效性与可满足性

公式 φ\varphiφ 是

  • 有效的（valid），记作 ⊨φ\models \varphi⊨φ⁠，如果它在每个结构中、在每个赋值下都为真；
  • 可满足的（satisfiable），如果它至少在一个结构中、在至少一个赋值下为真；
  • 不可满足的（unsatisfiable），如果它在任何结构中、任何赋值下都不为真。

如果在每一个使 Γ\GammaΓ 中所有公式都为真的结构和赋值下，φ\varphiφ 都为真，就说公式集 Γ\GammaΓ（gamma）逻辑蕴涵（entails）φ\varphiφ⁠，记作 Γ⊨φ\Gamma \models \varphiΓ⊨φ⁠。这时 φ\varphiφ 是 Γ\GammaΓ 的逻辑推论（logical consequence）。

和模块 2 一样，φ\varphiφ 是有效的，当且仅当 ¬φ\lnot \varphi¬φ 不可满足。区别在于情况的数目：真值表只有有限多行，结构却有无穷多个，大小各异，你不可能把它们全部检查一遍。不过，要表明一个公式不是有效的，一个结构就够了。

定义 3.9反模型

φ\varphiφ 的反模型（countermodel）是一个结构，连同对 φ\varphiφ 的自由变元的一个赋值，使 φ\varphiφ 在其中为假。一个公式是有效的，当且仅当它没有反模型。

例 3.5一个反模型

(∀x. P x∨Q x)⟶(∀x. P x)∨(∀x. Q x)(\forall x.\ P\ x \lor Q\ x) \imp (\forall x.\ P\ x) \lor (\forall x.\ Q\ x)(∀x. P x∨Q x)⟶(∀x. P x)∨(∀x. Q x) 是有效的吗？它说的是：“如果每样东西都是 PPP 或 QQQ⁠，那么每样东西都是 PPP⁠，或者每样东西都是 QQQ⁠”。这听起来似乎有道理，直到你设想一个只是 PPP 的元素和另一个只是 QQQ 的元素：D={a,b}D = \{a, b\}D={a,b}⁠，P={a}P = \{a\}P={a}⁠，Q={b}Q = \{b\}Q={b}⁠。前提为真，因为 aaa 是 PPP⁠，bbb 是 QQQ⁠。但 ∀x. P x\forall x.\ P\ x∀x. P x 在 bbb 处不成立，∀x. Q x\forall x.\ Q\ x∀x. Q x 在 aaa 处不成立，所以结论为假。这个结构就是一个反模型，因此这个公式不是有效的。不过它是可满足的：在每样东西都是 PPP 的每个结构中，它都为真。

要表明一个公式是有效的，就要对一个任意的结构进行论证：关于论域和解释，论证中除了公式本身所说的，什么也不能用。

例 3.6证明有效性

断言：(∀x. P x⟶Q x)∧P c⟶Q c(\forall x.\ P\ x \imp Q\ x) \land P\ c \imp Q\ c(∀x. P x⟶Q x)∧P c⟶Q c 是有效的。任取一个结构 M\mathcal MM⁠。如果蕴涵式的左边在 M\mathcal MM 中为假，那么蕴涵式为真。否则两个合取项都为真。第一个合取项说 P x⟶Q xP\ x \imp Q\ xP x⟶Q x 对 xxx 的每个值都成立，特别是对元素 cMc^{\mathcal M}cM 成立；第二个合取项说 PPP 对 cMc^{\mathcal M}cM 成立。两者合起来就得到 Q cQ\ cQ c⁠。无论哪种情况，这个公式在 M\mathcal MM 中都为真；而 M\mathcal MM 是任意取的，所以这个公式是有效的。这就是第 3.1 节那个论证的缩影。

有效的公式包括命题重言式的每一个实例，例如 P x∨¬ P xP\ x \lor \lnot\, P\ xP x∨¬P x⁠，还包括许多命题逻辑无法解释的公式，例如 (∀x. P x)⟶P c(\forall x.\ P\ x) \imp P\ c(∀x. P x)⟶P c⁠。

量词推理

如果两个公式恰好在相同的结构和赋值下为真，也就是说 φ⟷ψ\varphi \iff \psiφ⟷ψ 是有效的，就说它们是等价的（equivalent），记作 φ≡ψ\varphi \equiv \psiφ≡ψ⁠。利用等价式可以改写公式：化简一个规约，否定一条需求，看懂一个证明。本节汇集了你最常用的定律，以及那些看起来对、其实不成立的“定律”。

量词定律

在两个元素的论域 {a,b}\{a, b\}{a,b} 上，∀x. P x\forall x.\ P\ x∀x. P x 的意思是 P a∧P bP\ a \land P\ bP a∧P b⁠，∃x. P x\exists x.\ P\ x∃x. P x 的意思是 P a∨P bP\ a \lor P\ bP a∨P b⁠。所以 ∀ 就像一个长长的合取，∃ 就像一个长长的析取，模块 2 中关于 ∧ 和 ∨ 的定律都有对应的量词版本。

事实 3.1量词的否定
¬(∀x. φ)≡∃x. ¬φ¬(∃x. φ)≡∀x. ¬φ\lnot (\forall x.\ \varphi) \equiv \exists x.\ \lnot \varphi \qquad\qquad \lnot (\exists x.\ \varphi) \equiv \forall x.\ \lnot \varphi ¬(∀x. φ)≡∃x. ¬φ¬(∃x. φ)≡∀x. ¬φ

“并非一切都是 φ\varphiφ⁠”意味着“有某样东西不是 φ\varphiφ⁠”，“没有东西是 φ\varphiφ⁠”意味着“一切都不是 φ\varphiφ⁠”。这就是量词的德摩根律（De Morgan’s laws）。把否定向内推时，它经过的每个量词都会变成另一种量词。

例 3.7否定一条需求

一条需求和对它的违反互为否定。以“每个请求都得到响应”为例：

∀r. request r⟶answered r\forall r.\ \mathit{request}\ r \imp \mathit{answered}\ r∀r. request r⟶answered r

它的否定描述了测试或模型检测器要表明这条需求被违反，必须找到什么：

¬(∀r. request r⟶answered r)  ≡  ∃r. ¬(request r⟶answered r)  ≡  ∃r. request r∧¬ answered r\lnot (\forall r.\ \mathit{request}\ r \imp \mathit{answered}\ r) \;\equiv\; \exists r.\ \lnot (\mathit{request}\ r \imp \mathit{answered}\ r) \;\equiv\; \exists r.\ \mathit{request}\ r \land \lnot\, \mathit{answered}\ r ¬(∀r. request r⟶answered r)≡∃r. ¬(request r⟶answered r)≡∃r. request r∧¬answered r

“有某个请求没有得到响应。”最后一步用到了模块 2 中的 ¬(A⟶B)≡A∧¬B\lnot (A \imp B) \equiv A \land \lnot B¬(A⟶B)≡A∧¬B⁠。遇到嵌套的量词，否定会依次穿过每一个量词：¬(∀x. ∃y. trusts x y)≡∃x. ∀y. ¬ trusts x y\lnot (\forall x.\ \exists y.\ \mathit{trusts}\ x\ y) \equiv \exists x.\ \forall y.\ \lnot\, \mathit{trusts}\ x\ y¬(∀x. ∃y. trusts x y)≡∃x. ∀y. ¬trusts x y⁠，即“有某个人谁也不信任”。

事实 3.2分配律
∀x. (φ∧ψ)≡(∀x. φ)∧(∀x. ψ)∃x. (φ∨ψ)≡(∃x. φ)∨(∃x. ψ)\forall x.\ (\varphi \land \psi) \equiv (\forall x.\ \varphi) \land (\forall x.\ \psi) \qquad\qquad \exists x.\ (\varphi \lor \psi) \equiv (\exists x.\ \varphi) \lor (\exists x.\ \psi) ∀x. (φ∧ψ)≡(∀x. φ)∧(∀x. ψ)∃x. (φ∨ψ)≡(∃x. φ)∨(∃x. ψ)

另外两种组合只在一个方向上成立：

(∀x. φ)∨(∀x. ψ)⊨∀x. (φ∨ψ)∃x. (φ∧ψ)⊨(∃x. φ)∧(∃x. ψ)(\forall x.\ \varphi) \lor (\forall x.\ \psi) \models \forall x.\ (\varphi \lor \psi) \qquad\qquad \exists x.\ (\varphi \land \psi) \models (\exists x.\ \varphi) \land (\exists x.\ \psi) (∀x. φ)∨(∀x. ψ)⊨∀x. (φ∨ψ)∃x. (φ∧ψ)⊨(∃x. φ)∧(∃x. ψ)

例 3.5 已经表明，第一条单向定律不能反过来。第二条也不能：“有人是管理员，也有人在值班”并不意味着有管理员在值班。反模型仍然是 D={a,b}D = \{a, b\}D={a,b}⁠，P={a}P = \{a\}P={a}⁠，Q={b}Q = \{b\}Q={b}⁠。

代入与变元捕获

从 ∀x. φ\forall x.\ \varphi∀x. φ 可以对任何一个特定的对象推出 φ\varphiφ⁠：从“每个管理员都在值班”可以推出“如果 Alice 是管理员，那么 Alice 在值班”。这一步把变元 xxx 替换成了一个项。

定义 3.10代入

φ[t/x]\varphi[t/x]φ[t/x]⁠, read “φ\varphiφ with ttt for xxx”, 是从 φ\varphiφ 通过用项 ttt 替换变量 xxx 的每个 free 出现而得到的公式，必要时先重命名约束变元，使得 ttt 的自由变元不会变为约束变元。xxx 的约束出现不被替换。

例如，(P x∧(∀x. Q x))[a/x](P\ x \land (\forall x.\ Q\ x))[a/x](P x∧(∀x. Q x))[a/x] 是 P a∧(∀x. Q x)P\ a \land (\forall x.\ Q\ x)P a∧(∀x. Q x)⁠：只有第一个 xxx 是自由的。

事实 3.5实例化
∀x. φ⊨φ[t/x]φ[t/x]⊨∃x. φ\forall x.\ \varphi \models \varphi[t/x] \qquad\qquad \varphi[t/x] \models \exists x.\ \varphi ∀x. φ⊨φ[t/x]φ[t/x]⊨∃x. φ

前提是：把 ttt 放到 xxx 的位置上时，ttt 中没有任何变元因此被约束。

这个附加条件并不是吹毛求疵。设 φ\varphiφ 是 ∃y. R x y\exists y.\ R\ x\ y∃y. R x y⁠，即“xxx 有一个 RRR 后继”。那么 ∀x. φ\forall x.\ \varphi∀x. φ 说的是每样东西都有后继。如果不小心用 yyy 代入 xxx⁠，就会得到 ∃y. R y y\exists y.\ R\ y\ y∃y. R y y⁠，即“有某样东西是它自己的后继”：你代入的 yyy 被 ∃y\exists y∃y 捕获（capture）了，意思也就变了。以自然数为论域、以 <<< 为 RRR⁠，∀x. ∃y. x<y\forall x.\ \exists y.\ x < y∀x. ∃y. x<y 为真，而 ∃y. y<y\exists y.\ y < y∃y. y<y 为假，所以这个粗心的步骤从一个真命题推出了一个假命题。补救的办法是先给约束变元改名。∃y. R x y\exists y.\ R\ x\ y∃y. R x y 与 ∃z. R x z\exists z.\ R\ x\ z∃z. R x z 等价，而 (∃z. R x z)[y/x](\exists z.\ R\ x\ z)[y/x](∃z. R x z)[y/x] 是 ∃z. R y z\exists z.\ R\ y\ z∃z. R y z⁠，即“yyy 有一个后继”，这确实可以推出。

只在约束变元的名字上不同的公式，例如 ∃y. R x y\exists y.\ R\ x\ y∃y. R x y 和 ∃z. R x z\exists z.\ R\ x\ z∃z. R x z⁠，称为 α 等价的（alpha-equivalent）。它们的意思相同；谈论代入时，总是允许先做这样的改名。

相等是一个含义固定的谓词。结构可以选择 PPP 和 RRR 的含义，却不能选择 === 的含义：在每个结构中，t1=t2t_1 = t_2t1​=t2​ 为真，当且仅当 t1t_1t1​ 和 t2t_2t2​ 代表同一个元素。这就是 === 被算作逻辑符号的原因。它的定律在每个结构中都成立。

事实 3.6相等的定律
  • 自反性：t=tt = tt=t⁠。
  • 对称性：t=u⟶u=tt = u \imp u = tt=u⟶u=t⁠。

编写规约

把需求变成公式是一门手艺，公式好不好，全看它背后的翻译好不好。按下面的步骤做会有帮助：

  1. 确定论域和词汇表：有哪些对象，哪些性质和关系，哪些函数。
  2. 利用下面的模式，一条一条地翻译每个需求。
  3. 把公式逐个符号、按字面意思用平实的中文读回来，再与需求比较。
  4. 在小结构上检验它：找一个应当满足它的结构，再找一个不应当满足它的结构。第 3.3 节的模型探索器和 Nitpick 都能帮上忙。

    ∀d. doc d⟶(∃u. user u∧owns u d∧(∀v. owns v d⟶v=u))\forall d.\ \mathit{doc}\ d \imp (\exists u.\ \mathit{user}\ u \land \mathit{owns}\ u\ d \land (\forall v.\ \mathit{owns}\ v\ d \imp v = u))∀d. doc d⟶(∃u. user u∧owns u d∧(∀v. owns v d⟶v=u))
  2. 只有文档的所有者或管理员才能删除它：
    ∀u d. can_delete u d⟶owns u d∨admin u\forall u\ d.\ \mathit{can\_delete}\ u\ d \imp \mathit{owns}\ u\ d \lor \mathit{admin}\ u∀u d. can_delete u d⟶owns u d∨admin u
  3. 管理员能读每一份文档：
    ∀u d. admin u∧doc d⟶can_read u d\forall u\ d.\ \mathit{admin}\ u \land \mathit{doc}\ d \imp \mathit{can\_read}\ u\ d∀u d. admin u∧doc d⟶can_read u d
  4. 有某个管理员不拥有任何文档：
    ∃u. admin u∧¬(∃d. doc d∧owns u d)\exists u.\ \mathit{admin}\ u \land \lnot (\exists d.\ \mathit{doc}\ d \land \mathit{owns}\ u\ d)∃u. admin u∧¬(∃d. doc d∧owns u d)

现在把它们读回来。需求 1 是在一个 ∀ 里面套用“恰好一个”模式。需求 2 含有“只有”，所以箭头从 can_delete\mathit{can\_delete}can_delete 指向条件。需求 3 需要守卫 doc d\mathit{doc}\ ddoc d⁠：没有它，这条需求还会说管理员能“读”用户。需求 4 是“有的 AAA 是 BBB⁠”模式，其中“不拥有任何文档”写成了一个被否定的 ∃。

类型：从多类别逻辑到 HOL

例 3.10 的策略需要守卫 user\mathit{user}user 和 doc\mathit{doc}doc⁠，因为一个论域里装着两类对象。守卫写起来很烦琐，而漏掉一个就会悄无声息地改变意思。去掉需求 3 中的守卫，它就会说管理员能“读”用户。把“每份文档都有所有者”写成 ∀d. ∃u. owns u d\forall d.\ \exists u.\ \mathit{owns}\ u\ d∀d. ∃u. owns u d⁠，你就断言了每个对象（包括用户）都被某个东西拥有。还有，像 owner\mathit{owner}owner 这样的函数符号即使对用户也必须给出一个值，因为结构是用整个论域上的函数来解释它的。

定义 3.11多类别逻辑

在多类逻辑或带类型的逻辑中，词汇表为每个常量、函数符号和谓词符号的每个参数、以及每个函数的返回值指定一个类（sort），也称类型。按这里的约定，结构为每个类配备一个非空的论域，每个变量只在其中一个论域取值。∀d::doc. ∃u::user. owns u d\forall d{::}\mathit{doc}.\ \exists u{::}\mathit{user}.\ \mathit{owns}\ u\ d∀d::doc. ∃u::user. owns u d 读作“对每个文档 ddd⁠，都存在一个用户 uuu⁠，此用户拥有 ddd⁠”。只要有一处实参的类不匹配，整个表达式就不构成公式。

多排序一阶逻辑可翻译为单域一阶逻辑。量词变为受限量词：∀d::doc. φ\forall d{::}\mathit{doc}.\ \varphi∀d::doc. φ变为∀d. doc d⟶φ\forall d.\ \mathit{doc}\ d \imp \varphi∀d. doc d⟶φ⁠，∃u::user. φ\exists u{::}\mathit{user}.\ \varphi∃u::user. φ变为∃u. user u∧φ\exists u.\ \mathit{user}\ u \land \varphi∃u. user u∧φ⁠。该翻译还需假设排序非空且常量与函数遵守其声明的排序。类型将此类限制纳入语言，使错误排序的参数成为计算机在证明前即可发现的错误。此翻译涉及一阶排序；HOL 还增加了高阶量化。

Isabelle/HOL 从头到尾都是有类型的。每个项都有一个类型。公式是类型为 bool 的项，bool 的两个值是 True 和 False。类型为 τ（tau）的对象上的谓词，是一个类型为 τ ⇒ bool 的函数，它把每个对象映射到 True 或 False；τ 与 σ（sigma）之间的关系，是一个类型为 τ ⇒ σ ⇒ bool 的函数。所以 Isabelle 中的 P x 是把一个函数应用于一个参数，结果是一个公式。由于谓词和函数都和其他东西一样是值，HOL 还允许你对它们进行量化，例如 ∀P. P x ⟶ P x：正是这一点使它成为一种高阶逻辑（higher-order logic）。模块 8 会深入讲解 HOL 的类型和函数。

在 Isabelle 中声明一个词汇表时，用 typedecl 声明它的类型，用 consts 声明它的符号：

Isabelle

可判定性：工具能做什么，不能做什么

对于命题逻辑，模块 2 给出了一个判定有效性的算法：计算真值表。这个算法可能很慢，但它总会结束，并给出正确的答案。谓词逻辑有这样的算法吗？大卫·希尔伯特（David Hilbert）和威廉·阿克曼（Wilhelm Ackermann）在 1928 年提出了这个问题，称为判定问题（Entscheidungsproblem）。答案分两部分给出。

事实 3.7哥德尔完备性定理

谓词逻辑有这样的证明系统（自然演绎就是其中之一，见模块 6）：在其中，一个公式能被证明，当且仅当它是有效的。库尔特·哥德尔（Kurt Gödel）在 1929 年的博士论文中对其中一个这样的系统证明了这一点，论文发表于 1930 年。

完备性（completeness）带来一个很实际的结果。证明是程序可以检查的有限文本，所以程序可以按从短到长的顺序列出所有证明，连同它们证明的公式。每个有效公式迟早都会出现在这个列表中。要弄清一个公式是否有效，就运行这个程序，等着这个公式出现：如果它是有效的，最终会得到答案“是”。如果它不是有效的，你就会永远等下去，而且在任何时刻，你都不知道再等一会儿是否有用。

事实 3.8谓词逻辑的不可判定性

没有算法能对谓词逻辑的每个公式判定它是否有效。阿朗佐·丘奇（Alonzo Church）和艾伦·图灵（Alan Turing）在 1936 年各自独立地证明了这一点。即使词汇表只有一个二元谓词符号，有效性仍然是不可判定的（undecidable）。

图灵的证明与模块 1 提到的停机问题有关：对每个程序，都可以写出一个公式，使这个公式有效当且仅当这个程序会停机；所以，判定有效性的算法也就能判定停机，而没有算法能做到这一点。

定义 3.12可判定与半可判定

一个关于输入的问题，如果有某个算法对每个输入都能正确地回答它，并且总会终止，这个问题就是可判定的（decidable）。如果有某个算法对每个答案为“是”的输入都回答“是”，但对其他输入可能永远运行下去，这个问题就是半可判定的（semi-decidable）。

谓词逻辑中的有效性是半可判定的，但不是可判定的。不可满足性也是如此，因为 φ\varphiφ 不可满足当且仅当 ¬φ\lnot \varphi¬φ 有效；而可满足性连半可判定都不是。

Gödel的两个定理容易混淆。完备性定理（1929/1930）涉及有效公式，即在每个结构中均为真的公式：所有有效公式均可被证明。他的不完备性定理（1931）关注在某个特定结构（自然数）中为真的公式：任何其公理由程序可验证、且仅证明真语句的证明系统，都无法证明所有此类公式。HOL可以描述自然数，因此不完备性同样适用于Isabelle的逻辑。

为什么有些公式能让两种搜索都无功而返？因为反模型可以是无限的。看这个公式：

(∀x. ¬ R x x)∧(∀x y z. R x y∧R y z⟶R x z)⟶¬(∀x. ∃y. R x y)(\forall x.\ \lnot\, R\ x\ x) \land (\forall x\ y\ z.\ R\ x\ y \land R\ y\ z \imp R\ x\ z) \imp \lnot (\forall x.\ \exists y.\ R\ x\ y) (∀x. ¬R x x)∧(∀x y z. R x y∧R y z⟶R x z)⟶¬(∀x. ∃y. R x y)

此处irreflexive表示无元素与自身相关，transitive表示R x yR\ x\ yR x y与R y zR\ y\ zR y z共同蕴含R x zR\ x\ zR x z⁠。该公式表述为：“若RRR为irreflexive且transitive，则存在某元素无RRR-后继。”该公式非有效：以自然数为论域且<<<为RRR时，两前提均成立，且每个数均有更大的数。但在所有有限结构中该公式为真（Exercise 3.8要求证明其原因），故通过有限结构的搜索永找不到反例，证明搜索也永找不到证明，因为不存在证明。此类公式必然存在。若每个非有效公式均有有限反例，则可并行运行证明搜索与反例搜索；二者必有一方终止，从而有效性可判定，但Church与Turing已证明其不可判定。

这在实践中意味着：

  • 证明搜索 (simp, blast, auto, 以及 Sledgehammer 在 Module 9 中调用的证明器) 可以关闭目标、留下子目标、失败或达到资源限制。完成的证明给出定理；未完成的尝试并不确立该主张为假。
  • 反模型搜索（Nitpick 和 Quickcheck）是另一半：一个真正的反例表明公式不是有效的；找不到反例则什么也说明不了。
  • 两者都放弃时，就轮到你了：找出证明的思路并引导 Isabelle 完成它（第二部分和第三部分会教你怎么做），或者找出一个工具看不到的反模型。

并非所有问题都是不可判定的。命题逻辑是可判定的，且谓词逻辑中每个谓词仅接受一个参数且无函数符号的部分也是可判定的。SAT 和 SMT 求解器（Module 1）能高效求解许多可判定片段中的有用实例，尽管无法保证每个实例都有实际运行时间。这就是为什么 Isabelle 的工具会调用它们来提供帮助。

要点

谓词逻辑中的有效性是半可判定的：只要证明存在，系统的搜索就能找到它；但没有程序总能告诉你证明不存在。这就是为什么 Isabelle 既提供证明器，也提供反例搜索器；为什么自动化有时会在真的陈述上放弃；也是为什么本系列的其余部分要教你自己引导证明。

小结

  • 谓词逻辑在命题逻辑的基础上加入了为对象命名的项、陈述性质和关系的谓词，以及量词 ∀（“对所有”）和 ∃（“存在”）。
  • 在 Isabelle 中，量词的辖域尽可能向右延伸。变元在其量词辖域中的出现是约束的，其他出现是自由的；语句没有自由变元。
  • 结构是一个非空论域，加上对词汇表的一个解释。为假的 ∀ 语句有反例，为真的 ∃ 语句有见证。
  • 公式如果在每个结构中都为真，就是有效的；如果在某个结构中为真，就是可满足的。一个反模型就能否定有效性；而要确立有效性，需要一个对每个结构都成立的论证。
  • 否定使 ∀ 和 ∃ 互换；∀ 对 ∧ 可分配，∃ 对 ∨ 可分配，反过来则不行；∃y. ∀x 蕴涵 ∀x. ∃y，反之不然。代入不能捕获变元。
  • 对于受限语句如“每位管理员都在值班”，使用 ∀ 与 ⟶；对于“某位管理员在 call"，使用 ∃ 与 ∧。这些是翻译模式，而非对量词下可出现的联结词的限制。“Only”引入必要条件，计数使用等式。
  • 在 Isabelle 中，谓词是取值为 bool 的函数；typedecl 和 consts 声明词汇表；引理中的自由变元隐含地是全称量化的；blast 证明一阶目标，nitpick 寻找反模型。= 比 ¬ 和 ∧ 结合得更紧，⟷ 则和 ⟶ 一样松。
  • 有效性是半可判定的（哥德尔完备性定理），但不是可判定的，即不可判定的（丘奇和图灵，1936）：证明器可能在有效的公式上放弃，反模型搜索器会漏掉无限反模型。

  2. 用 Nitpick 表明：这两条需求加上 admin bob，推不出 Bob 能读那份报告。解释这个反模型。

Isabelle
consts
  can_read :: "user ⇒ doc ⇒ bool"
  bob :: user

lemma "(∀u d. can_delete u d ⟶ can_read u d) ∧
       (∀u d. owns u d ⟶ can_delete u d) ∧
       owns alice report ⟶ can_read alice report"
  by blast

Alice 拥有那份报告，所以她能删除它，因而她能读它：这要用到两条 ∀ 需求的两个实例，blast 能找到它们。

       (∀u d. owns u d ⟶ can_delete u d) ∧
       admin bob ⟶ can_read bob report"
  nitpick [card user = 1, card doc = 1, show_consts]

在单用户反例模型中，Alice 和 Bob 表示同一用户。Bob 是管理员，但无人拥有任何内容，也无人能读取或删除任何内容；两个要求均空真成立。要求中未赋予管理员任何权利。若管理员应读取所有内容，则属于额外要求，例如例 3.10 中的要求 3。

自测题

1
哪个公式表达“每个管理员都在值班”？
用 ∀ 时，“是管理员”这一限制是一个条件，所以 ∀ 与 ⟶ 搭配。第一个选项说的是每个人都是管理员；最后一个选项说的是只有管理员才值班。
2
按照 Isabelle 的辖域约定，在 ∀x. P x⟶(∃y. R x y)∧Q y\forall x.\ P\ x \imp (\exists y.\ R\ x\ y) \land Q\ y∀x. P x⟶(∃y. R x y)∧Q y 中，哪一个出现是自由的？
括号在 R x yR\ x\ yR x y 之后结束了 ∃y\exists y∃y 的辖域，所以 Q yQ\ yQ y 中的 yyy 在这个辖域之外。∀x\forall x∀x 的辖域一直延伸到公式末尾。
3
哪个公式是有效的？
如果有一个 yyy 对每个 xxx 都行得通，那么每个 xxx 都有一个 yyy⁠。另外三个公式都有含两个元素的反模型。
4
一个公式的反模型能说明什么？
反模型是一个使公式为假的结构，所以这个公式并非在每个结构中都为真。它仍然可能是可满足的。
5
Isabelle 怎样读 ¬ x = y ∧ P x？
= 比 ¬ 结合得更紧，¬ 又比 ∧ 结合得更紧。Isabelle 把这个公式打印成 x ≠ y ∧ P x。
6
Nitpick 对一条引理回答“Nitpick found no counterexample”。你能得出什么结论？
Nitpick 在有限范围内进行搜索，并对部分 HOL 构造使用近似。其默认域大小范围是 1–10。某些无效公式（如第 3.9 节中的公式）仅有无限反例。
