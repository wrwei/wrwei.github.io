用 Isabelle 学形式化方法

从逻辑和离散数学出发，学习用 Isabelle/HOL 检查证明，验证程序和系统模型。课程的证明由 Isabelle2026 检查。

14 个模块约 51 小时Isabelle2026EN · 中文
从模块 1 开始 →

本系列适合谁

你会用某种语言写一点程序，也还记得中学代数。你没有学过逻辑或证明，也从未用过证明助手。你可能是计算机科学或软件工程专业的学生，也可能是一名希望验证设计、而不只是测试设计的工程师。本系列不假定其他任何基础，每个概念都会先在纸上讲清楚，再交给 Isabelle 检查。

你将能够做什么

  • 用命题逻辑和谓词逻辑写出精确的规约，并运用集合、关系、函数和归纳进行推理。
  • 解释什么是证明，手工构造自然演绎证明，并在 Isabelle 中重现它们。
  • 在 Isabelle/HOL 中定义函数和数据类型，并借助自动化、Isar 结构化证明和归纳证明它们的性质。
  • 对照规约验证函数式程序，把系统建模为状态机并证明其不变式，并证明一个小型编译器是正确的。

学习方式

共四个部分、十四个模块，总计约 50 小时。每个模块都有例题、三个层次的练习（附完整解答）和一组简短的自测题。这些页面上的每一个 Isabelle 输出，包括每一条错误消息，都是 Isabelle2026 根据所示文本产生的；每一个证明，包括练习的解答，都经过了 Isabelle 的检查。请从模块 1 开始，它也会带你安装 Isabelle。

第一部分 · 基础

模块 12.5 h
什么是形式化方法
了解形式化方法能够证明软件的哪些性质、规约与证明如何配合，以及 Isabelle 在这些方法中的位置。最后，在 Isabelle/HOL 中编写你的第一个理论。
✓
模块 23.5 h
命题逻辑
认识由 ¬、∧、∨、⟶ 和 ⟷ 构成的公式。用真值表检验重言式、等价关系和论证的有效性，把公式改写为范式，再用 Isabelle 检验需求公式。
✓
模块 34 h
谓词逻辑
用量词描述对所有对象成立或对某些对象成立的性质，判断公式在给定结构中是否为真，寻找反模型，并在纸上和 Isabelle 中把需求写成精确的公式。
✓
模块 43.5 h
集合、关系与函数
用集合描述对象的汇集，用关系表示元素之间的联系，找出系统可达的状态，用函数比较集合的大小。通过 Isabelle 检查过的例子和证明，理解为什么有些无限集比另一些更大。
✓
模块 54 h
归纳与递归
递归地定义数、列表和树上的函数，并逐步计算它们的结果。在纸上和 Isabelle 中用归纳法证明一般命题，理解为什么 Isabelle 的 fun 需要终止性证明。
✓

第二部分 · 形式化证明

模块 63.7 h
什么是证明？自然演绎
了解什么样的论证构成可由机器检查的证明。学习各个联结词、两种量词和等号的自然演绎规则，手工构造推导，再像 Isabelle 一样从目标倒推。
✓
模块 74 h
在 Isabelle 中使用自然演绎
逐条应用规则，把模块 6 的纸上证明写成 Isabelle 证明脚本。读懂每一步的证明状态，并找出证明步骤失败的原因。
✓

第三部分 · Isabelle/HOL 实践

模块 83.5 h
HOL 中的函数式编程
把 Isabelle/HOL 用作带类型的函数式编程语言。定义数据类型和函数并用它们求值，读懂 Isabelle 输出的类型和消息，证明递归定义的终止性，再把可执行的定义导出为 Haskell 代码。
✓
模块 93.5 h
证明自动化
理解 Isabelle 的自动化工具如何工作。引导化简器，为逻辑、集合或算术选择证明方法，查找引理与反例，使用 Sledgehammer，并在自动化失败后继续推导。
✓
模块 103.7 h
用 Isar 编写结构化证明
写出读者能逐行理解、Isabelle 能逐步检查的证明。用 Isar 表达每一步，传递事实，用等式和不等式链推理，并把证明拆分为不同情形与归纳步骤。
✓
模块 113.7 h
深入学习归纳法
从失败的证明状态入手，判断该推广还是加强命题，找到缺少的引理。你将沿着函数本身的递归结构做归纳，对由规则定义的谓词证明性质，并为不同目标选用合适的归纳方式。
✓

第四部分 · 验证

模块 123.8 h
验证函数式程序
证明程序对每个输入都满足规约。你将验证插入排序、二叉搜索树和用两个列表实现的队列，理解规约中每个条件的作用，并把验证过的函数导出为 Haskell 代码。
✓
模块 133.8 h
系统建模：状态机与不变式
用状态机描述系统并在 Isabelle 中证明安全性质。定义状态、事件、守卫和效果，刻画可达状态，用不变式证明坏状态不可达。你还将加强无法归纳证明的不变式，把反例写成轨迹，并把抽象模型上已证明的性质传递到更具体的模型。
✓
模块 144 h
综合项目：验证编译器
在 Isabelle 中构建一个小型编译器，把算术表达式编译成栈机指令，先测试，再证明生成的代码对所有表达式都正确。接着验证一个优化过程，把编译器导出为 Haskell 代码，并加入减法、条件表达式和跳转。
✓

应用项目

Isabelle 模型验证承接模块 13和模块 14。你将以一个盖子模型为例，编写守卫条件，证明状态不变式，并验证表示之间的转换保持含义。项目提供交互式守卫演示、八道带解答的练习和 Isabelle2025-2 理论文件。
