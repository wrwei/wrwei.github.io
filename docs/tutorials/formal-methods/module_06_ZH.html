模块 6什么是证明？自然演绎

了解什么样的论证构成可由机器检查的证明。学习各个联结词、两种量词和等号的自然演绎规则，手工构造推导，再像 Isabelle 一样从目标倒推。

⏱ 220 分钟开始之前：模块 1–5，尤其是模块 2 和模块 3（真值表与 ⊨，量词与结构）

在本模块中，你将

  • 认出非形式化证明中的常见模式，并说出每种模式背后的规则
  • 解释 ⊢ 与 ⊨ 的区别，以及可靠性和完备性各保证了什么
  • 用 ∧、∨、⟶、¬、∀、∃ 和 = 构造自然演绎推导，并正确地解除假设
  • 检查量词规则的附加条件，并找出违反这些条件的证明中的错误
  • 分辨哪些证明需要经典推理（RAA），哪些不需要

你已经会的证明

A proof 通过有根据的步骤从明确假设中确立所陈述的主张，其效力取决于这些假设和所用规则。你之前可能已构建过此类论证，即便没有该名称。当你说服同事某个循环总是终止，或某个函数从不返回负数时，你提供了理由，且每个理由都基于前一个理由。

本节收集此类论证使用的模式。模块的其余部分将每种模式转化为精确规则，以便计算机可以检查每一步。模块 2 和 3 提供了公式及其含义；本模块发展模块 1 的一种检查方法：证明系统。

例 6.1取款永远不会让余额变成负数

断言。 对于数学整数 a 和 b，如果余额 b 至少为 0 且金额 a 至多为 b，则 b − a 至少为 0。此处的算术运算不存在机器整数溢出。

证明：假设 b ≥ 0 且 a ≤ b。在 a ≤ b 的两边同时减去 a，得到 0 ≤ b − a。∎

记号 ∎ 表示证明结束。这里用到了两种模式。要证明一个“如果……那么……”形式的陈述，证明先假设（assume）“如果”部分成立，再证明“那么”部分；这个假设只能在这段论证内部使用。而它所走的那一步，是由已知事实直接得出的，这里用的是一条算术定律。还要注意，假设 b ≥ 0 根本没有用到。证明可以不用某个假设；这时，断言在比所陈述的更一般的条件下也成立。

例 6.2最大值不小于它的第一个参数

断言：对所有整数 x 和 y，都有 max(x, y) ≥ x，其中 max 的定义是

max(x, y) = if x ≥ y then x else y

证明：要么 x ≥ y，要么 x < y。情形 x ≥ y：这时 max(x, y) = x，而 x ≥ x。情形 x < y：这时 max(x, y) = y，而 y > x。在两种情形下都有 max(x, y) ≥ x。∎

这就是情形分析（case analysis）：当你知道几种情形中必有一种成立时，就在每种情形下分别证明断言。这里的情形对应定义中的 if，这很典型：带分支的程序，通常需要一个分情形的证明。各种情形必须涵盖所有的可能。这里确实如此，因为对任意两个整数，要么 x ≥ y，要么 x < y。

例 6.3两个偶数之和是偶数

如果对某个整数 k 有 n = 2k，整数 n 就是偶数（even）。

断言：对所有整数 m 和 n，如果 m 和 n 都是偶数，那么 m + n 是偶数。

证明：设 m 和 n 是任意整数，并假设它们都是偶数。因为 m 是偶数，所以对某个整数 k 有 m = 2k。因为 n 是偶数，所以对某个整数 j 有 n = 2j。于是 m + n = 2k + 2j = 2(k + j)。所以对整数 i = k + j 有 m + n = 2i，即 m + n 是偶数。∎

这个简短的证明用到了三种模式，都与量词有关：

  • “设 m 和 n 是任意整数”：要证明某件事对所有整数都成立，就取任意的整数，除了断言所允许的之外，对它们不做任何假设，再对它们证明这件事。因为对它们没有做任何假设，这个论证对每一种选取都行得通。
  • “对某个整数 k 有 m = 2k”：要使用一个形如“存在 k 使得……”的事实，就给这个未知的值起一个名字，然后用它来推理，除了这个事实所说的，对它不做任何假设。
  • “对整数 i = k + j”：要证明一个形如“存在 i 使得……”的事实，就给出一个这样的值，即一个见证（witness），并检查它确实满足要求。
注意

给未知的值起的名字必须是新的。如果证明对第二个数也写“n = 2k”，重复使用 m 的那个 k，那就等于假设了 n 的一半与 m 的一半相同，也就是 n = m。这样的“证明”就只涵盖了 m + m 这种和。第 6.6 节会说明自然演绎怎样排除这种错误。

须知

单个观测到的故障可以确立关于该运行的存在性主张：“某些输入使此解析器崩溃”。它并未确立对未测试输入的行为。如 Module 1 所述，穷举检查可以覆盖一个小的有限域，但采样测试并未确立关于所有输入的无限制主张。

例 6.4不存在最大的自然数

断言：不存在最大的自然数。

证明：为了导出矛盾，假设存在一个最大的自然数，把它叫作 N。那么 N + 1 是自然数，并且 N + 1 > N，所以 N 不是最大的。这与 N 的选取相矛盾。所以不存在最大的自然数。∎

这就是反证法（proof by contradiction）：假设你想要的结论的反面，推出某种不可能的事情；那么这个假设一定是假的。这个论证依赖于 N + 1 是自然数这一点。对数学中的自然数，这是对的；对 64 位机器整数，这却是错的，因为最大值加一会溢出。证明的价值取决于它所用的事实，所以关于程序的证明，需要一个精确描述程序中的数的模型。

例 6.5如果 n² 是偶数，那么 n 是偶数

直接证明很别扭：从 n² = 2k 出发，怎样才能得出关于 n 的结论？不如改为证明它的逆否命题（contrapositive）：如果 n 不是偶数，那么 n² 不是偶数。

证明：设 n 是一个不是偶数的整数。那么 n 是奇数：对某个整数 k 有 n = 2k + 1。所以 n² = 4k² + 4k + 1 = 2(2k² + 2k) + 1，这是奇数，因而不是偶数。∎

蕴涵“如果 A，那么 B”和它的逆否命题“如果非 B，那么非 A”排除的是同一种情况：A 为真而 B 为假。证明了其中一个，也就证明了另一个。（从逆否命题回到原来的蕴涵需要经典逻辑，第 6.5 节会解释这一点。）

要点

表中的每种模式，要么是证明某种形状的陈述（蕴涵、“对所有”、“存在”），要么是使用这样的陈述（“或”、“存在”）。自然演绎（natural deduction）正是建立在这种划分之上的：每个联结词和量词都有引入规则（introduction rule），用来证明它；也有消去规则（elimination rule），用来使用它。

注意

非形式化证明中常见三种错误：

  • 检查示例而非证明。在 Module 1 中，double n = n * n 对 n = 0 和 n = 2 成立 当 n = 1 时失败。反例反驳全称命题；通过选定示例的测试使未测试的情况保持开放。在有限域中检查每个情况则不同。
  • 假设要证明的内容。将 A 作为未解除的前提并不在 该前提。证明规则使用并释放的临时假设是合法的；若将期望的结论保留在假设中，则构成循环论证，因为目标正是直接证明该结论。
  • 证明了逆命题。 要你证明“如果 A，那么 B”时，很容易不知不觉地去证明它的逆命题（converse）“如果 B，那么 A”。它们是不同的断言：“如果下过雨，街道就是湿的”不同于“如果街道是湿的，就下过雨”。

什么是证明系统

非形式化的证明依赖于读者。“同理”“由此可得”“不失一般性”这类说法，都是在请读者填补一个空缺，而不同的读者填补的方式不同，甚至会填错。要让机器检查证明，每一步都必须是某条事先确定的规则的一个实例，而检查一步不应需要任何洞察力。这样一组规则就是一个证明系统（proof system）。

先看一个与逻辑相去甚远的小例子。下面是关于形如 even n\mathit{even}\ neven n 的陈述的两条规则：

even 0  (ev0)even neven (n+2)  (ev2)\dfrac{}{\mathit{even}\ 0}\;(\mathrm{ev}_0) \qquad\qquad \dfrac{\mathit{even}\ n}{\mathit{even}\ (n+2)}\;(\mathrm{ev}_2) even 0​(ev0​)even (n+2)even n​(ev2​)

定义 6.1证明系统与推导

证明系统规定一种公式语言和一组推理规则（inference rule）。一条规则有零个或多个前提和一个结论；没有前提的规则是公理（axiom）。推导是一棵由公式组成的树，画的时候根在最下面。树中的每个公式，要么是一个假设（assumption），即上方没有横线的叶子，要么由紧挨在它上方的公式通过某条规则得出。根上的公式是这个推导的结论。

假设是不经证明、直接当作已知的公式：这时推导说明的是，如果假设成立，会得出什么。下面是同一个系统中的一个推导，最上面是一个假设：

even 1
ev₂
even 3
ev₂
even 5

它说明 even 5\mathit{even}\ 5even 5 可以由假设 even 1\mathit{even}\ 1even 1 得出。这个假设是假的，但推导是正确的：它说的是，如果 even 1\mathit{even}\ 1even 1 成立，会得出什么。

定义 6.2可推导性

Γ ⊢ A，读作“Γ 推导出 A”或“A 可由 Γ 推导”，表示存在一个推导，其结论为 A，且其所有开放（或未被消去）的假设均属于公式集 Γ（希腊大写字母 gamma）。该集合以列表形式书写：even 1 ⊢ even 5。⊢ A，左侧为空，表示 A 的推导没有任何假设；此时 A 是该证明系统的定理。

所以 ⊢ even 4\mathit{even}\ 4even 4⁠，并且 even 1\mathit{even}\ 1even 1 ⊢ even 5\mathit{even}\ 5even 5⁠。那么 even 3\mathit{even}\ 3even 3 呢？没有哪个不带假设的推导能得到它；下一节会说明，怎样不必尝试每一棵可能的树，就能确信这一点。

打个比方

编译器的类型检查器并不运行你的程序。它对照类型规则检查每个表达式：如果 e1 的类型是 int，e2 的类型也是 int，那么 e1 + e2 的类型是 int。证明检查器对推导也是这样工作的：它对照规则检查每一步的形状，而不检查公式是否为真。这就是证明助手的内核可以很小的原因（模块 1）：内核正是这样一种检查器。

逻辑有许多证明系统：具有多条公理和一条或两条规则的 Hilbert 风格系统、序列演算、语义表以及自动定理证明器使用的归结法。对于命题逻辑和一阶逻辑，可靠且完备的版本确立相同的推论；它们仅在便利性上有所不同。本模块使用 自然演绎，因为它紧密遵循第 6.1 节的非正式模式，并且 Isabelle 围绕它设计（模块 7）。

对于下述规则呈现，True（亦写作 ⊤）是 ¬⊥ 的缩写，A ⟷ B 是 (A ⟶ B) ∧ (B ⟶ A) 的缩写；在构建推导时展开这些缩写，此处未列出关于 True 或 ⟷ 的独立规则。完备性声明采用此约定及 Module 3 的非空论域。

可推导与为真

证明系统只是在摆弄符号。它不知道 even\mathit{even}even 是什么意思，也不知道 ∧ 是什么意思。公式的真假则是另一回事，它由模块 2 和模块 3 定义：一个赋值（valuation）使一个命题公式为真或为假；一个结构（structure）连同自由变元的取值，使一个一阶公式为真或为假。所以，关于公式集 Γ 和公式 A，有两个问题：

  • Γ ⊢ A：能否由 Γ 推导出 A？这是一个关于规则的问题（语法）。
  • Γ ⊨ A：在使 Γ 中所有公式都为真的每个赋值或每个结构中，A 是否都为真？这就是模块 2 中的逻辑推论（logical consequence），是一个关于含义的问题（语义）。

这是两个不同的问题。一个好的证明系统对这两个问题给出相同的答案。

定义 6.3可靠性与完备性

如果一个证明系统推导出的一切都是逻辑推论，即对所有 Γ 和 A，若 Γ ⊢ A 则 Γ ⊨ A，就说它是可靠的（sound）。如果它能推导出每一个逻辑推论，即对所有 Γ 和 A，若 Γ ⊨ A 则 Γ ⊢ A，就说它是完备的（complete）。

even 系统在小规模上展示了两个性质。赋予 even n 其自然含义“n 能被 2 整除”。该系统是 sound：(ev₀) 得出一个真命题，且 (ev₂) 将真命题转化为真命题，因为只要 n 能被 2 整除，n + 2 也能被 2 整除。推导有限次应用这些规则，因此其结论在 其开放假设成立时 为真（对推导进行归纳，如 Module 5 所示）。特别地，even 3 为假，因此它没有无假设的推导：soundness 在不尝试任何树的情况下回答了上一节的问题。对于无假设的命题，该系统也是 complete：每个真命题 even 2k 都有推导，其中使用一次 (ev₀) 和 k 次 (ev₂)。

如果这两个性质中有一个不成立，那意味着什么？

  • 一旦失去可靠性，推导就可能得到前提并不蕴涵的结论。假设在本 模块的规则中加入一条貌似合理的规则：从 A ∨ B 推出 A。（“请求来自管理员或访客，所以来自管理员。”）这样就有 A ∨ B ⊢ A，但 A ∨ B ⊭ A（读作“A ∨ B 不蕴涵 A”）：当 A 为假而 B 为真时，A ∨ B 为真而 A 为假。后果还不止于此。第 6.5 节对任意公式 A 推导出 A ∨ ¬A，利用这条新规则就会推出任意 A，包括始终为假的公式 ⊥。在不可靠的系统中，可推导性不再保证语义蕴涵。对证明辅助器来说，这是最严重的错误，所以模块 1 所述的 LCF 内核要保持小巧并接受仔细检查。
  • 如果完备性失败，则某些结论没有推导。一个系统可以是可靠的但不完备： 它仅推导前提的结论，但无法推导所有结论。搜索失败无法告知是运气不佳还是系统过于薄弱。第 6.5 节给出了一个示例：若缺少最后一条规则，自然演绎无法推导 A ∨ ¬A，尽管其真值表的每一行均为真。
事实 6.1自然演绎既可靠又完备

对命题逻辑和一阶逻辑，本模块的自然演绎系统（连同它的全部规则）既是可靠的，也是完备的：对每个公式集 Γ 和每个公式 A，Γ ⊢ A 当且仅当 Γ ⊨ A。

可靠性是常规的那一半：只需检查每条规则都把真的前提变成真的结论。解除假设的规则和量词规则需要多加小心，它们的附加条件（第 6.6 节）正是为了让这项检查能够通过。完备性则是一个深刻的定理。库尔特·哥德尔（Kurt Gödel）在 1929 年的博士论文中对一阶逻辑证明了它，他用的是另一个证明系统，但它推导出的公式与自然演绎相同。

由此得出的三点在实践中很重要。

  1. 反例可以证明推导不存在。 要证明不能从 Γ 推导出 A， 无需尝试所有推导。找到一个使 Γ 为真而 A 为假的赋值或结构。由可靠性可知，不存在这样的推导。Isabelle 中的 Quickcheck 和 Nitpick（模块 1–3）所做的正是这件事：一个确实满足前提的反例足以驳斥这些前提下的结论。若报告标记为可能不实，则需要进一步检查。
  2. 证明搜索可能成功，但并非总是失败。推导可以按大小依次列出， 且每个均可机械检查。遍历列表的程序最终将找到每个有效的一阶公式的推导。对于非有效公式，它可能永远搜索：一阶逻辑的有效性是不可判定的（Module 3），因此没有算法能对每个一阶公式始终终止并给出正确的是否答案。Isabelle 的 blast 等证明搜索工具接受这一点：它们搜索至某个界限后放弃。
  3. 哥德尔不完备定理涉及其他内容。 完备性关乎每个 结构；1931年的不完备性定理（Module 3）涉及单一结构中的真理性，即自然数：任何仅推导算术真语句的可机械检查的证明系统都无法推导所有真语句。Isabelle/HOL可以表达算术，因此其证明系统（如同所有机器可检查的系统一样）无法推导关于自然数的所有真语句。Isabelle保证的是可靠性（soundness），而当你信任一个定理时，你所依赖的正是可靠性。

自然演绎：联结词

格哈德·根岑（Gerhard Gentzen）在 1934/35 年提出了自然演绎，同一篇论文还提出了相继式演算；斯坦尼斯瓦夫·雅希科夫斯基（Stanisław Jaśkowski）在 1934 年独立发表了一个类似的系统。根岑想要一个像数学家那样推理的形式系统：先做出假设，再从假设得出结论。所以自然演绎没有关于联结词的公理。相反，你可以假设任何公式，而有些规则会解除（discharge）假设，这就是“假设 A……因此，如果 A，那么 B”的形式化版本。每个联结词都有引入规则，说明怎样证明以这个联结词为主的公式；也有消去规则，说明怎样使用这样的公式。

哪些规则适用于一个公式，取决于它的主联结词（main connective）：构造这个公式时最后用到的联结词，也就是位于其语法树（parse tree）根部的联结词。在 A ∧ B ⟶ B ∧ A 中，主联结词是 ⟶，因为 ∧ 结合得更紧（模块 2）。在下面的规则中，A、B 和 C 代表任意公式：一条规则适用于每个形状合适的公式。

用第 6.4 节的规则，你可以推导出许多重言式（tautology），但不是全部。试试 A ∨ ¬A，即排中律（law of excluded middle）：(∨I₁) 需要 A 的推导，(∨I₂) 需要 ¬A 的推导，而这两者你都没有。¬¬A ⟶ A 以及德摩根律中的一条 ¬(A ∧ B) ⟶ ¬A ∨ ¬B 也是如此。这三个公式都是重言式（可以检查它们的真值表），但用目前的规则，一个也推导不出来。再加一条规则就能补上这个缺口：

直觉主义逻辑

不带（RAA）的自然演绎是直觉主义逻辑。它源于二十世纪初 L. E. J. Brouwer 的观点，即证明必须构造其所讨论的内容；Arend Heyting 于 1930 年确立了其规则。基本直觉主义演算中的封闭证明具有析取性和见证性：A ∨ B 的证明产生其中一边的证明，∃x. P x 的证明产生一个见证。带有前提或额外公理时，提取此类证据也取决于这些前提所提供的证据；仅假设 A ∨ B 并不能告诉你哪一边成立。经典存在论证不必选择显式见证，如下例所示。

这个证明说明了合适的一对数是存在的，却没有说明它是两组候选中的哪一组。

须知

直觉主义证明可被读作程序：A ⟶ B 的证明是从 A 的证据到 B 的证据的函数，A ∧ B 的证明是一个对，A ∨ B 的证明是一个标记为 left 或 right 的值。A ∧ B ⟶ B ∧ A 的推导则是交换对的一个函数，而 (A ⟶ B) ⟶ (B ⟶ C) ⟶ (A ⟶ C) 的推导则是两个函数的组合。这就是 Curry–Howard correspondence，Rocq 和 Lean 等证明助手即建立于此。这些助手也支持经典推理；使用经典公理通常不提供相同的构造性提取保证。经典证明也有计算解释，例如使用延续（continuations），但 (RAA) 并不给出一个决定 A ∨ ¬A 哪一边成立的通用算法。对于任意计算命题的此类算法将决定停机问题。

Isabelle/HOL 是经典逻辑，与大多数数学一致：(RAA) 是其规则之一（Module 7）。然而，请注意证明何时使用 (RAA)：它可能在未选择特定情况或存在性见证的情况下确立主张。

量词规则

在 ∀ 和 ∃ 的规则中，P x代表任意一个公式，变元 x 可以在其中自由出现；P t 代表把其中每个自由出现的 x 都换成项（term）t 之后得到的公式。和模块 3 一样，必要时要给约束变元（bound variable）改名，使 t 中的变元不会被捕获（capture）。例如，如果 P x 是 x ≤ y，那么 P 3 是 3 ≤ y；如果 P x 是 ∃y. x < y，那么 P y 是 ∃z. y < z，而不是 ∃y. y < y。

  • (∃E)给见证命名。要用 ∃x. P x 来证明目标 C，就给见证起一个新名字 a，假设 P a，然后推导出 C；这条规则解除 [P a]。附加条件：a 不在 ∃x. P x 中、不在 C 中，也不在 C 的推导中除 [P a] 以外的任何未解除的假设中自由出现。C 不能提到 a，因为在这段论证之外，见证是未知的。

正是附加条件使 (∀I) 和 (∃E) 成为可靠的规则。上面两个错误的结论在一个有两个元素的结构中都为假，所以它们没有正确的推导，而错误的推导恰恰是在附加条件上出的错。手工检查推导时，先检查每个本征变元。

寻找证明：反向与正向

检查推导是机械的；寻找推导则需要搜索。搜索有两个方向。

正向：从假设出发，不断应用规则，直到目标出现。关于 even\mathit{even}even 的系统就是这样得到 even 4\mathit{even}\ 4even 4 的。它的弱点是，规则能推导出无穷无尽的公式（单是 (∧I) 就能造出 A ∧ A、A ∧ (A ∧ A)……），却没有什么能告诉你其中哪些通向目标。

反向：从目标出发。选一条结论与目标相匹配的规则；规则的前提成为新的目标，叫作子目标（subgoal），而规则所解除的假设可以在这些子目标中使用。重复这样做，直到剩下的每个目标都是它自己的假设之一。目标引导着搜索：它的主联结词决定用哪条引入规则，它的假设则提示可以用哪些消去规则。Isabelle 就是这样工作的。它的证明状态（proof state）是一个目标列表，每个目标都带着自己的假设；每一步证明都把一个目标换成某条规则的子目标（模块 7）。

把一个目标写成 Γ ⊢ C：Γ 列出它的假设，C 是还有待证明的东西。下面一步一步地为 A ∨ B ⟶ B ∨ A 搜索推导（图 6.3）：

  1. ⊢ A ∨ B ⟶ B ∨ A。主联结词是 ⟶，所以应用 (⟶I¹)。新的目标是 A ∨ B ⊢ B ∨ A。
  2. A ∨ B ⊢ B ∨ A。有两类规则适用。对目标应用 (∨I₁) 会留下 A ∨ B ⊢ B，而当 A 为真、B 为假时它不成立：这是一条死路（dead end）。对假设 A ∨ B 应用 (∨E²) 会留下两个目标 A ⊢ B ∨ A 和 B ⊢ B ∨ A，两个都必须证明。
  3. A ⊢ B ∨ A。应用 (∨I₂) 留下 A ⊢ A，这个目标就是它自己的假设之一：它被关闭了。
  4. B ⊢ B ∨ A。应用 (∨I₁) 留下 B ⊢ B：关闭。

没有剩下的目标了。把这些步骤从最后一步倒着读回第一步，就得到第 6.4 节中的那个推导。

反向工作时，消去规则作用于目标的某个假设：

  • 已有 A ∧ B 时，(∧E₁) 和 (∧E₂) 把 A 或 B 加入假设。
  • 已有 A ∨ B 时，(∨E) 把目标一分为二，一个以 A 为新假设，一个以 B 为新假设。
  • 有假设 A ⟶ B 时，(⟶E) 把目标 B 变成目标 A。
  • 有假设 ¬A 时，(¬E) 把目标 ⊥ 变成目标 A。
  • 已有 ∀x. P x 时，(∀E) 加入 P t，其中 t 是你选择的项。
  • 已有 ∃x. P x 时，(∃E) 加入 P a，其中 a 是一个新名字。

有些步骤永远不会出错；另一些则是在打赌。

定义 6.6安全的步骤

如果反向搜索中的一步永远不会把一个可证的目标变成不可证的目标，即只要目标能被证明，所有子目标也都能被证明，这一步就是安全的（safe）。不安全的步骤可能把你带进死路，那时你必须退回去，换一种做法。

(⟶I)、(¬I)、(∧I) 和 (∀I) 对目标而言是安全的，而 (∧E₁)、(∧E₂)、(∨E) 和 (∃E) 对假设而言也是安全的。如步骤 2 所示，(∨I₁) 和 (∨I₂) 并非如此，(∃I) 亦非，因为其见证者可能是错误的，(⊥E) 亦非，因为它将目标替换为 ⊥。Isabelle 的参考手册为自动证明器做出了相同的区分：安全规则“绝不能将可证明的目标归约为不可证明的子目标集合”。

保留全称假设并添加其一个实例同样保持可证性。然而，存在无限多个可能的实例，因此不加选择地尝试它们会阻碍搜索的进展。保持可证性本身并不能保证搜索终止。

经验法则如下：

  1. 如果一个目标是它自己的假设之一，就关闭它。
  2. 对目标应用安全的引入规则：(⟶I)、(¬I)、(∧I)，以及带新名字的 (∀I)。
  3. 对假设应用安全的消去规则：拆开 A ∧ B，按 A ∨ B 分情形，用一个新名字打开 ∃x. P x。
  4. 然后再做选择，并随时准备退回。如果某个假设 A ⟶ B 的结论恰好是目标，就用 (⟶E) 使用它。用 (∀E) 以一个已经出现过的项实例化 ∀x. P x。对于目标 ∃x. P x，用 (∃I) 选一个你已经有的见证。对于目标 A ∨ B，用 (∨I₁) 或 (∨I₂) 选择能从假设得出的那一边。
  5. 如果目标是 ⊥，就找一个假设 ¬A，试着用 (¬E) 去证明 A。如果目标是别的公式，而假设之间相互矛盾，就用 (⊥E) 把目标变成 ⊥。
  6. 如果卡住了，就用 (RAA)：假设目标的否定，然后以 ⊥ 为目标。像 A ∨ ¬A 这样两边都无法单独证明的目标 A ∨ B，就需要这样做。

对量词来说，第 3 步和第 4 步的顺序很重要：先打开存在量词的假设，让它们的见证有名字，再用这些名字实例化全称量词的假设。在万能钥匙的推导中，(∃E²) 把万能钥匙命名为 a，然后 (∃I) 用 a 作为它的见证。

在逆命题 (∀y. ∃x. R x y) ⟶ (∃x. ∀y. R x y) 上试试这个策略。用了 (⟶I) 之后，目标 ∃x. ∀y. R x y 没有可用的安全规则，假设也没有，所以你必须做出选择。用某个名字 c 实例化假设，再打开得到的结果：对一把新钥匙 a 有 R a c。取 a 作为见证：目标变成 ∀y. R a y，而 (∀I) 需要一扇新的门，它不能是 c，因为 c 出现在假设中。所以它是一扇新门 d，而目标 R a d 遥不可及：你知道的只是 R a c。用 d 实例化假设会得到 d 的一把钥匙，但 (∃E) 必须给它起一个新名字，不能叫 a。每一扇新门都带来一把新钥匙，搜索永远无法结束。这并非偶然：这个公式不是有效的，所以由可靠性，每一次搜索都必定失败。

相等

相等有两条规则：一条用来证明等式，一条用来使用等式。

t=t  (=I)s=tP sP t  (=E)\dfrac{}{t = t}\;(\mathord{=}\mathrm{I}) \qquad\qquad \dfrac{s = t \qquad P\,s}{P\,t}\;(\mathord{=}\mathrm{E}) t=t​(=I)Pts=tPs​(=E)

(=I) 即自反性（reflexivity），它没有前提：每个项都等于它自己。(=E) 即代入（substitution），它说：如果 s = t，那么对 s 成立的任何事情对 t 也成立，也就是说，可以用相等的东西替换相等的东西。和量词规则中一样，P x 是一个 x 在其中自由出现的公式，P s 和 P t 是把其中的 x 分别换成 s 和 t 得到的公式。通过选择 x 在 P x 中的位置，你可以选择替换哪些出现。

由此可以推出相等的对称性：

[s = t]¹
=I
s = s
=E
t = s
⟶I¹
s = t ⟶ t = s

这里 P x 是 x = s。于是 P s 是 s = s，由 (=I) 提供；P t 是 t = s，即结论。传递性也可以推出：

r = t
⟶I²

这一次 P x 是 r = x：由 s = t 和 P s（即 r = s），得出 P t（即 r = t）。

第三个推论对程序员很重要。对一个函数符号 f：

[s = t]¹
=I

=E

⟶I¹

这里 P x 是 f s = f x：函数对相等的参数给出相等的结果。在程序中，这只对纯函数（pure function）成立，即结果只取决于参数的函数；对读取时钟的方法就不成立。一个复用 f(s) 的值、而不再次调用 f 的编译器，依赖的就是这条定律，所以它必须先确认 f 是纯函数。Isabelle/HOL 中的函数是数学意义上的函数，所以在那里这条定律总是成立。

注意

从纸面到 Isabelle

Isabelle 自带的 Isabelle/HOL 教程说，Isabelle“是围绕自然演绎设计的”。模块 7 会在 Isabelle 中一条规则一条规则地重现本模块的推导；在这里，先让证明搜索来完成工作。blast（模块 2 和模块 3）是 Isabelle 中针对这类目标的证明搜索工具。它的参考手册把它描述为一个表列证明器（tableau prover），它使用 Isabelle 的经典规则，这些规则像第 6.7 节那样分为安全的和不安全的两类；它找到的证明会用 Isabelle 的规则重新构造出来，并由内核检查。把下面这些引理加到一个理论中，例如模块 1 中的那个理论：

Isabelle
lemma "A ∧ B ⟶ B ∧ A"
  by blast

lemma "(A ⟶ B) ⟶ (B ⟶ C) ⟶ (A ⟶ C)"
  by blast

lemma "A ∨ B ⟶ B ∨ A"
  by blast

lemma "¬(A ∨ B) ⟶ ¬A ∧ ¬B"
  by blast

Isabelle 接受了全部四条引理：没有出现任何错误。Isabelle/HOL 是经典的，所以第 6.5 节的公式也都是定理：

Isabelle
lemma "¬¬A ⟶ A"
  by blast

lemma "A ∨ ¬A"
  by blast

lemma "¬(A ∧ B) ⟶ ¬A ∨ ¬B"
  by blast

量词的例子也是一样。给关系起一个比 R 更能说明含义的名字，再用 k 和 d 表示钥匙和门，万能钥匙引理就写成：

Isabelle
lemma "(∀x. P x ∧ Q x) ⟶ (∀x. P x) ∧ (∀x. Q x)"
  by blast

lemma "(∃k. ∀d. opens k d) ⟶ (∀d. ∃k. opens k d)"
  by blast

和模块 3 中一样，自由变元 P、Q 和 opens 不需要声明：Isabelle 会推断它们的类型，并把它们看作代表任意的谓词。逆命题则失败了：

Isabelle故意出错的例子
lemma "(∀d. ∃k. opens k d) ⟶ (∃k. ∀d. opens k d)"
  by blast
输出
Failed to apply initial proof method⌂:
goal (1 subgoal):
 1. (∀d. ∃k. opens k d) ⟶ (∃k. ∀d. opens k d)

blast 放弃了，Isabelle 报告“Failed to apply initial proof method”（未能应用初始的证明方法）。单凭这一点什么也证明不了：blast 只搜索到某个界限为止（它的参考手册说，它先不允许任何不安全的步骤，然后允许一步，依此类推，直到 20 步，然后停止），更聪明的搜索也许能成功。反例才能解决这个问题。在 Isabelle/jEdit 中，Auto Quickcheck（模块 1）可能已经给这条引理标出了一个反例；Nitpick 则能给出更清楚的图景：

Isabelle
lemma "(∀d. ∃k. opens k d) ⟶ (∃k. ∀d. opens k d)"
  nitpick [card = 2]
  oops
输出
Nitpicking formula...

Nitpick found a counterexample for card 'a = 2 and card 'b = 2:
  Free variable:
    opens =
      (λx. _)
      (b1 := (λx. _)(a1 := False, a2 := True),
         b2 := (λx. _)(a1 := True, a2 := False))
  Skolem constants:
    λk. d = (λx. _)(b1 := a1, b2 := a2)
    λd. k = (λx. _)(a1 := b2, a2 := b1)

Isabelle 推断出了两个类型，一个是钥匙的类型，一个是门的类型；Nitpick 在每个类型中考察了两个元素：钥匙 b₁ 和 b₂，门 a₁ 和 a₂。它给出的 opens 的值是一张由表组成的表：钥匙 b₁ 能打开门 a₂，打不开 a₁；钥匙 b₂ 能打开门 a₁，打不开 a₂。所以每扇门都有钥匙，却没有哪把钥匙能同时打开两扇门。Skolem constants（Skolem 常量）这一部分给出了反例背后的选择：λk. d 对每把钥匙 k 给出一扇它打不开的门 d，λd. k 对每扇门 d 给出能打开它的钥匙 k。钥匙是门的函数，这正是这个例子的要点：在 ∀d. ∃k 中，钥匙可以依赖于门。由可靠性，这条引理不存在证明。

最后，相等也在 Isabelle 的规则集中：

Isabelle
lemma "s = t ⟶ t = s"
  by blast
要点

在纸面和 Isabelle 中，你使用相同的两个工具：推导建立 ⊢，反例反驳 ⊨。可靠性将它们联系起来。对于普通的已完成 Isabelle 证明，逻辑步骤已通过内核操作进行检查。这仍然相对于 Module 1 中讨论的公理、假设和可信基础设施；被承认的证明或预言机结果并非相同的证据。

小结

  • 证明是一串步骤，每一步都以一条规则为依据。非形式化的证明遵循几种模式：假设前提、情形分析、反证、逆否命题、任意元素、见证，以及给见证命名。
  • 证明系统由推理规则组成；推导是一棵由规则应用构成的树。Γ ⊢ A 的意思是 A 有一个推导，其中未解除的假设都在 Γ 中；检查推导是机械的。
  • Γ ⊨ A关于真值。Soundness（⊢ 蕴含 ⊨）意味着真前提仅导致真结论； 完备性（⊨ 蕴涵 ⊢）意味着每个语义后承都可推导。命题逻辑和一阶逻辑的自然演绎都兼具这两种性质。反例表明推导不存在。
  • 自然演绎有引入规则和消去规则，前者用来证明带某个联结词的公式，后者用来使用这样的公式：(∧I)、(∧E₁)、(∧E₂)、(∨I₁)、(∨I₂)、(∨E)、(⟶I)、(⟶E)、(¬I)、(¬E) 和 (⊥E)。(⟶I) 这样的规则会解除假设，被解除的假设写作 [A]¹；它只能在解除它的规则之上使用。
  • (RAA)使这个系统成为经典的：A ∨ ¬A、¬¬A ⟶ A 和 ¬(A ∧ B) ⟶ ¬A ∨ ¬B 都需要它。没有它，逻辑就是直觉主义的，它的证明可以读作程序。
  • 量词规则 (∀I)、(∀E)、(∃I)、(∃E) 对应于非形式化的模式。(∀I) 和 (∃E) 的本征变元必须是新的；大多数错误的量词证明都违反了这个条件。
  • 相等有两条规则：(=I) 即自反性，(=E) 即用相等的东西替换相等的东西。
  • 反向搜索从目标出发，把它换成子目标，Isabelle 就是这样做的。先应用安全的规则，再做选择，卡住时用 (RAA)。blast 就是这样搜索的；Nitpick 则寻找反例。

练习 6.1★说出模式

下面每个论证都用到了第 6.1 节中的一种或两种模式。说出它们的名称，以及每种模式背后的自然演绎规则。

  1. “如果门锁上了，警报就处于戒备状态。门锁上了。所以警报处于戒备状态。”
  2. “设 u 是任意一个用户。每个用户都有密码，所以 u 有密码；每个密码都以哈希形式存储，所以 u 的密码也是。因为 u 是任意的，所以每个用户的密码都以哈希形式存储。”
  3. “一个事务要么提交，要么中止。如果它提交了，日志会记录下来；如果它中止了，日志会记录这次中止。无论哪种情况，日志中都有这个事务的一条记录。”
  4. “假设某个进程同时持有两把锁；把它叫作 p。那么 p 在持有第一把锁的同时获取了第二把锁，而锁管理器从不允许这样做。所以没有进程同时持有两把锁。”
  5. “对输入 [3, 1, 2]，这个函数返回 [1, 3, 2]，它不是有序的。所以这个函数对某个输入是错的。”
查看解答
  1. 一个直接的步骤，即肯定前件式：由 A ⟶ B 和 A 得出 B。规则 (⟶E)。
  2. 任意元素：先通过 (∀E) 使用关于所有用户和所有密码的两个一般性事实，再对 u 应用 (∀I)。本征变元条件成立：所用的事实都没有提到 u。
  3. 情形分析：对“提交或中止”应用 (∨E)，在每种情形中再用 (⟶E)。
  4. 用反证来证明一个否定的陈述，即 (¬I)：假设某个进程同时持有两把锁，然后推出不可能的事情。在这个论证内部还有给见证命名：“把它叫作 p”就是 (∃E)。
  5. 见证：输入 [3, 1, 2] 是“存在一个使函数出错的输入”的见证，规则 (∃I)。一个测试就能证明一个存在性的断言。
练习 6.2★可靠、完备，还是都不是？
  1. 一个命题逻辑的证明系统包含第 6.4 节的全部规则，外加一条：由 A ⟶ B 和 B 得出 A。它是可靠的吗？用一个赋值来说明你的理由。
  2. 另一个系统只有 (∧I)、(∧E₁) 和 (∧E₂) 三条规则。它是可靠的吗？对命题逻辑来说，它是完备的吗？
  3. 对一阶公式 A 搜索了一个小时仍未找到推导。此时能对 A 作出什么判断？
  4. Nitpick 找到 A 的一个真实反例。在相同假设下，关于 ⊢ A 你知道什么？
查看解答
  1. 不可靠。 新规则由 A ⟶ B 和 B 推导出 A。A 为假、B 为真的赋值使两个前提都为真（A ⟶ B 为真，因为 A 为假），而使结论 A 为假，所以 A ⟶ B, B ⊭ A。用话来说：“如果下过雨，街道就是湿的；街道是湿的；所以下过雨”不是一个有效的论证。
  2. 可靠，因为每条规则都把真的前提变成真的结论。不完备：不带假设时，它什么也推导不出来，因为每条规则都需要前提，所以它漏掉了每一个重言式，例如 A ⟶ A。即使有假设，它也只能把合取式拆开、再拼起来：A ∧ B ⊨ A ∨ B，但没有任何推导能得到含 ∨ 的公式。
  3. 什么也不知道。 这个公式可能是有效的，只是搜索很慢；也可能不是有效的。一阶逻辑的有效性是不可判定的，所以没有哪种搜索总能分辨出来。去找一个反例：如果有反例，A 就是不可推导的。
  4. A 没有推导：由可靠性，⊢ A 会蕴涵 ⊨ A，而反例表明 A 并非在每个结构中都为真。别再试图证明 A 了，应该去修正这个陈述。

    ∀E
    P a
    ∃I
    ∃x. P x
    ⟶I¹
    (∀x. P x) ⟶ (∃x. P x)

  2. 见证是一个在其他地方未出现的名称 a。 (∀E) 允许任何项，(∃I) 接受任何项作为 witness。无需特定命名常量：自由变元 a 表示赋值下的任意元素，依赖于域非空的约定。

  3. 这个公式是有效的，因为每个结构的论域都至少有一个元素，而规则内含了这一点：任何名字都可以充当见证。在空论域中，∀x. P x 会为真，因为没有什么需要检查；∃x. P x 会为假，因为什么也找不到。一阶逻辑排除了空论域，所以这个推导是可靠的。

  4. Isabelle 的类型也从来不是空的。Isabelle/HOL 教程解释了原因：否则“量词规则就会是不可靠的，因为 ∃x. x = x 是一个定理”。所以 blast 能证明这个公式：

    Isabelle
    lemma "(∀x. P x) ⟶ (∃x. P x)"
  by blast

自测题

1
⊢ A ∧ B ⟶ B ∧ A 说的是什么？
⊢ 讲的是推导：一棵由规则应用构成的树，它未解除的假设都在 ⊢ 的左边，这里一个也没有。在每个赋值下都为真，说的是 ⊨；可靠性和完备性表明两者是一致的。
2
一个证明系统是可靠的，如果……
Soundness 是“⊢ 蕴含 ⊨”：每当前提为真时，结论为真。推导可能具有假开放假设；Soundness 不断言这些假设。第二个选项是 Completeness。
3
在一个推导中，(⟶I¹) 得出 A ⟶ B。假设 [A]¹ 会怎样？
解除把假设移进了结论。它的辖域是推导中位于解除它的规则之上的那一部分。
4
哪个公式没有 (RAA) 就推导不出来？
双重否定消去属于经典逻辑。另外三个公式在第 6.4、6.5 节和练习 6.5 中都有不用 (RAA) 的推导。
5
这一步为什么是错的：由未解除的假设 P a，用 (∀I) 得出 ∀x. P x？
这是 (∀I) 的本征变元条件：a 不能在任何未解除的假设中自由出现。在这里，正是假设 P a 使 a 变得特殊。
6
反向搜索到达了目标 A ∨ B ⊢ B ∨ A。哪一步是安全的？
(∨E) 永远不会丢失可证性。(∨I₁)、(∨I₂) 和 (⊥E) 则可能丢失：A ∨ B ⊢ B、A ∨ B ⊢ A 和 A ∨ B ⊢ ⊥ 都不可证，尽管原来的目标是可证的。
