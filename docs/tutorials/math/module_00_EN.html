Fractions signs and operation order

A fraction p/qp/qp/q describes division by a nonzero denominator. Multiplying its numerator and denominator by the same nonzero value preserves the ratio: 1/2=2/41/2=2/41/2=2/4. To add fractions, express them using the same denominator; adding denominators does not perform the required operation.

Ratios percentages and scientific notation

A percentage is a ratio per hundred. Twenty-five percent is 25/100=1/425/100=1/425/100=1/4. A percentage change compares a difference with the chosen starting value: increasing from eighty to one hundred gives (100−80)/80=25%(100-80)/80=25\%(100−80)/80=25%, while falling from one hundred to eighty is a 20%20\%20% decrease. The different denominators explain the difference.

Ratios need units and a reference. Three milliseconds per request multiplied by ten requests gives thirty milliseconds under a simple additive timing model. The same arithmetic does not establish a concurrent system’s elapsed time; the model tells us when adding durations is appropriate.

Thus 0.00032=3.2×10−40.00032=3.2\times10^{-4}0.00032=3.2×10−4 and 45000=4.5×10445000=4.5\times10^445000=4.5×104. When multiplying, multiply the leading factors and add the powers: (2×103)(3×10−2)=6×101=60(2\times10^3)(3\times10^{-2})=6\times10^1=60(2×103)(3×10−2)=6×101=60. This keeps small and large scales readable.

Equations inequalities and reversible operations

Solving an equation means finding values that make both sides equal. Apply the same reversible operation to both sides to preserve its solutions. Adding or subtracting a fixed value is reversible. Multiplying or dividing by a nonzero fixed value is reversible. Dividing by an expression that might be zero needs a separate case; otherwise you may discard a valid solution.

Worked example
Solve and check a linear equation

From 3x+5=173x+5=173x+5=17, subtract five to get 3x=123x=123x=12, then divide by three to get x=4x=4x=4. Substitute into the original: 3(4)+5=173(4)+5=173(4)+5=17. Checking the original equation catches transcription and arithmetic errors.

For inequalities, adding the same value preserves the comparison direction. Multiplying or dividing by a positive value also preserves it, but a negative value reverses it. From −2x<6-2x<6−2x<6, division by −2-2−2 gives x>−3x>-3x>−3. Check one included value such as zero, and the excluded boundary −3-3−3.

Squaring is not reversible on all reals: both two and minus two square to four. If a rearrangement squares both sides, verify any candidate in the original equation. For example, x=x−2\sqrt{x}=x-2x​=x−2 requires both x≥0x\ge0x≥0 and x−2≥0x-2\ge0x−2≥0; squaring alone can produce a candidate that violates these restrictions.

Coordinates slopes and reading graphs

An ordered pair (x,y)(x,y)(x,y) names a point: horizontal coordinate first, vertical second. A function graph places (x,f(x))(x,f(x))(x,f(x)) for allowed inputs. To read a value, find the input on the horizontal axis and follow to the curve, then read the vertical coordinate. Check the axis units and displayed range before interpreting a shape.
