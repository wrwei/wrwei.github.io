How to study

Predict before calculating. State the domain, show intermediate steps, and explain why an answer is valid. Modules 01–30 combine worked examples, three runnable labs, exercises with complete solutions, an interactive explorer and a ten-question review. The capstones provide implemented reference projects, proof obligations, actual outputs and assessment rubrics. Progress and written reviews are saved in this browser.
