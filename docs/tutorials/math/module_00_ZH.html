分数 符号与运算次序

分数 p/qp/qp/q 表示除以非零分母。分子与分母乘相同非零值，比例不变：1/2=2/41/2=2/41/2=2/4。相加前应统一分母；把分母直接相加不是正确操作。

例题详解
通分后相减

3/4−2/3=9/12−8/12=1/123/4-2/3=9/12-8/12=1/123/4−2/3=9/12−8/12=1/12。十二能同时被四和三整除，因此可作为公分母。检查符号：0.750.750.75 大于约 0.6670.6670.667，结果应小而为正。

乘法为 (p/q)(r/s)=pr/(qs)(p/q)(r/s)=pr/(qs)(p/q)(r/s)=pr/(qs)。除以非零分数等于乘倒数：(3/4)/(2/3)=(3/4)(3/2)=9/8(3/4)/(2/3)=(3/4)(3/2)=9/8(3/4)/(2/3)=(3/4)(3/2)=9/8。除数不能为零。只能约去乘积中的共同因子，不应约去和中的项：当 y≠0y\ne0y=0 时，(2x)/(2y)=x/y(2x)/(2y)=x/y(2x)/(2y)=x/y，但 (x+2)/(y+2)(x+2)/(y+2)(x+2)/(y+2) 通常不能化成 x/yx/yx/y。

负数的相反数为正，减去负数等于加上相应正值：5−(−2)=75-(-2)=75−(−2)=7。括号决定负号是否属于被平方的底数：−32=−9-3^2=-9−32=−9，(−3)2=9(-3)^2=9(−3)2=9。先括号、后乘方、再乘除、最后加减；同优先级运算按适用顺序处理，有歧义时增加括号。

检验理解

计算 1/2+1/31/2+1/31/2+1/3 与 2−(−4)2-(-4)2−(−4)。为什么 (x+2)/2=x/2+1(x+2)/2=x/2+1(x+2)/2=x/2+1 而不是 xxx？

查看答案

结果为 5/65/65/6 与 666。分子各项都除以二，得到 x/2+2/2=x/2+1x/2+2/2=x/2+1x/2+2/2=x/2+1。分子是和，直接删去二不能保留含义。

比例 百分比与科学计数法

百分比是以一百为基准的比率，25/100=1/425/100=1/425/100=1/4。百分比变化把差值与选定起始值比较：从八十增加到一百为 (100−80)/80=25%(100-80)/80=25\%(100−80)/80=25%，从一百降低到八十为 20%20\%20%。分母不同解释了变化率不同。

比率需要单位与参照。在简单可加时间模型中，每请求三毫秒、十个请求共三十毫秒。但这不能自动证明并发系统的总耗时；模型决定何时允许相加。

科学计数法写为 a×10ka\times10^ka×10k，通常要求 1≤∣a∣<101\le|a|<101≤∣a∣<10。0.00032=3.2×10−40.00032=3.2\times10^{-4}0.00032=3.2×10−4，45000=4.5×10445000=4.5\times10^445000=4.5×104。相乘时乘前导系数、加指数：(2×103)(3×10−2)=6×101=60(2\times10^3)(3\times10^{-2})=6\times10^1=60(2×103)(3×10−2)=6×101=60。这种写法保持极大与极小尺度清晰。

检验理解

将 0.00450.00450.0045 写成科学计数法。数值从五十增至六十，百分比增加多少？

查看答案

4.5×10−34.5\times10^{-3}4.5×10−3；(60−50)/50=0.2=20%(60-50)/50=0.2=20\%(60−50)/50=0.2=20%。必须说明作为分母的原始参照值。

方程 不等式与可逆操作

解方程是寻找使两边相等的值。两边执行相同可逆操作，才能保持解集。加减固定数可逆，乘除固定非零数也可逆。若除以可能为零的表达式，需要单独讨论，否则可能丢掉有效解。

例题详解
解线性方程并代回检查

3x+5=173x+5=173x+5=17 两边减五得到 3x=123x=123x=12，再除三得到 x=4x=4x=4。代回原式：3(4)+5=173(4)+5=173(4)+5=17。检查原方程能发现抄写与算术错误。

不等式两边加相同数不改变方向；乘除正数也不改变方向，乘除负数则反向。由 −2x<6-2x<6−2x<6 除以 −2-2−2 得 x>−3x>-3x>−3。可检查包含的零与排除的边界 −3-3−3。

平方在全部实数上不可逆，因为二与负二都平方为四。若整理过程中平方两边，必须把候选值代回原式。例如 x=x−2\sqrt{x}=x-2x​=x−2 要求 x≥0x\ge0x≥0 且 x−2≥0x-2\ge0x−2≥0；只平方可能产生违反限制的候选值。

检验理解

解 2x−7=52x-7=52x−7=5 与 −3x≥9-3x\ge9−3x≥9。为什么 x(x−1)=0x(x-1)=0x(x−1)=0 不能直接除以 xxx？

查看答案

x=6x=6x=6；x≤−3x\le-3x≤−3。原乘积方程允许 x=0x=0x=0，除以它会丢掉有效解。完整解集为 {0,1}\{0,1\}{0,1}。

分配律为 a(b+c)=ab+aca(b+c)=ab+aca(b+c)=ab+ac。逐项应用得 (x+2)(x−3)=x2−3x+2x−6=x2−x−6(x+2)(x-3)=x^2-3x+2x-6=x^2-x-6(x+2)(x−3)=x2−3x+2x−6=x2−x−6。只合并同类项；xxx 与 x2x^2x2 表示不同次幂，不能变成一个 xxx 的系数。

因式分解逆转展开。3x+6=3(x+2)3x+6=3(x+2)3x+6=3(x+2) 提取公因子；x2−x−6=(x−3)(x+2)x^2-x-6=(x-3)(x+2)x2−x−6=(x−3)(x+2)，因为负三与二的和为负一、积为负六。展开因式分解结果来检查。

实数乘积为零时，至少一因子为零，因此 (x−3)(x+2)=0(x-3)(x+2)=0(x−3)(x+2)=0 得 x=3x=3x=3 或 x=−2x=-2x=−2。分式仅在因子不为零时允许约去。(x2−1)/(x−1)(x^2-1)/(x-1)(x2−1)/(x−1) 在 x≠1x\ne1x=1 时等于 x+1x+1x+1；一处仍未定义，除非明确另定义一个新函数。

检验理解

展开 (x+1)2(x+1)^2(x+1)2，并用代数与 x=1x=1x=1 解释为何不是 x2+1x^2+1x2+1。

查看答案

乘方 对数与三角函数预览

非零 aaa 满足 a0=1a^0=1a0=1、a−k=1/aka^{-k}=1/a^ka−k=1/ak。正底数满足 aras=ar+sa^r a^s=a^{r+s}aras=ar+s 与 (ar)s=ars(a^r)^s=a^{rs}(ar)s=ars。区分 x2x^2x2 与 2x2^x2x：变量角色不同。实平方根要求非负输入，根号表示非负平方根；因此 9=3\sqrt9=39​=3，但方程 x2=9x^2=9x2=9 有两个解。

当 a>0a>0a>0、a≠1a\ne1a=1、x>0x>0x>0 时，log⁡ax\log_a xloga​x 是使底数 aaa 产生 xxx 的指数。因为 23=82^3=823=8，所以 log⁡28=3\log_2 8=3log2​8=3；2x=82^x=82x=8 的解为 x=3x=3x=3。对数把正数乘积转成和，不普遍分配到加法上。模块 01 将详细解释定义域和恒等式。

三角函数为后续几何与微积分作预览。弧度是弧长与半径的比；半周为 π\piπ 弧度，即 180180180 度。单位圆上角度 θ\thetaθ 的坐标为 (cos⁡θ,sin⁡θ)(\cos\theta,\sin\theta)(cosθ,sinθ)，满足 cos⁡2θ+sin⁡2θ=1\cos^2\theta+\sin^2\theta=1cos2θ+sin2θ=1。零角度对应 (1,0)(1,0)(1,0)，π/2\pi/2π/2 对应 (0,1)(0,1)(0,1)。Python 标准三角函数使用弧度；模块 01 的实验不要求三角计算。

坐标 斜率与图像阅读

有序对 (x,y)(x,y)(x,y) 表示一个点，先水平后垂直坐标。函数图在允许输入上放置 (x,f(x))(x,f(x))(x,f(x))。读值时，先在水平轴找输入，沿曲线读垂直值。解释形状之前检查坐标单位与显示范围。

当横坐标不同，两点 (x1,y1)(x_1,y_1)(x1​,y1​)、(x2,y2)(x_2,y_2)(x2​,y2​) 间斜率为 (y2−y1)/(x2−x1)(y_2-y_1)/(x_2-x_1)(y2​−y1​)/(x2​−x1​)。(1,2)(1,2)(1,2) 与 (3,6)(3,6)(3,6) 给出 (6−2)/(3−1)=2(6-2)/(3-1)=2(6−2)/(3−1)=2，相应直线为 y=2xy=2xy=2x。y=2x+1y=2x+1y=2x+1 斜率仍为二，但纵截距为一。

画直线可先计算两三个点。y=2x+1y=2x+1y=2x+1 使用 (0,1),(1,3),(2,5)(0,1),(1,3),(2,5)(0,1),(1,3),(2,5)；平方使用 (−2,4),(−1,1),(0,0),(1,1),(2,4)(-2,4),(-1,1),(0,0),(1,1),(2,4)(−2,4),(−1,1),(0,0),(1,1),(2,4)。平方图弯曲，只用两点直线连接会误表示。垂直直线的横坐标差为零，因此本公式不给出有限斜率。

检验理解

求 (0,1)(0,1)(0,1) 与 (2,5)(2,5)(2,5) 间的斜率。若某一轴从米改为厘米，数值斜率会改变吗？

查看答案

斜率为 (5−1)/(2−0)=2(5-1)/(2-0)=2(5−1)/(2−0)=2。单轴单位改变会改变数值比率；解释物理含义前应声明单位。
