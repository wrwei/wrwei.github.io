Git and GitHub, step by step

A beginner’s tutorial in eleven short lessons. Learn to keep the history of your work with Git, share it on GitHub, and publish your own web page. On Windows, macOS or Linux; no experience needed.

Who this is for

Anyone who has never used Git: students, researchers, writers, designers, and programmers who have so far got by without it. You do not need to be able to program, and you do not need to have used a terminal before. If you can type and follow instructions, you can do this.

What you will be able to do

  • Keep the full history of a project, and go back to any version of it.
  • Try out ideas on branches, and merge them in, or throw them away.
  • Resolve a merge conflict calmly.
  • Keep your work on GitHub, and work on it from more than one computer.
  • Propose, review and merge changes with pull requests, alone or with others.
  • Fix the usual mistakes, and know which “undo” to use.
  • Publish a web page of your own with GitHub Pages.

All along you build one small project, a personal web page, and at the end it is online at your own address.

The lessons

Do them in order: each lesson starts where the last one ended. Each takes 15 to 45 minutes.

How to use these lessons

Start with Lesson 1: it explains how the lessons work. You need no experience. Lesson 2 shows you how to install everything, and how to open a terminal, the window where you type commands.

When you are stuck

  • The troubleshooting page lists the messages beginners meet most, with what each means and how to fix it.
  • The cheat sheet has every command from the series on one page, and a glossary.
